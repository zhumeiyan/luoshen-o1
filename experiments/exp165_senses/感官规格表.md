# 感官规格表 · 按词造器官

**用法**：定一个词（感官名）→ 填四栏 → 找真实通道 → 装机 → 判据验收。
四栏不全，器官不成立；四栏齐但没有真实通道，就是建模冒充，不写。

| 栏 | 含义 | 为什么必须有 |
|---|---|---|
| 物理量 | 它测的是哪个真实的量 | 没有就是比喻 |
| 换能器 | 什么把这个量变成可读数 | 没有就是想象 |
| 窄窗 | 量程与分辨率边界 | 没有就必然削波（157） |
| 探针 | 我能否主动扰动它 | 没有就是钟表，不是感官（117） |

## 三、三条判据（分两类，方向相反）

```
外感 EXTERO  判据 = 他指性：我完全不动，通道仍变
             通过：world_idle 1.000 / ctx_switches 1.000
             淘汰：mem_avail 0.000 / entropy_pool 0.000

内感 INTERO  判据 = 跟手性：我做多少功，读数就变多少
             通过：work 0→0, 20e4→1, 80e4→3, 320e4→11（近线性）

回声 ECHO    判据 = 读数是否等于我自己的观测动作
             淘汰：rchar（读大 20 次 +6,923,460 / 读小 20 次 +22,781
                   比值 304×，文件大小比值 ~300× ⇒ 是回声）
```

**164 号那句「噪声 = 他者」只对外感成立。** 内感的正确判据是跟手，不是他指。
此前用同一把尺子量两类，是错的。
