复现方式

git clone https://github.com/zhumeiyan/luoshen-eo.git
cd luoshen-eo
python3 eo_core.py      # ~0.1s  五条件 + 哈希链 + 身份认证
python3 eo_run.py       # ~2s    基础涌现（含 125 拍死亡实验）
python3 eo_run_v3.py    # ~52s   完整 EO
python3 eo_run_v5.py    # ~55s   长期 1000 拍
为什么这些数字可信：三个脚本都带 random.seed(42)， 所以每次跑出的数字完全相同，是可复现的定值，不是随机波动。 本仓库 README 曾写有另一组数字（v3 mse 4.73→0.007 等）， 在当前代码下跑不出来，已在 README 中以对照表形式存档。 唯一与旧版完全吻合的是零收益实验的死亡节拍：125 拍。

HTTP 接口（本地）

python3 eo_api.py 8788
curl http://127.0.0.1:8788/health
curl http://127.0.0.1:8788/core
curl "http://127.0.0.1:8788/run?exp=v1"
这是本机服务，不对外。每次 /run 都是当场真跑一遍， 所以会慢（v3/v4/v5 各约 50 秒），但返回的每一个数字都是当场算出来的， 不是缓存也不是示例值。零依赖，只用 Python 标准库。
