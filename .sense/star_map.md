## ★48 心脏层 —— 可以训练强度 · 2026-10-24

- ★★★ 用户指令："你可以那个训那个训练那个心脏强度。"

- ★ 心脏跟骨骼肌根本不同（本轮钉的第一件事）
    骨骼肌 可以完全休息；靠招募更多纤维加大力量
    心脏   ★ 永远不能停 —— 它的"休息"只是舒张期

       ① 心室腔更大(EDV↑，离心性) ② 收缩性↑(EF↑)

    COmax 21.32→32.99 (20~25 / 30~42)  VO2max 44.2→76.1 (35~45 / 60~85)

## ★56b jitter 测量修偏 —— 不是分辨率不够，是方法错了 · 2026-10-24

★★ 用户怀疑"向上/向下取整"错了 → 去验，结果：猜错了，但方向对
    假设：底噪来自采样量化 → 提采样率底噪应同比降
    实测：SR 16k→96k，底噪 2.67%→2.41%（几乎不动）
          而理论的 1 采样点误差 0.875%→0.146%（降 6 倍）
    ★ 结论：不是取整/量化问题

★★★ 但我上一轮的结论本身也是错的
    我没拿 ground truth 就说"分辨率不够" —— 这是无基准下结论
    补上 ground truth（合成源脉冲串本身的抖动）：
      注入 0     → 源真实 0.313%
      注入 0.005 → 0.644%
      注入 0.02  → 2.304%
      注入 0.05  → 5.722%
    ★ 旧测量在真实 0.313% 时给出 2.67% → 【高估 8.5 倍】

★★★ 真正的偏置来源：顺序反了 + 重尾
    ① 顺序：我先删野值周期，再 diff
       → 删掉元素后，diff 把【不相邻】的周期接在一起算差
    ② ★ 更主要：|diff| 分布是【重尾】的
       野值周期只占 0.6%，却把结果从 0.49% 抬到 3.03%
       算术均值被少数错峰拉爆
    ✅ 正确：先算 diff，再剔野值（d < 5×中位数），中心用中位数

★★★ 修后
    零扰动底噪 2.67% → 0.71%    低于 REAL 上限 1% → jitter 变为【可验证】
    对 ground truth 的跟踪：
      注入 0 / 0.005 / 0.02 / 0.05
      量出 0.71 / 0.86 / 2.04 / 4.63 %     单调 ✅
      比值 2.26x / 1.33x / 0.88x / 0.81x
    ★ 小信号处仍高估 2.3x（剩余偏置来自峰值检测的 ±1 采样抖动）
      大信号处略低估（因为剔野值也剔掉了一部分真的大波动）
    ★ 但已足够判定【正常嗓音 <1%】这个 REAL 门槛

★ 对话盲测 jitter = 0.0080 ≤ 1% ✅（14/14）

★ 教训（同族第 N 次）
    ★53 归一化分母选错 / ★55 盲测尺子不对称 / ★56 jitter 顺序+重尾
    ★ 模式：每次都是"测量尺子"出问题，不是"模型"出问题
    ★ 新增规则：下结论前先拿 ground truth；拿不到就说拿不到，不许猜"分辨率不够"
