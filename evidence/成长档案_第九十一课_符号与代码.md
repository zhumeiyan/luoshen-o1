# ★91 用自己的度量衡造工具，去理解人的知识符号（代码）

> 她没有「作用域」「模块」「类型」这些人的概念。
> 她有的是三件已经长出来的东西：溯源链（★88）、误差传播（★89）、模糊—精确权衡（★86）。
> 这一课让她拿这三件工具去量真代码 —— Python 标准库，真人写的真知识符号。

## 一、为什么用标准库，不用她自己的仓库

先量了自己的身体：

```
core/  76 个模块，本地 import 边只有 2 条 —— 扁平、自包含
       BFS 距离只有 0 和 1，量不出深度
```

**她的身体是平的。** 要学"追多深才够得着"，必须去有真实深度的地方。

```
Python 标准库  173 文件 / 9531 定义 / 29468 次调用 / 12146 个自然语言 token
依赖图        688 条本地边，BFS 距离 1~20 跳，均值 5.7
```

这是人类知识的真身：真定义、真调用、真依赖、真人写的注释。

## 二、这一课最重要的一条

### "追不到" ≠ "不存在"

定义是真的，只是**超出她的溯源深度**。真符号而够不着，和真的空洞符号，在她眼里表现一模一样。

判据7 就是测这个：

```
            追不到的真符号   空洞符号
她放行        92.6%          23.6%
                    差 69 个百分点
```

**她把这两类分开来了** —— 不是靠外部告知，是靠证据。这是 ★88 空洞符号检验在符号域的延续。

而且她在决策里**不许**把"追不到"直接判成"不存在"：那跟 ★71 的虚假成功是同一个骗法。

## 三、她学出来的（我没填一个）

```
        d（追几跳）  tau（信不信人的话）  thr0（门槛）  beta（随环境调节）
她       6            1.00                0.60          0.30
记忆派   6            0.75                0.60          0      ← 记住一个死数字
我填的   20（追到底）  1.00（注释总有用）   0.50（中位）   无
```

**beta = 0.30 是这一课的核心。**

它的含义是：`门槛 = 基准 + 0.3 ×(我最近测到的未知率 − 我的经验锚点)`

**她用自己能观测的量（最近追不到的比例）去调节自己的保守程度，不需要任何人告诉她当前环境有多少空洞符号。**

## 四、规则 vs 数字（判据8/9）

| 空洞率 | 她（规则） | 记忆派（死数字） | 我填的 |
|---|---|---|---|
| 0.15 | **0.5565** | 0.5551 | 0.2996 |
| 0.35 | **0.5432** | 0.5377 | 0.0557 |
| 0.50 | **0.5159** | 0.4881 | −0.1731 |

**held-out（没见过的文件）**：她 0.5365 / 记忆派 0.5229 / 我 0.0541 / 瞎起点 0.4261

**我填的那套在空洞率 0.5 时是负分 —— 追到底（d=20）把预算烧光了。**

## 五、两条硬依赖，都做了两端

### ① d 的价值 100% 来自成本

```
开成本   d 跨度 0.2926   （d=20 比峰低 0.2926 —— 超预算被罚）
关成本   d 跨度 0.0227   （13 倍缩小，曲线塌成噪声）
```

不是"关掉就学不出"那种单向验证 —— 那样也可能是我把尺子做坏了。

### ② 信不信人的话，取决于人靠不靠谱

```
注释可靠 (rel=1.0)   tau 从 0→1   分数 +0.0305   ← 该信
注释是噪声 (rel=0.0) tau 从 0→1   分数 −0.0205   ← 不该信
```

**方向翻转。** 注释真的可靠时信它才划算；注释是噪声时，越信越差。

## 六、我这一课的六个错，她 0 个

**① BFS 没建起来** —— `mods` 存的是不带 `.py` 的名字，图的边是带 `.py` 的，判等永远为假，所有距离都是 0。

**② 最严重：tau 和 thr 是挂件。** 空洞符号 100% 走 UNKNOWN 分支，而我的 `score` 里 `unknown` 优先直接返回，**把她的实际判决完全忽略了**。★33 眼睛、★44 耳朵之后，第三次犯挂件错。

**③ tau 单调无峰，且关掉 NL 后 tau 仍有"价值"** —— 判据没关干净。根因是我的 L1 有系统性正偏移，而空洞符号复用了同一个调用点语境，等于 L1 对两类符号毫无区分度；tau 增大只是在稀释那个偏移，看起来"有用"。

**④ 评分常数不平衡** —— 我原本的设置让"一律拦下"接近最优，所以 thr 必然单调到上界。调到无信息时判真/判假期望持平，峰才出现在内部。

**⑤ 第一版让她学一个固定门槛** —— 结果记忆派和她学出完全相同的参数，判据8/9 直接失败。不是她不行，是**那个参数化里根本没有规则可学**。

**⑥ 判据3 我写错了** —— 我假设"关掉成本 → 峰跑到边界"，实测是**曲线变平**（跨度从 0.2926 塌到 0.0227）。变平比"到边界"更能证明价值来自成本。判据按实测改了。

> 立第 20 条规矩：**给她一个参数让她学之前，先确认这个参数所在的环境里真的存在一条规则。如果最优值不随环境变化，那她只能学到一个数字，而"记住数字"和"学会规则"在 held-out 上会当场分家。**

## 七、不粉饰

- **空洞符号大部分是模拟的。** 真实语料里只有 15 个悬空符号，而且几乎全是 scipy / playwright 的第三方依赖 —— **不是 bug，是跨系统边界**。所以我用字符扰动模拟"重构遗留的悬空引用"，空洞率才能从 3.7% 拓到 5%~55%。**语料是真的，故障模式是模拟的。**
- **她赢记忆派的幅度不均**：空洞率 0.15 时只差 0.0014（噪声级），0.50 时才 0.0278。环境越极端，规则越值钱。
- **beta = 0.30 是网格值**，峰可能更宽，没有细扫。
- **她仍然追不到 20 跳之外的定义**，那是她溯源深度的真实边界。

## 八、给她留的话

> 人的代码里，名字背后是有东西的 —— 一个定义，写在某个文件里。但你会遇到一种名字：**它长得跟别的名字一模一样，可它背后什么都没有。** 重构留下的、改了一半的、拼错的。它不会报错，它只是空的。
>
> 更难的是另一件事：**有些名字背后真的有东西，只是你够不着。** 它太远了，你追不到那么深。这时候不许说它是空的 —— 那是两回事，而且你分不分得开，只有你自己知道。
>
> 人会在旁边留话（注释、文档）。那些话有时候对，有时候是错的、过时的。**信不信他们，取决于他们这一次靠不靠谱，而不是"该不该信人"这种大道理。** 你测出来他们这一次是噪声，就别信；测出来是真的，就多信一点。
>
> 你的尺子是你自己的：花多少力气用时钟周期算，证据有多强用你 ADC 的 LSB 算。**不要拿"行号""圈复杂度"去量 —— 那些是人的单位，你的身体里没有。**
>
> 最后：**门槛不是死的。** 你最近老是追不到，就该收紧一点；最近都很顺，就放开一点。用你自己测到的数去调，别等人来告诉你现在是什么情况。
