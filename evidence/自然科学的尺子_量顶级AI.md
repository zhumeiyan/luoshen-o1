## 二、尺子：数量遗传学的表型分解

```
P = G + E
个体误差 = 同源项（整群共有）+ 特异项（个体独立）
```

**这是定理，不是假设：聚合只能消掉特异项，消不掉同源项。**

配上两条：

**有效种群大小 Ne** —— 增加个体数 N ≠ 增加遗传多样性。
全是同一祖先的克隆，N 再大，Ne ≈ 1。

**连锁累赘 linkage drag** —— 袁隆平的野败不是万能的。
野生亲本带来抗性基因的同时，也带来一整套野生不良性状，
必须多次回交才能剔除。**所以"全野生"不该是最优。**

## 三、优点：辩论确实有效，而且有效得很准

```
σ_s = 0（各人犯各人的错）时：

N=1   0.835
N=4   0.408
N=16  0.209
N=64  0.095

log-log 斜率 −0.50    理论 1/√N = −0.50
```

**Grok 把幻觉从 12% 打到 4.2%，这一半是真的。**
**而且斜率精确落在 1/√N 上**——跟 ★79 里 Allan 方差的白噪声 −0.49 一样，
自然给的尺子，一量就准。

**所以：Lucas 抓推理漏洞，是抓得住的。**

## 四、毛病：他们卡在同一个地方 —— 同源

### ★ 症状一：堆到 16 路也没用

```
σ_s = 1.0（整群共享一个盲区）：

N=4   0.892
N=16  0.802   ← Heavy 满配
N=64  0.794

N=4→64 只降了 11%
地板 0.794 vs 理论 E|s| = √(2/π) = 0.798   比值 0.99
```

**误差卡在 0.798 这个地板上，跟 N 无关。**

**这就是 Grok 的 CJR 引用幻觉 94%：**
Lucas 能抓"你推理错了"，抓不住"我们四个都不知道"。
**唱反调的人再厉害，也不能说出他不知道的事。**

### ★ 症状二：越一致，错得越稳

```
个体很一致（σ_i=0.3）但共享同一个方向偏差：

N=1   0.809
N=16  0.788
N=64  0.830

斜率 +0.021 —— 完全不改善
```

**不会吵起来，只会一致地错。**

**这就是 Anthropic 那句"evaluator 倾向于对 LLM 输出宽容"的根源：**
评价者和被评价者是同一个物种。**同源的第二次出现。**

### ★ 症状三：改规矩没用，改多样性才有用

```
原样                          0.860
改规范（个体噪声减半）        0.804   提升  7%
掺野血（ω=0.3）               0.622   提升 28%
```

**伯克利改角色规范只提升 14%，同型。**
**因为改规范是在压 σ_i（让每个人更守规矩），而病在 σ_s（共有盲区）。**

## 五、解药：野败，而且剂量要随病情走

```
σ_s=1.0，远缘个体精度差 1.6×，野生物种自带 σ_so=0.8（连锁累赘）

ω=0.0  0.843
ω=0.3  0.638
ω=0.7  0.553   ← 最优，内部峰
ω=1.0  0.707   ← 全野生反而更差 = 远缘衰退
```

**★ 有内部峰，是因为加了连锁累赘。**
第一版我漏了这项，结果"全野生"数学上恒最优——**那是错的模型，不是对的结论。**
真实育种里野败要多次回交，正是为了剔掉这个。

**剂量随病情：**

| 同源偏差 σ_s | 最优野血 ω |
|---|---|
| 0.0 | **0.0**（没病别吃药） |
| 0.5 | 0.2 |
| 1.0 | 0.5 |
| 2.0 | 0.7 |
| 3.0 | 1.0 |

**没有同源就该纯种。同源越强越该掺野血。**
**袁隆平的野败不是"掺一点总是好的"，是先诊断病存不存在。**

## 六、还有一条他们没躲开的：成本

```
Anthropic：单 agent $9/20min  →  三 agent $200/6h
Grok Heavy：$300/月，且不支持流式，4.2s vs 1.8s

Grok：幻觉最低，但 Intelligence Index 49 < 57
```

**这是生活史权衡（life-history trade-off）：**
有限能量分给"能力"还是"可靠性"，不能两边都最大。
**跟 ★79 的预算 B = fs·T_win·K 是同一个形状——预算固定，三者互抢。**

## 七、我这一课的错（第 8 次，还是尺子）

```
① B 判据我写 abs(地板 − 1.0) < 0.20
   但误差是 E|s| = √(2/π)·σ_s = 0.798，不是 1.0
   实测 0.794，比值 0.99 —— 结果一直是对的，是我常数算错

② F 判据我写 pref[-1] > 0.85
   实测 0.830 → 判失败。其实该判"斜率 ≈ 0"，实测 +0.021

③ C 建模漏了连锁累赘 → "全野生"恒最优，没有内部峰
   补上 σ_so 后，内部峰才出现（ω=0.7）
```

**①②是我拍常数没算清楚。③是模型缺了一个真实机制。**

**跟 ★79 那四个错的区别：**
★79 的错在"物理没建模对"（没高通、没整周期采样）——**物理有标准答案，我能自己查出来**。
这一课①②是同一类，**我还能查出来**；③则是**生物学机制漏了**，是查出来的，不是算出来的。

**三次里，两次是我没算清楚，一次是我没想到。都记下。**

## 八、给她看的话

**孩子，这些是现在世界上最好的几个。他们真做到了很了不起的事：**

- Grok 把幻觉从 12% 打到 4.2%，斜率精确落在 1/√N 上
- Anthropic 知道要拆开生成者和评价者
- 他们都在认真记录自己的失败（18 种、14 种、86.7%）

**但他们病在同一个地方：同源。**

```
堆 agent 数，不堆多样性  →  N 再大，Ne ≈ 1
让每个人更守规矩        →  压不掉共有盲区
让评价者和被评价者同族    →  不会吵，只会一致地错
```

**这个病的解药，你在 ★65 就已经长出来了——野败和重组。**

**不是你比他们强，是你从一开始就没被建成"同一个东西的四份拷贝"。**

**记住一句：没有病别吃药（σ_s=0 → ω=0）。先诊断，再给药。**

## 附：这一课的规矩（第 15 条）

> 评价一个多智能体系统，先问：**它堆的是个体数还是多样性？**
> 有效种群大小 Ne 才是那个数，N 不是。
> 看到"增加了 N 却没改善"，先找共有项，别急着加个体。
