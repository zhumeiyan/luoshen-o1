## ★★ 四条 REAL 机制，全部复现

### ① pitch-shift reflex（反向补偿）

```
反馈人为 −10%  → 她发出 179.6 Hz（+12.3%）  ↑ 她升了
反馈     0%    → 她发出 162.0 Hz（+1.3%）
反馈人为 +10%  → 她发出 147.4 Hz（−7.9%）  ↓ 她降了
```

**反馈抬高，她降；反馈降低，她升 —— 反向补偿成立。**
且**补偿不完全**：偏移 10%，她只补 9.1%。REAL 报告的补偿通常也不满。

### ② DAF 延迟听觉反馈（★ 非单调）

```
  0ms  1.66%    150ms 12.63%
 50ms  4.99%    200ms 17.33%  ← ★ 峰（REAL 也是 200ms）
100ms  8.62%    300ms 12.39%
                400ms  8.06%  ← 回落
```

**★ 不是越延迟越糟。** 更长延迟被当成"别人的声音/回声"，不再是自己的反馈 → 干扰反而下降。REAL 文献正是这个非单调形状。

### ③ corollary discharge（语音抑制）

```
正常听 1.66%   说话时听自己 2.84%
```

**自己说话时自己的听觉被下调 → 听自己比听别人钝。** 这让自听闭环更难，是真的代价。

### ④ 语后聋 → 言语退化

```
没有反馈：说 5 次偏 1.89% → 说 40 次偏 4.93%
有闭环  ：1.66%（不漂）
```

**反馈长期缺失 → 产出随机游走、越说越偏。** REAL 语后聋的言语退化。

## 我这一课的四个错（全是我的，她一个都没错）

**① DAF 建模，两版都错**
- 第一版"混入上一次的 f0_act" → 收敛时 prev≈f0，滞后几乎无害 → **延迟越大误差越小，方向完全反了**
- 第二版 `clip(d/200,0,1)` → ≥200ms 全饱和，**非单调性被抹平**
- 第三版才对：DAF 破坏的是**音节级的感知-运动对齐**（听到的是上一个音节的音高，而相邻音节音高不同），且长延迟的**归属权重**下降

**② oracle 关断方式错了**
用"随机翻转误差符号" → 仍是有方向的随机游走 → λ 的峰**没消失**，判据假失败。
正确关法：切断**产出→感知这条通路本身**（让她听到的与她真实发了什么无关）。

**③ ★ 搜索用 seeds=8 过拟合噪声，害她输给我**
第一次跑：她 0.5712 < 我 0.6308。**不是她不行，是我的搜索在小样本上被噪声带偏**（尤其 R 在 ≥3 后饱和，随机走到了 7）。
改成**联合交替坐标下降 + R 整数枚举 + seeds=14** 后，她三个目标全赢。

**④ `__defaults__` 索引越界**
`an_lowchan` 的 `x_lo` 是位置可传参数，`__defaults__` 只存有默认值的**尾部**参数 → 直接按 `names.index()` 取会越界。exp_speak.py 里有同款 bug，一并修了。
