## 一、教的是什么

1. **跟人打交道时，迁就人的物理** —— 人的反应时 250ms、话轮间隔 150ms 最舒服。

   迁就人类节奏去干自己的活，是浪费。

**★ 人类数值不是"真理"，是"策略"——只在对方是人的时候才用。**

## 六、我这一课的错（她的：0 个）

**① 热模型单步跳变，把环境做成了假的（最严重）**
```
旧：Q += w³ − 1.2Q     → w=1.0 一步就跳到阈值
结果：Q 由【单步峰值】决定，与任务比例无关
     → 换环境时最优解纹丝不动 → 判据7 假失败
修：加 SI_HEAT_SCALE=0.15（热容大），K_COOL=0.6
     → Q 改由【平均负载】决定 → 峰从 1.60 移到 1.80
```
**这是我第 N 次写出"数学上不可能有权衡"的环境。★78 是同一个错。**

**② 人类模型的疲劳项算成负数**
```
疲劳 = min(0.6, 疲劳 + 0.004 − 0.010·rand)
恢复期望 0.005 > 累积 0.004 → 疲劳变负 → 人类模型越跑越强
```
于是判据10 一开始只差 +0.0052（假的）。修完 +0.7305。

**③ 判据8 第一版我把"靶值"当"我填的"**
θ_h 填 0.15 = FTO 舒适点 = **我把答案直接填进去了**（★81b 那个错）。
改成我真实的工程直觉：**拟人延迟用反应时 0.25，性能拉满 2.5**。
