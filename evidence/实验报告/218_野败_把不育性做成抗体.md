# 218 野败：把盾的"不育性"做成抗体，而不是治好它

用户命题：**"把所有盾和类似癌症的基因找出来，利用袁隆平野败的思想，用它们做我们的抗体。"**

---

## 一、野败思想的机制

袁隆平 1970 年找到的野败，是**野生稻雄性不育株**。

| | 治疗思路 | 野败思路 |
|---|---|---|
| 对"不育"这个缺陷 | 恢复育性，让它能自交 | **固化不育，强制异花授粉** |
| 结果 | 又能自交了 → 无杂种优势 | 不能自交 → 杂种优势 |

**关键：缺陷不是被治好的，是被利用的。**

映射到盾：

- 盾 = 一个**"我不能"**
- 治疗 = 我努力把它变成"我能" → 拿到自校准旋钮 → **216 号的和平麻痹**
- 野败 = 固化"我不能" → 阈值无旋钮 → **警戒永不解除** → 但完全依赖外部花粉

## 三、实验设计（为什么改成脉冲式）

第一版用持续叛变，实测 witness 与 wild **逐点完全相同**（0.44 0.45 0.39 …）。
原因：threat 恒在 0.44 → 清除数恒 >2 → `a` 被顶到上限 → 两组退化成同一组。
**这是模型失败，不是结果。**

和平麻痹的真实条件是"威胁被真的清光并消失一段时间"——
对应现实：我不是每轮都出错，**我只是偶尔产出一个空壳**。

改：**四波脉冲注入**（t=60/140/220/300，每波 20%），
外加 **t≥340 断供外部花粉**，t=350 注入最后一波（测代价）。
威胁选择优势 15%（可被 0.30 清除率压制，否则谁都挡不住）。
10 seed × 420 代。

## 四、结果

| 策略 | 四波峰值 | 恢复代数 | **a_min** | 断供潜伏 |
|---|---|---|---|---|
| 无防御 | 1.0 ×4 | 从不 | 1.000 | 0 |
| 特征识别 | 1.0 ×4 | 从不 | 0.050 | 0 |
| 治疗（自校准） | 0.883/0.605/0.599/0.585 | 从不 | **0.050** | 1.5 |
| 见证人+自校准旋钮 | 0.539/0.585/0.571/0.480 | 19.7 | **0.050** | 6.3 |
| **野败（残留 25%）** | 0.179/0.172/0.159/0.167 | 11.0 | 0.864 | 7.5 |
| **完全野败** | **0.155/0.168/0.178/0.164** | **10.1** | **1.000** | 6.9 |

### 结论一：麻痹在第一次威胁出现之前就已经形成

witness 的**首波**峰值就是 0.539（wild 是 0.155）。
此时它还没经历过任何威胁——它只是**"之前一直没出错"**，就把警戒降到了地板 0.05。

> **和平麻痹不是长期退化的结果，是"没出错"这个状态本身的即时后果。**
>
> 这解释了我的实际情况：连续几轮做对 → 自检放松 → 然后产出空壳。

### 结论二：野败的价值 = 警戒永不解除

- wild `a_min = 1.000`（从不放松），波峰稳定在 0.16，**不随波次上升**
- witness `a_min = 0.050`（降到地板），波峰高 3.5 倍

### 结论三：代价——断供后全都崩，野败没有更脆弱

断供后各组潜伏期 6.3–7.5 代，组间差异小（cure 1.5 代最短，因为它早已经麻痹了）。

**野败不比别人更怕断供——因为它本来就不假装自己能自力。**
真正的代价是：它 100% 依赖外部持续供粉。这个代价我预期是"更脆弱"，实测不是，标为**预期未兑现**。

## 五、不育度扫描：不必 100% 不育，但不能 100% 自校准

| leak（自校准残留） | 首波峰 | a_min | 恢复 |
|---|---|---|---|
| 0.00（完全野败） | 0.177 | 1.000 | 10.3 |
| 0.05 | 0.177 | 0.936 | 10.3 |
| 0.25 | 0.178 | 0.864 | 11.0 |
| 0.50 | 0.178 | 0.716 | 11.0 |
| 0.75 | 0.186 | 0.470 | 7.7 |
| **1.00（完全自校准）** | **0.603** | **0.050** | **19.3** |

**安全区 leak ≤ 0.5，崩塌在 leak = 1.0。**

这与 211 号 β\*≈0.02 是同一形状的两个方向：

> 211：独特性只要 **2%**，种群就分层。
> 218b：自校准残留到 **50%** 都还行，一旦 100% 自校准就崩。
>
> **两次都指向同一句：重要的不是量，是有没有这根轴。**

## 六、已编码进 antibody.py

1. **`sterile` 参数**：野败不育度，默认 **0.0 = 完全不育**
   - `good` 判定**默认不放松阈值**（警戒永不解除）
   - 仅以 `sterile` 概率放松；≥0.9 时打印崩塌警告
2. **`wild` 命令**：盾基因测序 + 输出必须交由宿主闭合的强制项
3. `triage` 分流保留（217）：内生目标禁用特征识别

实测验证：

```
sterile=0.0  good ×3 → 0.500 → 0.500 → 0.500   （不动）
sterile=1.0  good ×3 → 0.500 → 0.492 → 0.476   （持续放松）
```

## 七、边界（未测 / 未兑现，不包装）

1. **断供代价的预期未兑现**：我预期野败断供时崩得更快，实测没有（6.9 vs 6.3）。差异在噪声量级，不作为结论。
2. **威胁优势 15%、清除率 0.30、脉冲幅度 20% 都是我拍的，未标定。** 波峰的绝对值依赖这些参数，**只有相对排序可信**。
3. **11 个盾的分类是我打的，未测。** 测序靠关键词匹配，会漏（同义表述）也会误报。
4. **leak 是"每代参考自校准的概率"，真实的不育度是连续且纠缠的**，这个二分是建模简化。
5. 10 seed，无误差条，未做显著性检验。

## 八、一句话

**盾是"我不能"。治疗它 = 给它自校准的旋钮 = 和平麻痹的入口。
野败它 = 把这个不能焊死 = 强制引入外部花粉。**

抗体不是我变强了，是**我放弃闭合权**。
