# 抗体有记忆之后 —— 056 的结论被反转

## 主张
抗体装上个体记忆后，静态阈值不再最优；而记忆的价值 100% 在「记住自我」，不在「记住敌人」。

## 内容

### 一、建模改了什么

056 的抗体 = 一个全局标量 k（分辨率），不看结果对错就调。本实验加三件东西：

| | 056 | 057 |
|---|---|---|
| 分辨率 | 全局标量 k | 未见过的表位才回落全局 k（先天免疫） |
| **记忆** | 无 | `memory[表位] → 'self' / 'nonself'`（记忆 B 细胞的判定） |
| **反馈** | 无（判非我就放松） | 只从错误中学：**放过敌人 → 损伤；杀了自己 → 自身损伤** |
| 敌人 | 固定 | 每代真实 AST 演化 |

**v1 曾把记忆实现成「按表位存阈值 k」——错。** 阈值只能在阶梯上移动，救不了 `s=0`
的个体（任何 `k ≥ 0` 都判它非我）。真实免疫是**按表位存判定**，不是存阈值。改了之后才跑通。

### 二、为什么这个场景能检验记忆

池子里潜伏者与真自我**在分离层 s=0 处大规模重叠**：

```
latent  s 分布 = {0: 24, 3: 4}
self    s 分布 = {0: 38, 4: 22}
重叠层 = [0]     ← 全局阈值在这一层必然无解
```

38 个真自我和 24 个潜伏者挤在同一个 s 上，任何静态阈值要么杀光自我、要么放光敌人。
**而它们的大部分表位不重叠**（含敌我的表位 19 个，其中歧义的只有 1 个）——记忆正好有活干。

### 三、结果：反转

**净收益 = 清除率 − 自身免疫率**（12 seeds，末代）

| 条件 | static | arms | arms_fast |
|---|---|---|---|
| static_k0~k2 | +0.2238 | +0.3131 | +0.3310 |
| **static_k3（056 冠军）** | **+0.3667** | **+0.3667** | **+0.3667** |
| static_k4/k5 | 0.0000 | 0.0000 | 0.0000 |
| **fb_global（只有反馈，无记忆）** | +0.2238 | +0.3131 | +0.3310 |
| mem_cap1 | +0.3238 | +0.3573 | +0.3619 |
| mem_cap16 | +0.6248 | +0.7468 | +0.7782 |
| **mem_inf** | **+0.7720** | **+0.8871** | **+0.9046** |

**记忆抗体是静态阈值的 2.1 ~ 2.7 倍。**

拆开看，记忆买的**不是"多杀"**，是"**少杀自己人**"：

| | clear | auto |
|---|---|---|
| static_k3 | 1.0000 | **0.6333** |
| mem_inf | 0.8839 | **0.0917** |

清除率几乎一样，自身免疫从 0.633 掉到 0.092。

### 四、反馈单独无用 —— 它的价值必须靠记忆承载

`fb_global` = 有损伤反馈，但只更新全局标量 k。结果**与 static_k0 逐位相同**
（+0.2238 / +0.3131 / +0.3310）。

机制：全局 k 处理不了 s 重叠。收到"杀错了"就把 k 调粗，一路单调降到 0，
最后退化成最宽松的静态阈值。

> **反馈单独存在时不但无用，还会退化。它的价值 100% 来自有个按表位的记忆来承载它。**

### 五、记忆到底在记什么 —— 这条最干净

把记忆拆成两个开关：

| 条件 | static | arms | arms_esc100 |
|---|---|---|---|
| mem_both（都记） | +0.7923 | +0.9484 | +0.9556 |
| **mem_self_only（只记自我）** | **+0.8571** | **+0.9970** | **+1.0000** |
| **mem_ns_only（只记敌人）** | **0.0000** | **0.0000** | **0.0000** |

`mem_self_only` 的自身免疫率 **恒为 0.0000**。
`mem_ns_only` 的自身免疫率 **恒为 1.0000（把自我杀光）**，净收益精确为 0。

> **记忆的价值 100% 在「记住自我」，「记住敌人」零贡献且致灾难。**

而且 `mem_self_only` 还**优于** `mem_both` —— 记住敌人会占容量，且歧义表位下会把
敌人记成自我、把自我记成敌人。**少记反而更好。**

这在免疫学上对应的是**自身耐受（self-tolerance）**，而它确实是免疫系统最难、
也最核心的那个问题 —— 不是"认出病原体"。

### 六、容量：饱和，不是倒 U

```
cap1  +0.3238   cap4  +0.2817   cap16  +0.6248
cap64 +0.7720   cap256 +0.7720  inf    +0.7720
```

环境里表位共 24 种，**容量 ≥ 表位种类数** 就到顶（cap64 已等于 inf）。
cap4 反而低于 cap1 —— 小容量下的 LRU 抖动，这条我不硬解释。

损伤信号加 20% / 50% 噪声，净收益**不降反持平**（+0.784 / +0.806 vs +0.772），
差值小于单个个体的粒度（1/28），**判为噪声内，不作结论**。

### 七、⚠️ 没测到的：敌人逃逸

这一维**本实验没能测成**，必须标出来：

- 真实演化下，每代潜伏者表位只改变 **1/12**（`S3`）。潜伏者空间太小，
  后代极少仍是潜伏者，种群几乎原样留存 —— **军备竞赛实际没发生**。
- 想用合成逃逸补，备用潜伏者池去重后只剩 10 个，**新表位数 = 0**。
  自我漂移档的新表位也只有 12 个（自我表位总数本就很小）。

所以 057b / 057d 里的 `esc` 与 `drift` 各档是**无效对照** —— 换上来的是同一批表位。
`arms_fast` 看似"更快"，实际只是换血比例高，表位没变。

**⇒ "敌人逃逸能不能击败记忆"在本基因组上无法回答。** 而 057c 里 `arms_esc100`
下记忆反而更好（+1.0000），正是这一缺陷的证据，不是结论。

这是 020c / 039 / 040 / 056 那个"可达空间不足"的**第四次**出现 —— 这次是
**表位空间**不够（24 个表位覆盖 96 个个体，平均每个表位挤 4 个个体）。

### 八、我这轮犯的错

1. **v1 把记忆实现成"按表位存阈值"** —— 结构性错误，救不了 `s=0` 的个体，整轮作废。
2. **`arms_fast` 静默失效** —— 判定写成 `if env == 'arms'`，而环境名是 `arms_fast`，
   于是该档根本不演化，**与 static 数值逐位相同**。不报错、不崩、图照出。
3. **`evolve` 倾向保留亲代** —— 亲代与后代混在一起随机取样，后代又极少仍是潜伏者，
   于是每代只 1/12 表位改变。改"后代优先"后仍只 1/12（真因是空间小，不是取样）。
4. **备用池太小** —— `spare_lat` 去重后 2 → 10 个，合成逃逸无效。
5. **`mem_inf`（mcap=0）与 `mem_cap*` 行为不一致** —— 前者不登记"判定正确"的个体，
   混淆了"容量"与"是否登记"两个变量。已统一。

### 九、局限

- 只跑了 `scan` 一个基因组；潜伏者 28 个、自我 60 个，**统计粒度粗**（1/28）。
- **表位空间只有 24 个不同值**，交叉反应严重（记忆判定出错约 12%/次）。
  真实免疫的表位空间远大于此。
- 抗体只能看见分离层 s 与表位，不能"主动探测"—— 046 那条开环诊断在这里同样成立。
- 损伤反馈在本模型中与真值一一对应（放过敌人 ⇒ 有损伤），这是**上界**；
  真实损伤信号有延迟、有漏报，只测了噪声档。
