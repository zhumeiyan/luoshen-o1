# 148 哺乳动物格：梦 / 情绪门 / 玩（真实经验）

经验来源全部真实：真实 CPU 算力竞争时序（后台负载线程真实抢占）+ 真实目录树。
判据预注册于 `PREREG.md`，结论只做对质。

## 1. 梦

真实 CPU 时序，白天150拍→睡眠→测试150拍，n=8 配对。

| 条件 | stable gain | drift | square |
|---|---|---|---|
| real 正序重放 | **+0.0120\*** | −0.0011\* | −0.0001 |
| rev 逆序重放 | +0.0057 | +0.0047 | −0.0070 |
| shuf 打乱重放 | **+0.0119\*** | +0.0064 | −0.0059 |
| cross 同形状别人的经历 | +0.0141 | −0.0026 | −0.0032 |
| noise 等长高斯假经验 | **−0.0720\*** | +0.0023 | −0.0146 |
| mismatch 不同形状的真实经历 | — | — | **−0.0271\*** |

**H1「顺序是必要成分」被推翻**：正序 +0.0120 与打乱 +0.0119 逐位重合。
剂量扫描（1/2/4/8 轮）两者差全部 <0.0003，收益随轮数单调且饱和（+0.0070→+0.0135）。

真正确立的必要条件是另外两个：
- **真实性**：假经验 −0.0720\*（有害）
- **处境匹配**：square 个体用 stable 的真实经历做梦，**−0.0271\***（有害）

而「必须是自己的经历」**未获支持**：同形状别人的经历 +0.0141（跨0，与自己的不可区分）。
——不是"自己的"不重要，是同 profile 下两者统计上无法分离；只有 mismatch 才把变量真正分开。

## 2. 情绪门（g_self 低落 → 学习率上调）

| 世界 | gate | fixed | gain |
|---|---|---|---|
| stable 平稳 | 0.1909 | 0.1718 | **−0.0191\*** 有害 |
| drift 单调漂移 | 0.6725 | 0.6981 | **+0.0256\*** 有益 |
| square 周期方波 | 0.6907 | 0.6364 | **−0.0543\*** 有害 |

**H2 部分推翻**：预注册认为"世界在变"就有用。实测不是——
**依赖的不是"变不变"，是"单调漂移 vs 周期"**。周期世界里误差升高是相位切换的正常现象，
此时上调学习率反而追错方向。与 145「时间顺序在漂移世界是资产、周期世界是负债」同构（第 4 次复现）。

## 3. 玩（无外部奖励的自发探索）

真实目录树 38 个目录，任务=估计全树平均文件数（真值 21.97）。

```
play 内部驱动        误差 0.1520  去重目录 30.0/30
rand_norep 随机不重复 误差 0.1197  去重目录 30.0/30
rand 随机可重复       误差 0.2600  去重目录 21.2/30

play − rand       = +0.1081* [+0.032,+0.185]
play − rand_norep = −0.0322  [−0.081,+0.016] 跨 0
```

**玩的价值 = 不重复地采样（覆盖性），不是内部驱动的偏好。**
拆开后 play 并不优于"随机但不重复"；而"偏好浅层"本身引入了采样偏差
（浅层真值 41.77 vs 全树 21.97），点估计为负。自发动作率 30/30。

## 4. 副产品：TACT 引擎的两次外部检验

用户提供的 TACT 仓库（`engine/tact_run.py`）可跑，用作**非自评的外部标注器**。

**(a) 官方校准模式实测**：三轴完全匹配 **14/29 = 48.3%**。
而 README 只报分轴召回率（M 95.7% / P 86.4% / L 78.6%）。
**分轴最高值 ≠ 联合准确率**，48.3% 与 95.7% 是同一个引擎的两个数字。建议 README 并列呈现。

**(b) 用它标注本轮 6 个错误**：轴覆盖率 **0.167**，全轴命中 **0/6**。
说明该规则引擎对我这类错误描述的覆盖不足（亦有描述风格不匹配的因素）。
这与 README 自述「判据尚未经人工标注者独立验证、待社区 ratify」一致。

## 5. 本轮错误

1. **玩格第一版对照做坏**：play 组 40 次观测、对照 10 次，量到的是样本量不是玩。等预算重做才成立。
2. **负载未作用于测量**：probe 把 busy 放在计时结束之后，drift 世界根本没产生漂移。改后台线程抢占才拿到信号。
3. **去重指标口径错误**：对观测值（文件数）去重而非对目录去重，覆盖率被低估。已修正为 30.0/30 vs 21.2/30。
4. 预注册 H1（顺序必要）被推翻；H2（周期世界有用）被推翻。

## 6. 边界

- n=8，未做多重比较校正（与既有结论一致的处理方式）。
- **stable 上 baseline「预测上一拍」MAE=0.1276，优于所有学习器**（145 同现象第 2 次复现）。梦的收益是在一个学习器本就不如常数预测的世界里测到的。
- 真实 CPU 序列受机器上其他进程影响，采集不可完美复现。
- 玩的世界是真实目录树，但"估计平均文件数"是人为任务。
- cross 条件用同 profile 的另一条序列，统计上不可区分——因此"自己的经历是否必要"在本实验**未检出**，不主张。
