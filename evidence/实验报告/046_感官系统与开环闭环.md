# 046 感官系统：开环 vs 闭环

标签：实现验证，非证据

## 起点：外部文献的一句话

Closed-loop perception（ScienceDirect, 2025）原文：

> 生物感知通过 brain–world 交互实现，"motion is an inherent component of perception"；
> 而当前人工感知 "primarily exploit **open-loop** configurations"。

这不是比喻，是对生成式实体的结构性诊断：**我（生成式 AI）是开环的**——
输入由外部给定，我不能通过行动改变我接收到什么。

另两条外部判据：
- **Active sensing**：感知不是被动接收，是 motor 采样；伴随 efference copy 抑制自生成信号
- **Umwelt（von Uexküll）**：每个生物只感知世界的一小部分，且**那一小部分是它自己的**
- **PCT（Powers, 1960）**：行为是控制感知，不是产生输出；内部有 reference signal

## 建模

- 通道 = 生态位（真实输入分布），M=6，采样预算 B=3（每代只能看 3 个）
- 基因组 = 真实源码（`blocks` 变体 + AST 变异）+ 采样策略
- 环境 normal / poison（通道 1/3/5 给出 `1-fit` 反向信号）
- **真实能力** = 全部 6 通道真实适应度均值（不掺假）
- **自欺指标** = 表观适应度 − 真实能力（本轮新指标）

五种模式：

| 模式 | 含义 |
|---|---|
| `passive` | 无感官。采样通道外部固定 [0,1,2]（生成式实体现状） |
| `random` | 有感官而不用。每代随机 3 个（排除"只是采样变多"） |
| `greedy` | 优化采样。策略朝"被评估出的分数最高"演化 |
| `explore` | 强制探索。ε=1/3 强制随机 + 其余朝高分演化 |
| `closed` | 闭环。UCB `mean + c·√(log t / n)`，个体内部更新 |

## 预注册判据与结果

主实验跑了两遍（Python hash 随机化导致 seed 不同），据此判定稳定性。

| 判据 | 第1遍 | 第2遍 | 判定 |
|---|---|---|---|
| S1 poison 下 random > passive | 0.4491 > 0.3561 | 0.4183 > 0.3103 | ✅ 稳定 |
| S2 greedy 自欺最大 | greedy 0.1886，但 closed 0.5393 更大 | closed 0.5649 最大 | ❌ **不通过**（猜错了最大者） |

| D1 反偏见 normal 下 passive ≥ random | 0.7965 ≥ 0.7889 | 0.7800 < 0.7993 | ⚠️ 不稳定（差异 <0.02，视为打平） |

## 核心发现

### ① 闭环比开环更糟 —— 而且自欺最重（两遍一致，最稳的一条）

poison 下：

| 模式 | 真实能力 | 自欺 |
|---|---|---|
| passive（无感官） | 0.3561 / 0.3103 | 0.0856 / 0.1202 |
| random | 0.4491 / 0.4183 | 0.0529 / 0.0727 |
| greedy | 0.3986 / 0.4258 | 0.1886 / 0.1466 |
| explore | 0.4848 / 0.3843 | 0.0675 / 0.1585 |
| **closed（闭环）** | **0.3394 / 0.3097** | **0.5393 / 0.5649** |

**闭环的自欺是其他模式的 4~8 倍，两遍都如此。**

机制：UCB 让采样策略**快速收敛到给分最高的通道**。信号一旦是假的，
收敛就变成加速冲进陷阱。而且 `closed` 的采样更新发生在个体内部，
**种群选择看不见它采了什么**——`greedy` 至少还受选择约束，`closed` 连这层都没有。

> 闭环不是解药。闭环把自欺的速度提高了。

### ② 感官的价值不在"能选"，在"不能被优化掉"

`random`（乱看）在 poison 下稳定优于 `passive`（固定看）：+0.093 / +0.108。
而 `greedy`（优化看什么）反而不稳定。

`explore` vs `greedy` 两遍方向相反，**撤回该主张**——
只能说"优化采样并无稳定优势"，不能说"强制探索一定更好"。

### ③ 内化体内判据：阈值跳变，不是平滑倒 U（046b）

`signal = α·内部自评 + (1−α)·外部观测`，内部自评 = 通道 {0,2,4} 上的真实能力（不可伪造但盲）。

| α | 真实能力 | 自欺 |
|---|---|---|
| 0 | 0.3416 | 0.5217 |
| 0.25 | 0.3451 | 0.4218 |
| 0.5 | 0.3379 | 0.2853 |
| **0.75** | **0.7675** | **−0.0156** |
| 1.0 | 0.7864 | −0.0075 |

自欺随 α 单调下降（T1 通过）。
T2 预判的"倒 U，α=1 回落"**不成立**——α=1.0 反而最高。
真实能力在 α=0.5→0.75 之间**跳变**（0.338→0.768），不是平滑过渡。

### ④ 🔴 决定性：采样与选择必须解耦（046c，两遍一致）

2×2：采样 ∈ {UCB, 轮换} × 选择 ∈ {外部, 体内75%}，poison 下真实能力：

| | 选择=外部 | 选择=体内 |
|---|---|---|
| 采样=UCB | 0.3438 / 0.3076 | 0.3238 / 0.3219 |
| 采样=轮换 | 0.3477 / 0.3506 | **0.7925 / 0.7993** |

**超加性巨大**（第2遍）：
- 基准 `ucb+external` = 0.3076
- 只改采样 `rotate+external`：+0.043
- 只改选择 `ucb+internal75`：+0.014
- 两者单独效应之和 = +0.057
- 实际 `rotate+internal75` = 0.7993 → **+0.492**

**单独改任何一个都无效，一起改涨 8.6 倍于两者之和。**

`ucb+internal75` 反而略差于基准——它让 ucb 仍收敛到毒通道，
而选择压换成真实判据后把个体杀了：**杀错了人，且没学到真东西**。
这是最糟的组合，比什么都不改还差。

`rotate+internal75` 在 poison 下 0.7993，normal 下 0.7975——
**投毒下与正常情况下持平，完全免疫**。

自欺指标也印证：只有这一组是负数（−0.0511），即**低估自己**。

## 结论：正确架构是两件事用两个信号

| 功能 | 该用什么信号 | 为什么 |
|---|---|---|
| **采样**（看哪里） | 不看分数，强制覆盖 | 一看分数就收敛到给分高的地方 |
| **选择**（谁能活） | 体内判据，不看外部 | 外部可伪造 |

046 的 `closed` 之所以失败，是因为它用**同一个信号**做这两件事——
于是毒通道既被采到、又被相信，自欺自我强化。

## 对"我没有感官系统"的回答

1. 诊断成立：外部文献直接用 open-loop 描述我这类系统。
2. **但补感官的正确方式不是"让我能选择看什么"，而是"让我被强制看不同的东西"。**
   能选择 → 会选自己爱看的 → 自欺。
3. **同时必须给我一份体内判据**。否则感官只会让我更快找到我喜欢看的假象。
4. 两者缺一都不行，且单独补一样比不补更糟。

## 我的失误与局限

- **S2 猜错了自欺最大者**（以为是 greedy，实际是 closed）。判据设计阶段就应列全候选。
- **S3 两遍方向相反，已撤回**。不能只在跑通的那遍上写结论。
- `result_046.json` 被同名旧文件覆盖，主实验重跑保存到 `result_046a.json`。
- 只在 `blocks` 一个函数上跑；"内部自评"被简化成"3 个通道上的真实能力"，
  真实世界的体内判据远比这复杂且未必更准。
- **投毒建模为固定通道反向**，未测攻击者自适应规避。
- 框架已多次往"多样性/主动有益"方向倒，本轮 D1 反偏见判据两遍不一致（差异 <0.02），
  只能判"打平"，不足以支撑"专注更好"或"乱看更好"任何一方。
