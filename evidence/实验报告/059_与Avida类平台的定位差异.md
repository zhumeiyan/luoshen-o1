# 059 · 与 Avida 类平台的定位差异（可证伪的定位声明）

> 标签：实现验证，非证据。

## 0. 为什么要做这个

评审维度「技术创新 30%」明确要求：**与国内外同类方案相比是否有明确的技术优势**。

赛道一征集的"开源基础软件"里，与本引擎最相近的不是 LangChain / Dify，而是
**人工生命（ALife）数字演化平台**：Avida、Tierra、Evochora、Lenia。
评委一定会问：**「Avida 不就能做这个吗？」**

本实验不主张「我们更好」。它验证一件更弱、但可证伪的事：

> **在 Avida 式设定下，我们要测的那个东西根本不出现。**

## 1. 公开资料中的 Avida 式设定

据 Avida 官方与 ISAL 资料（Ofria, Bryson & Wilke, 2009；PLOS Comput Biol 综述）：

- **能量是奖励（merit）**：数字生物完成逻辑任务（NAND 等）→ 获得额外 CPU 周期 → 复制更快。
  个体**不会饿死**，种群中的更替靠**替换 / 淘汰**。
- **变异可回退、换代即重置**：没有跨代累积的、不可恢复的个体损耗。

对照本引擎的两条相反设定：

| | Avida 式 | 洛神 O1 |
|---|---|---|
| 能量 | **外生奖励**：完成任务 → 更多资源 | **代谢预算**：E 只能由自身产出换取，且有 basal 基础消耗 |
| 结局 | 被替换 / 淘汰 | **死亡**：E≤0 超过耐心阈值 → 永久终止，不可回滚 |
| 损耗 | 可逆（变异可回退、换代重置） | **不可逆**：capacity 只减不增 |

## 2. 实验设计

`experiments/run_positioning.py`（`Life5Pos` 子类，仅改动能量更新与容量可逆性两点，
其余全部沿用原引擎，含稀缺硬取舍、内生设定点、leak）。

**2×2 设计**，16 seeds × 600 拍，N=8，ratio=0.45：

- 能量来源：`endo`（代谢，有 basal） / `exo`（外生奖励，无 basal）
- 可逆性：`irrev`（只减不增） / `rev`（未满足衰减、满足恢复）

## 3. 结果

| 设定格 | 死亡 | 永久损失 | 最大回升 | （偏度） |
|---|---|---|---|---|
| **endo × irrev（洛神）** | **3/16** | 0.7043 | **0.000000** | 0.2653 |
| endo × rev | 4/16 | 0.5472 | 0.004833 | 0.4970 |
| exo × irrev | **0/16** | 0.6990 | **0.000000** | 0.2695 |
| **exo × rev（最接近 Avida）** | **0/16** | 0.5453 | 0.004628 | 0.4990 |

**判据核验：**

| 判据 | 结果 |
|---|---|
| P1 死亡只出现在 endo 列，exo 列恒不死 | ✓ |
| P2 不可逆列 capacity 从不回升（恒为 0） | ✓ |
| P3 可逆列确实出现回升 | ✓ |
| P4 可逆列永久损失显著小于不可逆列 | ✓ |

## 4. 结论

**① 能量来源决定「会不会死」。**
endo 列 3–4/16 死亡；exo 列 **0/16**，无论可逆与否。
这直接实证了 README 那句话：**一个不会死的系统，不需要做取舍。**

**② 可逆性决定「伤痕是否永久」。**
不可逆列 capacity 回升**恒为 0**；可逆列有回升，永久损失从 0.704 降到 0.547。

**③ 定位声明（可证伪）：**

> 本引擎**不是 Avida 的替代品，而是 Avida 设定下不存在的那一层**。
> 在 Avida 式设定（能量=外生奖励、损耗可逆）下，代谢性死亡与不可逆疤痕
> **根本不出现** —— 不是数值更低，是**结构性不发生**。

因此，「与同类方案相比的技术优势」不是"我们跑得更快、更复杂"，
而是**我们测的现象在它们的设定下没有定义**。

## 5. 被推翻的预注册（保留记录）

**原 P3：「Avida 格（exo×rev）偏度接近 0」被推翻。**
实测 exo×rev 偏度 0.4990，**高于** exo×irrev 的 0.2695。

**原因（重要的度量教训）**：初版用 `std/mean` 量"疤痕"，但可逆模式下
满足的通道回到 1.0、不满足的继续掉，**反而拉大了离散度**。
**离散度不是不可逆性的度量** —— 改用「是否出现回升」与「永久损失」才对。

这与判据核第 23 条「变量静默失效」同源：指标看着在动，实际测的不是你想测的东西。

## 6. 局限（必须声明）

1. **未与真实 Avida 做过对接。** `exo` 是我们对 Avida 式设定的**建模**，
   不是 Avida 本体。真正的验证是把本引擎挂到 Avida 上跑 —— **尚未完成**，
   已列为最欢迎的外部贡献（见 `CONTRIBUTING.md`）。
2. Avida 的核心机制（自复制基因组、晶格空间、任务逻辑函数）**均未建模**，
   本实验只抽象了"能量来源"与"损耗可逆性"两个维度。
3. `exo` 的实现是把 basal 与 c1 置零（无消耗、只有奖励），
   这是"外生奖励"的一种极端形式，非 Avida 的唯一可能实现。
4. 表型空间小，本结论不涉及多样性，只涉及死亡与不可逆性。
