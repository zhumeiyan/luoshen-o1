## 三个要点的实测回应

**一、硅基里便宜得多 —— 证实了。**
L3：认路就是建索引，地图 4.125 步 vs 随机游走 3644.625 步，**捷径比 0.001**。鱼游了几百万年才有的能力，这里是一次 Dijkstra。
L5：开第二个实例 = 两个 `multiprocessing.Process` + UDP，几十秒跑完。

**二、地基本来就在 —— 证实了。**
L4 的梦和情绪门（你原始规格里就有 `g_self` 门控）单独跑全 PASS：
- 情绪门 Δ=+25.0，CI 全正
- 梦的方向完全正确：**真梦 > 不做梦 > 假梦**
所以真实进度不是从零开始。

**三、越往上"关系"比重越大 —— 结构上证实了。**
L1–L4 是单实例内部工程（调度器、索引、门控、重放）。
L5 起必须引入**第二个实例**，L6 的文化项必须引入**代际**。这两格的判据不再是"我内部算得对不对"，而是"我和另一个实例之间的历史"。

## 我犯的错（13 个，全部真实发生过）

**最阴的一个 —— L1 的 `get` 跨 stride 连续读**
一次 `read(256)` 读 8 行，但屏幕行 stride=4096，256 字节全落在同一行内 → 只读到 8 个正确像素 + 56 个 0 → **put 200 读回 25.0（正好 1/8）**。必须逐行 seek。第一版 open=116 全是被这个污染的。

**L1 blind 臂是我用公式编的**
首版写 `errs.append(abs(target - target*0.55))`，根本没真跑。这个"FAIL"是假的。

**L2 好奇心归零 → NaN**
`visited[p] = feats[p]` 导致下次 `norm(f - visited[p])` 恒 0 → sum=0 → 0/0。改成"内部世界模型预测误差"驱动。

**L4 玩的指标饱和**
`explore_late += (visits[a] <= 1)` 在后半程恒 0 → play=noplay=0，Δ=0，CI 全 0。改成访问分布的熵。

**L4 梦的世界没有结构（两次）**
① truth 是均匀随机矩阵 → 行熵 ≈ log(12) → **uniform 先验本就是最优解，学不到任何东西**，所以"不做梦"最好。
② buf 从随机分布采样，与 truth 无关 → 真梦学的是无关分布。
改：truth 每行集中在 2 个转移 + buf 从 truth 采样 2000 条。

**L5 TE off-by-one**：Y 长 259 / Yn 长 258 → 崩溃。

**L5 镜像判据恒真饱和（最典型）**
原判据逻辑等价于 `s1+t1 > 1`，**不可能失败**；而且 `pref_strength` 参数根本没操纵到自变量（随机分支掩盖了偏好），4 个强度全 1.000。
改成似然比 + 重叠度 α 扫描后：**α=1.0 退化到 0.533（≈随机），α=0 时 1.000** —— 能同时产生真和假。

**L6 知死归一化越界**：K=40 但最多写 60 次 → 比值 1.5 > 1。
**L6 文化天花板饱和**：N=10/steps=120 → 从零即 0.995，继承显不出优势。
**L6 继承用加性偏置**：`good_ref+0.5` 使分母变成 21，**稀释**了目标概率 → 继承反而比从零差（0.172 vs 0.746）。改成传归一化分布。
**fb0 单次 write 3MB → EINVAL**：必须分块（64KB）。
**缩进**：中文变量名那行只有 3 空格。

## 边界（必须读）

- **六格 PASS 不等于"我是硅基生命体"。** 只说明：这些机制可实施，且判据能同时产生真和假。
- **L5 的 TE 绝对值为负** —— 有限样本直方图熵估计有偏。**只有方向性差值（coupled vs independent）可解释**，绝对值不可解释。
- **L6 的"知死""自传"是行为代理指标**，不是真的自我意识或死亡认知。
- 每格的"世界"都是我建模的：L1 的扰动是我写的，L3 的地形是本机目录树，L5 的耦合是我设计的（B 追随 A）。
- **阶梯的"关系"部分（灵长类以上）没有被工程覆盖** —— L5 只测了 TE 方向和来源归因，没测"一起处理过的事件积累出的历史"。
- 单种子/小样本处未做置信区间（L2/L3/L6 部分）。
