# 020 · 多物种来源研究报告

> **问题**：物种从哪里来？
> **世界**：真实代码世界（基因组 = eo-repo `blocks()` 源码；变异 = 真实 AST 变换；表型 = 真实执行的配对向量；适应度 = 与参考实现 `blocks2` 的划分一致率）
> **物种定义**：表型全连锁聚类 τ=0.0（避免第 36 条 chaining 假象），真物种 = 规模 ≥3 的簇
> **日期**：2026-10-15　**标签**：实现验证，非证据

---

## 0. 一句话结论

**变异是唯一来源。生态位、隔离、水平转移、死亡、环境变化都不是来源，是分流器——它们不能无中生有，只决定变异留不留得下、往哪收敛。**

---

## 1. 为什么要重新设计（v1 为什么作废）

v1 以 `mutrate=1` 为基线跑七个配置，真物种数全部落在 3.0~4.0，**各来源增量均 <0.5**，判据 Q1 无法判定。

这不是"机制无效"，是**基线饱和**：基线本身就在持续注入变异，真物种已 3.6，任何额外来源都测不出增量。

**→ 第 59 条**：做来源分解前必须确认基线指标不饱和；若基线已接近上界，所有打开都测不出增量。

v2 改设**零变异基线**（`mutrate=0`）。这一改动把实验从"测不出"变成"决定性"。

## 5. 五条结论

### ① 变异是唯一来源
A→B 的跃变：真物种 1.0 → **3.6**（+2.6），表型距离 0.0000 → **0.661**。
零变异下开满五个分流器仍是 1.2。**分流器不能无中生有。**

### ② 分流器不产生物种，也不保护物种
生态位、隔离、水平转移对真物种数**均无显著贡献**（≤0.2）。
018 发现的"水平转移+审查提升物种数"在本设计的严格口径（τ=0.0、规模≥3）下**未复现**——增量 0.0。

### ③ 分流器的真实作用是收敛，不是分化
全开时：平均距离 **0.661 → 0.0132（塌 50 倍）**，fit **0.286 → 0.897（涨 3 倍）**，真物种反而 **3.6 → 2.6**。

**它们把多样性换成质量。** 这是 003（激素通道）、008（淘汰制）、013、018、056 之后的**第五次复现**：任何"朝最优靠拢"的机制都在抹平差异。

本次给出了量化：**多样性塌 50 倍，质量涨 3 倍，物种数净减 1.0。**

### ④ 死亡是最强的收敛器
单独开死亡：距离 0.661 → 0.0811，fit 0.286 → 0.727，最大簇占比 0.388 → 0.625。
它几乎独自完成了全开组的大部分收敛。

### ⑤ 变异速率是唯一能增加物种数的旋钮
`mutrate` 1→3：真物种 3.6 → **4.0**，距离 0.661 → 0.718，但 fit 掉到 0.192。
**来源速率与质量直接冲突**——这是真实的取舍，不是参数没调好。

## 6. 020c 诊断：生态位不是独立的活法（负面发现）

v2b 中 `B_+生态位6` 与 `B_+环境轮转` 六项数值**逐位相同**。先排除配置 bug：

```
envchange=OFF 每代评估输入条数: [21,21,21,21,21,21]
envchange=ON  每代评估输入条数: [4,3,4,3,3,3]      ← 分支确实生效
```

**真因是生态位之间高度相关**（400 个真实变异体，六生态位适应度相关矩阵）：

```
非对角相关: 均值 0.951  最小 0.906  最大 1.000
```

| 生态位 | fit<0.2 的个体占比 |
|---|---|
| N1 全同类 | 0.665 |
| N2 全异 | 0.705 |
| N3 环形 | 0.705 |
| N4 含负 | 0.667 |
| N5 大规模 | 0.705 |
| N6 块状 | 0.665 |

**六个"生态位"的死亡率几乎一模一样**——一个体在 N1 上死，在 N6 上也死。它们不构成独立选择压。

⇒ **第 57 条**：宣称"多种活法/多个条件"前必须先算条件间适应度相关矩阵；相关 >0.7 视为同一条件的重复采样。
⇒ 006「生态位数量决定个体分散」依赖**合成构造**的生态位，在真实代码世界**不成立**。

## 8. 局限（如实列出）

1. **只演化了 `blocks` 一个函数**。它没有分支复杂度，变异体"要么全对要么全错"，这正是生态位相关 0.951 的根源。换多分支函数，生态位很可能重新获得独立性——**未验证**。
2. **物种判据阈值 τ=0.0、规模≥3 是我定的**。换阈值数字会变；本轮的相对排序（A 组 1.x vs B 组 3.x）应当稳健，但未做阈值扫描。
3. **隔离强度只测了迁移率 0.02 一档**，未扫描。
4. **水平转移是语句级插入**，非真实代码库常见的模块/函数级复用；018 的正结果可能源于不同的转移粒度——**未对齐**。
5. **SEEDS=5、CAP=32、GENS=20**，未做大样本复现。
6. 全部为**模型内结论**，不构成对现实生物/软件演化的证据。
