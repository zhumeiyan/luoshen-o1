# 024 · 抗体与变异体（多物种世界）

**日期** 2026-10-15
**类型** 规律 + 证据
**支撑** A（有代码可复现：真实代码基因组 + 真实 AST 变异 + 真实执行表型；8 seed；预注册 prereg_024.json）
**来源** 元宝，问题来自 016 的"癌症"结论——免疫系统能否抓住功能等价的同义变异体
**改核** 否

## 核心

| 结果 | 数值 |
|---|---|
| 无免疫 30 代后：自我占比 / 同义占比 / 功能 gt | **0.000 / 1.000 / 1.000** |
| 认"功能"的抗体：同义变异体通过率 | **0.927**（≈ 无免疫的 1.000） |
| 认"写法"的抗体 τ=0.98：同义通过率 / 自身免疫率 | **0.001 / 0.225** |
| 特异性倒 U 型：τ 0.98 → 0.995，清除率 | 0.990 → **0.339** |
| 只巡逻常规环境：自身免疫率 / 末代 gt | 0.057→**0.094** / 0.852→**0.443** |
| 判别窗口宽度（中位 / 最大） | **0.0089 / 0.0000** |
| 与自我 token 袋完全相同的同义变异体占比 | **38.2%（窗口宽度精确为 0）** |

## 一句话

> 功能正常与身份仍在是两条独立的线：前者满分时后者可以是零。
> 癌症不是没被发现，是有一类癌症在原理上不可发现——而这是**表示层**的问题，不是强度问题。

## 被推翻

- C4（免疫压力加速同义漂变）方向对但效应弱（+18%，噪声量级），判弱
- C5（免疫组物种数 ≤ 无免疫组）被推翻：免疫组反而更多（1.000 → 1.625）
- 所有条件下自我占比恒 0.000：免疫系统无能力保住原型

## 局限

窗口宽度由表示分辨率决定；只演化 `blocks` 一个函数；τ 只扫 4 档；未测自适应规避。
