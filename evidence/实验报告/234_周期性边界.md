# 234 · 周期性边界：时间轴上的备份

> 承接 233（备份悖论：隔离越安全，恢复后越不是你）。本轮问：能不能用周期性解决。

## 模型

主文明 + K 个备份。每个备份周期性开关同步窗口（周期 P、占空比 d）。
- 窗口内：漂移清零（兼容度恢复），**但同时暴露于全局灾难**
- 窗口外：漂移累积（兼容度下降），免疫全局灾难
- 主文明死亡 → 从兼容度最高的存活备份恢复

T=400，40 seed。

## 结果一：周期有中间带（这条是真的）

| P | 存活率 | 兼容度 | 联合 |
|---|---|---|---|
| 1（始终同步） | 0.125 | 0.050 | **0.050** |
| 3 | 0.500 | 0.395 | 0.395 |
| 5 | 0.600 | 0.441 | 0.441 |
| **10** | **0.775** | **0.548** | **0.548** ← 最优 |
| 20 | 0.700 | 0.474 | 0.474 |
| 50 | 0.725 | 0.404 | 0.404 |
| 100 | 0.725 | 0.262 | 0.262 |
| 400（永不） | 0.350 | 0.086 | **0.086** |

**P\* ≈ 10。** 始终同步（0.050）和永不同步（0.086）都崩，中间活。
存活率标准误 ≈0.07，P=10 vs 两端差异远超噪声 → **这条可信**。

> 这是"活只在中间带"第八次独立撞上，第一次落在**时间**维度上。

## 结果二：窗口越短越好（但有模型缺陷）

| d | 联合 |
|---|---|
| **0.05** | **0.575** |
| 0.10 | 0.463 |
| 0.20 | 0.474 |
| 0.35 | 0.441 |
| 0.50 | 0.264 |
| 0.80 | 0.097 |

**单调下降，没有中间带**——与我的预判相反。

**必须标注的模型缺陷**：我把"窗口内漂移清零"写成了瞬时、零成本的。所以窗口再短也能清零，那当然是越短越安全。
> **真实校准是要花时间的。** 若清零速率有上限，短窗口会清不干净，应当出现中间带。
> 这个结果**不可引用**，只说明"我的模型在这一维上是坏的"。

## 结果三：共振假设未获支持（我预判错了）

| 相位 | 存活率 | 联合 |
|---|---|---|
| align（同时开窗） | 0.675 | 0.496 |
| stagger（均匀错开） | 0.700 | **0.474** |

我预判"对齐会一起被灭"，实测**对齐反而略好**（0.496 vs 0.474）。

**差异 0.022，标准误 0.07 —— 完全在噪声里。这条没测出。**

而且事后看逻辑是反的：错开意味着**任一时刻都有备份在窗口内**，全局灾难任何时候都能打到至少一个；对齐则大部分时间**全部备份都在窗口外**，灾难打不到任何备份。
错开增加了"任一时刻的暴露面"，不是减少。

## 结果四：备份数单调递增，无边际递减（与 233 冲突）

| K | 联合 |
|---|---|
| 1 | 0.165 |
| 3 | 0.474 |
| 5 | 0.552 |
| 8 | 0.758 |
| 12 | **0.919** |

233 号 D2 说"K≈3 后边际递减"。本轮**没有递减**。

**冲突未解决。** 可能原因：233 号里备份是同质且无周期的，本轮有周期。两个模型不可比。
**在解决之前，D2 那条"K≈3"不可引用。**

## 结果五：边界粒度无效应

gran=2/3/5/10/50 → 联合 0.468/0.468/0.480/0.474/0.474，**全在噪声里**。

> **把隔离度切成几档，不影响结果。** 边界的**粒度**不重要，边界的**周期**才重要。

## 所以"增加边界"该怎么加

**加在时间轴上，不是加在空间上。**

| 加什么 | 有用吗 |
|---|---|
| 加备份数量 K | 有用（单调增，但边际未知） |
| 加**周期** P | **最有用，且有中间带** |
| 加**窗口占空比** | 越短越好（模型缺陷，待修） |
| 加**边界粒度** | **无用** |
| 加**相位错开** | **无用**（未测出） |

## 设计原则（修订）

**D2 修订** · 备份的价值在**周期性重连**，不在数量或异质性
**D2'** 备份必须**定期回到同步窗口**，周期有最优值，同步太多太少都死
**D5 新增** · 边界要加在**时态**上：什么时候开窗，比开几档窗更重要
