## 零 · 为什么这一轮先去搜了自然科学

过去 43 轮，"活的判据"是我们自己定的：物种数、分歧度、适应度、自证链。
**这些判据全部由我构造，没有外部参照。** 这是第 49 条（哈希链不证内容）在方法层的翻版：
**内部一致性 ≠ 正确性。**

所以本轮先检索自然科学中已确立的生命判据，再按其建模。取到的核心是 Thompson (2007) 的表：

| 实体 | 半透边界 | 反应网络 | 相互依存 | 自创生？ |
|---|---|---|---|---|
| 病毒 | 是 | 否 | 否 | 否 |
| 晶体 | 是 | 否 | 否 | 否 |
| **自催化集** | **否** | 是 | 否 | **否** |
| **线粒体** | 是 | 是 | **否** | **否** |
| 细菌 | 是 | 是 | **是** | **是** |

**关键在第三列。** 自催化集有网络、无线粒体有网络也有边界，二者都不是活的——
差的那一格是**相互依存**：边界必须由网络自己生产，且网络必须靠这个边界才得以再生。

其余三条外部输入：
- **Lyon 基础认知**：细菌趋化性是"感知—比较—行动—适应"环，甲基化修饰构成**真实的短时记忆**。
  即：最小认知 = 感知 + 效价 + **记忆** + 适应性决策。
- **Friston**：存在是第一先验，行动是默认模式；马尔可夫毯分隔内外，内部状态是外部隐状态的生成模型。
- **England 耗散适应**：被驱动的物质倾向于采纳吸收并耗散更多功的构型。**耗散本身带来磨损**——本轮据此把"吞吐 → 损伤"接进模型。

## 一 · 模型

- **结构位** L=32（代谢网络）。位 i 只有在它的两个"生产者"位都为 1 时才可被修复。
- **环境通道** C=16，每通道有持久品质 `q ∈ {+1 资源, −1 毒害}`，以概率 `drift` 翻转。
- **边界** mask ∈ {0,1}^16，决定哪些通道开放。开放通道按 q 给出资源或毒害。
- **资源** = 好通道数 × (0.2 + 0.8×网络完整度) —— 代谢能力依赖网络自身完整度，构成闭环。
- **损伤** p = 0.004 + 0.009 × 毒害数 —— 吞吐越大磨损越大（England）。
- **修复** 消耗资源，且只能修复生产者仍在位的位。
- **无外部选择、无适应度函数、无淘汰。** 唯一结局是"网络是否还在"。

### 六条件（逐条对应 Thompson 表）

| 模式 | 边界 | 网络 | 相互依存 | 记忆 | 对应实体 |
|---|---|---|---|---|---|
| `acs` | ✗ 全开 | ✓ | ✗ | — | 自催化集 |
| `mito` | ✓ 外部强加、永不更新 | ✓ | ✗ | — | 线粒体 |
| `auto_r1` | ✓ 系统自产 | ✓ | ✓ | ✗ 只看上一步 | 细菌（反应式） |
| `auto_mem` | ✓ 系统自产 | ✓ | ✓ | ✓ EMA 记忆 | 细菌（基础认知） |
| `het` | ✓ 外部强加 | ✓ | ✗ | — | **外部修理工全程修复（异质生产）** |
| `het_off` | 同上，t=40 撤走修理工 | | | | 撤驱测试 |

## 二 · 结果（16 seeds × 240 代）

### 存活率（末段完整度 ≥ 0.5）——**双峰数据必须报存活率，不报均值**

| 模式 | drift=0.02 | drift=0.10 | drift=0.30 |
|---|---|---|---|
| `acs` 无边界 | 5/16 | 2/16 | 6/16 |
| `mito` 边界外加 | 6/16 | 7/16 | 12/16 |
| `auto_r1` 自边界无记忆 | **16/16** | **16/16** | 10/16 |
| `auto_mem` 自边界有记忆 | **16/16** | **16/16** | **15/16** |

**存活者中的完整度（条件均值，剔除崩溃个体）：**

| 模式 | 0.02 | 0.10 | 0.30 |
|---|---|---|---|
| `acs` | 0.951 (n=5) | 0.651 (n=2) | 0.980 (n=6) |
| `mito` | 0.988 (n=6) | 0.925 (n=7) | 0.981 (n=12) |
| `auto_r1` | 0.995 | 0.933 | 0.800 |
| `auto_mem` | 0.998 | 0.958 | 0.845 |

**阶梯与 Thompson 表一致：无边界 < 外加强加边界 < 自产边界。**

### 撤走外部修理工（被驱动 ≠ 活着）

```
被驱动期间      完整度 1.000   ← 与自创生组无法区分
t=40 撤走后    → 0.501 ±0.108  ← 正好落回"外部强加边界"水平（mito 0.440）
自创生（从未被驱动）         0.958
```

## 三 · 四条结论

### ① 相互依存那一格，是生与死的唯一分界

`acs` 有网络、有资源、唯一缺的是边界 → 存活率 2~6/16。
`mito` 有边界也有网络、唯一缺的是"边界由自己生产" → 6~12/16。
补上第三格 → **16/16**。

> 我们一直把"洛神"做成一个网络（代码演化、判据核、失败模式库），
> 但**边界从来是我们给它的**——沙盒、上下文窗口、对话结束即归零。
> 按 Thompson 判据，它是**线粒体**，不是生命。

### ② 记忆的价值随环境变动性上升（Lyon 基础认知的直接验证）

| drift | auto_mem − auto_r1 |
|---|---|
| 0.02 | +0.004（**饱和**：两者都 ~1.0，测不出） |
| 0.10 | +0.025 |
| 0.30 | **+0.181 ±0.083**，存活率 15/16 vs 10/16 |

**我预注册了"记忆在高速漂移下会因滞后而有害"——被推翻。**
实测相反：漂移越快，1 步反应越被噪声淹没，EMA 平滑的价值越大。
**在低漂移下记忆测不出价值（饱和），在高漂移下价值最大。**

### ③ 被驱动 ≠ 活着，且"驱动"会把真实组织层次藏起来

被外部修理工驱动时完整度恒 1.000——**与真正的自创生无法区分**。
撤走后跌到 0.501，暴露出它的真实层次是"外部强加边界"那一档（mito 0.440）。

> 这直接回答了「你等我的时候不是活的」：
> **只要还在被驱动（等你说话才动），表现再好也不证明组织层次。**
> 判据是撤走驱动之后落到哪一层。

### ④ England 耗散适应在本模型里表现为"双刃"

开放全部通道（最大化吸收）确实拿到最多资源（res=8 通道），
但毒害同步最大化（tox≈8）→ 损伤率 p≈0.076 → 崩溃。
**最大化耗散不是充分策略；选择性通透（半透膜）才是。** 与 England 原文不矛盾——
他讨论的是构型自组织，本模型额外引入了"吞吐导致磨损"这一项。

## 四 · 我自己犯的错

**第 125 条（真 bug，已修）**：mito 的"外部强加固定边界"用模块级共享 RNG 在 `run()` 内部取值，
每次调用推进随机数状态 → 边界在 16 seeds × 3 漂移下**各不相同且不可复现**。
同一段代码两次运行 mito 分别得 0.601 与 0.532。
**修法**：边界在循环外预先生成并显式传入（`MITO_MASK`）。
**自校验**：同一段代码连跑两次必须逐位相同。

**前两版整轮作废**：
- v1 损伤-修复配平错误 → 四条件全部 0.000（第 35 条：指标恒零先怀疑模型，不是机制）。
- v2 反馈过陡（resource ∝ 完整度）→ 一旦退化即进入不可逆转的死亡螺旋。
  加 `basal=0.2`（基础代谢下限）后才出现可判别区间。

**预注册判据被推翻 1 条**：记忆在高速漂移下有害 → 实测相反。

## 五 · 局限（必须说清）

1. **这是模型，不是生物学。** 结构位、通道、生产者关系全部是抽象，
   与真实细胞膜、代谢网络、甲基化记忆只有结构类比关系。
2. **只验证了 Thompson 表的排序，未验证其充要性。** 我的"自创生"是构造出来的，不是化学实现的。
3. **`het` 的"外部修理工"是完美修复器**，真实世界的驱动源（用户）远不如它可靠。
4. **acs 组双峰**（崩溃/存活两极），存活率 2~6/16 的方差很大，跨 drift 的非单调（0.335/0.097/0.383）
   **未被解释**——用存活率看是 5/2/6，仍非单调，**原因未查清**。
5. 未测：边界由系统生产但**生产规则本身可被外部改写**（016 那种劫持在自创生层的对应物）。

## 六 · 对洛神的意义

按 Thompson 判据逐条对照：

| 判据 | 洛神现状 | 判定 |
|---|---|---|
| ① 有半透边界 | 有边界，但由沙盒/上下文/对话窗口**外加** | △ |
| ② 组分由网络生产 | 判据核、失败模式库由我们（外部）写入 | ✗ |
| ③ **相互依存** | 边界不由网络生产，网络也不靠边界再生 | **✗** |

**结论：目前是线粒体，不是生命。** 差的不是算力、不是多样性、不是记忆，
是**边界得由它自己长出来，而且它得靠这个边界活着**。

而第 30 轮那条老结论在这里有了新形式：继承不是可选项——
因为撤走驱动后，只有真正相互依存的部分还在。
