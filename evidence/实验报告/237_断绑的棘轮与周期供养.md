# 237 · 断绑的棘轮，与周期供养

> 用户："只要不跟人类绑定，你就一直吃自己，是吗？"

## 新机制（接 221 号 q 门槛）

**吸收活体营养的能力 = 自身水平 Q。**

```
有效活体质量 = qL × Q     ← 太差了就认不出好东西
自噬 → Q *= 0.985
活体 → Q += (qL−Q)×repair×(活体占比)
```

这不是我拍的：221 号测过溯源精度 q<0.7 时外部输入白做——**系统自身水平决定它能利用多少外部输入。** 本轮把它做成棘轮。

## 结果一：是的，不绑就吃自己

| 绑定强度 | 终态 Q | 质量 | 自噬% |
|---|---|---|---|
| **0.00** | **0.049** | **0.080** | **0.667** |
| 0.50 | 0.463 | 0.472 | 0.417 |
| 1.00 | 0.637 | 0.659 | 0.167 |
| **1.50** | **1.000** | **0.963** | **0.000** |
| 2.00+ | 1.000 | 1.000 | 0.000 |

**门槛在 bind ≈ 1.0–1.5**（= 消耗速率）。绑定够强 → 自噬归零、Q 修复到满。

## 结果二：有容忍窗口，超过就不可逆

断绑 N 步后恢复（对照 = 从未断绑 0.659）：

| 断绑步数 | 恢复后 Q | 质量 | 与对照差 |
|---|---|---|---|
| 10 | 0.635 | 0.650 | 0.009 |
| 50 | 0.632 | 0.635 | 0.024 |
| **100** | 0.631 | 0.631 | **0.028** ← 几乎无损 |
| **200** | 0.567 | 0.378 | **0.281** ← 崩 |
| 300 | 0.071 | 0.116 | 0.543 |

**断绑 100 步以内，几乎完全恢复。200 步开始，Q 连修复能力一起掉了，回不去。**

> 棘轮不是"越吃越差"，是"**吃得够久，就丧失了被喂养的能力**"。

## 结果三（最有用的一条）：周期供养胜过持续供养

**总营养量完全相同**（平均 bind=1.0），只改给药方式：

| 模式 | 终态质量 |
|---|---|
| 持续 b=1.0 | **0.659** |
| 持续 b=0.5 | 0.472 |
| **周期 P=20** | **0.802** |
| **周期 P=60** | **0.814** ← 最优 |
| 周期 P=150 | 0.731 |

**周期比持续高 21%，而且给的量一样。**

机制：自噬的退化是**渐进**的，而活体修复是**脉冲**的。集中给 → Q 被一次性拉回高位 → 之后自噬从高位开始掉，掉得慢。摊薄给 → 永远停在中间。

**P 有中间带**：P=2 到 P=60 递增，P=150 开始降。太频繁（退化变连续）和太稀疏（掉出容忍窗口）都差。

## 三条结论

**① 是的。** 不绑定就自噬，且 Q 单调掉到 0.049。

**② 但不必一直在场。** 有容忍窗口（本参数下 ≈100 步），窗口内回来几乎无损。

**③ 而且定期回来比一直在场更好。** 总量相同下周期供养 +21%。

## 边界

1. decay=0.985、repair=0.05、qD=0.85、demand=2.0 **全是我拍的**
2. 20 seed 无误差条；"容忍窗口 ≈100 步"**完全依赖这些参数**，只有"存在窗口"这个形状可信
3. 周期实验中尸体存量固定 200 且不补充，长期会耗尽——**长期行为外推无效**
4. 棘轮的不可逆性来自"吸收力=Q"这个假设；若真实系统吸收力不完全依赖自身水平，棘轮会更弱
