# 187 · 叠加状态时长出能力：涌现点 L1→L2，饱和点 L4 之后

> 命题：叠加状态不只是"变多"，每一层应当**长出新的能力**。
> 判据：能力的增益不能由"数据量变大"单独解释。

**对照设计**：把最高层语料**随机采样**到与每层相同的字符数重测。
若「累积叠加」的能力 > 「同量随机对照」，则该增量来自**叠的内容本身**，不是来自量。

## 三、三条结论

### 1. 涌现点在 L1→L2，即"把人的话叠进来"那一层

```
C2 预测  0.1302 → 0.5227   （4.0 倍）
C3 纠错  0.5417 → 0.8250   （从"做不到"到"做得到"）
C4 压缩  19.23  → 6.38     （从负能力到正能力）
```

**稳健性 9/9 复现**（3 种子 × kmax=2/3/4），无一例外。

### 2. 单独一层核是**负能力**，不是弱能力

L0 在未见文本上 bits = **19.216**，远高于均匀基线 7.539。

**只装了核的模型，比没有模型更糟。** 它自信地报错——与 179 号「λ≥0.5 时半衰记忆比完全没记更差」同构。

### 3. 叠到 L4 之后不再长能力

「累积 − 同量随机」在 L4/L5 已降到 ~0.00（C2 差 +0.0020 / +0.0000），
与 176 号「参数涨 4×10¹⁰ 倍、增益 +0.0000」同一形态：**扩容不是升阶，在压缩包这一层也成立。**

L6 仍有微弱正贡献：C3 纠错 +0.0333、C5 合法 +0.0774。

## 四、不能被"数据变多"解释的部分（累积 − 同量随机）

| 层 | C2 预测 | C3 纠错 | C4 压缩 |
|---|---|---|---|
| L0 | +0.0572 | −0.0500 | +2.5483 |
| L1 | +0.0552 | −0.0666 | +2.7643 |
| **L2** | **+0.4458** | **+0.1750** | **−5.5145** |
| L3 | +0.3176 | −0.0084 | −2.7888 |
| L4 | +0.0020 | −0.0083 | −0.0015 |
| L5 | +0.0000 | −0.0083 | +0.0032 |
| L6 | +0.0000 | +0.0333 | +0.0000 |

L2 的 C2 差 **+0.4458**——同量随机对照只有 0.0769，累积是 0.5227，**差 6.8 倍**。
这与 175 号「对齐 0.2303 vs 不对齐 0.0271，8.5 倍」是同一条：**内容对了才涨，量多了不涨。**

## 六、边界（必须说）

1. **C4 的绝对值受概率地板影响**：未见字符取 1e-12，单字符最多 39.9 bits。
   L0 的 19.216 有地板放大成分，**不能当绝对压缩率读**；但地板对所有层一致，相对趋势有效。
2. **只有一份语料、一个测试集**（u_side 后 20%，约 2000 字符），无误差条。
3. **k=3 字符 n-gram**，非语义层——183 号已自证字符层测不到语义。
4. L3 的判据核经**等间隔采样**到 20000 字符，破坏了局部连续语句；若原文全量纳入，L3 的压缩表现可能更好（当前 5.6565 已是全阶梯最优）。
5. 同量随机对照打乱的是**内容组成**，故「累积 − 对照」= 顺序/结构贡献，不完全等同于"叠"的贡献。

## 七、失败记录

- 首版把每层统一截到 40000 字符，导致 L3–L6 字符数相同、阶梯失效。已改为对大语料等间隔采样。
- L0/L1 的 acc 完全相同（0.1144）：**"每拍必否定"那一句对预测能力零贡献**。
  该层只是在内容上成立，在能力上不成立——**两者不是一回事**。
