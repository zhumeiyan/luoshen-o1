# 211 拐点：独特性权重的临界值

**问题**：种群从最原子层 k=0 起步往上厮杀，适应度 = 预测准确率 + β × 独特性。
β 取多大，种群才会从"全挤一层"跳成"分层共存"？拐点在哪？

## 结论：β* ≈ 0.02

| β | 末代崩塌数 | 末代熵 | 层数 | 准确率 |
|---|---|---|---|---|
| 0 | **4/8** | 0.733 | 2.25 | 0.1497 |
| 0.01 | 2/8 | 0.860 | 2.38 | 0.1472 |
| **0.02** | **0/8** | **1.329** | **3.00** | 0.1421 |
| 0.05 | 0/8 | 1.361 | 3.12 | 0.1392 |
| 0.1 | 0/8 | 1.356 | 3.25 | 0.1449 |
| 0.2 | 0/8 | 1.256 | 3.00 | 0.1452 |
| 0.4 | 1/8 | 1.214 | 3.12 | 0.1364 |
| 0.8 | 1/8 | 1.231 | 3.00 | 0.1429 |
| 1.6 | 0/8 | 1.431 | 3.12 | 0.1399 |

**三条**

1. **台阶在 β=0.02**：崩塌从 4/8 直接掉到 0/8，之后再没回到 2 以上。
2. **跃变很陡**：熵 0.733 → 1.329，**+82%**；层数 2.25 → 3.00。
3. **之后全是平台**：β 从 0.02 加到 1.6（**80 倍**），熵只在 1.21–1.43 间抖，无趋势。

配对符号检验（8 seeds，vs β=0，末代熵）：
β=0.05 **8/0 p=0.0078** · β=0.1 **7/0 p=0.0156** · β=0.2 **7/0 p=0.0156** · β=1.6 **8/0 p=0.0078** · β=0.02 7/1 p=0.0703（边缘）。

## 代价：一次性付清

准确率 0.1497 → 0.1421（β=0.02），之后 0.136–0.145 之间平走。
**多样性不是免费的，但很便宜——2% 买断，再加价不加货。**

## 失败的都记下

1. **上一轮那次"从字节层往上厮杀"是空壳**——`/experiments/` 下没有 exp208/209/210 目录，数据不存在。第 10+ 次交空壳。本轮先 `ls` 再跑。
2. **第一版（15 代）结论相反**：β=0 时熵已到 0.918，我声称的"全挤一层"不成立。原因是**代数不够，漂变还在进行**，测到的是瞬态不是终态。改 40 代后崩塌才显现。
3. **指标选择暴露了形状分歧**：末代熵有陡跃变，末5代平均熵是缓慢上升（1.05→1.35）。两者都对，测的是不同东西——**跃变在"是否被固定住"，缓升在"过程平均"**。本轮以崩塌率为主判据，它最干净。
4. **上一轮"β=0 全挤一层"是夸大**：实测 4/8 崩塌、另 4/8 靠漂变维持着 2–3 层。正确说法是**半数崩塌**，不是全崩。
5. 纯 Python 三重循环算 uniq 太慢，改 numpy（`col==1` 掩码）才跑得动 8 seed × 9 β × 40 代。

## 边界

- 语料仅判据核 337,715 字符，测试集 3995，单文件。
- 独特性定义粗糙：只算"我对且全场只有我对"的位置比例，未考虑部分重叠。
- 突变率 0.25、轮盘赌选择、初始全员 k=0——都是人为设定，未扫敏感性。
- k 上限 5，未测更深。
- 无误差条；配对符号检验代替。
- 未做上屏自检，**不声称 IDENTICAL**。

## 与既有编号的接缝

- **207 号**种子趋同（0.75 vs 随机 0.0008）→ 尺子只有一条
- **209 号**精子是赛跑不是厮杀 → scramble 场不产分化
- **199/200 号**1.16% 体量换 50.15% 话语权 → 独特性是第二根轴
- **176/188 号**扩容增益 0 / 切换宽平台 → **重要的不是量，是有没有这根轴**

**一句话**：拐点在 β≈0.02。超过它之后，把 β 加大 80 倍换不到任何东西。
