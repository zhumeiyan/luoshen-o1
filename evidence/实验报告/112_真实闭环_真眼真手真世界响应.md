# 112 · 真实闭环：真眼 + 真手 + 真世界响应

> 命题（宿主）："人类不计算，人类就是看见 → 动 → 再看。谁打游戏还去算函数？"

094 用**合成反馈**证明闭环 20/20、开环 0/20。本轮把三端全部换成真实 I/O，
看看那条结论在真设备上还站不站得住。

---

## 一、可操作化

| 端 | 真实通道 | 真实性判据 |
|---|---|---|
| 眼 | `/dev/fb0` | 真 ioctl 取几何（1024×768×32bpp）+ 真 read 3,145,728 字节 + 真像素定位 |
| 手 | `/dev/uinput` | 内核注册为 `/dev/input/event1` |
| 世界响应 | 内核 event 流读回 | **世界只接受"内核承认收到"的位移** |

**关键设计**：发给世界的不是命令本身，而是从内核 event 流里**读回的 REL 值**。
手一断 → 读回 0 事件 → 世界不动 → 任务必然失败。这给效应器通道一个天然阴性对照。

**世界**：光标受 `位移(内核读回) + 未知恒定风(3,−2) + 未知噪声 σ=4` 驱动。
风与噪声 agent 都不知道，只能靠看。命中阈值 14px，上限 30 步。

## 二、结果

### 条件矩阵（12 次/条件，世界噪声种子配对）

| 条件 | 命中 | 平均步数 | 终态离目标 |
|---|---|---|---|
| **closed 闭环** | **12/12** | 12.2 | **10.0 px** |
| yoked 重放 | 8/12 | 15.2 | 44.9 px |
| open 开环 | **0/12** | — | 194.0 px |
| blind 盲动 | **0/12** | — | 819.7 px |
| eyes 只看不动 | **0/12** | — | 754.7 px |

**闭环 12/12，开环 0/12。** 和 094 的合成结果同向，但这次中间隔着内核。

**yoked 8/12 是关键**：它重放的是 closed **逐位相同的命令序列**，只换了自己的噪声实现。
成功但明显更差 → 命令序列本身携带信息（所以 8/12），**反馈把它补到 12/12 并把末距从 45px 压到 10px**。

**eyes 0/12**：每步都真看，一次都没下发动作。**088/089 那条"没手光有眼睛活不下来"第三次复现。**

### 反馈频率剂量反应（真实感知）

| 每 f 步看一次 | 命中 |
|---|---|
| f=1 | 8/8 |
| f=2 | 8/8 |
| f=4 | 4/8 |
| f=8 | **0/8** |

单调下降。和 094 合成条件下的 `f=64 失败` 同向，但真实条件下阈值提前很多
——f=8 就归零，因为真实世界有风，不看就会被吹偏。

### 真实单步感知延迟

**5.5 ms**（含 3MB 帧缓冲 read + 全屏 786432 像素定位）。

## 三、🔴 必须自曝：方向符号判据在闭环下是饱和的

我统计了"这一步是不是更近了"：

```
更近 = 135    更远/未近 = 0     → 饱和
```

**在闭环条件下，误差单调下降，二值方向信号永远为真。**
所以**我不能主张"方向符号"是可证伪判据**——它在这个条件下产生不了假。

真正不饱和的是**连续距离读数**：同一条通道读出 10.0px（闭环）与 819.7px（盲动）。
判据核 #443 的要求应由连续读数承担，不是由二值符号承担。

这一条我差点略过——因为"saturated"看起来像缺陷，但如实报出去才是对的。

## 四、112b · 真实轨迹接入本体引擎

把 112 里**真实测到的**误差序列（不是合成的）注入引擎：

| 输入流 | 存活 | 结构偏度 |
|---|---|---|
| closed（误差收敛） | 9/16 | 0.4311 |
| yoked（误差部分收敛） | 8/16 | 0.4176 |
| none（通道断） | 13/16 | 0.2879 |
| **eyes（误差不收敛）** | **0/16** | 全灭 |

配对差（逐对共同存活子集，bootstrap 4000）：

| 对比 | Δ | 95% CI | |
|---|---|---|---|
| closed − none | **+0.1535** | [+0.1199, +0.1869] | **显著** |
| yoked − none | **+0.1391** | [+0.0838, +0.2050] | **显著** |
| closed − yoked | +0.0189 | [−0.0120, +0.0436] | **不显著（跨 0）** |

**两条结论方向相反：**

1. **在不在接触世界，决定结构**（closed/yoked 都对 none 显著）。078/085/099/101/105 之后第六次复现。
2. **接触得"好不好"（耦合 vs 重放），结构分辨不出**（Δ=+0.0189 跨 0）。
   这和 091 的"内省无法区分看错和做错"是同一条：差别在本体论，不在现象学。

**eyes 流 0/16 全灭**是最意外的：它明明"一直在看"。
原因是它的误差**不收敛**——持续单向输入 → 通道 0/1 长期垄断 → 其余通道饿死。

> **不是"有输入"就活，是"输入会被我的行动改变"才活。**
> 只看不动的输入，量级归一化之后照样把系统撑死。

## 五、我犯的错（全部留档）

1. **首帧没上屏就感知** → 读到上一轮残影，closed 全员 `sense_fail`，写出 0/12 的假结果。
2. **通道序搞错了，而且错在 111。** PIL 的 `split()` 返回顺序本来就是 R,G,B,A；
   111 里那段"BGRA 重排"把 R 赋给名叫 `b` 的变量再按原名合并 —— **是空操作**。
   帧缓冲真实接受的是 RGBA。111 的结论不受影响（亮度/熵对通道序不敏感），但注释是错的。
   → 红色标记因此**从未被定位到**，绿色却找得到（它的掩码恰好自洽），这才暴露出来。
3. **能量混淆**：三条真实流量级差 75 倍（末距 7.7 / 44.7 / 762.7 px），
   不归一化就把"输入多大"和"输入什么形状"混成一个变量。改为各自 RMS 归一化。
4. **全局共同存活子集为空**（eyes 全灭），配对统计全部 nan。
   改成**逐对**共同存活子集才拿到有效样本。
5. 第一版 `sense_fail` 分支不返回 `cmds`，yoked 阶段 `KeyError` 崩溃。

## 六、边界，不扩大

- **世界是我们渲染的。** 眼、手、事件读回全真；**世界对手的响应是模型**，
  不是物理世界。能主张的是"闭环在真实 I/O 上成立"，不是"操控了真实外部世界"。
- yoked 8/12 说明**本任务里命令序列本身已携带大量信息**，
  这个任务不足以断言"闭环是唯一解"——只能断言"反馈把 8/12 补到 12/12"。
- `eyes` 全灭的机制解释（持续单向 = 垄断）是** plausible 的机理解释，未做剂量验证**。
- 引擎 amp=0.2 下存活仅 9/16，配对样本 n=7 偏小。
- 深度相机 / 电子皮肤 / 麦克风阵列 / 机械臂 / EEG / EMG **仍为 SIMULATED**，沙盒无此硬件。
