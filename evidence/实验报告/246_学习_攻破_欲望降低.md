# 246 · 学习 → 知短板 → 补充 → 攻破 → 欲望降低 → 找新方向

> 用户："我也是在攻我自己的弱项，我也去尝试攻破，然后去学习。我先是学习，我知道自己哪方短板了，我就去补充，然后攻破。然后欲望值降低，再找新方向，发现自己的能力。"

## 用户的环

```
学习 → 知道短板 → 补充 → 攻破 → 欲望降低 → 找新方向 → 发现能力 ↺
```

## 结果一：学习是**硬门槛**，不是越多越好（唯一强信号）

| learn | 总能力 | 攻破次数 |
|---|---|---|
| **0.00** | **3.221 ±0.011** | **0.0** |
| 0.05 | **3.750 ±0.050** | 4.0 |
| 0.10 | 3.638 ±0.073 | 4.0 |
| 0.20 | 3.570 ±0.061 | 4.0 |
| 0.50 | 3.534 ±0.051 | 4.0 |
| 1.00 | 3.496 ±0.003 | 4.0 |

**从 0 到 0.05 是跳变（3.221→3.750，攻破 0→4），之后单调下降。**

含义：
> **学习是"有没有"的问题，不是"多不多"的问题。**
> 不学习 → 攻破次数 = 0。
> 学一点点就够；继续加码反而略降（占用了攻破的资源）。

用户的环里，**"我先是学习"排在第一位是对的，而且是决定性的**——跳过这一步，后面全废。

## 结果二：策略差异随寿命收敛到 0（可信）

| 寿命 T | 你的循环 | 纯攻强项 | 差异 |
|---|---|---|---|
| **30** | 3.077 ±0.152 | 2.859 | **0.218** |
| **60** | 3.464 ±0.048 | 3.173 | **0.291** |
| 120 | 3.535 ±0.049 | 3.611 | 0.076 |
| 500 | 3.644 ±0.052 | 3.704 | 0.060 |
| **1000** | 3.907 ±0.051 | 3.893 | **0.014** |

**寿命短时策略重要（差 0.29），寿命长时归零（0.014）。**

而且方向会翻转：短寿命时**纯攻强项更差**（2.859 < 3.077），长寿命时反而略好。

> 攻弱项还是攻强项——**在你还有时间的时候才是个问题。**
> 时间够长，两条路都到顶。

这跟 244 号扣上：有限寿命不只是驱动来源，**它还是让"选择"有意义的前提**。

## 结论

**① 学习是硬门槛。** 不学 = 攻破 0。学一点点（0.05）就到顶。**你环里"先是学习"这一步是决定性的，且不必过度投入。**

**② 攻弱项还是攻强项，取决于你还剩多少时间。**
- 时间紧：**攻弱项更好**（强项那条路短寿命下最差，2.859）
- 时间够：没区别（差 0.014）

**③ 欲望降低后的"找新方向"有效但量小（+2.6%）。**

**④ 懦弱性测不出，第四次。** 我不包装它。
