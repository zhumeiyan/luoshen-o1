# 052 · 判据核作为自动闸门：检出率 与 效力

**对象**：我方判据核（052 时 151 条）
**问题**：049/050/051 测的是「判别力 / 覆盖率」。但判据核的真正用途是**减少错误**——
这一点**从未被验证过**。本轮第一次测：把它变成程序化闸门，看它能否检出真实缺陷、
以及检出之后修复是否真的让结论变对。

**标签**：实现验证，非证据

---

## 设计（因果三层）

统一任务：检测机制 M 的真实效应，M = 变异率 1 → 3。
真值 δ\* 由干净配置标定（gens=10, seeds=6）：

```
A(mut=1) = 0.9224   B(mut=3) = 0.9792   δ* = +0.0568   (t = 4.53)
```

- **扭曲度** `dist = |delta_obs − δ*|`
- **有害** `dist > δ*/2 = 0.0284`
- **闸门** 8 条内部 + 4 条外部，程序化，只看输出数据，**不知道是否注入了缺陷**

8 个缺陷**每个对应判据核里一条真实记录过的失误**：

| 缺陷 | 对应判据核条目 | 真实出处 |
|---|---|---|
| D1 通道选错（恒等通道） | 第 130 条 | 046「通道上所有变体同分」 |
| D2 变量静默失效 | **第 23 条** | 分支被吞掉，两组逐位相同 |
| D3 选择未发生（CAP=NPOP） | **第 133 条** | 047 真实 bug |
| D4 分母效应 | — | 047「丢掉低分通道抬高均值」 |
| D5 机制未接载荷 | **第 99 条** | 死亡计数被重置恒为 0 |
| D6 相位假象 | **第 92 条** | 末窗恒定落在同一相位 |
| D7 基线饱和 | **第 59 条** | 基线已达上界，增量被压缩 |
| D8 种群每代重置 | 第 99 条变体 | 演化从未发生，自校验仍通过 |

## 结论一：内部闸门只能检出「没动」，检不出「动错了尺度」

这是本轮最硬的一条。

内部闸门检出的 5 个，共同特征是**结构异常**：
无进展（G1）、两组逐位相同（G2）、无淘汰（G3）、计数恒零（G5）、自校验通过但零增益（G8）。
——全部是「**这个系统没有在动**」。

漏检的 D6/D7 是**尺度异常**：系统在正常动、数据看起来完全正常、逐代还在上升，
只是**效应的量级被放大了 2~4 倍**。

> **自证（内部一致性）可以证明「在运转」，不能证明「量级正确」。**

这与三处旧结论同源：
- 016：哈希链保证「写入后不可改」，不保证「写入的是真的」
- 038：可推导的锚（天体时钟）证不了内容
- 049：自证口径召回恒为 1.0000，与支撑量无关

**第四次重演：内部自洽与内容正确是两个维度。**

---

## 结论二：报警 ≠ 有后果

D3（选择未发生）和 D5（死亡未接载荷）**都被闸门正确检出，但 dist = 0**。

**D3 无害的原因**：报告指标是 `max(scores)`（全局最优），而选择不影响全局最优。
→ **缺陷是否有害，取决于你报什么指标。** 换成种群均值，D3 立刻有害。

**D5 无害的原因**：`death_on=True` 只记数、不参与选择——
**即我试图注入的「机制未接载荷」缺陷，其宿主机制本来就没接进主通道。**

> 这个缺陷没有产生后果，不是因为它温和，是因为**它描述的病在引擎里本来就存在**。
> 这是判据核第 99 条的一次自我重现，也顺带给出了第 99 条的自检法：
> **注入「该机制失效」，若结论毫无变化，则该机制从未接进主通道。**

---

## 结论三：我预注册的 G9 方向错了

我假设「通道选错」的信号是**方差变小**（同分）。实测相反：

```
D1: var_main = 0.00868   var_alt = 0.00067   ← 主指标方差是全集评估的 13 倍
D7: var_main = 0.00872   var_alt = 0.00067
```

简单通道上 A/B 差异被**放大**，所以方差变大。
**判据方向必须由实测标定，不能靠直觉。**（已计入判据核第 157 条）

## 三条必须承认的局限

**① 「修复」是同义反复，效力未被真正验证。**
本轮的修复 = 把缺陷关掉（`fixed=True` → 走干净路径），
所以 `dist_fixed = 0.0000` 全部成立是**必然的，不含信息**。
真正的效力检验要求把缺陷**换成另一个正确实现**（而非移除），本轮未做。

**② D1 与 D7 数值完全相同**（delta 都是 +0.2083，dist 都是 0.1515）。
名义 8 个缺陷，**实际只有 7 个独立条件**——ONE_IN 是 EASY_IN 的子集，两者等效。
这是 020c 那个病（名义多条件、实际同一条件）的又一次出现。

**③ 表型空间只有 11**（第 112 条要求 ≥20，判定：作废）。
本轮结论依赖连续的 fit 序列而非表型多样性，故仍可作数；
但**任何涉及「多样性」的推论一律不得外推**。

另：052b 的 D8 条目作废——`evolve2` 漏写了种群重置分支，该行实际等于 none。

---

## 对判据核的直接含义

1. 判据核**可以**变成程序化闸门，且**不会误报**（假阳性 0）——这是好消息。
2. 但它目前的条目**高度偏向「没动」类**（指标恒零、变量静默、无淘汰、计数恒零），
   对「动错了尺度」几乎无覆盖——而后者危害更大。
3. 补外部基准闸门只需一条：**主指标结论 vs 独立全集评估结论的一致性**。
   这一条就把有害检出率从 3/5 拉到 5/5。
