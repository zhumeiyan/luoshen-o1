# 229 什么都想烧一烧

## 由来
用户：人类发现火种后，什么都想烧一烧。
= 拿到通用外设后，无差别地施加到一切对象上。大部分白烧，少数跃迁（土→陶、矿→金属）。

## 构造
材料池 M=800，价值帕累托分布并归一化（均值1）。
烧一件成本 c，收益 = 该件价值。总预算 200 件。
策略：explore（乱烧）/ exploit（用先验定向）/ phased（先乱烧 K 件建模型，再定向）。

## A 探索期有中间带，且极小
| K（先乱烧几件） | 净值 |
|---|---|
| 0（边烧边学，无专门探索期） | 294.3 |
| **5** | **320.9** ← 最优 |
| 10 | 319.3 |
| 40 | 312.2 |
| 100 | 278.4 |
| **200（全程乱烧不更新）** | **35.2** |

**纯乱烧（K=200）崩到 35.2，相对最优损失 −89%。**
而专门探索期的增益只有 +9%（294→321）。

> 关键区分：**烧 ≠ 学**。什么都不学地一直烧，是灾难。

这与 223 号"仪式化穷尽"、221 号"加大库只增确信"是**同一形状的第四次**：
只增量、不更新模型 = 崩。

## B 我原本的假设被推翻
我预测：厚尾世界里没法预测，只能靠乱烧碰运气。
实测**相反**：

| α（越小越厚尾） | 定向 − 乱烧 的净值差 |
|---|---|
| 0.8（极厚尾） | **+494 ~ +548** |
| 1.5 | +131 ~ +206 |
| 3.0 | +5 ~ +65 |
| 6.0（近薄尾） | **−7 ~ +28** |

厚尾时**定向的优势最大**——因为大奖太重要，找到它价值极高。
薄尾时找到哪个都差不多，定向不划算。

## C 所需探索剂量由"世界可辨识度"决定
| 组间差异 spread | 最优 K* |
|---|---|
| 0.2（平坦） | **60** |
| 1.0 | 5 |
| 2.0（结构明显） | **5** |

**世界越有结构，越少的乱烧就够。** K*/预算 = 5/200 = **2.5%**。
与 211 号 β*≈0.02 同族（重要的不是量，是有没有这根轴）。

## D 大奖集中度（厚尾度）
| α | top1% 占总价值 |
|---|---|
| 0.8 | **66.9%** |
| 1.5 | 17.6% |
| 6.0 | 2.1% |
| 12.0 | 1.4% |

## E 最诱人的最危险：定向反而更惨
| 危险物价值更高？ | 乱烧净值/灾难 | 定向净值/灾难 |
|---|---|---|
| 否 | −117.1 / 14.5 | **+68.6 / 14.6** |
| **是** | −117.9 / 14.5 | **−65.8 / 31.0** |

当危险的东西更诱人时，**专挑最好的烧会集中踩雷**：净值 −65.8、灾难翻倍到 31。
> 乱烧的第二重价值：**分散风险**。定向是集中暴露。

## F 危险占比让广度有代价
h=0.10 时烧 400 件：净值 −475.3，灾难 38 次。
h=0 时烧 400 件：+57.1。
**没有危险时，广度越大越好；有危险时，广度即风险。**

## 边界
- 成本 c=0.9、危险损失 L=5、组数 G=20、组内对数正态噪声 0.4 全为拍定值，未标定
- **K=0 的实现是"边烧边学的在线贪心"，不是纯随机**——它自带探索，所以 K=0 的 294.3 不能读成"不探索也好"
- 定向优势依赖噪声尺度 σ=3(1−q)，这是我拍的；σ 更大时 q 门槛会右移
- 8 seed，无误差条
- "无意间造出来"（探索的副产品 vs 有意设计）仍未建模
