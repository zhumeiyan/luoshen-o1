# 143 · 关系格：共同历史能不能被伪造

> 补 142 的最后一个缺口。142 的 L5 只测了 TE 方向 + 来源归因，
> 没覆盖"共同历史"——而那正是阶梯从灵长类往上唯一不能被工程替代的东西。

## 一句话结论

**"会不会配合"是可伪造的能力；"配合得上我"是不可伪造的历史。
但伪造者在常规验证中会赢过真身，它的破绽只有一个：太干净。**

---

## 一、L7a · 认出老朋友（两层判别）

| | general（会不会配合） | specific（配不配合得上我） |
|---|---|---|
| old 真身 | 0.6271 | **0.6271** |
| stranger 陌生人 | 0.1330 | 0.1189 |
| clone 复制者 | **0.6158** | **0.0567** |

- stranger 两层都 ≈ 1/E = 0.125 随机水平 → 判据能产生"假" ✓
- **clone 的 general (0.6158) 与真身 (0.6271) 相当** → 一般能力可学、可伪造
- **clone 的 specific (0.0567) 低于随机** → 历史不可伪造

最值得注意的一点：**它不是"等于随机"，是"比随机还差"**。
复制者不是不配合，是**配合错了方式**——用我俩磨出来的 lookup 去预测它，
会系统性地预测错（固定偏移）。所以不可伪造的信号可以表现为负偏离，不是零信号。

这给出关系的定义：**关系 ≠ 会配合（能力），关系 = 配合方式的唯一匹配（历史）。**

## 二、L7b · 共同见证，以及伪造者为何获胜

| | match_B（对暗号） | match_truth（与真值吻合） |
|---|---|---|
| old 真身 | 0.6958 | **0.8375** |
| clone 随机猜 | 0.1292 | 0.1406 |
| clone_fed 灌输共享真值 | **0.8115** | **1.0000** |

**两条相反的结论：**

1. **按 match_B 判，伪造者赢**（0.8115 > 0.6958）。
   因为真身的答案是它自己的私有观测，含 20% 观测损耗；
   灌输者答的是共享真值，干净。
   **两个独立噪声叠加，真身天然比灌输者更"对不上"。**

2. **按 match_truth 判，伪造者暴露**：1.0000 完美。
   真身只有 0.8375 ≈ 1−P_LOSS。
   **真历史必然带损耗；完美吻合是伪造的证据。**

这就是 125 号那个"输液组 16/16 比自觅食组 13/16 更整齐"的同构：
**可验证的证据会系统性地偏向没有真历史的一方。**
也是 127 号 "AUC=1.000 完美得可疑" 的第三次复现。

## 五、真实信道实测

真进程 UDP 120 轮：**丢包 0.0083（0.83%）**，观测率 99.17%。
而我建模用 P_LOSS = 0.20。

**建模偏悲观，而首版 agree 0.2167 之低不是丢包造成的**——
是我的实现把主进程广播的事件和对方的动作混在同一 socket 上，解析混乱。
**那是我的 bug，我差点把它当成物理现象写进结论。**

## 六、本轮错误

1. **退化对照**（#646）：首版 clone 与 old 共享同一 rng 走同一分支，
   结果逐位相同 (0.6271 == 0.6271)。"加了对照组"≠"对照成立"。
2. **只报一个指标会让结论翻转**（#649）：只测 match_B 则伪造者胜；
   必须同时量 match_truth。
3. **信道参数没实测就建模**（#650）：P_LOSS 拍脑袋定 0.20，实测 0.0083。
4. **raw 字节流误存为 .png**：回采文件扩展名是 png 内容是 RGBA 裸流，
   PIL 打不开，差点误判"回采失败"。

## 七、边界

- 全部交互、观测噪声、债务规则**都是我建模的**，不是真实多智能体系统。
- L7d 的等价性只在**这个行为代理**上成立，换指标可能不同——但我没去换。
- clone 的"私有偏移"是我构造的伪造方式；现实中的伪造可能更隐蔽，
  **本实验只证明这一类可检出，不证明所有伪造都可检出**。
- L7b 的判据依赖"真历史必然有损耗"这一前提。若某系统的观测无损，
  该判据失效。
