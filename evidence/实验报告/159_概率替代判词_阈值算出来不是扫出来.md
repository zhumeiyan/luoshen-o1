# 159 · 概率替代判词：阈值是算出来的，不是扫出来的

> 用户判词："按判词找原因太笨，你应该用概率学，你自身就是数学公式。"
> 本轮把 157 号"扫 τ 找工作区"重做为解析解，并检验公式的前提。

## 0. 立场

判词 = 事后归纳（跑完才贴标签），概率 = 事前解析（阈值可闭式求解）。
但本轮的核心发现是：**公式用错比不用更糟**——必须检验公式的分布前提。

## 1. A · 决策论阈值 vs 经验扫描

### 公式（Neyman–Pearson + 损失，不依赖分布）

```
行动 ⟺ P(d|o)·C_miss > C_fp
⟺ LR(o) > (C_fp/C_miss)·((1-π)/π)        ← 阈值由先验与代价解出
```

高斯移位下 log LR 有闭式：
```
log LR = sig·z/sd0 − sig²/2      (z = o − mu0)
行动 ⟺ z > sd0·[ sig/2 + ln((C_fp/C_miss)((1-π)/π)) / sig ]
```
sig→0 时阈值自动发散 → **"看不清就不动" 的解析版**。

### 真实量（非假设）
- 噪声：真实时序抖动 n=4000，mu=24076 sd=3352
- 抢占成本：真实 fork+SIGKILL+waitpid 计时 = 106694 ns
- 漏报代价：8× 抢占成本

### 结果（12 格：π ∈ {0.05,0.15,0.40} × sig ∈ {0,1,2,4}）

| 方法 | 额外实验 | 胜出 |
|---|---|---|
| **emp（经验密度比 + 决策论阈值）** | **0** | **11 / 12** |
| scan_best（扫 5 档取最优） | 5× | 1 / 12 |
| gauss（高斯闭式） | 0 | **0 / 12** |
| fixed τ=1.0（157 号做法） | — | **0 / 12** |

**零调参的方法赢了需要 5 倍扫描的方法。157 号的固定阈值做法全输。**

### 退化检验（公式自行处理 LR=1）
```
π=0.05  π·C_miss=45539  < C_act → 不行动  ✓ 与解析一致
π=0.15  π·C_miss=136617 > C_act → 全行动  ✓
π=0.40  π·C_miss=364312 > C_act → 全行动  ✓
```
157 号"看不清就不动"不是一条规则，是公式在 LR=1 时的自然退化。

## 2. 高斯闭式为什么 0/12

真实抖动分布实测：
```
skew +2.660   kurt +12.688   max 13.9σ   中位比均值低 9.8%
```
**严重右偏重尾，高斯假设完全不成立** → 闭式阈值系统性偏低 → 过度触发。

> 修复：保留决策论阈值（与分布无关），用**经验密度比**代替高斯公式。
> 这一步把 0/12 变成 11/12。

## 3. B · 互信息能否事前挑表示

假设：I(label; 表示) 的排序 = 判别度排序 → 可不跑分类器就挑表示。

**结果：假设被推翻，且方向相反。**
```
未校正 MI：Spearman = −0.600
```

### 为什么（公式给的原因）
```
MI(unigram) = MI(bigram) = 0.5438   完全相同
H(label)    = 0.5441
unigram 不同取值数 = 2395，而 N = 2400
```
**MI 饱和到 label 熵**——那不是"表示有用"，是"表示细到能记住训练集"，
测试集上从未见过 → 全判 0 → 判别度精确为 0。

### Miller–Madow 偏差校正
```
偏差项 ≈ (|X|−1)(|Y|−1)/(2N)
```
| 表示 | 取值数 | MI原 | 偏差 | MI校正 | 判别度 |
|---|---|---|---|---|---|
| unigram | 2395 | 0.5438 | 0.4988 | 0.0450 | 0.0000 |
| bigram | 2395 | 0.5438 | 0.4988 | 0.0450 | 0.0000 |
| first | 430 | 0.2232 | 0.0894 | 0.1338 | **0.1333** |
| len | 26 | 0.0200 | 0.0052 | 0.0148 | 0.0464 |

**校正后 Spearman = +0.400，符号翻转。**

未校正的互信息会推荐最没用的那个表示（unigram）。

## 4. 我犯的错（全部记入判据核 752–758）

1. **用 1−CDF 当似然**：尾概率恒 ≥1 → 阈值一压就永远触发（bayes 成本恒等于 C_act）
2. **经验分布重采样 + 高斯公式**：数据与模型错配，闭式解失效（后由 skew/kurt 定位）
3. **漏了 always 臂**：sig=0 三格误判 scan 赢，实际无条件行动才最优
4. **emp 在 sig=0 硬编码 False**：应由公式退化为 π·C_miss vs C_act，不该替它决定
5. **代价设定使问题退化**：π 全 > C_act/C_miss → 信息无价值；改到跨越 0.125 两侧
6. **互信息未校正即主张**：差一点把 −0.6 写成"互信息可预测判别度"
7. 打印参数错位致 p99.9 行数值无意义（已弃用该行）

## 5. 边界

- 信号（移位量 sig）与损伤概率**是我建模的**；噪声、抢占成本、语料全部真实
- `C_miss = 8×C_act` 是我设的，换比值结论可能不同
- B 只测 4 种表示、N=2400；校正后 +0.400 仍非强正相关，只主张符号翻转
- 经验密度比的分箱数 60 未扫敏感性
- 本轮**未做多重比较校正**

## 6. 一句话

**公式比判词强，因为它能算、能退化、能自我检验；但它的前提必须单独验证——
本轮高斯前提一验证就废（0/12），互信息一校正就翻转（−0.6 → +0.4）。**
