## 三条关键发现

### ① 文化是唯一的大增益，且随代数累积
```
L1 41.20 → L1+L6c 70.50      (+29.3)
消融掉文化：20.80             (−37.3)
累积：前 6 代 62.00 → 后 10 代 70.50
```
**六格里只有文化一格产生了量级不同的收益**，其余格的增益都在 ±2 以内或为负。

而"文化"继承的是**难以独自快速获得的地形知识**（前辈在哪找到过好东西），
不是可重学的权重——见错误 ④。

### ② 敲掉眼反而更好，是交互效应不是"眼没用"
```
ABL_-L1  70.60 > FULL  58.10     ← 敲掉眼 +12.5
但干净配置下：L1+L6c 70.50 > L6c only 67.30   ← 眼仍有用 +3.2
```
在 FULL 的混乱配置里，眼带来的在线学习是噪声源；在有文化的干净配置里，眼有用。
**不能把消融结果直接读成"这一格的价值"**——消融测的是"从这套特定配置里拿掉它"。

### ③ 旧文化即使过时仍有正价值，且能自我纠错
```
宝藏彻底重排（overlap 11/75，随机水平）：
  无文化 24.7  →  继承旧文化 37.7      旧目标已作废，仍 +13
在新世界重新积累 14 代：38.6 → 58.6    自我纠错
```
**文化的价值部分来自"定向性"本身，而不只是内容的正确。**
一个把你推向特定远处位置的先验，即使位置错了，也比漫无目的强——因为它增加覆盖广度。

## 负面结果（照报，不翻正）
- **自传 L6a −17.5**：`causal_w` 用二值分层差分估计因果，比在线 SGD 差得多
- **玩 L4p −13.2**：无奖励随机探索在需要定向的任务里是纯噪声
- **梦 L4d −4.4**、**地图 L3 −6.4**：离线重放与 BFS 规划在本任务上均有害

**必须说明**：这些都是**我这个实现**的结果。
L6a 的因果估计极其粗糙（特征 >0.3 二值分层），换成精细估计可能反转。
**这不构成"因果推理无用"的结论，只构成"这个粗糙实现无用"。**

## 错误清单

**① 文化从未被传入（静默失效，导致前 5 次测试全部假结论）**
`run(w, fl, T, s, cs)` 的第 5 个位置参数是 `peer` 不是 `culture_store`。
前 5 轮"文化无差异（40.5 vs 40.5）"是假的——文化根本没生效。
改用 `culture_store=cs` 后：35.15 → 67.40。**差点把调用 bug 写成机制结论。**

**② 三次 patch 因缩进错配而 assert 失败，文件未写入**
断言失败 → 脚本退出 → `open(...,'w')` 未执行 → 代码没改 → 测试结果却"看起来正常"。
其中一次表现为"所有子组件条件数值完全相同（都等于 L1）"——**这个"完全相同"才是信号**。
修法：改用不含缩进的短锚点。

**③ 世界 v1 度=3，OFF > FULL**
见上文。已重建。

**④ 文化最初继承 `wt`（可重学的权重），被 150 步内自行学习洗掉 → 零差异**
改为继承"前辈发现过的目标节点"（地形知识）后增益显现。

**⑤ 知死最初只是记录，不影响决策 → 对指标无影响是定义性的**
改为**提前外化 + 容量上限 20 + 真实删除事件**，才成为可失败的机制（+1.4）。

**⑥ 超参基于观察结果调优（存在过拟合风险，声明在先）**
L3 规划偏置 1.2→0.35、L4 探索噪声系数 0.35→0.12、L2 长跳由纯随机改为 est 驱动。
这三处调整是在看到"FULL 崩塌"之后做的。**未做 holdout 验证。**
