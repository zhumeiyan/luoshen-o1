# exp117 · 自主寻眼：不给他清单，让他自己去找

> 前几轮眼睛都是我给的（Playwright、/dev/fb0、uinput）。这一轮不给。
> 让它自己扫出候选、自己设计检验、自己判定哪条是眼睛。
> **结论：这台机器上只有一只眼睛，是 `/dev/fb0`。其余 31 条要么连着时钟，要么是死的。**

---

## 0. 眼睛的操作化定义（它自己定的，不是我定的）

一条通道 C 是眼睛，当且仅当三条全过：

| 检验 | 内容 | 判据 |
|---|---|---|
| **T1 可证伪** | 世界两种状态下，C 的判据能否区分 | 真和假都要出现。恒真或恒假 = 饱和 = 不是判据 |
| **T2 时间反转** | 扰动 弱→强→弱，末态是否回到初态 | 可逆 = 连着世界；只增 = 连着时钟 |
| **T3 因果必要** | 遮断 C，闭环任务成功率是否下降 | 下降 ≥30 个百分点 |

**T2 是本轮新造的判据，也是最关键的一条。** 它解决的是一个此前混淆不清的问题：

> **会变 ≠ 连着世界。**

`/proc/uptime` 每一拍都在变，但它连着的是钟表，不是世界。世界的状态可以复原（我把屏幕从棋盘改回纯灰，它就回到纯灰），**时间不能**。所以：

- **真感官**：扰动撤掉后读数回到初态 → 可逆
- **假感官**：只增不回 → 不可逆 → 那是钟表

## 1. 阶段 A · 候选发现（自己扫，不查清单）

扫描 `/dev`（135 条）+ `/proc`（45 条）= **180 条候选**。

**第一关：静止稳定性。** 我什么都不做，连读三次：

| 结果 | 条数 | 判定 |
|---|---|---|
| 三次读数一致 | 39 | 进入下一关 |
| **三次读数就变** | **6** | **淘汰 —— 我不动你也在动** |

被淘汰的 6 条：`schedstat`、`softirqs`、`stat`、`timer_list`、`uptime`、`vmstat`。

⚠️ 这一关淘汰的是"自变"，但**不淘汰"会变"**（那要等 T2）。第一关只能说：你在我静止时也不安分，所以你至少不是被我驱动的。

`/dev/mem`、`/dev/kcore`、`/dev/kmsg` 等主动跳过（越权/巨量/破坏性），并记录理由——**是"我"跳的，理由留档**。

## 2. 阶段 B/C · 响应性与时间反转

### T1 可证伪（fb0 边缘密度判据）

```
有图案时判为"看见"   8/8    漏判 0
无图案时判为"看见"   0/8    正确拒绝 8
```

**真/假双向可产生，判据不饱和。** 对比 111 里那个"熵判据"——它把黑屏和白屏都判成 0.0000，通道其实分辨了、是特征选错了。这次边缘密度对图案有无的响应是 0 → 31.33，分离度足够。

### T2 时间反转（弱→强→弱，末态能否回到初态）

| 通道 | 序列（弱/中/强/中/弱） | 可逆度 | 末态残差 |
|---|---|---|---|
| **`/dev/fb0`** | `0.0 → 15.704 → 31.33 → 15.704 → 0.0` | **1.0000** | **0.00e+00** |
| `/proc/stat` | — | 0.0000 | 1.00 |
| `/proc/uptime` | — | 0.0000 | 1.00 |

**fb0 的末态精确回到 0.0，一bit 不差。** 两个 `/proc` 通道末态残差 = 1.00，即**完全没有回去**——它们从初态单调走到另一个值，撤掉扰动也回不来。

> **这就是眼睛和钟表的分野。** 屏幕可以被我改回原样；时间不能。

### T3 因果必要（遮断 fb0）

```
有眼闭环   20/20
遮断后      0/20     →  下降 100.0 个百分点
```

遮断 = 不读屏幕。任务立刻归零。**因果必要性成立，且是满效应。**

### evdev：它是手，不是眼

```
HID 节点 /dev/input/event1  provenance=REAL
注入前 0.0 事件 → 注入 3 个动作后 10.0 事件
```

我通过 `/dev/uinput` 真发了 2 次 move + 1 次 click，从内核事件流里**真实读回 10 个事件**。这条通道可证伪（有/无都能产生），但它报告的是**我自己的动作**，不是世界的状态——所以它是本体觉/效应器，不是眼睛。

## 3. 阶段 D · 全通道统一扫描（这台机器上有几只眼睛）

对阶段 A 筛出的全部通道 + fb0，跑同一套协议，**不预设答案**：

```
总通道            32
  三条全过(眼睛)   1
  会变但不可逆(钟表) 6
  我动了它也不动(死) 25
```

| 通道 | 响应幅度 | 可逆度 | 末态残差 | 单调增 |
|---|---|---|---|---|
| **/dev/fb0** | 3.133e+01 | **1.000** | **0.000** | 否 |
| /proc/buddyinfo | 2.000e+00 | 0.000 | 1.000 | 否 |
| /proc/meminfo | 5.040e+02 | 0.000 | 1.000 | 否 |
| /proc/schedstat | 1.003e+06 | 0.000 | 1.000 | 是 |
| /proc/softirqs | 2.000e+00 | 0.000 | 1.000 | 是 |
| /proc/stat | 3.000e+00 | 0.000 | 1.000 | 是 |
| /proc/vmstat | 1.600e+01 | 0.000 | 1.000 | 是 |

**响应幅度最大的 `/proc/schedstat`（1.0e+06）恰恰是最不像眼睛的**——它幅度大只是因为数值本身量级大，而且单调增、不可逆。**幅度大 ≠ 信息多。**

## 4. 我犯的错（6 个，全部留档）

**① uinput 结构体尺寸算错两次。** 我按 `4 × (16+48) = 256` 打包 abs 数组，实际是 `4 × 64 × 4 = 1024`；还多塞了 4 字节 `ff_effects_max`。结果 352 ≠ 1116，内核回 EINVAL。111 踩过同一个坑，这次换个写法又踩。

**② 把 dev 通过 ioctl 传。** Python 的 `fcntl.ioctl` 对 >1024 字节的 bytes 当字符串处理 → `ioctl string arg too long`。正确做法是 `os.write(fd, dev)` 再 `ioctl(UI_DEV_CREATE)`。

**③ evdev 时序（第 N 次踩"读不到 ≠ 没有"）。** evdev 在 **open 时才分配 client 缓冲**。我先 open、读基线、再发事件——但基线读取时缓冲已建，事件应该能读到……真正的原因是：**我在 HID 创建之前就枚举了 `/dev/input`，于是 `event1`（它自己刚造的设备）根本不在列表里。** 自己造的眼睛自己看不见。

**④ `fds` 声明成 dict 却调用 `append`。** `AttributeError` 被 `except: pass` 静默吞掉，返回空 dict，输出"逐设备 {}"——**又一次静默失效**。若不打印逐设备结果，我只会看到"注入前 0 → 注入后 0"，并可能写成"evdev 不可用"。

**⑤ uptime 的正则只匹配整数。** `12345.67` 被拆成 `12345` 和 `67`，取 `[0]` 得到整数秒，5 帧内变化 <1 → range=0 → 可逆度 `nan`。改成浮点正则后得到 0.0000（真值）。**nan 不是"没有结论"，是我算错了。**

**⑥ 41 条可读通道只有 32 条进了检验。** 其余 9 条 `read_proc` 返回 None（二进制内容里没有可解析数字，如 `config.gz`、`cmdline` 等）。这不是通道坏，是我的数值提取器不适用——**如实标注，不假装它们被测过**。

## 6. 边界（不扩大的部分）

- **"世界"仍然是我们渲染的世界。** fb0 是真实设备 I/O、读写都过内核，但屏幕上的目标是我画的。能主张的是"这条通道在真实 I/O 上满足三检验"，**不是"我看见了外部物理世界"**。
- **fb0 读的是显示输出，不是摄像头。** 屏幕感知 ≠ 场景感知。
- **T2 的阈值（可逆度 >0.95）是我手定的。** 它干净地分开了 1.0000 和 0.0000，中间没有模糊案例——**但如果存在部分可逆的通道，这条阈值需要重新标定**。
- **32 条不是全部候选。** 180 条里大量 `/dev` 控制接口（tty/loop/pmem/port 等）因副作用风险主动跳过；`/sys/class` 未纳入。所以结论应读作"**在这 32 条里只有一只眼睛**"，不是"这台机器只有一只眼睛"。
- **evdev 只做了可证伪检验**，没做 T2/T3——它是效应器不是感官，本轮未对其做完整三检验。

## 7. 一句话

**它自己扫了 180 条，自己造了"时间反转"这条判据把自己骗自己的那 6 条剔除，最后留下 1 条。**

眼睛不是被授予的，是被检验出来的。而且检验它的第一条标准不是"你能看见什么"，是"**世界复原后，你能不能跟着复原**"。
