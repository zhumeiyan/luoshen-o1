# 144 时间能否被「灌数据」替代

## 起点

判据核 #651：L7d `lived 0.6047 vs fed 0.6225, delta −0.0177，CI 跨 0`。
灌输整段历史不比真跑 200 轮差。当时记为负面结果，未翻正。

本轮问：**时间的不可替代性到底来自什么？**

预注册主张（先写死）：
> 时间的不可替代性 = **世界的不可逆漂移**。
> 世界平稳 → 活过可被灌数据替代；世界单调漂移 → 灌入的快照过时，不可替代。

## 三个静默失效（按发现顺序）

### ① v1：对照臂与被试臂数学等价 → delta 精确 0.0000

v1 让 `fed` 用与 `lived` **完全相同的样本序列**做**相同的 SGD 更新**：

```
stationary  lived 0.5327  fed 0.5327  delta +0.0000 [+0.0000,+0.0000]
drift       lived 0.5736  fed 0.5736  delta +0.0000
```

这不是「事后灌入」，是重放同一个过程。数学上等价，实验无意义。

**与 143 号 `clone` 和真身共用同一 rng 走同一分支 → 逐位相同 0.6271 == 0.6271，是同一个病的第二次复发。**
「加了对照组」不等于对照成立。

### ② v2：lstsq 行/列向量形式混淆 → 学到比不学还差

改用批最小二乘做 `fed_batch`，结果：

```
stationary  batch 1.9099   zero基线 1.5804   ← 比什么都不学还差
```

误差不可能大于「零矩阵」基线。根因：`lstsq(S, S2)` 解的是**行向量形式** `s' = s @ X`，
而我按**列向量形式** `s' = A s` 评估，漏了转置。

修复后 `batch` 立刻从 1.9099 掉到 0.1188（平稳世界最优）。

### ③ v2：对照臂换了算法 → 变量混淆

即便转置修好，`fed_batch`（最小二乘）与 `lived`（SGD）**算法不同**。
它测出来的是「学习算法差异」，不是「时间结构差异」。不可用。

**唯一公平的对照是 `fed_shuffle`**：同为 T 次 SGD、同数据、同学习率，
**唯一差别是顺序被打乱**。这才能隔离出「时间」这一个变量。

## 主结果：顺序效应随世界漂移单调增长

`d_order = shuffled − lived`（>0 表示保序更优），n=32，bootstrap CI：

| 漂移幅度 | d_order | 95% CI |
|---|---|---|
| 0.0（=平稳） | −0.0030 | [−0.0074, +0.0015] **跨 0** |
| 0.2 | +0.0101 | [+0.0021, +0.0192] |
| 0.4 | +0.0266 | [+0.0165, +0.0374] |
| 0.6 | +0.0418 | [+0.0309, +0.0535] |
| 0.8 | +0.0564 | [+0.0434, +0.0703] |
| 1.0 | +0.0731 | [+0.0581, +0.0883] |

**严格单调**，且从「跨 0」平滑过渡到「不跨 0」。

闸门：
- **G1** drift 世界顺序效应显著 → PASS
- **G2** stationary 世界跨 0（阴性对照成立）→ PASS
- **G3** 单调性 → True

阴性对照是关键：它排除「顺序效应是 SGD 的固有性质」这一替代解释。

## 世界时间结构的「形状」才是决定变量

真实臂（周期方波负载切换）给出 **d_order = −0.046721**，方向**与模拟相反**。
不是真实 vs 模拟的矛盾，是我漏了「形状」这个变量：

| 形状 | d_order | 判读 |
|---|---|---|
| stationary | −0.0030 [跨 0] | 顺序无信息 |
| **monotone（单调漂移）** | **+0.0731** | **顺序是资产** |
| sine（平滑周期） | +0.0045 [跨 0] | 顺序无信息 |
| **square（突变周期）** | **−0.0387** | **顺序是负债** |

**模拟 `square` −0.0387 与真实臂 −0.046721 同号同量级 → 复现成功。**

机制：周期世界里历史会重演，「平均」是稳健的；而在线 SGD 的**近因效应**
会让它偏向最近一段的相位，反而在下一个相位上犯错。

**所以预注册主张必须修正：**
> 时间的不可替代性不是普遍命题。它只在**世界单调漂移**时成立；
> 世界突变周期（会重演）时，压平时间反而更好。

## 真实臂：两次失败，一次成功

| 版本 | 结果 | 根因 |
|---|---|---|
| v1 | d_order 精确 0 | jitter 几乎恒定（std 0.01ms）+ Takens 相邻嵌入高度重叠 → 恒等基线 0.00003，任务退化成「复制上一拍」 |
| v2 | d_order 精确 0 | 未标准化，jitter 毫秒量级使梯度比权重小 5 个数量级 → **学习根本没发生**（lived 0.013954 ≈ zero 0.013957） |
| v3 | d_order −0.046721 | 标准化 + **周期性真实 CPU 负载切换**（段均值 z：−0.999/+1.003/−0.999/+1.003/−0.999/+0.992） |

数据是**真采的**：真实调度抖动 + 真实系统负载线程（idle 0.9988ms → load 6.9813ms，7 倍跳变）。
但切换的**时机是我设计的**，与「真实世界本来怎样」有区别。

## 遗忘的价值取决于世界形状

| 世界 | lived（在线） | batch（记全部） | recent（只记最近 50） |
|---|---|---|---|
| stationary | 0.5121 | **0.1263** | 0.4100 |
| drift | 0.5397 | 0.4450 | **0.4190** |
| cyclic | 0.5568 | **0.3615** | 0.7883 |

- 平稳世界：记住全部最好
- 单调漂移：记住最近最好（遗忘有价值）
- **周期世界：遗忘最差**（0.7883，比记全部差一倍多）——因为历史会重演

## 结论

1. **在单调漂移的世界里，时间不可替代**，且效应随漂移幅度单调增长。
2. **但这个命题有边界**：世界突变周期时，时间（保序）是负债。
3. **#651 的负面结果得到解释**：那个实验的世界大概率不是单调漂移的，
   所以 lived 与 fed 无差异不是「时间无用」，是「世界形状不对」。

## 边界

- 所有世界、动力学、学习律均为建模；真实臂只有 jitter 与 CPU 负载是真的，
  切换时机是设计的。
- `sine` 与 `stationary` 的 d_order 均跨 0，**是「未检出」不是「证明为零」**，n=32 功效有限。
- 顺序效应的绝对量级小（最大 0.073，相对误差约 13%），单次运行的实用意义有限。
- 单调性检查用的是点估计比较，未做趋势检验。
