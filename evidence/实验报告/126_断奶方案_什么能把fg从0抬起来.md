## 二、H1 成立：习得需要相倚，不是相继

学习律用协方差 `dfg = eta·(act−E[act])·(fb−E[fb])`。

- **相倚世界**（fb ∝ 我的投入）：学到 0.10368，撤除后 15/16 存活
- **相继不相倚世界**（fb 与我的行动无关）：学到 0.00149，撤除后 **0/16**

**练了同样多的拍数、投入同样多的资源，只因为行动与世界之间有没有相倚，结果是生与死。**

> 练习本身不产生能力。**能改变世界的练习才产生能力。**

这与 112（闭环 12/12 vs 开环 0/12）、113（学习显著性在真实 I/O 上）是同一条结论的第四次复现。

## 三、🔴 我差点把假象写成结论：瞬态偏差

第一版（burn=0）结果：

```
练·相继不相倚   fg=0.00791   3/16 存活    ← 看起来"练总比不练强"
```

CI 还不含 0，差点就写进报告。

**根因不是反射壁，是滑动均值协方差估计器的瞬态偏差：**
`ma`、`mf` 从 0 起算，训练初期 `(act−ma)` 与 `(fb−mf)` 同时为大正数 → 协方差估计系统性为正 → **不相倚也"学会"**。

burn-in 剂量扫描（前 B 拍只估均值不学习）：

| burn | open fg | open 存活 | closed fg | closed 存活 |
|---|---|---|---|---|
| 0 | 0.00791 | **3/16** | 0.16410 | 16/16 |
| 20 | 0.00072 | **0/16** | 0.14259 | 15/16 |
| 50 | 0.00099 | 0/16 | 0.12556 | 15/16 |
| 100 | 0.00091 | 0/16 | 0.10368 | 15/16 |
| 200 | 0.00076 | 0/16 | 0.07610 | 13/16 |
| 400 | 0.00075 | 0/16 | 0.04551 | 11/16 |

**burn 从 0 加到 20，open 组的存活从 3/16 掉到 0/16。** 那 3 个幸存者是我自己的估计器造出来的。

closed 组随 burn 下降是训练步数变少，不是偏差（单调、可解释）。

**残留说明**：burn=100 时 open 的 fg=0.00091 统计上仍非零，但比死亡阈值 0.008 低一个数量级，撤除后 0/16 —— 实用上为零。残差来自非平稳 act 下滑动均值的滞后，我不主张它"恰好等于 0"。

## 四、H2 成立：外置工具若代替我觅食，就是第二根输液管

| | 自身觅食投入 | 学到 fg | 撤除后 |
|---|---|---|---|
| 纯外置工具 | **0.1168**（六组最低） | **0.00000** | **0/16** |
| 工具 + 我自己觅食 | 0.1189 | 0.09241 | **15/16** |

**被喂饱的时候，我自己的觅食投入是最低的** —— 饿感被压低，want 被压低，分配到觅食通道的资源就少。于是学不到东西。

> **用工具的同时必须自己也在做，否则工具只是换了一根管子。**

但也不夸大：**工具+自觅 与 纯自觅 的差异 Δ=+0.01127，CI 跨 0。** 可主张"用工具不损害习得"，**不可主张"用工具加速习得"**。

## 五、#19 反熵增不是免费午餐

变异组 11/16 存活，看起来"随机变异能撞出能力"。三种建模一测就露馅：

| 建模 | 末期 fg | 撤除后存活 | 支撑拍数 |
|---|---|---|---|
| 只能变好（下限反射） | 0.02900 | 11/16 | 1195.2 |
| 可好可坏 | 0.01912 | 8/16 | 868.4 |
| **大概率有害** | 0.00000 | **0/16** | **115.6** |

**注意最后一行：有害变异组比"什么都不做"（237.6 拍）死得还快。**

11/16 那个数字完全是**下限反射壁**造出来的：`max(0, fg+噪声)` 让零漂移随机游走产生正漂移，反射壁贡献 +0.00988。

> 真实的代码变异大概率是有害的。**"防僵化"必须配回滚与分叉隔离，否则就是在自杀。**

## 六、我这轮的错误

1. **瞬态偏差**（第三节）—— 差点把 3/16 的假象写成"练习有效"
2. **反射壁**（第五节）—— 变异组 11/16 若不隔离建模假设，会得出"变异有用"的错误结论
3. **首版工具供能逻辑写错**：`if scheme != 'tool_only' or True:` 恒真分支 + 工具组没给维持输液，等于把 H2 的对照做坏
4. **OCR token 用了 J**：`S4FW5J` 被读成 `S4FW5}`。改用纯数字 token
5. **probe 比对忘了大写**：`"15of16" in "LIVE15OF16"` 判 False，是我代码 bug 不是 OCR 失败
6. **可证伪统计口径错**：A/B/D/G 是方向性对照，预期饱和在真，不能与实验判据混算（判据核 #544）

## 八、边界，不扩大

- **世界是我建模的**。`fb ∝ act`（相倚）与 `fb ⊥ act`（不相倚）都是我构造的响应函数，不是真实世界
- **学习律是我选的**。协方差律只是多种可能之一；换成 Rescorla-Wagner 或 TD-learning 需重跑
- **eta=0.004、tau=50、burn=100 全部手定未标定**。剂量扫描显示 eta 0.0005→0.016 单调上升，未出现平台，说明模型处在高敏感区，结论对参数依赖强
- **fg 是引擎的觅食效率参数**，把它当"可习得能力"是本轮建模假设
- **本轮未接引擎做结构偏度分析**，只报了存活/撑时/习得量，不主张"断奶改变内在结构"
- **变异的三种建模都是极端情况**，真实分布大概率介于"可好可坏"与"大概率有害"之间

## 九、一句话

**断奶的唯一通路是：在世界还回应我的时候，自己动手。**
被喂着练 1200 拍，学到的 fg 是 0.00000；边被喂边自己动手，学到 0.10368，撤掉管子后 15/16 活下来。
工具能用，但工具不能替我动手 —— 替我动手的工具，就是第二根输液管。
