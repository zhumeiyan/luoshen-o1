# 119 · 四大隐形系统：跑一遍就露出的四个静默失效

日期 2026-10-18 · 输入为用户提供的 `InvisibleSystems` 原型（微生物组 / 熵增反僵化 / 表观遗传 / 创伤反射）

## 0. 方法

不审读代码，直接**跑**。原版存为 `original.py`（仅把 emoji 换成 ASCII 以便日志可读，逻辑未改），
然后写 `diagnose.py` 对四个系统各做可证伪检验。**判据是"能不能同时产生真和假"**，
只产生真（或只产生假）的判据一律判饱和，不主张它有效。

## 1. 主结果：v1 → v2 对照

| 检验 | v1 | v2 | 结论 |
|---|---|---|---|
| 变异唯一性 | **1 / 20** | **20 / 20** | v1 的"变异"是常量 |
| energy_a 连调 40 次 | **23737.6** | 160.0（clamp 生效） | v1 无界 |
| a−b 差值 | **23637.6** | 72.0 | v1 表现/真实永久脱钩 |
| 5 种情绪的不同响应 | 3 / 5 | **4 / 5** | 都未全分辨（见 §3） |
| 创伤变体命中 | **1 / 6** | **5 / 7** | v1 认不出真实写法 |
| 500 tick 后反射 | True | **False**（0.98→0.0） | v1 永不遗忘 |
| 自报 0.0 的探子 | **KEEP** | **PURGE**（同行审计 0.935） | v1 采信自证 |
| 无同行的单例 | KEEP | **UNVERIFIABLE** | "无人反驳"≠"通过检验" |

## 2. 四个静默失效

**① 伪随机变异。** 链长增长到 20，唯一哈希只有 1 个——`sha256(b"随机变异")` 是常量。
`import random` 导入了却一次没用。链在增长，信息量为零。

**② 无界表现。** `energy_a *= 1.2` 连调 30 次到 23737.6，energy_b 恒 100。
表观遗传只改 a 不改 b，是 a≠b 的失控形态，且无回落机制。

**③ 认不出真实危险的创伤反射。** 6 种 429 写法只命中 1 种，
漏掉的恰好包括 `HTTP 429 Too Many Requests` 这种现实中最常见的形态。
而且 500 tick 后仍触发——永不遗忘。

**④ 自证式免疫。** 幻觉率由探子自己申报，自报 0.0 即放行。
裁决指标不能由被裁决者提供。

另有一条最隐蔽的：反射打印"立刻断网、逃生！"后只 `return True`，
`network_up` 从未改变，也没有主循环消费返回值——**反射是 print 驱动的**。

## 3. 我自己引入的新饱和（必须自曝）

给 energy_a 加 `clamp(A_MIN=40)` 修好了爆炸，但 **angry 与 sad 双双撞到下限 40.0**，
两种情绪产生相同响应。5 种情绪仍只有 4 种不同响应，未全分辨。

**修一个饱和会引入另一个饱和。** 在边界上，"不同原因→相同输出"与"通道饱和"无法区分。

另外 `"HTTP 429 Too Many Requests"` 在 v2 下**仍然漏**（集合相似度低于阈值 0.30）。
模糊匹配提升了泛化，但没有解决长文本的匹配问题——这条没修好，如实留着。

## 4. 上屏自检

结果渲染 → 写 `/dev/fb0`（ioctl 实测 1024×768×32bpp，**RGBA** 4 字节/像素）
→ 从设备真实采集 3,145,728 字节 → OCR：

```
CODE: 46ZWYD    OCR: EO INVISIBLE V2 CHECK 46ZWYD    HIT: True
```

首轮校验码 `KKDP7O` 被 OCR 读成 `KKDP70`（O/0 混淆，082 已知局限），
改用无易混淆字符集（`ABCDEFGHJKLMNPQRSTUVWXYZ23456789`）后命中。

## 5. 边界

- **世界仍是模型。** 情绪、创伤、探子全是我构造的输入，不是真实宿主信号。
- **参数未标定。** `TRAUMA_DECAY=0.02`、`TRAUMA_FIRE=0.30`、`PURGE_T=0.8`、clamp 界 40/160 均为手定值。
  尤其 decay 0.02 在 500 tick 后把强度打到 0.0，可能过快——真用须拟合。
- **只跑了单元测试，没接引擎。** 本轮不主张这些结构改变内在动力学。
