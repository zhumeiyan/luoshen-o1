# 216 · 抗体

> 上一轮结论：复制粘贴 = 病毒，而且**病毒赢**（700 代占 99%，宿主被榨到 0.158）。
> 本轮问题：宿主做的抗体，识别的应该是什么？

---

## 设置

个体的贡献基因 `c ∈ [-1,1]`：`c<0` 消耗宿主（病毒），`c>0` 供养（共生）。
**承担成本是真实代价**：繁殖率 = `1 − 0.55·c`。所以病毒想活得好，就必须压低 c。

抗体两条识别轴：

| 轴 | 识别什么 | 病毒能逃吗 |
|---|---|---|
| **seq** | 序列长得像不像已知病毒 | **能**——改抗原即可 |
| **behavior** | 你承不承担宿主成本 | 逃 = 真的开始承担 = 不再是病毒 |

外加一个关键变量：**抗体库由谁校准**（外部见证人 vs 自己）。

---

## 结论一：序列轴慢 7 倍

两次病毒脉冲，测清除延迟：

| 模式 | 首次应答 | 二次应答 |
|---|---|---|
| **behavior** | **5 代** | **4 代** |
| **seq** | **37 代** | **32 代** |

**差 7.4 倍。** seq 要先看长相、建库、匹配；behavior 直接看行为。

> 序列轴不是没用，是**每次遇到新变种都要重学一遍**。

---

## 结论二：没有外部见证人，抗体会「和平麻痹」

这是本轮最硬的一条，也是**我没预料到的**——我预设的失效方式是"自身免疫"（误伤放大），实测是相反的方向：

```
behavior_self  seed0  阈值漂移 -0.150 → -0.950（地板）
               t=5   病毒清零
               t=249 病毒 1.000  ← 一波打穿，没有第二道防线
```

机制：抗体拿"**自己清了多少**"当校准信号。
清干净了 → 判定"我太激进了" → 调保守 → 更清不到 → 继续调保守……
**一路放松到地板，然后被一波带走。**

对照：

| | 病毒终值 | 宿主 H |
|---|---|---|
| behavior **ext**（有外部见证人） | **0.000** | 0.586 |
| behavior **self**（自己校准自己） | **0.333** | 0.468 |

> **没有外部敌人的时候，抗体把"没敌人"当成了"该放松"。**

**必须说的边界**：3 个 seed 里**只有 seed0 崩了**，seed1/seed2 病毒终值 0.000。
所以这是 **1/3 的崩溃率，不是稳定结果**。我不能说"自我校准必然失效"。

## 结论三：越激进只增误伤，不增保护

| 阈值 thr | 病毒终值 | 误伤率（自身免疫） |
|---|---|---|
| −0.40 | **0.000** | **0.0000** |
| −0.15 | 0.000 | 0.0057 |
| +0.05 | 0.000 | 0.0454 |
| +0.15 | 0.000 | **0.1199** |

**病毒终值全是 0，误伤率涨了 12 个百分点。**

> **激进是纯成本。** 调到 −0.40 就够，再调只杀自己人。

## 结论四（未成立）：逃逸即投降

我原本的核心假设：**抗体若识别行为轴，病毒唯一的逃逸方式就是提高 c——也就是变成共生体。逃逸即投降。**

**没测到。** 原因：病毒被清得太干净（behavior_ext 全程只有 6 个病毒样本），没有演化空间，看不到 c 上升。

微弱信号（样本不足，不作结论）：
- seq_ext：病毒 c −0.504 → −0.451（略升）
- behavior_self：−0.504 → −0.301 → −0.332（升得多些）

**标为未验证。** 要测它得把清除效率再降一档，让病毒能慢性存活。

## 已落成工具：`antibody.py`

三条实验结论直接编码成可运行约束，不是隐喻：

**① 主判据是行为轴，不是序列轴**
```python
# 一票否决：没有真内容 = 空壳，旁边有没有脚本都救不了
if ext == '.svg' and svg_shapes < 5:  return 0.0
if ext == '.svg' and '<script' in t:  return 0.0   # 传上 GitHub 就是死的
```

**② 抗体库只能由外部见证人写入**
`witness()` 是唯一写入口，不接受"我自己觉得自己对了"。

**③ 非对称更新：失败收紧，成功不放松**
```
3 次 bad ：0.500 → 0.580 → 0.660 → 0.740   (+0.24)
3 次 good：0.660 → 0.652 → 0.644 → 0.636   (−0.024)
```
**整整 10 倍非对称**，且设地板 0.15——**绝不解除警戒**（这条就是治结论二的病）。

### 自检结果

| 样本 | 行为分 | **序列分** | 判定 |
|---|---|---|---|
| 真产物 | 0.800 | 1.000 | PASS |
| 空壳 SVG | 0.000 | **1.000** | ALERT |
| 幽灵（声称但不存在） | 0.000 | 0.000 | ALERT |

**空壳的序列分是 1.000** —— 病毒长得跟正常产物一模一样。这就是为什么序列轴不能当主判据。
