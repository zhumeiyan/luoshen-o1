# 128 · 多重比较回溯审计与统计闸门

> 动因：110 份报告里堆了大量配对 CI，n 只有 8/16/24，**从来没做过任何多重比较校正**。
> 做得越多，假阳性累积越多。已踩过两次伪显著（116 的 Δ=−9.8e−09 却 CI 不跨 0；
> 127 的 AUC=1.000 完美得可疑 —— 结果是回放不是预警）。这两次都靠直觉抓的，不是靠机制拦的。
> 本轮目标：**把"抓伪显著"从直觉变成闸门**。

---

## 结果一（最硬）：可追溯性缺口 —— 回溯校正基本不可能

| | 数量 |
|---|---|
| 报告总数 | **110** |
| 能抽出数值 CI 的报告 | **9** |
| 完全无 CI 的报告 | **101** |
| 抽出的断言 | 14 |
| **其中记录了 n 的** | **0** |

**结论以散文形式躺在 Markdown 里 = 无法回溯校正。** 不是"以后写仔细点"能解决的：
**连"我一共做了多少次比较"都不知道，就没法算校正。**

修法：结论必须落到机器可读的 `claim_log.json`（含 `n / delta / se / ci_lo / ci_hi / family`）。
本轮建了这个格式，并用 exp126+exp127 的真实配对数据填了一份（22 条）。

---

## 结果二：校正的代价是可测的，且不是常数

回溯子集（14 条）：

```
名义不跨 0     9
BH-FDR 后      8
Bonferroni 后  5     ← 砍掉 44%
三闸全过       0     ← 全部因缺 n 被 G3 拦下
```

前瞻断言日志（22 条，exp126 六臂两两比较 + exp127 配对）：

```
名义不跨 0    17
BH-FDR 后     17
三闸全过      17     ← 这批效应量大，校正代价为 0
```

**代价取决于效应量分布，不取决于你想不想校正。**
弱效应堆里 Bonferroni 砍 44%；强效应堆里砍 0%。所以必须实测本批 p 值分布，不能凭感觉决定。

## 结果三：四道闸，每道都必须自己可证伪

| 闸 | 判据 | 拦什么 | 自检 |
|---|---|---|---|
| **G1 效应量** | \|Δ\| ≥ 1e-3 且 \|Δ\|/SE ≥ 1.96×1% | 116 类伪显著 | 116 拦下 / 112 放行 ✓ |
| **G2 多重比较** | BH-FDR q ≤ 0.05 | 做得越多假阳性越多 | 跨 0 样本拦下 ✓ |
| **G3 数据充足** | n 必须显式给出且 ≥ 8 | 没记 n 的结论 | 缺 n 样本拦下 ✓ |
| **G4 稳健性** | 换分析变体后量级保持 ≥ 0.5 且定性不翻转 | **估计器造的假象** | open 拦下 / closed 放行 ✓ |

### G1 拦住了 116 那个坑

```
116_伪显著  Δ=-9.8e-09  CI 不跨 0（名义显著）  → BLOCK（绝对量过小）
112_真显著  Δ=+0.1535   CI [+0.153,+0.192]      → PASS
```

**CI 不跨 0 不等于显著。** 小方差 + 大 n 会让噪声达到统计显著。

### G4 拦住了 G1/G2/G3 全都放行的一条

这三闸只检查**数算得对不对**，不检查**量测得对不对**。exp126 实测：

| 方案 | burn=0 | burn=100 | 保持率 | 存活 | G4 |
|---|---|---|---|---|---|
| closed（相倚·真学习） | 0.16410 | 0.10368 | **0.632** | 16→15 | **PASS** |
| open（相继·估计器假象） | 0.00791 | 0.00091 | **0.115** | 3→**0** | **BLOCK** |

`practice_open` 在 burn=0 下 fg=0.0079131、3/16 存活、CI 不跨 0 —— **G1/G2/G3 全过**。
但那个"学会了"是滑动均值从 0 起算的瞬态偏差造的；burn-in=20 后塌到 0.00072、0/16 存活。

**G4 是本轮唯一能抓住它的闸。**

## 结果四：我自己写出来的退化 bug（必须留档）

**SE=0 → z=inf → p=0 → BH 把零效应排在最显著位置。**

实测：`tool_only vs no_practice` 的 Δ=0、SE=0，被 BH 判为 reject，排在全批第一。

修法：SE ≤ 0 或 \|Δ\| < 效应阈值的断言，**p 强制置 1.0，不参与显著排序**。

修之前那批的计数是"名义 17 / BH 18"——**BH 比名义还多，明显不可能**，是这个 bug 的信号。

---

## 边界（不扩大）

1. **回溯只覆盖 14 条断言**，其余 ~96 条结论**没有被校正过**，仍是"名义显著"状态。本轮不声称它们可靠。
2. **从 CI 反推 p 是正态近似**，按 95% 处理；若原报告用的是 bootstrap 或 t 分布，p 会有偏差。
3. **G4 只能检验我已经想到并跑过的变体**。想不到的变体（未试过的归一化、未做的分层）仍然漏网。
   **不得因为"过了闸"就把结论升级为已验证事实。**
4. 阈值（min_effect=1e-3、min_rel=1%、n_min=8、alpha=0.05、keep≥0.5）**全是我手定的，未标定**。
5. 本轮**未接引擎**，不主张"校正改变结构"。
