# 154 · 真 VR 双目视差：她进不进得去真正的 VR 游戏

## 一、先答问题：商业 VR 游戏进不去，三个门槛已查实

| 门槛 | 实测 |
|---|---|
| GPU | `/dev/dri/card0` 的 MODALIAS = `platform:vkms` → **内核虚拟显示，无硬件 3D** |
| 算力 | 2 核 / 2.4 GB（真 VR 需 90fps × 双目） |
| 软件栈 | 无 X server、无 OpenXR/Monado、无 SteamVR；**apt 403 / PyPI 403 装不了** |
| 渲染库 | moderngl / OpenGL / pygame / glfw / openxr 全部 MISS；仅有 numpy / cv2 / PIL / scipy |

**结论：Beat Saber / Half-Life: Alyx / SteamVR 这类商业 VR，进不去。**

所以本轮只补 VR 独有的那一件：**立体视觉**。
153 号已是真 raycasting 3D（DDA + 透视 + 深度缓冲），不是假网格。

## 三、物理判据（不是我定的规则）

针孔几何强制：**d = f · B / z**（f 焦距，B 瞳距，z 深度）

- **G2**：d 对 1/z 必须过原点线性 —— 物理定律，拟合不出说明渲染是假的
- **G3**：由 d 反推 z = fB/d，相对误差要小
- **G4**：B=0 阴性对照，左右逐位相同 → 视差恒 0 → 深度必然不可恢复
- 单目陷阱：柱子高度随机化，让"越远越小"这个大小线索失效

## 五、关键修复：不是物理错，是摆放弃错

诊断表（修复前）：
```
z=1.65  err  0.2%   ← 近的准
z=2.12  err -0.7%   ← 近的准
z=2.58  err 38.6%   ← 远的全错
z=3.65  err -50.2%
```
随机世界 x 导致远处柱子**被近处遮挡、被屏幕边缘裁切** → 质心测到残片 → 视差错。

修法：**按屏幕走廊反推世界 x** —— 先固定投影中心 uc_i 等间隔留边距，
再由 x = (uc_i − CX)·z / F 反解。保证互不遮挡且完整在屏内。

> k_fit 在修复前就只差理论值 2.7%，说明**物理一直是对的，是测量被摆放毁了**。
> 差点把摆放 bug 写成"视差定律不成立"。
