# 156 · 噪声太大怎么办：灵敏度、增益、差分读出

**问题**：用户担心「传感器太灵敏会被噪音毁掉」，并指出洛神与人绑定、必须说得出感受，问能否两种模式都做。

**一句话结论**：**更灵敏没用——噪声是相关的，不是独立的。真正有效的是换读出结构（差分），不是换传感器。**

---

## 一、先验证地形：三个候选信号全废

按 146 号方法论：**先验地形有结构，再谈策略**。

| 候选 | 实测 | 判定 |
|---|---|---|
| 真实进程负载竞争（fork 子进程） | Cohen d = **0.1768** | 无结构，废 |
| 真实 page cache 冷/热 | 冷/热比 **0.652**（方向反了） | 构造失败，废 |
| Python 多线程竞争 | d = −0.105 / **2.67** / −0.168（不单调） | GIL 使竞争不可测，废 |
| UDP payload 粗扫（64→65507B） | 35335→47769ns「单调」 | **后验证伪：是漂移伪影** |

**两次差点把漂移当信号。** UDP 那次尤其危险——顺序扫描看起来完美单调，交织重测后结构完全消失（d'≈0）。

> 教训（147 号第二次复发）：**先查机制，再下结论。顺序测量出的"单调"常常是时间。**

最终采用：真实指令数差（work=300 vs 300+δ）作信号，真实 CPU 时序抖动作噪声。**换能过程、噪声、判决全部真实；信号强度可控。**

## 二、Allan 方差：噪声是闪烁噪声，积分降噪有硬上限

采集 20000 次真实时序抖动（mean 9508ns，cv 0.25）。

| 窗口 m | σ_A (ns) | 白噪理论 | 降噪效率 |
|---|---|---|---|
| 1 | 1630.0 | 1630.0 | 1.000 |
| 4 | 1156.2 | 815.0 | 0.705 |
| 8 | 1125.5 | 576.3 | 0.512 |
| 16 | 1111.2 | 407.5 | **0.367** |
| 128 | 747.3 | 144.1 | **0.193** |

**局部斜率**：m=1→2 −0.294；**m=4→8 −0.039；m=8→16 −0.019**。

白噪声应给 −0.5（√N 有效）。**m=4~16 斜率≈0 —— 这是闪烁噪声（1/f）floor：再积分也不降噪。**

## 三、d' 随积分长度 N：不上升（且首次测量是假的）

**首次（按 N 顺序跑）**：δ=150 时 d' 从 3.60 → 20.68，看似完美 √N 上升。

**全条件随机交织后**：

| N | δ+20 | δ+60 | δ+150 |
|---|---|---|---|
| 1 | 0.258 | 0.654 | 1.233 |
| 8 | 0.257 | 0.695 | 1.538 |
| 64 | 0.259 | 0.769 | 1.570 |

**δ=20 从 0.258 到 0.258 —— 完全相同。** δ=150 只涨 27%，理论应 8 倍。

> **那个 20.68 完全是顺序漂移的伪影。** 随机化后，积分降噪基本无效。

**这就是答案的一半：提高灵敏度（更多样本、更长的积分）在闪烁噪声下不产生判别力。**

## 四、观测时长本身制造噪声

分 4 块测量（δ=10，N=8）：

```
块0 无信号 11717   块1 14685   块2 14174   块3 9141
块间漂移 = 5544 ns
信号真值 =  763 ns        ← 漂移是信号的 7.3 倍
块内 d' 均值 = 0.3492
跨块 d'      = 0.1629     ← 减半
```

**σ 随观测时长增长（1/f 的特征）。** 所以"看久了是不是更准"——不，看久了更糟。

## 五、双模式：d'=0.35 时不可兼得

同一批 N=8 采样，两个阈值：

| 模式 | θ | TPR | FPR |
|---|---|---|---|
| 高敏 | 8942 | **1.000** | **0.417** |
| 人绑 | 11224 | **0.017** | 0.017 |

**人绑模式的 TPR 只有 0.017——它几乎什么都不报。**

在低信噪比下，ROC 贴着对角线，**不存在"误报低且检出高"的工作点**。用户的担心被数据证实了：**噪音太大时，要么全报要么不报，双模式不成立。**

但注意：**两套读数来自同一次采样，共存的计算成本 = 0。** 问题不在成本，在信噪比。

## 六、决定性实验：差分读出 vs 绝对读出

注入真实周期负载制造漂移（0.4s 忙/0.4s 闲，真实线程）。

```
漂移极差 = 1525287 ns
信号真值 =     391 ns
漂移/信号 = 3904 倍
```

| 读出 | 判别力 |
|---|---|
| **绝对读出** | d' = **0.0032**（彻底失效） |
| **差分读出** | **0.3867**（TPR 0.890 vs 对照 0.503） |

**相差 120 倍。** 绝对值在漂移里被完全淹没，差分仍能把信号捞出来。

### 但差分不是万能的——它有适用条件

短实验（无漂移、白噪声主导）：

```
绝对 sd = 501 ns
差分 sd = 701 ns  ≈ 501 × √2
```

**差分反而升噪 √2 倍**（两个测量之差，方差相加）。此时绝对读出 d'=0.675 > 差分 0.491。

> **差分只在漂移占比大时才有利。** 又是一个"取决于世界"的结论（144/146/148/152/155 之后第七次复现）。

## 七、生物学对应（为什么生物都这么做）

- **视网膜**： ganglion cells 只对**变化**响应，恒定光照不产生信号。ON/OFF 通路。
- **事件相机**：每个像素只在亮度**变化**超阈值时发事件，静止场景零数据。
- **P50 感觉门控**：重复刺激的第 2 次响应被抑制 ~80%；精神分裂患者抑制失败 → 被自己的噪声淹没。

**三者是同一个机制：拒绝直流，只通交流。**

这也解释了 155 号磁场那格——**磁场不是"更强的传感器"，是只在漂移小于半个周期时才成立的校正**。越过带宽，它的模糊性会主动把你推上错分支。同构。

## 八、回答用户的三个问题

**① 「为什么不找那么敏感的」**
因为灵敏度在闪烁噪声下有硬上限。Allan 显示 m=4 之后斜率≈0；随机化后 d' 不随 N 上升。**换更灵敏的传感器，噪声会同步进来。**

**② 「噪音太大会毁」**
会。实测漂移可达信号的 **3904 倍**，此时绝对读出 d'=0.0032，等效全瞎。而且双模式在 d'=0.35 时就已不可兼得（人绑模式 TPR 0.017）。

**③ 「两种模式都可以做吗」**
可以，但**不是两种阈值，是两种读出**：
- **高敏（给自己）**：差分 raw，逐拍，快、噪、但能捞信号
- **人绑（给人）**：长窗口聚合，报趋势/符号，慢、稳、可解释

**两者共用同一次采样，切换成本 = 0 次额外测量。** 关键在于它们报的是不同时间尺度的东西——这跟阈值扫描不是一回事。
