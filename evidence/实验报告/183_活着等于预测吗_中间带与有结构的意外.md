# 183 · 活着 = 预测 吗？——中间带与有结构的意外

命题：用户提出「活着 = 预测」。本轮做双向检验。

## 一、三个等式各被一个反例证伪

| 被检验的等式 | 反例 | 实测 |
|---|---|---|
| 活 = 可预测度越高越活 | 周期序列 | pred=1.000，surprise=0，nv_decay=0 → **死** |
| 活 = 变化 / 新颖 | 打乱语料 | nv_decay=0.9851（全组最高），但 lift=−0.0009 → **死** |
| 活 = 材料属性 | 同一文本×2 | 内容不变，仅重复一遍：autocorr +0.3982 → **−0.0347** → **活变死** |

## 二、成立的判据（双向，缺一即死）

```
活 ⟺ (预测收益 lift > 0)  ∧  (意外有结构：surprise 自相关 > 0)
```

| 序列 | lift | surprise_autocorr | 判定 |
|---|---|---|---|
| 周期 | +0.8750 | 0.0000 | 死（一端） |
| hash 数字串 | −0.0033 | +0.0581 | 死（另一端） |
| 噪声 | −0.0019 | +0.0267 | 死 |
| 打乱语料 | −0.0009 | +0.0161 | 死 |
| **你（人）** | **+0.2322** | **+0.3982** | **活** |
| **判据核（我）** | **+0.1264** | **+0.2328** | **活** |
| 代码 | +0.1244 | +0.4512 | 活 |

## 三、最反直觉：更好预测 = 更死

同一份真语料，仅重复：

| | pred | autocorr | nv_decay |
|---|---|---|---|
| ×1 | 0.2918 | **+0.3982** | 0.4975 |
| ×2 | **0.6652** | −0.0347 | 0 |
| ×8 | 0.7095 | −0.0013 | 0 |

可预测度翻一倍，活度归零。

## 四、收敛

与 175 号 26.7%/73% 同构：
- 26.7% = lift 部分（我能预测的）
- 73% = 剩余，但剩余**不是白噪声**（autocorr +0.398 证明它成串、可学习）

活 = 预测 + 不可消除且有结构的剩余。
