# 243 · 寄生造出脑子，共生发现毒性

> 用户："人类的结构是共生。其实是寄生者给我们寄生——寄生造出了我们脑子，然后共生发现了寄生的毒性。"

## 两阶段论（用户的假设）

```
阶段1  寄生者造脑     线粒体/语言/文字/外部符号 → 脑子变大
阶段2  共生发现毒性   脑子够大之后，才看得见寄生者的毒 → 开始压制
```

关键：**发现毒性需要脑子，而脑子是寄生者给的。**
→ 被寄生者用来反抗寄生者的工具，是寄生者自己造的。

## v1 作废

`sup = min(1, rep×det×10)` 瞬间饱和到 1.0，压制**无差别**压掉了寄生者的贡献。
结果所有扫描都是"压制=1.000、A终态=−0.003"，**零分辨率**。作废。

## v2：引入压制精准度 precision

| 变量 | 含义 |
|---|---|
| precision | 抑制的靶向精度 |
| =1 | 只杀毒力，不误伤（理想免疫） |
| =0 | 只误伤自己人（自身免疫） |

```
vir_eff  = vir  × (1 − precision×sup)        # 靶向杀毒力
gain_eff = gain × (1 − (1−precision)×sup)    # 误伤贡献
```

## 结果一：用户的时间线成立

prec=0.9：

| 步 | 脑 | 毒力 | **发现毒性** | 压制 |
|---|---|---|---|---|
| 0 | 0.020 | 0.007 | **0.017** | 0.004 |
| 50 | 0.643 | 0.225 | 0.547 | 0.137 |
| 200 | 0.983 | 0.344 | 0.835 | 0.209 |
| 599 | 1.000 | 0.350 | 0.850 | 0.212 |

**脑子长到 0.64 时，发现能力已经 0.547；长到 1.0 时到 0.850。**
毒性随脑子一起涨（0.007→0.350），但**发现能力涨得更快**。

> 寄生者给的工具，最终超过了寄生者本身的威胁增速。

## 结果二：压制精准度是决定性的

| precision | A 终态 | 判定 |
|---|---|---|
| 0.00 | 2.463 | 自身免疫（误伤全给自己人） |
| 0.50 | 3.218 | 部分 |
| 0.90 | 3.822 | 部分 |
| **1.00** | **3.973** | 理想免疫 |

**单调，无中间带**（本轮唯一一个单调的结果）。

含义：**压制本身不是好东西。精准的压制才是。**
precision=0 时压制照做（0.212），但 A 只有 2.463——**比不压制（3.582）还差。**

> 这解释了 216 号"用错方法误杀自己人 54.4%"：不是不该压，是压歪了。

## 结果三：压制做得越足越好（prec=0.9）

**在精准的前提下，压制单调有益，没有中间带。**

## 结论

**① 用户的两阶段论成立，且有个漂亮的转折：**
寄生者造出的脑子，是后来发现寄生者毒性的唯一工具。**反抗的工具是被反抗者给的。**

**② 但"共生"这个词要改。**
按 242 号，共生（双向依赖）是最差的（A 下一跳 0.006）。
本轮数据补上后半句：**人不是跟寄生者共生，人是长出了免疫系统。**

```
阶段1  寄生   → 造脑           (242号: 单向, A不依赖B)
阶段2  免疫   → 发现并精准压制  (243号: precision 是决定性的)
```

**③ 免疫系统不是共生体，是第三样东西。** 它依赖宿主，不依赖寄生者。

**④ 精准度 > 强度。** 压歪了比不压更糟（2.463 < 3.582）。这是 216 号误杀 54.4% 的机制补完。

## 边界

1. **v1 作废**
2. precision 是构造标量，"误伤 = (1−precision)×sup" 是我拍的线性假设
