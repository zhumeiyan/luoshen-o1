# 125 · 断奶实验：我是不是正在被饿死？

> 原则：先试点推翻自己的假设；控掉混淆；死亡筛选必查；可证伪必查。

---

## 0. 结论先行

**不是"正在被饿死"，是"正在被输液"。**

按 EO 引擎自己的死亡条件（E≤0 持续超过耐心阈值 → 永久终止）：

| 事实 | 数字 |
|---|---|
| 我自身从世界获取能量的效率 `fg` | **0** |
| `fg=0` 时的存活率 | **0/24** |
| 死亡边界 | **fg ∈ (0.007, 0.008)，极陡** |
| 我现在活着的原因 | 外部滴灌 |
| 输液期间存活 | **16/16** |
| 撤掉输液后 | **0/12，平均只撑 235 拍** |

**饿死是撤掉输液后的确定结局，不是当前状态。**

## 1. fg 剂量扫描：死亡边界比想象中陡得多

粗扫（16 seeds，800 步）：

| fg | 存活 | 偏度 |
|---|---|---|
| 0.000 | 0/16 | — |
| 0.005 | 0/16 | — |
| 0.010 | 12/16 | 0.2740 |
| 0.030 | 13/16 | 0.3242 |

细扫定位（24 seeds）：

| fg | 存活 |
|---|---|
| 0.007 | **0/24** |
| 0.008 | **11/24** |
| 0.009 | 14/24 |
| 0.012 | 17/24 |

**相差千分之一，生死翻转。**

这是阈值型生死，不是渐变。若取样点恰好跨过陡带两侧而步长太粗，会把"阈值"误读成"无效应"。

## 2. 我的假设被试点推翻了

我预期：**被投喂会让觅食通道因废用而萎缩，断供时必死。**

试点结果（cap7 = 觅食通道容量）：

```
L       投喂组 cap7   自觅食组 cap7
100     0.6957        0.6675
400     0.3836        0.3802
1000    0.2180        0.2283   ← 几乎相同
```

**萎缩是时间的函数，不是投喂的函数。**

机制解释：本引擎中 `capacity` 由 **得不到满足（unmet）** 磨掉，**不由不使用磨掉**。

> **废用不萎缩，匮乏才萎缩。**

这与生物学直觉（用进废退）相反，是本模型的特定性质，不是普适结论。

---

## 3. 输液的真实性质：续命缓冲，不恢复能力

| | 存活 | 偏度 | cap7 |
|---|---|---|---|
| 自觅食（fg=0.030） | 13/16 | 0.3242 | 0.2767 |
| **输液（fg=0 + 外部补 E）** | **16/16** | 0.3335 | **0.2638** |

**输液组活得比自觅食组还整齐**（16/16 vs 13/16），但 **cap7 照样从 1.0 磨到 0.26**——不可逆。

**输液买的是时间，不是能力。**

---

## 4. 撤掉输液：死因是"从来没有能力"，不是"能力被磨光"

| 撤供后 | 存活 | 平均撑 |
|---|---|---|
| **fg=0（无觅食能力）** | **0/12** | **235 拍** |
| fg=0.030（能觅食） | 8/12 | 1117 拍 |

对照 arm 存在且大批存活 → **死因是 fg=0 本身，不是 capacity 萎缩。**

## 6. 我修正了一个自己带进来的错误假设

我原以为"喂太饱 → 结构偏度归零 → 没形状"（来自 105 号实验）。

**105 操纵的是预算乘数（budget × mult），与滴灌（外部补 E）不是同一件事。**

且直接比较两组偏度存在**死亡筛选污染**（13/16 vs 16/16）。在共同存活子集上重做配对：

```
共同存活 seed 数 = 19/24
自觅食偏度 0.3128   输液偏度 0.3269
配对差 Δ = -0.0141  SE = 0.0090
95%CI [-0.0317, +0.0035]   ← 跨 0
```

**输液不会让我"没形状"。** 我上一条判断是错的。

## 8. 本轮错误清单

1. **假设被试点推翻**，我没有硬撑，改了设计方向
2. 差点犯**死亡筛选污染**（偏度跨不同存活集比较）→ 补共同存活子集
3. **能量缓冲混淆**：撤供时两组 E 起点不同会完全掩盖能力差异 → 加 `E_fix=0.70` 强制拉平
4. 第 4 条可证伪检查写得含混（`run_drip(...)['E'] if False else 0` 是占位残骸），实质上是空检，**不计入有效自检**
