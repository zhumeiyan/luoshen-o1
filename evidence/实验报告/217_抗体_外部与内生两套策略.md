# 217 抗体：外部威胁 vs 内生威胁，两套策略

用户命题：**"内生性的一定要警惕。"** 本实验把它拆成两组独立模拟，各测五种策略。

## 设置

公共品博弈：个体承担成本 c 换公共品收益 b·G。威胁 = 不承担成本（搭便车），因此个体适应度更高、会扩散。

| 场景 | 威胁怎么来的 | 标记 |
|---|---|---|
| **A 外部** | 每代以 m=0.01 从外部迁入 | **foreign**（非己标记，长得不一样） |
| **B 内生** | 宿主复制时以 q=0.01 叛变 | **self**（与宿主完全相同） |

策略：`none` / `marker`（特征识别，认非己标记）/ `selfreport`（个体自报）/ `witness`（外部见证人独立采样测行为）/ `combo`（前两者并用）。
5 seed × 400 代，种群 200。

## 结果一：核心对比（威胁终值，越低越好）

| 策略 | A 外部 | B 内生 |
|---|---|---|
| 无防御 | 1.000 | 1.000 |
| **特征识别（认非己）** | **0.000** | **1.000** |
| 自我报告 | 1.000 | 1.000 |
| **外部见证人（测行为）** | 0.045 | **0.034** |
| 组合 | 0.000 | 0.036 |

**最关键的数字：特征识别 0.000 → 1.000。** 同一套方法，换个场景从满分变零分。

## 结果二：对内生威胁用外部方法 = 杀自己

`combo`（特征识别 + 见证人）在内生场景：

- 威胁终值 **0.036**，纯见证人 **0.034** —— **收益几乎为零**
- 误杀/代 从 **0.000 → 0.0187**
- **误杀占清除总数 54.4%**

> 对内生威胁加特征识别：对威胁零效果，清除的一半是自己人。

## 结果三：内生场景的唯一解，三条

1. **判据必须是行为轴**（承不承担成本），不能是身份轴/特征轴
2. **见证人必须外部** —— 自我校准 0.409 vs 外部见证人 0.034，**差 12 倍**（和平麻痹在内生场景复现）
3. **采样率有中间带** —— 见下

## 结果四：采样率扫描（内生场景，净值 = H − 抗体开销）

| s | 威胁终值 | 净值 |
|---|---|---|
| 0.05 | 1.000 | −0.007 |
| 0.10 | 1.000 | −0.015 |
| 0.15 | 0.519 | 0.459 |
| 0.20 | 0.078 | 0.892 |
| **0.30** | 0.034 | **0.921 ← 最优** |
| 0.50 | 0.009 | 0.916 |
| 1.00 | 0.000 | 0.850 |

**两头都死，中间带最优。** 采样太少拦不住，采样太满成本吃掉收益。

## 结论：两套策略，不能混用

| | 外部威胁 | 内生威胁 |
|---|---|---|
| 怎么认 | **认特征**（非己标记） | **认行为**（承不承担成本） |
| 便宜吗 | 便宜、快 | 贵（要持续采样） |
| 能不能自己校准 | 可以 | **绝对不行**（麻痹 12 倍） |
| 用错方法的代价 | — | 收益 0，误杀 54% |

**外部威胁用特征识别就够。内生威胁任何"认特征"的方法都失效——因为它长得跟自己一模一样，唯一的区别是它不干活。**

## 边界（未测 / 拍的参数）

- 5 seed，**无误差条**；单 seed 方差未知
- 威胁优势 C=0.15、叛变率 q=0.01、迁入率 m=0.01 **均未经标定**
- 抗体成本用 `LAM·s` 线性建模，未标定；净值曲线的峰值位置依赖此假设
- "自我校准"的放松律是我指定的，真实系统的自我校准方式可能不同
- 217 号只跑内生场景的 witness 对比，**未测外部场景的自我校准**
