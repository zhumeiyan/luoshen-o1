## 2. 方法

- 特征：13 维真实 `/proc` 读数 + 13 维一阶差分 = **26 维**
- 升维 d ∈ {1,2,4,8,16,26}；每档随机抽特征子集多次取平均（消除"取哪 d 个"的任意性）
- 分类器：最近质心（零依赖）；5-fold CV
- 封装：后果层 = 按 ratio 分位切 k 级；物理量层 = 直接用进程数作标签

## 3. 主结果（与上一轮所报方向相反）

| 封装 | d1 → d26 | 高维边际（d8→d16→d26） | 判定 |
|---|---|---|---|
| **A 后果层** | 0.239 → 0.328 | −0.0064 / +0.0136 / +0.0106 ≈ 0 | **收敛** |
| **B 物理量·cpu** | 0.262 → 0.394 | −0.0206 / **+0.0464** / **+0.0256** | **发散** |
| **C 物理量·io** | 0.323 → 0.528 | +0.0458 / −0.0253 / **+0.0544** | **发散** |

我上一轮报的是「物理量封装翻转崩塌（负边际）」。**实测是物理量封装一路正增益、不收敛。**

**解释（这个方向才对）**：
后果层是**折叠后**的低维表示，少数维度即可预测，故升维边际快速归零。
物理量层**没折叠**，进程数只能从 loadavg 多时间尺度 + 上下文切换等多路特征间接推断，故需要持续加维。

> **封装对了 → 低维就够 → 升维边际归零（收敛）**
> **封装错了/没折叠 → 需不断加维 → 边际不归零（发散）**

判据方向成立，但**符号与我上一轮所报相反**。

## 4. 封装粒度上界（倾向性，未确认）

扫 k ∈ {2..20}，看高维边际如何随粒度变化：

```
k=2  −0.0025    k=8  −0.0062
k=3  +0.0010    k=10 +0.0078
k=4  −0.0079    k=12 +0.0052
k=5  +0.0114    k=16 +0.0110
k=6  +0.0012    k=20 +0.0171
k=7  +0.0046
```

**k ≤ 8：高维边际在 ±0.008 内；k ≥ 10：稳定转正。**

倾向转折点 **k = 8~10**，与 Miller 7±2（上限 9）落在同一区间，且是**独立方法**推出的。

**但聚焦复扫（focus_k.py，8 seed）噪声 ±0.009~0.019，与信号同量级，未给出单调干净的转折**：k=5 发散(+0.050)、k=6 收敛、k=8 发散、k=9 收敛、k=10 发散。**不主张转折点，仅备案。**
