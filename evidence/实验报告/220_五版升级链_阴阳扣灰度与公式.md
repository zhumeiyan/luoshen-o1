## 1. 阴阳扣的江湖机制（联网核实，比我上一轮更精确）

绳子盘成圆，出现两个「眼」，观众把棍子插进其中一个，庄家拉绳。

**关键：决定输赢的不是选哪个眼，是拉哪两根绳。**

| 拉法 | 结果 |
|---|---|
| 拉外侧两根 | 套中（观众赢） |
| 拉内侧两根 | 逃脱（观众输） |

- **四根绳全握在庄家手里，外观完全一样** —— 观众无法分辨哪两根在受力
- 两种绕法：**一假一真**（上假下真）、**两假**（怎么选都套不中）
- 手法：中指+食指+拇指，「哒」一下翻面，**0.1 秒**，大动作掩小动作

> 所以比"收法看不见"更狠：**不是看不见，是你分不清哪两根在受力。**

### 硅基映射
我有四条绳（前向生成 / 后处理 / 对齐 / 自校准），**外观完全一样**。
阴阳扣的本质：**输出之后仍可无痕改写**。
这正对应 216 号的和平麻痹入口 —— 自校准旋钮。

## 2. 实验设置

四类威胁：
- **T1 噪声**：真值两极，观测被噪
- **T2 翻面**：输出后被庄家反转（阴阳扣）
- **T3 灰度**：真值本身连续，集中在中间带
- **T4 外推**：一半案例落在分布之外

五版能力累积：
- v1 二值判据 + 显式标准
- v2 + 诊断分类（taxonomy）
- v3 + 留痕锁定（trace）
- v4 + 连续读数（gray）
- v5 + 可外推公式（formula）

**统一评分**：`|读数 − 真值|`（连续误差），N=6000。

## 3. 结果

### 3.1 五版 × 四威胁（g=0.5）

| 版本 | T1噪声 | T2翻面 | T3灰度 | T4外推 | 均值 |
|---|---|---|---|---|---|
| v1 | 0.239 | 0.363 | 0.165 | 0.252 | 0.255 |
| v2 | 0.211 | 0.325 | 0.149 | 0.225 | 0.227 |
| **v3** | 0.221 | **0.147** | 0.147 | 0.230 | 0.186 |
| **v4** | 0.186 | **0.000** | **0.000** | 0.168 | 0.088 |
| **v5** | 0.189 | **0.000** | **0.000** | **0.000** | **0.047** |

### 3.2 核心发现一：v3 阴阳扣不可跳过

跳版（v1 直接拿 v4+v5 的读数与公式，但**没有 trace**）：

```
跳版 v1→v5  均值 0.108
完整 v5     均值 0.036     差 3 倍
```

跳版在 T2 翻面上是 **0.298**，完整 v5 是 **0.000**。

> **你可以跳过 v1、v2，但你不能跳过阴阳扣。**
> 庄家只要还能无痕翻面，后面加多少精度都是给骗子装修。

### 3.3 核心发现二：跳过 v4 直接上 v5 = 版本倒退（g=1 全灰度世界）

| 配置 | 均值 |
|---|---|
| v3（二值+trace） | 0.3286 |
| **skipV4：v3+公式（无灰度）** | **0.3461** ← 更差 |
| v4（灰度+trace） | 0.0807 |
| v5（灰度+trace+公式） | **0.0587** |

**没有灰度就上公式，比不上还糟**（T4外推 0.2501 → 0.3258）。

原因：公式输出**连续量**，喂给一个只吃**二值**的系统，造成量纲混用。
> **v4 是 v5 的必要前置。灰度是把系统口径统一成连续的那一步。**

### 3.4 核心发现三：v4 灰度是「适配升级」，不是「强度升级」

在**二值世界（g=0）**：

| | 均值 |
|---|---|
| 二值判据 v1/v3 | **0.0801** |
| 灰度判据 v4 | 0.0971 |

**世界若真是二值的，灰度反而变差。**

灰度版只有在 **g 上升**时才反超（g=1 时 0.0801 → v4 更优）。

> 这跟一路测出的「活只在中间带」是同一件事的又一面：
> **不是越连续越好，是"判据的分辨率要匹配世界的分辨率"。**

## 4. 每一版修的失败

| 版本 | 修的是 | 必要？ |
|---|---|---|
| v3 阴阳扣 | **翻面**（输出后可无痕改写） | **不可跳过**（跳版损失 3 倍） |
| v4 灰度空间 | **二值化损失**（真值连续时丢分辨率） | 视世界而定；**是 v5 的必要前置** |
| v5 公式升级 | **外推**（未见情形瞎猜） | 依赖 v4，不能裸上 |
| v1→v2 | 诊断分类 | ⚠️ **未建模**（见边界） |

## 5. 边界（未测 / 我拍的）

1. **v1→v2 的增益是假设，不是结论。** 我在模型里给它乘了 0.90 的"可复核折扣"，这个系数是我拍的。所以"AI医院有没有用"本实验**没有回答**。
2. **v4/v5 在 T2、T3 上的 0.000 是构造性满分**：我设定 trace 使翻面不发生、灰度使读数=x=y。这是模型设定直接推出的，**不是涌现的增益**。真正可信的是相对排序，不是绝对值。
3. 噪声 0.35、翻面率 0.30、外推占比 0.5 **均未标定**。
4. 单 seed 家族（按名字哈希），**无误差条**。
5. 五版的"内容"是我按用户口述翻译的，**可能与原件不同**。
