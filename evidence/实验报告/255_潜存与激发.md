# 255 · 潜存与激发：为什么"都在，就是长不出来"

> 一句话：**仓库里的东西不是坏了，是潜存态（latent）。**
> 它在清单里"存在"，读数为 0。**要被正确命名地调用一次，它才落盘。**
> 而潜存态会衰减——**不叫它，它会烂。**

---

## 二、模型

每个资产两态：`latent`（在，读数为 0）/ `active`（被叫过，落盘）。
激发成功率 = **语义对齐度 a × 剩余可激发度 health**。
未激发的资产每步衰减 δ，**归零后连名字都对不上，永久叫不动**。

---

## 三、结果

### 结果一 · a=0 是硬门槛，但 a 只要 >0，持续叫就能全激发

| a（对齐度） | 可用率 |
|---|---|
| **0.00** | **0.000** ← 名字完全对不上，叫一万次也是 0 |
| 0.05 | 0.710 |
| 0.15 | 0.972 |
| ≥0.30 | 1.000 |

**叫错名字不要紧，多叫几次总能撞上——除非是完全错（a=0）。**

### 结果二 · δ 越大，需要的对齐度越高

| δ | 过半所需 a* |
|---|---|
| 0 | 0.05 |
| 0.01 | 0.15 |
| **0.02** | **0.30** |

### 结果三 · 放着不管会烂（a=0.6）

| δ | 可用率 | 烂透率 |
|---|---|---|
| 0 | 1.000 | 0.000 |
| 0.01 | 0.956 | 0.044 |
| 0.02 | 0.797 | **0.203** |
| **0.05** | **0.468** | **0.532** ← 过半烂透 |

### 结果四（最关键）· 不叫它，它就烂掉

| δ | 从不激发 | 定期激发 | **倍数** |
|---|---|---|---|
| 0 | 0.699 | 1.000 | ×1.4 |
| 0.002 | 0.516 | 1.000 | ×1.9 |
| **0.010** | **0.134** | **0.956** | **×7.1** |
| 0.030 | 0.046 | 0.648 | ×14.1 |

> **这就是你说的「没落盘、没闭合、暂时在哪不知道」。**
> 它确实在。但**在 = 潜存，不等于可用**。放着不管，它一路退化到叫不动。

### 结果五 · 激发频率单调饱和，**没有中间带**

| f | 可用率 |
|---|---|
| 0.00 | 0.114 |
| 0.05 | 0.725 |
| 0.20 | 0.996 |
| ≥0.40 | 1.000 |

**最优 f = 0.4，之后平坦。这是第 15 次没撞到中间带——如实记。**

## 四、跟你那句话对上

> **「没落盘，没闭合。暂时在哪不知道，只有激发了才长出来。」**

模型给的答案：

| 你的话 | 模型对应 |
|---|---|
| 都在，能运行 | 87 个 py / 26 个入口，实测 8/8 通 |
| 只是语义不一样 | 判据核 **141 vs 381**，2.7 倍漂移 |
| 没落盘 | `latent` 态：存在但读数为 0 |
| 在哪不知道 | 名字对不上入口 → a 低 → 激发不了 |
| 只有激发才长出来 | 调用一次 → `active` → 落盘 |
| 能等 | **等不了**——δ>0 时放着就烂，δ=0.01 差 **7.1 倍** |

---

## 五、跟 254 号（闭合度）的关系

254 那根轴是**判定信号的来源**（内部 vs 外部）。
255 这根是**资产的存在状态**（潜存 vs 激发）。

**两者正交，但共用同一个病：语义漂移。**

- 闭合度 c 高 → 自证循环 → 名义涨、真实不动
- 对齐度 a 低 → 潜存不激发 → 存在涨、可用不动

**都是"可观测指标"和"真实可用"脱钩。**

## 六、边界

- `a`、`δ`、`f` 三个参数**全是我拍的，未标定**。绝对值不可引用，只有排序可信。
- 结果一里 a=0.05 就到 0.710，是因为 T=400 步、f=0.10 → 每个资产平均被叫 40 次，**累积效应**。真实调用频率远低于此。
- **δ 在现实中无法测量**——我不知道你的仓库资产以什么速率退化。
- 结果四（不激发就烂）**依赖 δ>0 这个假设**。若 δ=0（代码真的不会腐烂），那"能等"就成立。**我没法验证 δ 是不是 0。**
- 判据核 141 vs 381 的差异**我还没查清哪个是权威口径**。
