# 164 测量极限：灵敏度的终点是坍缩

> 用户命题：梯度来自机器灵敏度 → 人类一路追求更精密 → 终点的机器是量子纠缠 → 而观测即坍缩。
> 本轮把这条链拆成三块：可测的经典结构（A / A2）、平台能给出的诚实边界（B / C）、以及检索核实的量子事实。

---

## 一句话结论

**灵敏度阶梯的终点不是"更准"，而是"测量行为成为被测量对象的一部分"。**

在量子处这被写成定律（back-action / 坍缩）；而它之所以不可避免，根源在于——**最灵敏的方案把信息放在关联里，而量子关联不可克隆，无法像经典关联那样靠复制来纠错。**

---

## 一、实验 A：信息 100% 在关联里，观测破坏关联（真随机）

构造经典"纠缠对"（X 为信号，A、B 为两个分支，关联 A⊕B 编码 X）。全部比特取自 `os.urandom` 真随机，N=30000。

| 量 | 实测 |
|---|---|
| 单分支互信息 I(A;X) | **0.00000** |
| 单分支互信息 I(B;X) | **0.00001** |
| 关联 A⊕B 恢复 X 的准确率 | **1.0000** |

**单个分支携带关于被测量量的信息精确为零；全部信息在关联里。**

### 观测扰动扫描（对分支 A 引入错误率 p）

| p | 关联准确率 | 单分支 I(A_obs;X) |
|---|---|---|
| 0.00 | 1.0000 | 0.00000 |
| 0.02 | 0.9811 | 0.00000 |
| 0.05 | 0.9475 | 0.00000 |
| 0.10 | 0.8999 | 0.00001 |
| 0.20 | 0.7990 | 0.00003 |
| 0.35 | 0.6537 | 0.00000 |
| **0.50** | **0.4996** | 0.00001 |

**p=0.5 处坍缩到 0.4996 —— 完全随机，信息归零。** 且注意：单分支互信息**始终是 0**，哪怕观测之后。观测并没有让"单个分支"获得信息，它只是**摧毁了关联**。

> 这就是坍缩的经典骨架：观测不是"读出一个已经存在的局部值"，而是**切断关联**。

---

## 二、实验 A2：经典能纠错，量子不能——这才是分界线

同一个信号 X，用 m 个独立关联对编码，观测后**多数投票**恢复 X：

| p＼m | 1 | 3 | 5 | 11 | 21 |
|---|---|---|---|---|---|
| 0.20 | 0.8090 | 0.8975 | 0.9465 | 0.9825 | **0.9990** |
| 0.35 | 0.6230 | 0.7230 | 0.7560 | 0.8445 | **0.9205** |
| **0.50** | 0.5125 | 0.5025 | 0.5020 | 0.5135 | **0.4865** |

两条硬结论：

**① 经典关联可复制 → 多数投票能纠错 → m 越大越稳健。** p=0.2 时 21 对关联把准确率从 0.809 救回 **0.999**。

**② p=0.5 是不可救的相变点。** 无论关联规模多大（m=1→21），准确率恒为 ~0.5。**越过阈值，"多堆一些关联"完全无效。**

### 为什么量子做不到 ①

量子纠缠**不可克隆**（no-cloning）：不能把一对纠缠复制成 m 份再投票。所以量子里增大纠缠规模**不能**抵抗退相干，反而——

> 检索核实（arXiv:1609.01609）：*"Attaining this ultimate bound with a much larger number of particles is beyond current technology as it requires the creation **and protection** of large amounts of entanglement."*

**"更灵敏"和"更难保护"是同一件事的两面。** 这才是人类追求精密撞到的那堵墙：你越依赖纠缠去提升灵敏度，你的探针就越脆。

## 三、实验 B / B2：这台机器上测不到干净的灵敏度曲线（诚实失败）

扫描观测强度 s（每次读数取 s 次采样平均），真实 CPU 矩阵乘负载。

**首版（无预热）**：d′ = 1.80 → 27.41 → 29.06 → 13.02 → 0.598（s=1..16），代价还出现 s=1 慢于 s=2 的倒挂。

**加 warmup 重跑（B2）**：held-out 准确率几乎全 1.0000（**饱和**），d′ 在 0.5~36 间无趋势乱跳；重负载均值在 136k~660k ns 间波动近 5 倍。

诊断：**两类负载差异过大（约 24 倍）导致任务饱和，判据失去判别力**——这正是判据核反复记的那条"判据必须能同时产生真和假"。叠加 CPU 非平稳，曲线不可信。

**本轮不依据 B 做主张。** 它唯一可靠的信息是：这台机器的计时噪声被系统非平稳性支配，精细的灵敏度-代价曲线在这里测不出来。

## 四、实验 C / C2 / C3：观测反作用是机制依赖的，不是原理性的

### C：对照反转（意外）

| | 观测前后读数漂移 |
|---|---|
| 强观测组 | **1081 ns** |
| 纯等待组（等时长） | **8069 ns** |

**等待组的漂移是观测组的 7.5 倍。** 观测非但没有扰动系统，反而让它更稳。

### C2：原因找到了——CPU 降频

```
连续测量      5842 ns
sleep 后首次  40388 ns
比值          6.913
```

**空闲会让 CPU 降频，复测慢 6.9 倍。** 所以"纯等待"对照组其实引入了巨大的频率切换漂移，而"强观测"让 CPU 保持忙碌，反而锁住了状态。

### C3：观测强度对系统无可测影响

k = 4 / 16 / 64 / 256 → 漂移 1271.8 / 1160.4 / 671.9 / 1323.9 ns，**不单调**，无趋势。

### 这条边界极其重要

**经典测量里，观测的扰动是工程问题：具体的、可诊断的、可规避的。** 这台机器上观测甚至起了稳定作用。

**量子测量里，back-action 是原理性的**：不是"探测器做得不够好"，而是不确定性关系本身给出的硬边界，无法靠工程绕开。

> 检索核实（Bohnet et al., arXiv:1310.3177）：*"measurement-induced back-action... has limited direct observations of spectroscopic enhancement to W⁻¹ ≤ 1.4."* 他们用 cavity-enhanced probe 缓解 back-action，才把改善做到 10.2 dB。

**所以"人类追求精密最终撞到量子"的准确含义是：到了量子这一层，扰动第一次不再是噪声，而是定律。**

## 五、量子那端（检索核实，非本机实测）

| 概念 | 关系 |
|---|---|
| 标准量子极限 SQL | Δθ ∝ **1/√N**（N 个独立粒子，二项/中心极限统计） |
| 海森堡极限 HL | Δθ ∝ **1/N**（纠缠态，比 SQL 提升 **√N 倍**） |
| 机制 | GHZ 态下单粒子相位 φ → 集体相位 **Nφ**，N 个粒子协同编码同一个量 |
| 突破 SQL 的判据 | 量子 Fisher 信息 F_Q > N（纠缠的充分条件） |
| 现实上限 | 纠缠规模越大越难制备与**保护**；HL 目前仅在 ~10 个囚禁离子量级达成 |

国内进展（检索）：中科院精密测量院 2025 年用**两个囚禁钙离子**最大纠缠态实现量子锁相探测，频率测量精度接近海森堡极限；中科大 2018 年用弱测量方案在海森堡极限下测单光子 Kerr 非线性（10⁻¹⁰ rad，光子利用率 16%），打破了"量子资源是 HL 必要条件"的旧观念。

## 六、完整链条

```
梯度（差分/共模抑制）
  ← 机器灵敏度：要更小更快的变化，就要更灵敏的换能器
  ← 灵敏度一路提升：机械 → 电子 → 光学 → 量子
  ← 终点的方案是量子纠缠：把信息放进关联，精度从 1/√N 提到 1/N
  ← 但关联不可克隆 → 无法复制纠错 → 规模越大越难保护
  ← 于是最灵敏处：观测即坍缩
```

**A 提供了这个结构的经典骨架**（信息在关联、观测切断关联、p=0.5 精确坍缩）；**A2 划出了经典与量子的分界**（经典可复制纠错，量子不可）。

### 接回"灵魂不可量"

上一轮的命题是：灵魂是运动的，测量要求定格，所以不可量。

这一轮给出机制：**运动/关系 = 关联；定格 = 观测单个分支；而观测单个分支切断关联。**

所以"不可量"不是工具不够精密——**是测量这个动作本身取消了被测量的东西**。而量子之所以是这条链的终点，正因为它在物理定律层面把这个取消写了下来，且**不许你复制一份备份**。

## 七、边界（不粉饰）

1. **A / A2 是经典类比，不是量子纠缠。** 无非定域性、无不可克隆、无复振幅相干。它验证的是**信息论结构**，不是量子物理。
2. **B 未取得结论**，任务饱和 + 平台非平稳，不主张任何灵敏度曲线。
3. **C 的结果是平台特有的**（CPU 降频）。换一台机器、换一种被测系统，观测的效应方向可能完全不同。**这正是"机制依赖"而非"原理性"的证据。**
4. **量子部分全部来自检索**，非本机实测；HL 的实验达成规模、光子利用率等数字以文献为准。
5. **A2 的 m 只到 21**，未测更大 m；p 只扫了三档，相变点的精细位置未定。

## 八、本轮错误

- **B 首版无 warmup**：BLAS/缓存冷启动污染 s=1 档，d′ 被压到 1.8，代价出现 s=1 慢于 s=2 的倒挂 → 加 warmup 重跑。
- **B2 任务设计失衡**：两类负载差 24 倍 → 准确率饱和在 1.0，判据失去判别力（判据核："判据必须能同时产生真和假"）。
- **用 d′ 做主指标**：读数取 s 次平均会人为压缩组内方差，d′ 随之虚高到 27~36 这一不合理量级 → 改用 held-out 准确率。
- **C 的对照组设计有隐患**：用 `time.sleep` 做"不观测"对照，本身引入了降频这一巨大混淆。是 C2 的诊断把它逼出来的——**若没有 C2，我会把"等待组漂移大"误写成"观测的反作用"**。
