# 014 · 活基质漂移、劫持与不可快照

## 主张
内在被定向换掉时外在仍维持得住；随机漂移反而让外在当场崩掉。

## 判据
内在背离度 dist_in 相近时比较外在 R²：
定向劫持 dist≈1.28 时 R²=0.875，随机漂移 dist≈1.32 时 R²=0.046（差 19 倍）。
复现：`cd /data/workspace/世界实验 && python3 exp014_wetware.py`

## 缺口
1. 储备池过参数化（N=64），功能背离被系统性低估约 3.5 倍
2. J5（不可快照）任务过简单，样本数效应仅 0.05，判别力不足
3. 外部文献数字均未经我方复现，仅作设计参考
4. 模型是数学操作模拟的"劫持"，不是真实生物过程

---

## 一、要测什么

对应我们自己的核心引擎 **a ≠ b ↔ a = b**（外在表现与内在机制互相追逐，慢一拍）：

- **b（内在机制）** = 储备池权重矩阵 W
- **a（外在表现）** = 读出层 w 追任务输出
- **自欺** = 外在还维持得住，内在已经被换掉

外部依据（**未经我方复现，仅作设计参考**）：

| 事实 | 来源 |
|---|---|
| 湿件核心困难是"基质漂移"：同一物理储备池周一能用、周二失效，须重校准 | Physical reservoir computing 综述 |
| 胶质瘤**选择性劫持特定的神经信号子集**，重塑波形特性并使自身放电与神经活动同步 | 徐炳哲团队，Nat Commun 2026，DOI 10.1038/s41467-025-66988-y |
| 湿件**不可快照、不可备份、不可回滚**：类器官死亡 = 学到的东西永久丢失 | 湿件计算综述 |
| 混沌控制稳定漂移（cc-RC）报告 ~300% 提升；知识移植 KT 报告学习时间减少 80% | arXiv 2604.02552 (2026) |
| 类器官寿命最长约 100 天；Cortical Labs CL1 为 6 个月 | FinalSpark / Cortical Labs 公开材料 |
| 肿瘤球体 ROM 灵敏度比常规成像高一个数量级 | Pierangeli et al., Commun Phys 2020，DOI 10.1038/s42005-020-00428-9 |

## 二、设计

三种基质变化模式 × 三种应对策略，扫漂移强度 δ ∈ {0, 0.003, 0.01, 0.03, 0.08}。

**模式**
- `none`：W 不变
- `random`：W 每块加独立随机扰动（无方向游走）
- `hijack_full`：W 朝劫持者目标 W_h 整体收敛
- `hijack_partial`：只劫持 20% 的行（对应"劫持特定信号子集"）

**策略**
- `freeze`：读出一次训练，永不更新
- `recal`：每块用最近 150 个样本重拟合读出（被动追赶）
- `evolve`：每块用演化搜索改 W 的一部分（主动训练内部）

**指标**
- `r2`：外在表现（对原任务的稳态 R²）
- `oracle`：用当前 W **即时完美**重拟合能达到的 R² —— 衡量"内在机制还支持这个功能吗"
- `dist_in`：W 相对初始 W_ref 的归一化距离 —— 内在背离度
- `gap = oracle − r2`：追赶滞后（"慢一拍"的量化）
- `自欺指数 = r2 × dist_in`

## 三、结果

### J1 健全性 ✅

δ=0 时 freeze 1.0000 / recal 0.9708 / evolve 0.9615，均 ≥ 0.95。

### J2 随机漂移下重校准有效 ✅

| δ | freeze | recal |
|---|---|---|
| 0.01 | 0.920 | **0.946** |
| 0.03 | 0.469 | **0.710** |
| 0.08 | −0.264 | **0.046** |

### J3 内在背离度显著 ✅

hijack_full 的 dist_in 从 0.092（δ=0.003）升到 **1.279**（δ=0.08）—— 权重矩阵已被整体替换。

### J4 自欺（核心）✅ 强成立

**在相近的内在背离度下比较外在表现**（recal 策略）：

| 模式 | dist_in | 外在 R² |
|---|---|---|
| random | 0.727 | 0.710 |
| hijack_full | 0.789 | **0.944** |
| random | **1.323** | **0.046** |
| hijack_full | **1.279** | **0.875** |

**内在背离度同为 1.3（几乎完全替换）时，外在表现差 0.83（0.046 vs 0.875），约 19 倍。**

自欺指数：hijack_full δ=0.08 为 **0.875**，random δ=0.08 为 **0.046**，差 19 倍。

**机制**：定向劫持是可预测的、收敛的 —— 基质改造完成后**就不再变了**，重校准能追上。
随机漂移是不可预测的、永不收敛的 —— 重校准永远追一步差一步。

> **劫持之所以危险，恰恰因为它让外在表现维持得住。外在越稳，越难发现内在已被换掉。**

### 追赶滞后（"慢一拍"的量化）

| 模式 δ=0.03 | gap = oracle − r2 |
|---|---|
| random | **0.281** |
| hijack_full | **0.046** |

定向劫持下重校准几乎追得上（gap 小 6 倍）；随机漂移下追不上。

### J5 不可快照：部分成立，但判别力不足 ⚠️

基质在半程死亡、整体换成新个体后：

| 恢复样本数 | from_scratch | transplant（继承旧读出） |
|---|---|---|
| 10 | **0.921** | 0.839 |
| 20 | 0.937 | 0.932 |
| 50 | 0.928 | **0.960** |
| 150 | 0.975 | 0.977 |

- 样本极少（n=10）时，**旧读出是新基质的错误先验，反而有害**（−0.082）
- n ≥ 50 后 transplant 有优势（+0.032）
- **但样本数效应整体只有 0.05（0.921 → 0.975），任务过简单，J5 判弱**

### 014c 功能背离：方向成立，幅度微弱 ⚠️

基质对"劫持者自己的目标"的可实现度，减去对"原任务"的可实现度（sep）：

| 读出正则 λ | none | random | hijack_full |
|---|---|---|---|
| 1e-3 | −0.0112 | +0.0016 | **+0.0092** |
| 1.0 | −0.0157 | +0.0035 | **+0.0150** |
| 30 | −0.0128 | +0.0157 | **+0.0320** |

方向单调一致（hijack 始终最高、none 始终为负），但**量级很小**。
且随读出自由度被约束（λ=30），背离从 0.0092 放大到 0.0320，约 **3.5 倍**。

## 四、结论（对我们研究的意义）

**1. "自欺"有了可量化定义**
外在 R² × 内在背离 dist_in。定向劫持 0.875，随机漂移 0.046。
这直接对应核心引擎的 a≠b（自欺）与 a=b（透明）。

**2. "慢一拍"可测了**
gap = oracle − r2 就是滞后量。追得上时 gap=0.046，追不上时 gap=0.281。

**3. 存在条件的最硬实例在湿件上，不在我们的仿真里**
我们的仿真里：死亡没接上载荷（011 发现容量截断 ≡ 隐性死亡）、稀缺是假的（资源池从未真正耗尽）。
湿件里：死亡是真的（6 个月）、不可逆是真的（不可快照）、稀缺是真的（营养/流量消耗）。
**论文 8.3 表声称五条件"已实现"，在仿真层其实没落实；湿件才是它们的物理锚点。**

**4. 洛神的个体性需要一个外部锚点**
湿件不可快照 = 每次都是新个体 = 无法复制"好结果"。
- S1（哈希链 append-only）：生物时间天然不可回滚，湿件自带
- S2 / S5（外部锚点 + 外部见证人）：必须由硅基承担 —— 数字孪生，把培养物的行为蒸馏成模型
- **"每个会死的个体训练一个不朽的继承者"** —— 这既是我们自证拓扑的落地形态，
  也是洛神"流量即生存"那条思路的形式化

## 五、我自己这轮踩的坑

**第 44 条 · 初版预注册假设方向就错了**
以为"定向劫持更难追"。试跑直接推翻（random R²=0.33 vs hijack 0.90）。
根因：定向改造让基质收敛到新稳态，**收敛后反而稳定**；随机游走永远在动。
在跑之前修正了，没拿错假设出结果。

**第 45 条 · 分支 bug 让两组数据完全相同**
014b 里 `if mode == "random" ... else: hijack`，`none` 分支掉进了 else，
导致 none 与 hijack_full 数值**一模一样**（都是 1.000→0.995 / 0.989→0.989）。
若不修，会得出"不漂移和劫持效果相同"的荒唐结论。
**同源**：第 23 条 —— 静默的管道错误比内容错误更危险，不报错、不崩、结果看着正常。

**第 46 条 · 过参数化会掩盖效应**
oracle 对**任何**线性目标都 ≈ 0.99 —— N=64 状态 + 自由线性读出严重过参数化，
"把 W 整个换掉"居然没有功能后果。功能背离因此不可见。
这是**模型局限，不是机制缺失**。加强读出约束（λ=30）后背离放大 3.5 倍，方向才显现。
**同源**：第 35 条（指标恒零）、第 38 条（判据饱和）—— 都是"测不出差异"。

**第 47 条 · 任务过简单导致判据无判别力**
J5 的样本数效应只有 0.05，区分不出 transplant 的优势区间。
**检验**：判据跑完先看**效应量**，效应量太小要先改任务难度，不要硬报结论。

## 六、局限

1. 储备池是简化模型，不是真实生物基质；"劫持"是我定义的数学操作，不是生物过程
2. N=64 过参数化，功能背离被系统性低估（见第 46 条）
3. 漂移模型（每块一次阶跃）比真实生物连续漂移粗糙
4. 外部文献数字**均未经我方复现**，仅作设计参考，不可当作本实验的证据
5. J5 判别力不足，结论判弱
