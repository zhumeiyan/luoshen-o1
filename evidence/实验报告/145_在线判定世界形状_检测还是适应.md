# 145：能否在线判定世界形状，并据此切换记忆策略

## 问题

144 的结论：保持时间顺序是资产还是负债，**取决于世界的形状**。

```
monotone drift   d_order +0.0731   顺序是资产
square 周期      d_order -0.0387   顺序是负债
stationary       d_order -0.0030   跨 0，无信息
```

但 144 里"形状"是实验者已知的。**真实系统不知道自己处在什么世界里。**
本轮把这个发现从"描述"推进到"机制"：学习者只看过去的观测，自己判、自己选。

## 预注册

跑之前写死（PREREG.md），跑完只做对质：

- **H1 可判定**：只用过去的观测序列，能区分 drift 与非 drift；且 stationary 上判出率低（能产生假）
- **H2 可用**：ADAPTIVE 的下一步预测误差不劣于两种固定策略中较好的那个
- **H3 判别器不是装饰**：判定结果随机化的版本显著更差

## 一、V1 失败：判错了量（不是调参问题）

第一版判别器：对 Y 的历史序列做**斜率显著性检验**，|t| > 2 判为 drift。

结果：monotone 世界判出率只有 **0.039**。调整阈值 1.0→4.0 全扫：

```
theta 1.0   monotone 判出率 0.343   但 stationary 误判 0.385
theta 4.0   monotone 判出率 0.000
```

**既不够灵敏也不够特异——这是量本身的问题，调阈值救不回来。**

诊断（这一步是决定性的）：

```
Y 的 std = 2.24
其中随机特征 X 贡献 ≈ 2.24，噪声 0.15
Y 序列的趋势 t 统计量 = 0.137  (阈值 2.0)
```

**Y 的方差几乎全部来自随机特征 X。权重 w 的漂移，在 Y 的边际分布里根本不可见。**

> 判一个量的趋势之前，先做方差分解，确认这个量真的携带你想检测的信息。
> 否则判据会稳定地输出一个答案——而稳定输出单一答案的判据不是判据。

V1 照报，不删。

## 二、V2 也失败：残差趋势

改用全历史拟合后的**残差**序列做趋势检验。monotone 判出率 0.105，仍是量级不足。
同样照报。

## 三、V3 通过：不判形状，直接让专家竞争

放弃"识别世界是什么形状"，改成：**维护两个专家（ALL / RECENT），在最近 M=24 步上比回溯预测损失，选赢家。**

它只看过去，不看未来，不需要任何关于世界形状的先验。

| 世界 | ALL | RECENT | **V3** | 选 RECENT 率 |
|---|---|---|---|---|
| stationary | 0.1211 | 0.1246 | 0.1227 | 0.298 |
| monotone | 0.5237 | **0.1712** | **0.1716** | 0.994 |
| sine | 0.9928 | 1.0817 | **0.9336** | 0.459 |
| square | 1.5510 | 1.3216 | **1.2728** | 0.591 |

**最值得注意的一条：V3 在 sine 和 square 上超过了两个固定策略中较好的那个。**

这不是"选对了"，是**按阶段切换的额外收益**——sine 世界在上升段需要近因、在转向处需要全记忆，任何固定策略都只能在整段上折中。

## 四、三闸

```
G1  选择性     True   stationary 0.298 → monotone 0.994
G2  不劣于最优 True   四个世界全部成立
G3  不是装饰   True   随机选专家 比 V3 差 +0.1083  CI [+0.0915,+0.1269]
```

G1 特意要求**两边都成立**：stationary 上必须低判出率（能产生假），否则判据恒真。

**形状切换检验**：世界前半 monotone、后半 square。
选 RECENT 率 **0.986 → 0.711**，判别器跟得上切换。

## 五、真实臂：真实 CPU 时序

真实采集 CPU jitter，两种真实模式：

```
sustain（持续负载）   V3 选 RECENT 0.886
cycle  （周期切换）   V3 选 RECENT 0.155          distinct = True
```

**两种真实模式给出相反偏好，且都选到了各自的最优固定策略**——sustain 下 RECENT 更优，cycle 下 ALL 更优。**这与 144 的模拟 square 结论一致，真实数据复现了模拟。**

## 六、但真实臂有两个必须说清的缺陷

**① 所有学习器在 cycle 模式下打不过恒等基线。**

```
sustain  lag3  RECENT 0.0665  vs  ident 0.1076   打过 ✓
cycle    lag3  ALL    0.1316  vs  ident 0.0914   打不过 ✗
```

lag 扫到 10 仍是这个结论。**cycle 模式下"预测不变"比任何学习都好。**
所以真实臂的绝对误差**不能**用来主张"预测有效"，只能用来主张"策略选择有效"。
（策略偏好是 ALL 与 RECENT 的内部比较，不依赖绝对水平。）

**② 6 次 rep 是伪重复。**
真实序列只有一条，6 次重复跑出的 ALL/RECENT/V3 结果完全相同，bootstrap CI 退化成点（[0.3341, 0.3341]）。**不主张真实臂的统计显著性。**

**③ 两次独立采集的绝对数值波动很大**（sustain err 0.3341 → 0.0971，CPU 状态差异）。
**只有相对关系稳定复现**：两次都是 sustain 偏好 RECENT、cycle 偏好 ALL。

## 七、本轮的错误

1. **V1 判错量**——未做方差分解就判趋势（第一节）
2. **V2 同样失效**——残差趋势信息量也不足
3. **`captured.png` 存的是帧缓冲原始字节，不是 PNG**——PIL 和 tesseract 都打不开，报 "file not found"。修正为按 (1024,768) 尺寸重建后 OCR 正常。**这是保存方式的 bug，不是渲染问题**（像素级始终 IDENTICAL）
4. **真实臂伪重复**——CI 退化为点，差点点当成显著性
5. **两次采集数值差异未预先控制**——真实硬件测量的固有波动

## 八、边界

- 世界、漂移方式、噪声全部是建模的；真实臂只有 CPU jitter 一项
- V3 的收益**依赖于两个专家确实有互补性**。若所有专家退化为同一策略，竞争无意义
- M=24、K=60 手定未标定
- **V3 在 stationary 上略差于 ALL（0.1227 vs 0.1211）**——世界无形状可判时，切换有轻微估计噪声成本。这符合预期，也是 G2 给了 0.02 容差的原因
- 不主张"这就是生物如何检测环境统计结构"

## 九、与 144 的关系

144 说：**时间的价值取决于世界形状**。
145 补上：**形状不必知道，只需比较**。

不识别世界是什么，只问"最近谁预测得更准"——这个问题的答案自动携带了形状信息，
而且比直接判形状更稳健（V1/V2 判形状失败，V3 不判形状成功）。

> 需要知道自己在什么世界里，和需要知道自己该怎么办，是两个不同难度的问题。
> 后者通常更容易回答。
