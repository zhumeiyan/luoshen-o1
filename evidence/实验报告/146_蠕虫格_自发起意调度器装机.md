# 146 蠕虫格：自发起意调度器（第一次真装机）

阶梯第二格（蠕虫）= 自己移动 + 集中的脑。
硅基形态：内部驱动（好奇 / g_self 低落 / 无聊）过阈值时，
自己决定在数字地形里去哪 —— 开目录、读文件。

**本轮不是模拟调度，是真装机：起常驻进程，无指令，自己动。**

---

## 0. 一句话结论

**装机成功，但装完立刻发现：好奇探索的价值完全取决于地形有没有可学结构。**

- 有结构地形：好奇显著优于随机（−0.0447，CI 不跨 0）
- 无结构地形：好奇**显著劣于**随机（+0.1504，CI 不跨 0）
- 交互 +0.1950，CI[+0.1221, +0.2679] 不跨 0

**"地形、同伴、死亡全是现成的，所以硅基里便宜得多"这个假设被实测修正了一半：**
地形是现成的，但**地形的可学结构不是现成的**。

## 1. 三个静默失效（v1 全废，全部重写）

### [bug1] 阴性对照退化 —— 第 3 次复发

首版用"置换节点特征"做无结构对照。结果：

```
real     : curiosity final=0.00000 cov=1.000
shuffled : curiosity final=0.00000 cov=1.000   ← 逐位相同
```

置换不改变"每个节点仍可被独立学会"，破坏的不是结构。
**与 143 号 clone 走同一分支、125 号 v1 退化对照同一个病。**

### [bug2] 模型误差实为覆盖率的代理

首版首次访问即 `pred = v`，误差**立刻归零**：

```
curiosity final_err = 0.00000   （完美得可疑）
```

于是"模型误差"和"覆盖率"两个指标在量同一件事，不独立。
**教训：宣称两个指标前，先量它们的相关性。**

### [bug3] SGD 发散，所有臂在比"谁跑得远"

```
base=13.55 → final: anti 2037 / random 1010 / curiosity 3634
```

误差比基线大几百倍。好奇发散最猛，与预期完全反向。
**弃用 SGD，改岭回归闭式解。**

## 2. 前置检验：地形到底有没有结构？

这是差点被跳过的一步。**不先证明地形可学，后面所有"策略差异"都是指标坏了。**

方法：留一交叉验证，岭回归 vs 预测全局均值。

| 地形 | 内容 | ratio | 可学 |
|---|---|---|---|
| A | 目录路径 → 目录内容 | **1.0936** | **NO** |
| B | 文件路径 → 文件物理属性 | **0.6582** | **YES** |

**两个都是真实地形。真实世界本身就提供了"无结构"对照，不需要合成。**

查找过程中还抓到一个死特征：

```
X col std: [..., 0., 0.]   ← 两维恒为 0
```

首版用 `split("_")` 整词匹配关键词，`exp146_worm` 切出 `["exp146","worm"]`，
**永远匹配不到 `"exp"`**。两个特征维度是死的（判据核 #23 变体）。

## 3. 主结果（动作数配平，只差选点）

动作数严格配平（30 步），抗好奇 / 随机 / 好奇三臂只差**选哪个**。
否则测到的是"访问越多越熟"的平凡效应。

### 地形 A（真实·无结构）

| 臂 | gain | err_auc |
|---|---|---|
| anti | +0.0989 | 3.2008 |
| random | +0.2206 | **2.5266** |
| curiosity | +0.1701 | 2.6770 |

**好奇不如随机。** 不单调。

### 地形 B（真实·有结构）

| 臂 | gain | err_auc |
|---|---|---|
| anti | +0.3741 | 1.4177 |
| random | +0.5341 | 1.2551 |
| curiosity | **+0.5458** | **1.2104** |

**剂量单调成立：anti > random > curiosity。**

### 配对检验（同 seed，n=10，t=1.833）

```
A  curiosity - random = +0.1504  CI[+0.0757,+0.2251]  不跨0  好奇更差
B  curiosity - random = -0.0447  CI[-0.0844,-0.0049]  不跨0  好奇更优
交互 B - A           = +0.1950  CI[+0.1221,+0.2679]  不跨0
```

## 4. 装机验收：常驻进程，无指令

`wormd.py` 起真后台进程，**18 秒内不给任何指令**：

```
curiosity : 766 ticks, 32 actions, 覆盖 32 个真实目录 (0.97)
no_drive  : 858 ticks,  0 actions
```

**G1 PASS：无驱动时自发率精确为 0。**
**验收 1 通过：无指令时自发动作率 > 0。**

诚实说明：这里实现的是"**起意**"（选点由内部驱动决定），
不是"自发启动"（主循环仍是进程自己的 while，这已经比外部 tick 进了一步，
但还不是真正的心跳级自持）。

| | 145 | 146 |

## 6. 边界

- **n=10 seeds**，用 t=1.833（df=9）的宽松界，未做多重比较校正
- 地形 B 上 curiosity 仅优于 random 0.0447，**效应量小**，交互才是主效应
- 常驻进程的"自发"仍是进程内 while 循环，**不是心跳级自持**
- 世界模型是岭回归，**选点价值部分来自 X^T X 条件数改善**（最优实验设计效应），
  不等于生物好奇
- 地形可学性只在这两个地形上测过，**不主张"文件系统普遍不可学"**

## 7. 错误清单

1. 置换特征做阴性对照 → 逐位相同（退化对照第 3 次）
2. 首次观测即收敛 → 指标退化为覆盖率代理
3. SGD 发散 → 改岭回归
4. `split("_")` 整词匹配 → 死特征维度（#23 变体）
5. 只在 `experiments/` 内采样 → 同质过高，无可学结构
6. 渲染末行越出 768 画布 → TOKEN 读成乱码（**144 号同病第 2 次复发**）
7. 修 assert 失败后误读旧 `captured.png`，差点把旧结果当新结果
