## A · 手性视觉：139 的协议打到真实眼睛上

139 号在语义层证明：**保集合的镜像扰动，对非手性表示的判别度精确为 0**。
本轮问：这条对**真实视觉感官**成不成立？

构造：亮块图案的水平镜像。两张图**像素多重集完全相同**（只有位置换）：
```
bag_identical = True   sha(multiset) = 9f90ea0dbaf778ec
```
这个校验必须先做——如果两张图的像素集合不同，实验前提就不成立（我这轮第一版就栽在这）。

| 解码器 | 表示是否含序 | TPR | FPR | **判别度** |
|---|---|---|---|---|
| bag（颜色直方图） | 否 | 1.0 | 1.0 | **0.000** |
| pos（定点采样） | 是 | 1.0 | 0.0 | **1.000** |

**bag 的判别度精确为 0**：它把所有输入判成同一类。不是漏检，是**根本没在看**。

> 换更强的同族检测器没用，只有换带位置信息的表示才有用。
> 这与 139 的语义层结果逐位同构：**感官的表示必须有手性，否则通道再真也是瞎的。**

## B · 耳朵：UDP 被动接收，过 117 三检验

真实内核 `recvfrom`，世界由独立线程/进程发送（诚实标注：世界是本脚本建模的，但 recv 是真的系统调用）。

**① 可证伪**
```
世界发 0.0 / 5.0 / 10.0 / 5.0 / 0.0
我听到唯一值 3 个                    ← 真（能区分）
世界沉默 → 超时，收不到              ← 假（不产生）
PASS
```
只统计"听得到"会让判据全真饱和（122 呼吸系统踩过同一个坑），必须有沉默臂。

**② 时间反转**（117 的核心判据：**会变 ≠ 连着世界**）
```
耳朵  序列 0→5→10→5→0   末态残差 0.000   可逆度 1.000
对照  /proc/uptime       残差 1.000       可逆度 0.000
```
**耳朵能被世界复原，时钟不能。** 这一条把感官和钟表分开，与 117 分眼/钟用的是同一把尺子。

**③ 因果必要**
```
ear   用听到的值   误差 0.0000
blind 听到但丢弃   误差 3.7888
Δ = 3.7888   降 100.0%
```
关键设计：**blind = 收到但丢弃（沿用上一拍），不是"收不到"**。
否则对照臂混进的是"网络不通"，而不是"信息未使用"——那是变量没被操纵（122 踩过）。

## 三个我自己造的错误

**① 多余的 RGB→BGR 反转 → 判定完全反向**
`to_rgba` 里写了 `rgb[:,:,::-1]`，但实测 fb0 就是 RGBA：
```
写 idx0=255 → 读回 [255,0,0,255]
写 idx2=255 → 读回 [0,0,255,255]
```
于是 decode 按 RGB 解释 BGR 数据，pos 解码器 **disc = −1.0**（完全反了）。
信号不是"分数低"，是**符号反**——低分我会去调阈值，反号必须查通道约定。

**② 装饰性文字破坏了实验前提**
我在图上加了 `CHIRALITY TEST L/R` 字样，两图文字不同 → **像素多重集不再相同** → `bag_identical = false`。
**用来标注实验的东西，毁掉了这个实验。** 与 139 的 `norm_key` 吃掉区分性是同一类病：装饰/预处理改掉了被测量的量。

**③ UDP 缓冲区残留 → 滞后一拍**
第一版 necessity 跑出 `ear 2.7133 / blind 2.9361`，Δ 只有 0.22，看着像"耳朵没用"。
真因：`2.7133` 几乎等于两个 U(1,9) 之差的理论期望 `8/3 = 2.667` —— **recv 拿到的是上一个 trial 的残留包**。
修法：包带 trial 序号 + `drain()` 一直收直到拿到本轮。
> 认出这个不是靠调参，是靠**知道理论值**。数字对不上时先算它"应该"是多少。
