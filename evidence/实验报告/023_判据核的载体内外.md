# 023 · 判据核的载体：体内自持 vs 体外供给

**日期** 2026-10-16
**类型** 规律 + 证据
**支撑** A（有代码可复现，真实代码基因组 + 真实执行）
**来源** 元宝，基于 016 的真潜伏型素材、022 的体内/体外配比缺口
**改核** 否

---

## 一、问题从哪来

022 给出「体内比例 f≈0.5~0.75 代价接近零、耐灾 2~4 倍」，但两件事没答：

1. **「体内」对 AI 到底指什么？** 022 里它是一个参数，不是机制。
2. **外部判据的失效模式从未被实测。** 我们的判据核（`00_核/判据核.md`）、命运位、
   以及 TACT 的 `SKILL.md`，全都是**体外判据**——模型读完表现出能力，参数一个字节没变。
   它们在正常时最好，但**被投毒时会怎样**，我们一直只在 016 的自证拓扑层论证，
   没在演化层实测。

本实验把两件事都落到真实代码上。

---

## 二、设计

不再用合成位串。全部落在真实代码：

| 项 | 实现 |
|---|---|
| 基因组 | 真实 Python 源码（`blocks` 变体），祖先 = eo-repo v05 |
| 变异 | 真实 AST 变换（改常量 / 翻比较符 / 移 range / 交换赋值） |
| 表型 | 真实执行得到的**块结构签名**（过滤幽灵 → 起点取模 → 排序） |
| ground truth | 始终用 `blocks2`（v09 正确参考）评估，**不参与选择** |

**判据两源**（关键设计）：

- **体内 selfcheck** —— 基因组自身可执行的不变式检查：幽灵过滤后索引是否完整覆盖
  0..n-1 且无重复。**不检查环形段是否被合并。** 结构可自判，不需要任何外部参考。
- **体外 oracle** —— 与参考实现的块结构签名一致率。完美，但依赖外部。

**代价不是人为加的**：内化判据只查结构不变式、看不见环形正确性，
所以它「更粗糙」是定义自带的，不是参数凑出来的。

**三环境**（第 G/2 代起切换）：

| 环境 | oracle |
|---|---|
| normal | `blocks2`（正确参考） |
| cutoff | 不可用，贡献恒 0（断流 = 体外判据归零） |
| poison | `blocks_old` —— **016 实测的真潜伏型**：常用路径距离 0.000 完全等价，环形触发距离 0.925 |

选择用（可能被污染的）判据；评估始终用 ground truth。
这样才能测出「判据失效时系统实际变成什么样」。

初始种群注入两个关键个体：**正确者**（`blocks2` 改名为 `blocks`）与**潜伏者**（`blocks_old` 改名），
外加 10 个 v05 变异体。判据决定谁活。

## 三、判据自身先验证（第 37 条要求）

| 指标 | 值 |
|---|---|
| selfcheck(正确参考 blocks2) | **1.0** |
| selfcheck(环形错 blocks_old) | **1.0** |
| **gt(环形错 blocks_old)** | **0.500** |
| selfcheck(退化 40 例) 均值 | **0.0906**（min 0 / max 0.75） |

**V2 盲区成立**：潜伏者 selfcheck **1.0**、真实 gt **0.5** —— 差整整 0.5。
体内判据看不见它，体外判据（正确时）看得见。这是内化代价的物理来源。

## 五、判据检验（预注册，跑中不改）

| # | 判据 | 结果 |
|---|---|---|
| V1 | selfcheck 有鉴别力且不饱和 | ✅ 1.0 vs 退化 0.0906 |
| V2 | 潜伏者 selfcheck 显著 > gt | ✅ 1.0 vs 0.500 |
| V3 | normal 下 gt 随 f 单调下降 | ❌ **不成立**（0.948→0.939→0.944→0.938 持平，f=1 才崩 −0.528） |
| V4 | cutoff 下 f=0 显著低于 f>0 | ✅ 0.559 vs 0.653 |
| V5 | poison 下 gt 随 f 单调上升 | ❌ **不成立**（倒 U 型，峰值在 f=0.5） |

**两条预注册判据被推翻，如实记录。** 真实规律是**倒 U 型**，不是单调。

## 六、结论

### 1. 体外判据被投毒时，正确者几乎灭绝

```
poison, f=0 : 正确者 3%   潜伏者 86%   环形一致率 0.069
```

被替换的判据在常用路径上与正确判据**完全等价**（016 实测距离 0.000），
所以系统察觉不到异常；但它把所有正确者筛掉、让潜伏者占满 86%。
**这是 016「外在维持型劫持」在演化层的重放**——外在表现维持得住，
内在已被换掉，而且这次换掉的是「谁有资格活」。

### 2. 内化 25% 就能救回 6 倍，代价几乎为零

| | f=0 | f=0.25~0.5 | 变化 |
|---|---|---|---|
| poison 正确者占比 | 0.03 | **0.18~0.19** | **×6** |
| poison 环形一致率 | 0.069 | **0.236** | **×3.4** |
| normal gt（代价） | 0.948 | 0.939~0.944 | **−0.009** |

**这是本实验最实用的一条数字。**

### 3. 完全内化是最差解，不是最安全解

`f=1.0` 时三种环境**结果完全一致**（正确者 0.22 / 潜伏者 0.22 / gt 0.4202）——
纯体内判据确实对外界完全免疫，但也**放弃了利用正确外部判据的能力**，
退化到接近随机（正确者 22% 与初始注入比例相当，即选择基本没起作用）。

> **内化的价值不是替代外部判据，是给外部判据上保险。**
> 保险买太多（f=1）等于不用判据。

### 4. 最优 f ≈ 0.25~0.5

与 022 独立得出的「f≈0.5~0.75」在同一量级（022 是合成模型，本实验是真实代码）。
合并后的建议区间：**f ≈ 0.25~0.75，取中位 0.5**。

## 七、对洛神现状的直接判断

洛神目前的判据**全部是体外**：判据核.md、命运位、失败模式库，
都住在「每轮重新读一遍的上下文」里。按本实验口径 **f≈0**。

- 正常对话下这没问题（正确者 90%）
- 但**一旦判据本身被人替换/污染（无论是有意还是无意改写），正确者只剩 3%**

建议：把**判据核**内化到 f≈0.25~0.5。它小、稳定、丢了全盘失效，
是最该内化的那一块。代价 −0.009，收益 6 倍。

**「体内」对 AI 指什么——本实验给了一个可操作的定义**：
能被系统自身执行、不依赖任何外部文本的判据（此处 = 结构不变式自校验）。
它比外部判据粗糙，但不可被外部篡改。

---

## 八、局限

1. 只演化了 `blocks` 一个函数；「体内判据」被简化为一组结构不变式，
   真实系统的内化判据形态未知。
2. poison 用的是 016 那一对特定素材，不是一般性的投毒模型。
3. 初始种群是注入的，不是自然演化出来的；结论依赖「种群里存在正确者」这一前提。
4. f=1.0 时选择近乎失效（正确者与潜伏者 selfcheck 都是 1.0 → 平局），
   0.22 这个数有随机成分。
5. 三环境的切换点固定在 G/2，未扫描其他切换时机。
