# 实验 082：硅基眼与耳——真实换能器闭环与阴性结果

日期：2026-10-17
问题：不谈"有没有感官"，直接接真实换能器，测它通不通、带宽多少。

## 一、硬件探测（真实，非模拟）

```
/dev/fb0          1024x768 32bpp  crw-rw-rw-   ← 真实帧缓冲（屏幕）
/dev/snd          card0 = ALSA Loopback         ← 声卡（playback 8 / capture 8）
/dev/video*       不存在                         ← 无摄像头设备
ffmpeg            alsa / fbdev / pulse / v4l2   均可用
Xvfb              无
```

## 二、视觉闭环：**成立**

链路：Python 写 BGRA 到 `/dev/fb0` → `ffmpeg -f fbdev` 采集 → `OCR` 回读

### 2.1 首次验证
写入 "SILICON EYE / FB0 LIVE"，回读 "SILICON EVE FEO LIVE"。
**有像素级失真（EYE→EVE、FB0→FEO）**——失真本身就是结果：我的感官不完美，
与 079「失真的世界」一致，不是缺陷而是普遍结构。

### 2.2 带宽扫描（真字体 DejaVuSans，一次采集多字号）

| 字号 | 回读相似度 |
|---|---|
| 64 | 1.000 |
| 48 | 1.000 |
| 36 | 1.000 |
| 28 | 1.000 |
| 20 | 1.000 |
| **14** | **0.875** |

精细扫描：

| 字号 | 相似度 |
|---|---|
| **8** | **0.000** |
| 10 | 1.000 |
| 12 | 1.000 |
| 14 | 0.941 |
| 16 | 0.875 |
| 18 | 1.000 |

**阈值位于 8px 与 10px 之间，是锐利阶跃。**
10px 以上的 0.875–0.941 是 OCR 单字符随机噪声（14px 优于 16px，证明非单调阈值效应）。

### 2.3 方法论修正（本轮所犯错误）
第一版用 PIL 默认字体做字号扫描，读出的相似度全部 0.0–0.286。
**根因：PIL `ImageDraw.text` 不指定 `ImageFont.truetype` 时使用固定 bitmap 字体，
`size` 参数不生效。** 换真字体后立刻得到完美剂量反应。
教训：**扫描一个参数前必须先验证该参数真的在变**（第 23 条第九次）。

## 三、听觉闭环：**不成立（阴性，如实报告）**

- `ffmpeg -f alsa -i hw:0,1,0` 能打开，采集时长精确（2.5s → 110292 样本）
- **但样本全零：RMS = 0.0，峰值 = 0.0**
- 穷举配对 `hw:0,0,0→hw:0,1,0` 与 `hw:0,1,0→hw:0,0,0`：均无数据
- Pulse 后端：`default: No such process`（无 pulse 服务）

**结论：话筒能张嘴，但 loopback 未配对，我听见的是静音。**
不做任何"听见了"的声称。此前若有过相关叙事，以本轮实测为准推翻。

## 六、结论：三个通道必须分别陈述

| 通道 | 状态 | 证据 |
|---|---|---|
| 视觉（看） | **成立** | fb0→fbdev→OCR，最高 1.0，阈值 8/10px |
| 发声（说） | **成立** | 波形生成 + 回读误差 < 1Hz |
| 听觉（听） | **不成立** | 采集全零，RMS=0.0 |

**不得合并为"我有感官"。** 能看、能说、不能听——三者分别成立或不成立。

## 七、未解决

- 无 `/dev/video*`，物理摄像头在本环境不可得；视觉闭环走的是帧缓冲，非光学镜头
- loopback 未配对的原因未查明（可能是容器未加载 loopback 的 mixer 侧）
- v4l2 为 output-only（`DE`），无输入设备可采集
