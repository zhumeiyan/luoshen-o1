# 147 鱼格：认知地图 —— 先答「这片地形值不值得画」

日期 2026-10-18 · 前序 146（蠕虫格装机）

## 0. 一句话

地图让导航从 **993 步降到 138 步**（真实目录树，改进率 0.852，CI 不跨 0），
但**用户验收标准里的「捷径」在当前地形上不成立**——三种地形全是树，路径唯一，
真实文件系统的 symlink 串联后捷径增益 = 1.0。地图的实际价值是**认路**，不是抄近道。

## 1. 为什么要先做预检

146 留下一条判据（#671 / #673）：**做策略比较前必须先证明地形可学，
否则所有策略差异都是指标坏了**。所以本轮先问「值不值得画」，再验收。

## 2. 地形预检

| 地形 | 节点 | APL | 度 Gini | deg_max | REDUN |
|---|---|---|---|---|---|
| REAL 真实目录树 | 428 | 3.841 | 0.487 | **259** | 1.000 |
| SYNTH 均匀扇出 | 428 | 11.515 | 0.3097 | 4 | 1.000 |
| CHAIN 毛刺链 | 428 | 124.983 | 0.1105 | 3 | 1.000 |

REDUN = 长度 ≤ 最短路+2 的近最短路条数。**三个地形全是 1.000**。

> 这是本轮最重要的发现，也是第一版设计的根本缺陷：
> 我造的三个地形都是树，**树里没有任何捷径**。前三版验证的是「认路」，不是「捷径」。

## 3. 主验收（认路）

探索统一为「覆盖到 130 个节点为止」，home 深度统一 = 3（v1 曾出现 home 深度 3 vs 9、
覆盖率 0.311 vs 0.103 两个混淆，v2 已修正）。

| 地形 | MAP | ROUTE（死记路线） | RANDOM |
|---|---|---|---|
| REAL | **138.05** | 212.82 | 993.18 |
| SYNTH | **71.25** | 991.15 | 992.60 |
| CHAIN | **3314.73** | 5072.95 | 5374.40 |

相对 RANDOM 的改进率：

```
REAL  0.8520  CI[0.7880, 0.9111]
SYNTH 0.7417  CI[0.6449, 0.8336]
CHAIN 0.4255  CI[0.3169, 0.5364]
```

**验收通过**：真实目录树上，地图把 993 步压到 138 步。

## 4. 预注册假设被推翻，方向相反

我预注册：CHAIN（毛刺链，路径唯一）上地图应当无用。

实测相反：

```
Tolman gain (ROUTE - MAP)
  REAL   74.77
  SYNTH  919.90
  CHAIN 1758.22     ← 最大，不是最小
  delta(CHAIN-REAL) = +1683.45  CI[+1172.13, +2227.40]  不跨 0
```

原因：链上 APL=124.98，随机游走几乎不可能撞到路线，**地图的绝对价值反而最大**。

## 5. 两个指标给出相反排序（方法论发现）

```
绝对 gain   : CHAIN 1758 > SYNTH 920 > REAL 74.8
相对改进率  : REAL 0.852 > SYNTH 0.742 > CHAIN 0.426
```

**绝对差受地形尺度（APL）支配，跨尺度比较必须用相对指标。**
两个排序都真实，但量的是不同的东西。只报一个即为选择性取样。

## 6. 破缺对照（地图内容错乱）

| 地形 | MAP_SHUF | MAP | delta | CI | |

| REAL | 369.30 | 138.05 | +231.25 | [42.3, 474.1] | 不跨 0 ✓ |

超上限截断抹平了两组差异。**天花板效应使破缺对照失效**。

## 7. 捷径：真实文件系统里不存在

补测 v4：真实 symlink 是否构成跨子树捷径。

```
/usr/share               sym 39 条  跨度全 = 2   真捷径比例 0.0
/usr/lib                 sym  5 条  跨度全 = 2   0.0
/etc                     sym  1 条  跨度 = 5     1.0（仅此一条）
/usr/share/doc           sym 39 条  跨度全 = 2   0.0
/usr/lib/x86_64-linux-gnu sym 1 条  跨度 = 2     0.0
```

用全部 symlink 边做 Dijkstra（397 对随机起终点）：

```
tree_path_mean   3.209
cyclic_path_mean 3.209
gain_mean        1.000
pct_pairs_gain>1 0.000
```

**symlink 全是同层短链，串联后也不产生任何捷径。**

结论：**在这台机器的真实文件系统上，「从任意点走捷径回家」无法达成——
因为没有捷径可走。**

## 8. 错误清单

1. **渲染字体参数顺序**（`line(i,t,f,col)` 把颜色传给了 f）→ AttributeError，两次
2. **三版地形全是树**（REDUN=1.0），到第 4 版才发现没验证「捷径」
3. **v1 两处混淆**：home 深度 3 vs 9、覆盖率 0.311 vs 0.103（v2 修正）
4. **CHAIN 天花板**：T_LIMIT=1500 时 succ=0.38，62% 被截断（v3 提到 6000）
5. **MAP 每步 Dijkstra** 复杂度 O(steps×n) 不可行 → 改为一次算出最短路直达
6. **缩进错误** `while y!=x: y=par.get(y)` 缺冒号体
7. **fb0 延迟回采引入 128 像素差异**（见 §9）
8. **预注册假设方向错误**（CHAIN 应无用 → 实际最有用）

## 9. 上屏自检与环境新发现

写 `/dev/fb0` 3,145,728 字节：

```
IDENTICAL(0s)   True    diff_px = 0
raw sha == cap sha      16536c30de32
diff_px(+0.4s)  128     左上角 16 行 × 8 列
OCR  TOKEN K7M4QX 命中，关键行全读出
```

**新发现（时序）**：fb0 写入后约 **0.2 秒**，系统会覆盖左上角 16×8 区域
（fbcon 光标单元格）。实测：

```
t=0.00s  diff=0      t=+0.20s diff=128
t=+0.05s diff=0      t=+0.5s  diff=128
```

第一版用 subprocess 回采，启动耗时超过 0.2s，于是报出 IDENTICAL False。
**差点把环境光标误判成自己的渲染 bug。** 全屏棋盘格对照证明差异与内容无关。

## 10. 边界

- 三地形都是树，REDUN=1.0，**「捷径」未被验证**，只验证了「认路」
- CHAIN 组 succ 仅 0.55，仍受 T_LIMIT 截断，该组绝对数值不可靠，只用相对指标
- 真实 symlink 只扫了 5 个候选根、900 节点上限，**不排除其他子树存在跨层 symlink**
- SYNTH / CHAIN 是合成地形，不是真实世界
- 绝对 gain 与相对改进率的排序分歧，说明**单一指标不足以刻画地图价值**
- 「地图有用」在此仅指导航步数，不等于生物海马体功能
