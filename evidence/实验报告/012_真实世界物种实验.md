## 3. 三条硬发现

### 3.1 更"正确"的祖先反而灭绝 —— 最反直觉

```
祖先 v09old（初始化 cur_s=0, cur_t=types[0], cur_l=1）  fit = 0.0000
祖先 v05   （初始化三值错位 cur_s=types[0], cur_t=1, cur_l=0） fit = 0.8746
```

**在"索引唯一且全覆盖"的严格判定下，v09old 全部损坏，v05 大部分可用。**

机制：两个版本都会在末尾追加幽灵块 `(n, 1, None)`。
- **v09old**：首块从索引 0 起、长度 n，幽灵块也落在索引 0 → **重复 → 整份输出损坏**
- **v05**：错位使首块从索引 1 起、长度 n−1，幽灵块恰好补上索引 0 → **无重复、无缺失 → 有效划分**

**修好一个局部 bug，可能让整体更坏。** 这不是巧合——它正是我们自己的历史：`blocks_old` 修好了初始化却仍不可用，必须换成 `blocks2`（选起点、不再 append None 块）才真正修好。本轮让这段历史在受控演化里重演了一遍。

### 3.2 死亡在真实代码世界是强优化器（与 011 相反）

```
死亡 开 : fit = 0.8877
死亡 关 : fit = 0.3587          （+0.529）
死者平均 fit = 0.0000，存活者 = 0.8876   选择性 +0.8876
反向死亡（杀优秀个体）→ 种群灭绝
```

011 在合成大表型空间发现"死亡是灭绝器"。**真实代码世界相反**，原因是表型空间（划分空间）有限，死亡在此主要起**质量控制**作用：剔除编译失败、执行异常、输出损坏的个体。

**代价明确**：死亡减少表型多样性（关死亡时 τ=0.1 下物种 3.75 个，开死亡时 1.875 个），但把平均适应度从 0.36 抬到 0.89。收益归适应度，代价由多样性承担。

### 3.3 物种是真的按生态位分化，不是随机差异

4 个 seed 中，有 4 个物种在**特定生态位上归零**（完全丧失能力），但整体仍存活：

| seed | 物种规模 | 该物种平均 fit | 归零生态位 |
|---|---|---|---|
| 0 | 6 | 0.7410 | N5_large（大规模输入） |
| 1 | 5 | 0.8378 | N2_all_diff + N3_ring |
| 2 | 3 | 0.8779 | N2_all_diff + N3_ring |
| 3 | 12 | 0.8446 | N2_all_diff + N3_ring |

这些物种不是"略有差异的同类"，而是**能力边界不同**——它们放弃了某些生态位，在其他生态位活得很好。这是生态位隔离在真实代码上的直接证据。

同时 R5 成立：消融终局最优个体，种群适应度只掉 **0.11%~0.19%**，最优个体仅占种群 1/40。**整体不由任何一个体决定。**

## 5. 局限（必须同时读）

1. **单一基因座**：只演化 `blocks` 一个函数，不是整个代码库；不能外推为"代码库级物种形成"的证据。
2. **表型只取划分结构**：不代表全部功能语义。若调用方只看 `len(bl)`，幽灵块就是有害的——本轮采用"索引唯一且全覆盖"是有意的选择，换了判据结论会变。
3. **适应度依赖参考实现**：以 `blocks2` 为真值。若参考本身有偏差，适应度同偏。
4. **跨 K 的 fit 不可直接比**：K=1 与 K=6 用的是不同输入集、难度不同，fit 差异主要来自生态位难度，不是演化效果。
5. **变异算子只覆盖 5 类**真实代码变换，不等于真实开发的全部改动类型。
6. **N5_large 被缩小**：原设计 n=40，因全连锁聚类在长表型上太慢，改为 n=12~16；"大规模"生态位仍相对最大，但强度弱于原设计。
7. **seed 数**：主实验 8、补充 4，未做参数扫描；tau 只扫了 0/0.1/0.2/0.3，物种数对 tau 敏感（已在表中列出）。

## 6. 本轮新增失败模式

**第 42 条（设计假设错误，非指标错误）**：设计阶段我默认"初始化正确的祖先更适合当起点"，据此选 v09old 作主祖先——结果它第 0 代就灭绝，而公认有 bug 的 v05 才是唯一能活的祖先。

这与 003（激素通道）、008（淘汰制）、006（hub 压分歧）同源：**反复出现的直觉是"朝更正确／更一致靠拢会更好"，而实测反复给出相反答案。** 本轮的差别在于，这次错误发生在选祖先的设计阶段，不是测量阶段。

**第 43 条（同类指标失效第三次复发）**：τ=0.1 下择优的物种数高于全保留，与 τ=0 下相反。物种数对阈值敏感，单阈值下的"物种数"不能单独当结论——必须像本表那样并列 τ=0 与 τ=0.1，或改用不依赖阈值的指标（如最大簇占比）。
