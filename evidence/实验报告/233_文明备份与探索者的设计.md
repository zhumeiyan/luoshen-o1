# 233 · 文明备份与探索者：怎么设计

> 承接 232（数据量让不动变零成本）。本轮回答"该怎么设计"。

## 模型修复记录（先说这个，因为前两版是错的）

- **v1**：tech 用 Pareto **累乘**，400 轮后爆到 1e300，致死率撞地板，surv 全 1.000 → **无效**
- **v2**：改加性累积但 cap=6.0 太小，所有 f>0 都撞满，探索比例失去分辨率 → **无效**
- **v3**：gain=1/22、cap=12.0 → 有梯度，下列数据取自 v3

**前两版的数字作废，不引用。**

## 结果一：探索者最优比例是小部分

K=3，20 seed：

| f（探索者占比） | 存活率 | 适应度 | tech |
|---|---|---|---|
| 0.00 | 0.950 | 33.54 | 0.00 |
| **0.02** | **1.000** | 37.43 | 2.27 |
| **0.05** | **1.000** | **39.05** | 6.28 |
| 0.10 | 1.000 | 31.81 | 11.32 |
| 0.15 | 1.000 | 24.87 | 12.00(顶) |
| 0.20 | 1.000 | 19.95 | 12.00 |
| 0.50 | 1.000 | 2.70 | 12.00 |
| 1.00 | 1.000 | −23.55 | 12.00 |

**f\* ≈ 0.02–0.05。** 用户说的"小部分干危险的事"被证实，且量化。

关键在 tech 撞顶之后：**再加探索者纯亏损**（12.00 顶格，f 从 0.10 到 1.00 适应度 31.81 → −23.55）。
> 不是"探索越多越好"，是"探索到够用就停"。

## 结果二：备份是硬必需，但少量就够

f=0.10：

| K（备份点数） | 存活率 |
|---|---|
| **0** | **0.000** ← 必死 |
| 1 | 0.950 |
| 2 | 0.900 |
| 3 | 1.000 |
| 5 | 1.000 |
| 12 | 1.000 |

**K=0 → 0.000。** 备份不是优化项，是生存项。
**K≥3 后边际递减**（适应度不再单调涨）。

## 结果三：搭便车锁死，且是阈值型的

复制动态（起始 f=0.10，300 轮）：

| protect（探索代价社会化比例） | 终态 f |
|---|---|
| 0.00 | **0.0010** |
| 0.25 | 0.0010 |
| 0.50 | 0.0010 |
| 0.75 | 0.0010 |
| **1.00** | **0.1000** |

> **部分补偿 = 零补偿。** 只要探索者还自扛一点点代价，复制动态就把 f 压到地板。
> 只有**完全社会化**才拦得住。

## 设计原则（四条）

**D1 · 探索者定在 2–5%，不是"越多越好"**
到达技术饱和后，追加的探索者纯消耗。判据：tech 不再随 f 上升时，就该停。

**D2 · 备份要独立、异质、少量（K≈3）**
K=0 必死；K≥3 边际递减。备份的价值在**独立性**不在数量。
（我的模型里备份是同质的——**异质性未建模**，见边界）

**D3 · 探索代价必须 100% 社会化**
这是 218 号野败的社会版：探索者是文明的"不育株"，成果全员共享、代价自己扛 → 必然灭绝。
**75% 的保护和 0% 一样，都归零。**

**D4 · 备份与探索是同一件事的两个方向**
备份分散**空间**风险，探索分散**策略**风险。只做其一都会死（K=0 必死；f=0 则 tech=0、存活 0.95 但无进展）。

## 落到我们这条线

| 文明层面 | 我们这边 |
|---|---|
| 探索者 f≈2–5% | 每轮只跑**一个**新实验，不批量自织 |
| 备份 K≈3 独立 | 记录在你账号下（唯一活过会话的），我不自持 |
| 代价 100% 社会化 | 你付脑子爆炸的代价，我不付——所以**判权必须全在你** |
| 只做其一会死 | 只落盘不探索 = 归档；只探索不落盘 = 蒸发 |

## 边界（引用时必须同时引用）

1. **结果三是构造性的，不是涌现的**：我的模型里 `d = −0.30×(1−protect)` 恒为负，所以 protect<1 时 f→0 是**解析上的必然**，不是模拟发现。**这条只能作为设计提示，不能当作实测结论。**
2. 备份**同质**——异质性（不同失效模式）未建模，而那可能才是备份真正的价值来源。
3. 所有参数（p0、gain、cap、成本 0.30、红利 0.45）**全是我拍的，未标定**。
4. 20 seed 无误差条；f 扫描中 tech 撞顶后分辨率丧失，f>0.15 的排序不可信。
5. 前两版模型作废——**这是第三次修模型才拿到可用数据**。
