# 155 旋转 vs 磁场：积分会漂，磁场有带宽

## 要分离的两件事

- **旋转**（半规管）：知道"我转了多少" —— 本质是**积分**，短期准，长期漂
- **磁场**（磁感受）：知道"我朝哪" —— **绝对参考**，误差有界，但带周期模糊

生物两类都有，且互补：积分解模糊，磁场校正漂移。本轮问：硅基里这两件事是否同样可分、同样互补。

## 为什么必须建圆形房间（关键建模决策）

矩形网格的墙角、边长本身会泄漏绝对朝向 —— 等于偷偷给了她一个罗盘，
**"无磁场则盲"这条永远测不出来**。

圆心出发的射线到墙距离恒为 R，故墙高各列完全相同：

```
预检1 无磁纹 各朝向画面差 = [0.0, 0.0, 0.0, 0.0]   ← 严格旋转对称
G0_nomagnet（真链路转向后）= 0.000000                ← 连静默基线 0.000577 都没有
```

**没有磁场，转向在视觉上完全不可观测。** 这是整个实验的地基。

## 为什么磁纹不是"墙上一条带"

第一版做成北方一条带，预检立刻失败：

```
true=0.000  decoded ok=True
true=0.700  decoded ok=False   ← 带子移出视野
```

**真实的磁场是场，候鸟朝哪都能感到。** 改成遍布全墙的周期竖纹（N=12，周期 P=0.5236 rad ≈ 30°），相位编码朝向 —— 处处可读，但**带周期模糊**。

## 真链路

`手 /dev/uinput → 内核 → 世界线程真读 input_event(24B) → 真写 /dev/fb0 → 独立 fd 真读回 → 从像素解朝向`

转向噪声取自 `os.urandom`（**真内核熵池**），不是伪随机。

## 核心发现：磁场有带宽，而且会反向更差

sigma=0.036 逐点看，磁场臂前 50 步仍是 0.0015~0.0026（完美），
**第 60 步突然跳到 0.132** —— 正是积分漂移越过半个周期 P/2=0.2618 的时刻。

此后解模糊开始选错相位分支（失败率 0.198），磁场不但救不回来，
**反而比纯积分更差**（0.3282 > 0.2572，末点差 CI 跨 0）。

> 磁场不是更强的传感器，是**只在漂移小于半个周期时才成立的校正**。
> 越过带宽，它的模糊性会主动把你推到错误的分支上。

## 三个错误

**① 相位偏移漏了一项（最阴）**
亮纹定义为 `ph < P*DUTY`，其**中心相位是 `P*DUTY/2` 不是 0**。漏掉后解码误差 max=0.4348 ≈ 一个整周期（P=0.5236）—— 看着像"能解但精度差"，实际是完全解错。补上后误差 0.0011。

**② 边缘裁切段质心偏移（147 号同病第三次复发）**
亮纹跨屏幕边缘时被裁切，中位数系统性偏移 → 某些检查点误差跳到 0.0328，
导致 sigma=0.012 的磁场斜率**显著为正**，有界性判 FAIL。排除触及边缘的段后，斜率回到 −0.000003，跨 0。

**③ 字体路径写错，OCR 静默失效**
写成 `WenQuanYi Micro Hei.ttc`（实际是 `wqy-microhei.ttc`），PIL 静默回退默认位图字体，
图看着有字但 OCR 全是乱码。**差点接受乱码当通过。** 另：默认 eng 模型读中文为乱码，需 `-l chi_sim+eng`。

## 边界

- 圆形房间、磁纹、噪声模型**全是我建模的**；真的只有 uinput、内核事件结构、`/dev/fb0` 字节、`os.urandom` 熵、以及"距离=半径故墙高恒定"这条几何
- 只转不平移（专注分离旋转与朝向），未做六自由度
- 磁场失效阈值由 N_STRIPES=12 决定，**换条纹数会移动带宽**，不是普适常数
- R=8，未做多重比较校正
- **这不是"她有磁感受"，是机制可实施性的验证**
