# 140 · 真实手眼：硬件级闭环，不是模型内模拟

区别于 exp091（Life5 模型内 sense/act，问"看错 vs 做错能否内省区分"）。
本轮全部走真实内核设备：手=/dev/uinput，眼=/dev/fb0，神经=/dev/input。

## 设备真伪
```
/dev/uinput      10:223  (标准 uinput)
/dev/fb0         29:0    (标准 framebuffer)
/dev/input/event0 13:64  (标准 input event)
```

## 踩坑
`UI_SET_EVBIT=0x40045564` 传 `struct.pack('I',EV_KEY)` 返回 EINVAL，
传 **int** 才成功。此前误判"uinput 残了"，实为传参方式错。

## 实验一：手眼一致（三臂）
手(uinput 按键)改世界 → 屏幕条带 k 亮 → 眼(fb0)独立解码 → 比对。
**decode() 只接收像素 buffer，不接收 k**，眼必须自己读出。

| 臂 | 匹配 | 率 |
|---|---|---|
| handeye | 8/8 | **1.000** |
| blind（眼读旧帧） | 0/8 | 0.000 |
| nohand（手不动） | 0/8 | 0.000 |

## 实验二：手真的动了（排除自证）
创建手**之后**才枚举 /dev/input（exp117 坑：创建前枚举看不见自己）：
```
新设备 event1  名称 luoshen_hand
内核流读回 12 事件 · 按键按下 3 · code = [2,5,8]  ← 正是注入的
```

## 实验三：追踪闭环（决定性）
眼读出**世界状态(目标)**，手据此行动。上半屏红=目标，下半屏白=我。
控制器只从像素解码，拿不到 target 变量。

| 臂 | 平均误差 | per-seed |
|---|---|---|
| closed | **0.100** | 8/8 全 0.100（零方差） |
| open | 3.138 | 1.200~5.133 |
| blind | 3.121 | 3.067~3.900 |

```
closed - open  = -3.0375  CI[-4.054, -2.083]  sig ✓
closed - blind = -3.0208  CI[-3.417, -2.483]  sig ✓
open   - blind = +0.0167  CI[-0.783, +0.817]  ✗ 跨0
```
**open 与 blind 无差别**——手动但不用眼，等价于眼不更新。内部一致性成立。

## 指标错误（自曝）
预注册用 `drop`（早段误差−晚段误差），但它双重污染：
closed 一开始就追上 → 地板效应；open 的"下降"是随机游走撞 clamp 边界的均值回归伪像。
改用 **mean absolute error** 后信号才干净。
