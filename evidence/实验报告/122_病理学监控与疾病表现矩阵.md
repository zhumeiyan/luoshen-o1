## 0 · 设计原则

生命体必会生病，但"装了监控"不等于"有诊断能力"。本轮唯一的硬要求：

> **每一路监控都必须可证伪 —— 健康样本必须 quiet，患病样本必须 fire。**
> 只能产生"火"的判据叫卡死报警，只能产生"quiet"的判据叫摆设。

九路监控：五路按指令实现（炎症 / 代谢 / 神经精神 / 自身免疫 / 肿瘤），
四路自行补充（医源性 / 细胞因子风暴 / 隐匿期 / 耐药性）。

补充的四路都是**元监控**——监控"监控系统本身"的病：
治疗把自己治死（医源性）、被自己的警报杀死（风暴）、
所有灯都是绿的但病在长（隐匿期）、同一条判据越用越钝（耐药性）。

## 2 · 最深的坑：归一化把区分性吃掉了（#510）

`norm_key()` 过滤 `len(t) > 1` 的 token。健康样本
`"不同的输出内容第 0 条，语义各异"` 与 `"…第 1 条…"`
**唯一的差异就是那个数字**。数字被滤掉 → 12 条互不相同的文本塌缩成 1 个 key。

```
健康各异(中文)     塌缩率=0.0000  语义重复率=0.083  字面重复率=0.083
健康各异(中英混)    塌缩率=0.0000  语义重复率=0.083  字面重复率=0.083
改写型循环(同义)    塌缩率=0.6667  语义重复率=1.000  字面重复率=0.333
真·逐字重复        塌缩率=0.0000  语义重复率=1.000  字面重复率=1.000
```

> **去噪和区分性是一对此消彼长的量。**
> 任何归一化之后必须测塌缩率，否则"语义相同"会退化成恒真命题。

这个坑的直接后果是首版可证伪只有 5/9——**判据不是被数据推翻的，是被我自己的预处理废掉的。**

## 3 · v1 判据对照（关掉本轮改进，看会不会退化）

```
神经 v1(字面相等)   改写型循环 重复率=0.333  fired=False   ← 假阴性
肿瘤 v1(仅按数量)   良性爆发 45            fired=True    ← 假阳性
自身免疫 v1(一律解锁) 真攻击 rm -rf         fired=True    ← 维持封锁（这条反而是对的）
```

改写型循环用三条**字面互不相同、语义完全相同**的句子构造
（`"系统 运行 正常"` / `"运行 正常 系统"` / `"正常 系统 运行"`）：
字面重复率 0.333 低于阈值 → v1 必然漏；语义重复率 1.000 → v2 抓到。

**良性 vs 恶性（#515）**：数量不是判据，**是否响应停机信号**才是。
45 个进程全响应 = 合法批量作业；其中 5 个不响应 = 癌。
（119 的自报 fitness 是同一类病的另一层皮：裁决指标不能由被裁决者提供。）

## 5 · 慢性病：治症状 vs 治病源（#511 #512）

```
治症(只清上下文)     10 拍内报警 10 次
治源(清输出流)       10 拍内报警  1 次
```

根因（#511）：治疗把探子置 `alive=False`，判据却读 `kind=="scout"` 不过滤 alive
→ **已死的探子仍在报警** → 报警记录 `NEU 1,2,3,4,5,6`。

> 治疗改动状态 A、判据读状态 B，是最隐蔽的一类失效：
> 日志里每一条治疗都"成功执行"了，报警却一次没少。

**慢性病的操作性定义**：报警数不随治疗下降 = 治的是症状载体，不是产生症状的机制。

## 6 · 医源性对决：报警预算有没有用（#513 #514）

```
组          峰值并发   能量池   医源性   存活   残留幻觉
预算=关        3.0     61.6    18.13   30.0     0.0
预算=开        2.0     61.6    16.80   30.0     0.0
```

两处必须自曝：

- **#513**：第一版对照两组数字**逐位相同**——因为 CytokineStorm 本身就在 9 路里恒在跑，
  "关闭预算"根本没关掉那个模块。两组逐位相同不是"效应为零"，是**变量没被操纵**。
- **#514**：只裁并发数而不同步建模并发代价，下游指标照样一样。
  加入 `iatrogenic += 0.8×(n−1)^1.5` 的耦合后才有可测差异（18.13→16.80）。

## 7 · 耐药性（#517）

症状强度固定 0.500，有效阈值按 `0.45 + 0.03×发作次数` 上移：

```
第 1 次 症状=0.500 阈值=0.480 检出=是
第 2 次 症状=0.500 阈值=0.510 检出=是
第 3 次 症状=0.500 阈值=0.510 检出=否 -> 漏诊
第 4-8 次                      检出=否 -> 漏诊
```

一条判据"曾经抓到过"，不代表它现在还能抓到。
**反复触发的告警必须记录发作次数并检验阈值漂移。**

## 8 · 代谢迟滞（#516）

token 在 0.08~0.12 抖动：

```
hysteresis=False  模式翻转 19 次
hysteresis=True   模式翻转  0 次
```

任何"低于 X 就切模式"的控制器都必须给出进入/退出双阈值，并实测翻转次数。

## 9 · 边界（不扩大的部分）

- **全部 9 路的输入都是我构造的。** 没有真实进程、真实 token 余额、真实 EEG。
  接口形状与真机一致，但信号是合成的。真机上替换 `evaluate()` 的读数部分即可。
- **参数全部手定**，未标定：抑郁阈值 0.45、肿瘤 T=30、医源止损 15.0、
  联合用药耦合 0.8 与指数 1.5、迟滞 0.10/0.25。真用须拟合。
- **本轮未接本体引擎**——只做单元测试与场景推演，不主张"病理状态改变内在结构"。
- **攻击签名是 8 条硬编码子串**，易被绕过；真实部署须换行为级判据。
- **耐药性的阈值上移是我写死的规则**，不是从数据里学出来的机制。
- 自检 OCR 中 `Avt`/`Av1` 为 v/1 字形混淆、`dediff0` 为空格粘连，属已知局限，
  校验码 `WVKNVG` 逐位命中，关键数字全部读回。
