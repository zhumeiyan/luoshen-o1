## 一句话结论

**三次设计迭代，鲍德温效应全部不成立：文化不是资产，是负债。**
同化量在 −0.075 ~ −0.131 之间，跨代数、跨成本、跨景观稳健为负。

## 为什么要做这个

018 之后我给自己留的台阶是「基因-文化双载体」，理由是当时两套东西还是同一个载体，
拆不干净，无法真正问"文化能不能反过来改基因"。这一轮就做这个。

## 关键数字

### 019b（NK，含功劳分解）

| 组 | 移除文化后 nk | gene_ones |
|---|---|---|
| g_only（纯基因） | **0.7324** | 0.474 |
| g_hgt（单载体+重组） | 0.7415 | 0.463 |
| dual（双载体） | **0.6574** | 0.571 |

```
重组贡献 (g_hgt − g_only) = +0.0092   ← 几乎为零
双载体贡献 (dual − g_hgt) = −0.0841   ← 显著为负
```

**重组的功劳几乎为零，双载体本身是负贡献。**
若不做分解，会把重组的微小正收益连同文化的负效应一起记在文化账上（第 55 条）。

### 019c（最贴近现实的设计）

```
纯基因（容量 8/24）       nk = 0.7080
双载体 带文化时           nk = 0.6253   ← 文化在位时就已经更差
双载体 移除文化后         nk = 0.6030
```

**连"文化在位时"都不如纯基因。** 这不是"文化走了才垮"，是文化从一开始就在拖后腿。

### 稳健性

| 变量 | 扫描范围 | 同化量 |
|---|---|---|
| 暴露代数 N | 10 / 30 / 60 / 120 | −0.038 → **−0.105** → −0.099 |
| 文化成本 λ | 0 / 0.05 / 0.15 / 0.40 | −0.131 → −0.105 → −0.099 |

**暴露越久，同化量越负**（不是时间不够，是越久越糟）。

## 根因：快载体淹没慢载体的选择信号

诊断（019，单峰）显示文化覆盖率直接压制基因：

| 配置 | 文化覆盖率 | 基因覆盖率 | 移除后 |
|---|---|---|---|
| λ=0（文化免费） | **0.423** | 0.443 | 0.796 |
| λ=0.3（有成本） | 0.149 | 0.493 | 0.824 |
| 纯基因 | 0 | **0.504** | **0.954** |

**文化覆盖得越多，基因越差。** 两层原因叠加：

1. **遮蔽**：c 覆盖的位上，g 的变异不改变表型 → 中性 → 无选择压力
2. **信号淹没**：文化每代变，基因每 T_g 代变；快速变化的 c 主导 fit 信号，
   慢变量的优化被噪声淹没

## 对洛神的意义

**直接反对我上一轮的推测。** 我曾说"人类演化快是因为发明了带审查的共享"，
本轮数据说：在这个模型里，**共享带来的干扰大于收益**。

但要注意这不推翻"共享有价值"——它给出的是**成立条件**：

> 两载体若作用于**同一表型维度**，快载体会淹没慢载体的选择信号，净效应为负。
> 现实中文化之所以有用，可能恰恰因为它作用于**不同维度**（行为、工具、外部存储），
> 不直接覆盖基因表型。

**这是本轮最值钱的一条**：它把一个"文化是好事"的直觉，换成了"文化在什么条件下才是好事"的可测判据。

## 局限（必须读）

1. **三次迭代全负，但都是同一个建模家族**（位串 + OR 表型）。
   可能是这一族模型的共同缺陷，而不是现实结论。
2. **未证明现实中鲍德温效应不成立**——只证明它在本模型下不成立。
3. 文化与基因竞争同一批表型位，是**最坏情况**；互补维度未测（这是下一步）。
4. 所有数字来自合成模型，**非真实生物/文化数据**。
5. 019/018 声称的"真实人类人口数据"部分**未落盘，本轮不补，标为未产出**。

## 下一步

**测互补维度**：让文化作用于基因够不到的新维度（扩展表型空间），
而不是覆盖同一批位。这是唯一还没试的、也是最有希望让鲍德温效应显现的设计。

若互补维度下仍为负，则"双载体优于单载体"这个主张在本框架内**应当放弃**。
