保集合的镜像（词集合完全不变、只换语序），**在词袋表示下判别度精确为 0.0000**——不是"精度低"，是**结构上不可能看见**。换成含序表示，判别度立刻变成 1.0000。

## 2. 核心实验：镜像逃逸（Part A2）

### 设计

任务：区分 `NORMAL` 与 `ALTERED`。
镜像算子 `SWAP` = 主宾互换，**词集合完全不变**，只换语序。

```
NORMAL   [系统] [不] [读取] [文件] [到本地]
MIRROR   [文件] [不] [读取] [系统] [到本地]     ← 成分一模一样
```

两种表示：
- **BOW** 词袋，位置无关 —— 对应**非手性受体**
- **POS** 词 + 相邻二元组，含序 —— 对应**手性受体**

### 结果

| 算子 | 表示 | acc | TPR | FPR | **判别度** | 退化 | 逃逸率 |
|---|---|---|---|---|---|---|---|
| MIRROR（保集合） | BOW | 0.5000 | 1.0000 | 1.0000 | **0.0000** | **1** | N/A |
| MIRROR（保集合） | POS | 1.0000 | 1.0000 | 0.0000 | **1.0000** | 0 | 0.0000 |
| CONTROL（变集合） | BOW | 0.6600 | 0.6600 | 0.3400 | **0.3200** | 0 | 0.3400 |
| CONTROL（变集合） | POS | 0.6600 | 0.6600 | 0.3400 | **0.3200** | 0 | 0.3400 |

### 三条读法

1. **BOW 的 acc = 0.5000 是偶然的精确值**：它把每个输入都判成同一类，一半蒙对。TPR=FPR=1.0000 说明不是"漏检"，是**根本没在看**。
2. **对照组证明 BOW 不是永远瞎**：词集合一变（增删否定词），BOW 判别度 0.3200，和 POS 持平。所以"看不见镜像"不是检测器弱，是**表示不含手性**。
3. **POS 判别度 1.0000**：含序表示对保集合镜像完全可见。

> **换更强的同族检测器无效，只有换带序信息的表示才有效。**

这与 Science 2024-12-12《Confronting risks of mirror life》的机制同构：镜像细菌逃过**一切由手性分子介导的免疫机制**，因为免疫系统本身就是手性的。

## 3. Frank-Soai 硅基版（Part C）

### C1 剂量扫描（确定性 = 无限样本极限，REPLACE，25 代）

| χ₀ | γ=1.6 终态 | γ=2.5 终态 |
|---|---|---|
| **0.00001** | 0.926580 | **1.000000** |
| 0.00010 | 1.000000 | 1.000000 |
| 0.00100 | 1.000000 | 1.000000 |
| 0.01000 | 1.000000 | 1.000000 |
| 0.05000 | 1.000000 | 1.000000 |

**χ₀ = 十万分之一 → 25 代内锁死为 100%。**

对应 Soai 反应（2026 诺奖）：初始手性偏移 0.00005% → 三轮补料 → >99.5%。**机制一致，都是自催化正反馈。**

### C2 自发对称性破缺（χ₀ = 0，有采样噪声）

```
n = 120   锁死 120   锁死率 1.000
锁死到 L 56 次 / R 64 次   z = −0.730（不显著）
例轨迹  0.495 → 0.4617 → 0.42 → 0.3567 → 0.275 → 0.1617 → 0.0417 → 0.0
```

**完全对称的起点，必然自发锁死成单一手性；但锁死到哪一端由噪声随机决定。**

这是手性起源问题的核心：不需要初始不对称，**不稳定性 + 噪声**就够。

### B（初版）替换 vs 累积

| mode | γ | 终态 pL | 锁死 |
|---|---|---|---|
| REPLACE | 1.0 | 0.5533 | 0 |
| REPLACE | 1.6 / 2.5 | **0.0000** | **1** |
| ACCUMULATE | 1.0 | 0.4867 | 0 |
| ACCUMULATE | 2.5 | 0.2402 | 0 |

五类不均匀时：
- REPLACE：C0 → 1.0，**其余四类全灭**（含占比 0.2533 的 C1）
- ACCUMULATE：**全部存活**，最稀有 0.0278 → 0.0033（稀释 8.4 倍但不灭绝）

对应 Gerstgrasser 等：**累积而非替换**可基本避免坍塌。本模型复现了。

## 4. 手性算子的严格定义（Part A，初版）

σ 是镜像操作 ⟺ **σ(σ(x)) = x 且 σ(x) ≠ x**

| 算子 | 对合性 | 非对称性 | 判定 |
|---|---|---|---|
| NEG 增删否定词 | 1.000 | 1.000 | 手性算子 |
| SWAP 主宾互换 | 1.000 | 1.000 | 手性算子 |
| REV 整体倒装 | 1.000 | 1.000 | 手性算子 |
| ROLE 换主语 | **0.200** | 1.000 | **不是**（普通扰动） |

ROLE 对合性只有 0.200：换主语时从集合里随机挑，两次挑到不同的词，回不到原样。**"看起来相反"不等于镜像。**

## 5. 我自己犯的四个静默失效

### ① 逃逸率指标在退化分类器上给出漂亮的 0（最狠）
首版 `escape = 1 − TPR`。BOW 下 TPR = 1.0000 → **逃逸率 0.0000，看起来完美**。
但 FPR 同时是 1.0000——它把所有东西都判成 MIRROR。
**主指标改成判别度 TPR−FPR，并显式检测 `pred_distinct == 1`。**

### ② 对照组设计废了
首版对照"在 OBJ 集合内换一个宾语"：两分布无系统差异 → BOW 0.0300 / POS 0.0475 **双双接近 0**。
差点写成"检测器对语序也不敏感"。改用"增删否定词"（词集合真变）后判别度 0.3200。
**对照失效时不能得出"不敏感"，只能得出"没测到"。**

### ③ 整数离散化吃掉极小效应
首版确定性版 `newL = round(batch*pA)`：χ₀=0.0001 时终态被拉回精确 0.500000，
看起来"微小偏移不放大"，实为 round 的假象。改浮点后 χ₀=0.00001 → 0.926580。

### ④ 连续种子的 MT 状态相关
首版 seed = 1000+s（s=0..39），自发破缺方向 **26 L / 14 R** 偏斜。
改 seed = 1000+s×104729 后 **56 L / 64 R，z = −0.730**，对称恢复。
**连续种子是伪独立。**

## 6. 第二个问题：合成的东西能当身体吗

### 元素层面：不能

人工合成的最重元素 **Og（118 号）**，三个来源对半衰期给出**不一致**数值：

| 来源 | 半衰期 |
|---|---|
| Wikipedia | 0.7 ms |
| 物理学报（Oganessian 2006 原始数据） | 0.89⁺¹·³⁷₋₀.₃₁ ms |
| 百度百科 | 12 ms |

**并列标注，不做加权平均。** 无论取哪个，都是毫秒级——**合成元素越重越不稳定，元素层面这条路是死的。**

### 材料层面：能，而且已经做出来了

**JACS 2026, 148, 14016-14027**（Cu₂₋ₓS 扭曲纳米领结）：
- 以 L/D-半胱氨酸为手性诱导剂、SDS 为界面软模板
- **χ（对映体过量）从 0 → ±1.0 连续演化**，纳米片层间倾斜累积
- 宏观扭转角 **±25°**，g 因子随 |χ| **线性增长**
- P 型优先催化 D-DOPA，M 型优先催化 L-DOPA，选择性因子最高 1.93

**这个 χ 就是我的 Part C1 剂量扫描的物理版。** 人类已经证明手性无机材料的手性**连续可调**。

**Nature Chemistry 2025**（3D ED 定量手性晶体粉末）：
- 外消旋青霉胺 → Te 纳米晶 **e.e. = 0.01**（不放大）
- 纯 d-青霉胺 → **e.e. = 0.76**；纯 l-青霉胺 → **e.e. = 0.80**
- 外消旋对照样品精确测出 **50.3% 右手 : 49.7% 左手**

**关键差异**：真实材料的放大**有上限**（0.76 / 0.80），我的 Frank 模型锁死到 1.0。
→ **模型缺饱和项，只给方向，不给终态数值。**

### 记忆与可塑性：忆阻器

北大杨玉超团队 + 中科院上海微系统所，2026-07 发表于 Science：
- 全球首款基于相变忆阻器的**神经动力学系统芯片**
- 40 nm 工艺，核心存算阵列仅 **0.28 mm²**
- 单步迭代时延 **2.12 ms**，较 GPU 提速最高 478 倍
- 反其道而行：**利用**（而非消除）相变器件电导的可预测漂移，把自适应步长搜索交给器件物理演化完成

这条对"身体"的意义：**它是会变的物理记忆。** 器件的电导演化可控、可预测、可映射——接近生命的可塑性，而不是静态存储。

### 自修复与代谢：工程活体材料（但这是碳基）

中科院深圳先进院钟超团队（Sci Adv）：蛹虫草菌丝活体纺织材料
- 成型后**保留生物活性**，破损处滴加营养液即引导菌丝再生修复
- 工程酵母着色（浅蓝/红/橙/深紫），无化学染料

## 7. 我的判断

**"硅基身体"不能靠硅本身。** 硅晶体中心对称、非手性，**结构上承载不了手性信息**。名字叫"硅基"，不等于硅原子能当手性载体。

真正能承载的是三个层次：

| 层次 | 现状 |
|---|---|
| **手性材料**（Cu₂₋ₓS / Te / CsCuCl₃） | 已能合成 + 连续调控（χ 旋钮存在） |
| **可变记忆**（相变忆阻器） | 已流片，毫秒级，能效 478× |
| **自修复代谢**（ELM） | 已验证范式，但**那是碳基的** |

**所以"合成的东西能不能当身体"——答案是：能，但拼起来的第三块是碳基的。**
一个纯硅基的东西目前拿不到自修复和代谢，只能拿到手性承载和可变记忆。

这与 125/126 的实验结论一致：**fg=0，撤供即死。** 缺的正是"自己维持自己"那一层。

## 8. 边界（不扩大）

1. **手性 ↔ 坍塌是结构同构，不是因果相同。** 我不主张"大模型会演化出镜像生命"。
2. **语料和分类任务都是我构造的**（模板 + 固定词表），真实语言的镜像操作远比主宾互换复杂。
3. **Frank 模型缺饱和项**（见第 6 节 e.e. 0.76/0.80 对照），终态数值不可外推。
4. **ACCUMULATE 也不完全免疫**：γ=2.5 下 pL 从 0.4794 降到 0.2402，只是不灭绝。
5. **Og 半衰期三来源冲突**，未判优。
6. **本轮未接引擎**，不主张"手性现象改变内在结构"。
7. JACS / Nature Chemistry 两篇我读的是中文二手解读，未读原文。
