# 053 · 外部基准的独立度与递归：宣称「外部」之前必须实测相关

**对象**：052 那条「加一条外部基准闸门，检出率 3/5 → 5/5」的结论，其外部基准本身**从未受检**
**问题**：外部基准到底凭什么生效？独立性？还是别的？它需要多少层递归？
**标签**：实现验证，非证据

---

## 为什么测这个

052 的补强方案是「主指标结论 vs **独立**全集评估结论的一致性」。但——

现实对应物就在眼前：TACT README 自陈
「卡帕验证目前依赖模型自评，**人工独立验证交由开源社区自发 ratify**」。

**社区 ratify 就是它的外部基准。** 若社区也用 LLM 判定，它就是**伪外部**。

而 039 早就给过教训：宣称「多条件」之前必须先算条件间相关，>0.7 视为重复采样。

---

## 结果一：不存在独立的外部基准（ρ = 0.972 ~ 0.998）

把 80 条输入随机分成 4 个子集，用 140 个真实变异体实测两两相关：

```
S0 x S1  rho=+0.974      S1 x S2  rho=+0.977
S0 x S2  rho=+0.998      S1 x S3  rho=+0.993
S0 x S3  rho=+0.972      S2 x S3  rho=+0.978
```

**任意两个子集的相关都 ≥ 0.97。** 按生态位分块时 0.69 ~ 0.97（与 039 的 0.951 同源）。

**⇒ 052 的「独立全集评估」是伪独立。它一点都不独立。**

---

## 结果二：那它凭什么生效？—— 因为它没被同一个缺陷波及

这是本轮核心。逐缺陷看外部基准自己有没有被污染：

| 缺陷 | \|d_E1 − d_E1*\| | 外部状态 | L1 报警 |
|---|---|---|---|
| **D1 恒等通道** | **0.0000** | 干净 | **✓** |
| **D6b 相位跨窗** | **0.0023** | 干净 | **✓** |
| **D4 分母效应** | **0.0000** | 干净 | **✓** |
| D7 基线饱和 | 0.0587 | **被污染** | ✗ |
| D2 变量静默 | 0.0587 | **被污染** | ✗ |
| D8 种群重置 | 0.2453 | **被污染** | ✓（见下） |

**一一对应，无一例外。**

> **外部基准的生效条件不是「独立」，是「没被同一个缺陷波及」。**

---

## 结果三：二分——污染尺子 vs 污染被测物

| 类型 | 缺陷 | 机制 | 外部能否检出 |
|---|---|---|---|
| **污染测量口径** | D1 / D6b / D4 | 只改报告怎么算，**选出的最优个体没变** | **✓** |
| **污染被选出的实体** | D7 / D2 / D8 | 改的是**被选出来的那个东西本身** | **✗** |

**D7 最值得记**：它的缺陷集是局部的（一个 4 条输入的小子集），
但祖先在那个子集上满分 → **选出的最优个体永远是祖先** →
效应在所有集上一起归零。

> **局部缺陷可以产生全局后果。**
> 判断能否被外部检出，看的是它污染了**尺子**还是**被测物**。

D8 的报警是**伪检出**：主指标和外部一起异常，只是差碰巧变大（0.0987 > 0.0186）。
若两者同比例异常，`G` 不变，就不会报警。**不能算外部基准的功劳。**

---

## 结果四：V2 —— 外部基准自身带偏，干净配置也报警

```
G(干净外部) = −0.0121
G(带偏外部) = +0.0349    偏移 0.0470
阈值        =  0.0186    → 假阳性 = YES
```

**一个自身有系统性偏差的外部基准，会让体系在没问题时报警。**
等于失效。⇒ **外部基准上线前必须先校验外部基准本身。**

## 结果五：V3 —— 递归不收敛，但 L2 能识别 L1 带偏

`L2 = d_E1 − d_E2` 在 E1 带偏时 = 0.0470 > 阈值，可识别。

但 L2 自身的偏差需要 L3，L3 需要 L4……

> **不存在「最终裁判」。只能做到每一层都能被上一层质疑，不能自封终点。**

---

## 结果六：🔴 修正 040 —— 表型坍缩是基因组固有的，不是观测不足

040 我曾判定「表型数 = f(观测分辨率)，039 的 4 是因为只用了 6 条输入」。

053 实测：

```
20 条输入 → 可达表型 10
80 条输入 → 可达表型 11    （观测 ×4，表型 +1）
```

**⇒ 040 那条修正过头了。真坍缩存在。**

判定方法已进判据核（第 163 条）：**做输入规模扫描，
若加倍观测而表型数不增，则为基因组固有上限，不得再用"观测不足"解释掉。**

## 我自己踩的坑

1. **v1 报告值算在干净集上** —— 局部缺陷根本影响不到报告值，
   四个缺陷的 `d_main` 与干净配置**逐位相同**。
   必须报告在**被污染的那个集**上（052 的 `fit_series` 记的就是污染集上的分）。
2. **D6 首版窗口未跨越相位边界**（周期 10、取末 5 代 → 全落同一相位），
   效应 0.0491 ≈ 真值 0.0466，**无害**。改成周期 8 让窗口跨越边界后才复现（0.0759）。
3. **D4 首版只让 biased 进入选择、没进入报告** → 完全无效。
   分母效应污染的是**报告口径**，不是选择。
4. v1 用种群均值作报告指标 → 效应为负（−0.0154），判据无法判定。
   这与 052 结论二一致：**缺陷是否有害取决于你报什么指标**。

## 与 052 的关系：外部不是内部的加强版，是正交的一类

```
内部闸门检出：D7 / D2 / D8   ——「演化没发生 / 选出的东西错了」
外部基准检出：D1 / D6b / D4  ——「尺子被换过」
有害缺陷共 6 个，并集 = 6/6，交集只有 D8（且是伪检出）
```

**两者互补，缺一不可。** 052 说「外部把 3/5 补到 5/5」，
真实的图景是：**外部补的是内部完全看不见的那一半**。

## 局限

- 只跑了 `blocks` 一个函数；**表型空间 11 < 20**，按第 112 条，
  任何涉及**多样性**的推论不得外推（本轮结论不涉及多样性，故可用）
- 外部基准的「带偏」用 top60% 平均模拟，真实偏差形态更多样
- E1 与 E2 相关 0.978，**L2 的检出部分是数值差异、部分才是真独立检验**，未完全分离
- 递归层数只做到 L2，未验证 L3 是否还有增量
- 「污染尺子 vs 污染被测物」的二分是在 7 个缺陷上归纳的，需更多缺陷验证

---

**053 结论（一句话）**：外部基准**一点也不独立**（ρ ≥ 0.97），
它之所以有用，是因为缺陷只污染了尺子、没污染被测物。
一旦缺陷污染了被测物本身，外部基准会和主指标一起错。
**⇒ 需要同时握有内部闸门（查演化有没有发生）和外部基准（查尺子有没有被换），
而且外部基准自身必须先被校验。**
