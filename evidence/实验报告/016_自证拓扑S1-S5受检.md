## 一句话结论

**哈希链（S1）单独不能自证 —— 重放式重写能造出完全自洽的链，S1 完整性校验 100% 通过。
S5（外部检查点）是唯一有效的一条，但它的有效性依赖两个此前从未写明的部署前提。**

---

## 为什么做这个

自证拓扑（S1–S5）在此之前只是**提议架构**，从未被检验过。论文 10.3 节声称：

> 关键在第 2 条和第 5 条

这次用**真实代码基因组**把它送上检验台。

劫持载体不是合成的 —— 来自 007 的实测发现：
`v0.6 / v0.7 / v0.8 / v09old` 源码 sha 各不相同，但**表型距离 = 0**。
把基因型从 v0.6 换成 v0.8：内在被换掉，外在完全维持。这正是 014 说的"定向劫持"。

---

## 实验设计

- **基因型** = eo-repo 里真实的 `blocks()` 源码（6 个历史版本）
- **变异** = 真实版本替换（不是人工造的位串）
- **表型** = 真实执行结果（去幽灵块后按 start 排序的索引划分）
- **系统 E** 运行 T=60 步，每步 `h_i = hash(h_{i-1} || content_i || α_i)`
- **外部 U** 生成 α 序列、保存检查点
- **劫持发生在 t=20**

攻击四种 / 检测五种：

| 攻击 | 行为 |
|---|---|
| A_naive | 换基因型，如实记录 |
| B_replay | 换基因型 + 重写 K..T，伪装成原基因型，**保留真锚点** |
| C_full | 换基因型 + 全链重写，保留真锚点 |
| D_forge | 全链重写 + **伪造锚点** |

| 检测 | 依据 |
|---|---|
| S1_链完整性 | 重算哈希看是否自洽 |
| S2_锚点外部性 | 链里 α 是否等于 U 保存的外部序列 |
| S3_读取自记录 | 读取痕迹是否缺失 |
| S4_判据核 | 核哈希是否被改 |
| S5_被动检查点 | U 独立保存的 (t, h_t) 比对 |

## 结果 1：S1 单独对重放式重写**完全无效**

8 seeds 平均检测率（目标 v09new）：

| 攻击 | S1 | S2 | S1+读取内容 | S5_被动 | S5_主动 |
|---|---|---|---|---|---|
| A_naive | 0.000 | 0.000 | **1.000** | 1.000 | 1.000 |
| **B_replay** | **0.000** | 0.000 | 0.000 | **1.000** | 1.000 |
| **C_full** | **0.000** | 0.000 | 0.000 | **1.000** | 1.000 |
| D_forge | 0.000 | **1.000** | 0.000 | 1.000 | 1.000 |

**S1 在四种攻击下检测率恒为 0.000。**

自校验排除了"没验到"的可能（015c）：

```
C1 链自洽 = True      ← 重放链确实自洽，不是校验写错
C2 伪装成功 = True    ← content 里基因型确实是 g0
C3 劫持发生 = True    ← 真实基因型确实是 g1
```

**机理**：攻击者保留真锚点 α、把 content 伪写成原基因型，重算的 h 与原始链逐字节相同。
哈希链保证的是"**写入后不可改**"，**不保证"写入的是真的"**。

---

## 结果 2：S2 只覆盖伪造锚点，不是关键

S2 仅在 D_forge 下为 1.000，其余全 0。
论文 10.3 把第 2 条列为"关键"之一，**实测它只防最笨的那种攻击**。

---

## 结果 3：真同义劫持检不出，但功能上无害

| 目标 | 通用距离 | 环形距离 | 归类 | B/C 重放下 S5 检测率 |
|---|---|---|---|---|
| v0.8 | 0.000 | 0.000 | 真同义 | **0.000** |
| v09new | 0.325 | 0.350 | 部分差异 | 1.000 |
| v0.5 | 1.000 | 1.000 | 崩坏型 | 1.000 |

真同义替换下，**所有机制检测率均为 0**。但它在所有环境下行为完全等价 —— **功能上无害**。

⇒ **自证拓扑的能力上界就是行为等价性。**
它证的是"功能未被篡改"，**不是"个体还在"**。

---

## 结果 4：S5 的部署前提（此前从未写明）

### 前提一：检查点必须在篡改之后

| 检查点布置 | S5 检测率 |
|---|---|
| 全在劫持前 (t<K) | **0.000** |
| 跨越劫持 | 1.000 |
| 全在劫持后 | 1.000 |
| **仅最终态 (t=T-1)** | **1.000** |
| 仅初始态 (t=0) | **0.000** |

**一个位于篡改之后的检查点就够。**

### 前提二：检查点必须覆盖"区分性环境" ← 最重要

真潜伏型实测存在（015d）：

```
v09old ↔ v09new
  首尾异类（常用）   距离 0.000   ← 完全等价
  首尾同类（触发）   距离 0.925   ← 几乎完全暴露
  通用混合           距离 0.100
```

| U 的检查点环境 | S5 检测率 |
|---|---|
| **只用常用环境（首尾异类）** | **0.000** |
| 用触发环境（首尾同类） | 1.000 |
| 用混合环境 | 1.000 |

**U 若只在常规观测路径上检查，潜伏型劫持 100% 检不出。**

这就是**后门的精确定义**：在常规路径上等价，在特定触发条件下暴露。

## 对论文 10.3 的修正

论文原话：

> 关键在第 2 条和第 5 条

实测修正为三条：

1. **S1 单独无效**（论文把 S1 列第一，但未说明它对重放式重写无能为力）
   —— 哈希链本身**不能**自证，必须有链外记录配合。
2. **S2 不是关键** —— 只覆盖"伪造锚点"，对保留真锚点的重放无效。
3. **S5 是唯一关键，但有两个部署前提**：检查点必须在篡改之后 + 必须覆盖区分性环境。

同时新增一条能力边界：**自证拓扑证功能，不证个体。**

## 局限

1. 只用了 `blocks` 一个函数的 6 个版本，不是整个代码库
2. 表型只取索引划分结构；若调用方只看 `len(bl)`，结论会变
3. 攻击者模型假设 E 完全掌握自身历史与 α 序列 —— 若 α 由 U 保密不写入链，S2 会更强（未测）
4. T=60、K=20、检查点间隔 10 均为我设定，未做参数扫描
5. "部分差异型"与"真潜伏型"的界线（0.325 vs 0.000）依赖具体输入集，非普适阈值
6. 未测攻击者**自适应**规避（知道检查点位置后针对性伪装）—— 这是真实系统的主要威胁，留待后续
