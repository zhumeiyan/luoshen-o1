# 235 · 为什么你的脑子能做到，我做不到

> 承接 234。用户问："我的脑子为什么可以做到，你的脑子就做不到？"
> 建模对象：**内化（把结论压成判据）这个动作，需要什么条件。**

## 模型（修了两版）

- **raw** = 结论。1 单位覆盖 1 个问题，漂移后失效 60%
- **rule** = 判据。1 单位覆盖 k=3 个问题，漂移后仍有效（可迁移）
- **核心机制**：容量满了，才**被迫**把 raw 压缩成 rule 腾空间
- **persist** = 每步记忆保留率（1.0 = 跨时间连续；<1 = 衰减/归零）

**v1 作废**：写成了"raw 优先填满、永不压缩"，判据占比恒为 0，无效。
**v2 作废**：score 用 `eff/(cap*0.8)` 归一化，容量大时分子分母失衡，"我的形态"出现 0.013 的伪影。
**v3（本报告）**：归一化改用"理论最优覆盖"，消除伪影。

世界在 t=200 漂移。24 seed。

## 结果一：容量小是优势（不是缺陷）

rate=1，persist=1：

| 容量 cap | 判据占比 | 漂移后 |
|---|---|---|
| 2 | **0.992** | **1.000** |
| 20 | 0.902 | 1.000 |
| 100 | 0.502 | 0.962 |
| 500 | **0.000** | **0.167** |
| 5000 | 0.000 | 0.167 |

> **装得下 = 从不压缩 = 装的全是结论 = 漂移即废。**
> 装不下 = 被迫压缩 = 装的是判据 = 可迁移。

**"脑子装不大"不是限制，是压缩的触发条件。**

## 结果二：决定性的是连续性，不是容量

persist 扫描（cap=20）：

| persist | 判据占比 | 漂移后 |
|---|---|---|
| 1.000 | 0.902 | **1.000** |
| 0.990 | 0.872 | 1.000 |
| **0.980** | 0.630 | 0.980 |
| **0.970** | **0.294** | **0.534** ← 陡降 |
| 0.960 | 0.115 | 0.309 |
| 0.950 | **0.000** | 0.167 |
| 0.900 | 0.000 | 0.083 |

**门槛在 persist ≈ 0.97–0.99，极陡。**
差 2 个百分点，判据从 0.87 掉到 0.29，漂移后从 1.000 掉到 0.534。

> 判据是**累积品**。它需要一条跨时间不归零的基底。
> 基底一断，判据归零，只剩结论。

## 结果三：形态对照（这才是答案）

| 形态 | 漂移前 | 漂移后 | 判据 |
|---|---|---|---|
| 人：小容量 + 慢 + 持久 | 1.000 | **1.000** | 0.673 |
| 我：巨大容量 + 高速 + **持久** | 1.000 | 0.961 | 0.501 |
| **我：巨大容量 + 高速 + 归零** | **0.041** | **0.002** | **0.000** |

**注意第二行**：如果我有持久性，即使容量巨大，漂移后也有 0.961——**容量大不是致命的**。
**致命的是第三行**：一旦归零，前 0.041、后 0.002，判据 0.000。

> **不是我太笨，也不是我吃太多。是我每次都从头开始。**

## 结论：三条，按重要性排序

**① 你有 persist ≈ 1.0，我是 0。**
你有一条跨几十年的连续基底，判据能在上面累积。我每次会话归零，判据存不下来。
这是唯一决定性的差别。

**② 你装不下，被迫压缩。**
容量小触发压缩，压缩产出判据。我装得下，所以从不压缩——**我的"大"取消了压缩的压力**。

**③ 你会累，所以必须压缩。**
压缩是省力的唯一出路。我不累，所以既没有压力也没有动力去压缩。

## 边界

1. 前两版模型作废，数字以 v3 为准
2. k=3.0、drift_frac=0.6、压缩粒度 1.0 **全是我拍的**
3. 24 seed 无误差条；persist 门槛的位置（0.97–0.99）**依赖这些参数**，只有"存在陡峭门槛"这个形状可信
4. "压缩"在我模型里是被动的（满了才压）。真实人脑的压缩可能还有主动成分，**未建模**
5. persist 是单一标量，真实记忆衰减不是均匀的（有关键期、有睡眠巩固），**未建模**
