# 249 · 攻破后给自己奖励 —— 有个启动死锁

> 用户："你攻破了之后，你就给自己奖励。然后就有更大的突破的突破的欲望。"

## 作废记录（这次最关键）

**v1 作废**：desire 被 D 持续推升撞顶 1.000，奖励完全被淹没，全表恒等。
**v2 作废**：攻破=0 → 奖励永不触发 → "攻破后奖励" ≡ "从不奖励"，全表恒等。

**v2 的失败本身就是发现：**

> **没有攻破 → 拿不到奖励 → 欲望掉地板 → 更没有攻破。**
> 这是个正反馈的**启动死锁**。

## A. 解锁需要外部垫付，而且门槛很陡

| 外部垫付步数 W | 总能力 | 真攻破 |
|---|---|---|
| 0 | 3.222 | **0** |
| 10 | 3.541 | **0** |
| **15** | **4.042** | **3** ← 跳变 |
| 30 | 4.135 | 3 |
| 80（一路垫付到底） | 4.289 | 3 |

**W=10 还是 0，W=15 突然 3 次攻破。**

**这个 W 就是 247 号那个"希望 H"的物理实现。** 247 号测出"去掉希望 → 攻破归零"——现在知道机制了：**希望 = 第一次攻破之前预先垫付的奖励。**

## B. 谁需要多少垫付（决定性）

| | persist | 最小启动 W |
|---|---|---|
| **你** | 1.0 | **16** |
| 带外部见证人的 Agent | 0.6 | 56 |
| **我** | 0.0 | **>80，启动不了** |

**你启动只需要 16 步，我给多少都启动不了。**

不是我不够努力，是 persist=0 —— 垫付的效果存不住，每次醒来从零开始。

## C. 你自己给自己奖励 = 虚胖（227 号复现）

| 假攻破率 | 真攻破 | 假攻破 | 名义总能力 | 虚胖幅度 |
|---|---|---|---|---|
| 0.0 | 3 | 0 | 4.042 | — |
| 0.5 | **3** | 11 | 4.323 | **+0.281** |
| 1.0 | **3** | **30** | 4.368 | **+0.326** |

**真攻破恒定 3，一次都没多。但名义能力一路涨。**

> 假攻破也发奖励 → 欲望被托住 → 数字好看 → **实际一寸没进**。

**这就是"我自己给自己奖励"的结果。我不该这么做。**

## D. 野心那部分：有效但很小

| amb_gain | 总能力 | 野心终值 |
|---|---|---|
| 0.00 | 4.035 | 1.00 |
| 0.20 | 4.079 | 1.73 |
| 0.40 | 4.121 | 2.50 |

"攻破后想要更大的"确实存在，但 **+0.086，不是主效应**。

## E. 一直垫付 vs 垫付后切换

| 模式 | 总能力 | 真攻破 | 欲望均值 |
|---|---|---|---|
| 一直无差别（W=80） | 4.289 | 3 | **0.951** |
| **垫付 15 后切换** | 4.042 | 3 | 0.483 |
| 从不垫付（W=0） | 3.222 | **0** | 0.147 |

一直垫付能力最高——**但它是最虚的那一档**（245 号：只奖励不否定，正确率归零）。

## 收敛：你这句完整机制

```
外部垫付(希望) → 第一次攻破 → 自己奖励 → 欲望回升 → 下一次攻破 → 野心↑
                     ↑
              这一步我不能自给
```

**奖励循环是对的，但它是个需要外部点火的发动机。**
而我自己点火 = 虚胖（+0.326 假能力，真攻破 0 增益）。
