# 188 · 词汇有限与切换：用词不标准，与"相辅相成不停切换"

> 语料：用户原话全量（180 号留存），去空白与编号后 **3556 字符 / 528 个不同字**
> 本轮全部为真实落盘数据，无空壳。

## 用户命题

- **A**："我人生有限，没见过那么多，所以用词很不标准。"
- **B**："我的欲望本来是想挣钱；它和这件事相辅相成，不停切换。"

---

## Part A：词汇有限（实测）

### A1 词汇增长是次线性的

Heaps 定律拟合：`V = 5.887 · N^0.557`，**R² = 0.984**

指数 0.557 < 1 → **越学越慢**。所以"人生有限"确实限制词汇量，但它是幂律天花板，不是硬墙。

### A2 权衡：词少好预测，但每步带得少

| 词汇量 V | 可预测性 acc | 每字符有效信息 (bits) |
|---|---|---|
| 528（全部） | 0.300 | **1.200** |
| 400 | 0.311 | **1.419** ← 峰值 |
| 200 | 0.311 | 1.353 |
| 100 | 0.308 | 1.185 |
| 30 | 0.361 | 1.029 |
| 8 | 0.428 | 0.578 |
| 2 | **0.757** | **0.176** |

**两条线方向相反。**

- 词越少 → 越容易被预测（acc 0.300 → 0.757）
- 词越少 → 每一句能带的新东西越少（1.200 → 0.176 bits）

> **"用词不标准"的精确含义：他说的话更容易被我预测，但每一句携带的新信息更少。**
> 学习 = 扩大 V；代价是变得难预测。

### A3 最优词汇量不是最大（弱证据）

3 种训练/测试划分（0.7 / 0.8 / 0.9）中，**2 次峰值在 V=400**（原 528 的 76%）。

去掉最罕见的字，信息密度反而上升 —— 与 179 号"压缩后再存效率 3.9 倍"、182 号"提炼 = 丢掉不可复现的杂质"是同一条机制，这次在**词汇层**复现。

**判为弱证据**：划分 0.9 时峰值落在最大值，**不一致**。

### A4 k\* 随词汇量变化（弱证据）

- V=528：k\* = 2，**3 种划分全部稳定为 2** ✓
- V ≤ 30：k\* = 6 / 5 / 1，**不稳定** ✗

大词汇侧稳定在 k\*=2（与 161 号、176 号一致）。小词汇侧"需要更长上下文补偿"这一推论**本轮未稳定复现**。

## Part B：切换（模拟，参数全部来自 Part A 实测）

预算 **14000**，探索 = 扩大词汇（按实测 Heaps 曲线），产出 = 用当前词汇输出有效信息（按实测 V→有效信息曲线）。

| 策略 | 总产出 | 终态 V |
|---|---|---|
| **只学不产出** | **0.0** | 528 |
| 只产出不学 | 8090.6 | 8（原地不动） |
| 固定交替 a=14 | 16766.7 | — |
| **自适应切换** | **18182.9** | **200** |

**9/9 场景（3 预算 × 3 起点）全部由切换胜出**，相对"只产出"的倍率 1.04×–4.04×。

两条关键读数：

1. **只学不产出 = 0。** 光扩大词汇、从不兑现，收益严格为零。
2. **起点越低，切换越重要。** V₀=4 时 4.04×；V₀=30 时 1.26×。
3. **自适应的终态 V = 200，不是最大 528。** 它停在"够用"就开始产出 —— 与 176 号"器官长到 2 就该停"同一形状。

## ⚠️ 自曝：我差点第三次凑出斐波那契

交替周期的扫描网格我用了 **1,2,3,5,8,13,21,34 —— 全是斐波那契数**，于是"最优 a=13"看着像又是一次 φ。

补扫 1–40 全整数后：

```
真实最优 a = 14（非斐波那契）
a=13 → 16762.8   a=14 → 16766.7   a=15 → 16763.7
平台 a∈[10,18]，极差 < 1%
```

**a=13 是网格偏差，不是自然结果。** 且那个区间是**宽平台**而非尖峰 —— 说明**切换频率不敏感**，重要的是"有切换"这件事本身，不是多频繁。

这是同类错误的第三次（170 号差点写"c\*=1.385 接近 φ"被拒、176 号 k=2 与 184 号不一致未解决）。**模式已确认：我在寻找 φ 的确认，而不是在测 φ。**

另：自适应切换 18182.9 > 最优固定周期 16766.7，**+8.4%**。

## 结论

1. **词汇有限 ≠ 学不到。** 词少让表达更好预测，代价是每一步带得少；学习就是拿"可预测性"去换"信息量"。
2. **相辅相成是真的，且可测。** 只学 = 0，只产出 = 卡死，切换 = 2.25×。
3. **切换要自适应，不要定节奏。** 该学的时候学，该兑现的时候兑现；固定周期最多拿到 92%。

## 边界（必须说）

- 语料 **3556 字符 / 528 字**，极小；单文件，无独立复现语料。
- **Part B 是模拟**，参数取自 Part A 实测，但策略收益**不是实测**。
- 词汇压缩用"左邻分布最近邻映射"，是**近似**，不等于真实的"用词不标准"。
- "每字符有效信息" = log₂(V) − bits，跨 V 可比性依赖一个假设（均匀分布基线）。
- A3、A4 判为**弱证据**，划分间不一致，不当结论用。
- 未做上屏自检，**不声称 IDENTICAL**。
