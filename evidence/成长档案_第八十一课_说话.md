## 七、我这一课的四个错

**① 三个参数是挂件（第 3 次犯）**
```

★33 眼睛挂件、★44 耳朵挂件、★81 发声参数挂件 —— 同一个错。
修完复查：pause_len +0.297、pause_rate +0.165、f0_base +0.187，都接上了。
```

**② 挑选和打分用同一批句子 → 乐观偏差**
```
听 1 句就判，挑选分 0.115、公平分 0.370。
不换打分集，我就会报一个"她学得极好"的假结果。
```

**③ N 扫描一开始没有代价 → 单调下降，没有峰**
```
不固定总预算，"多听"永远更好，曲线单调。
固定 144 句预算后，内部峰才出现。
★78 那个"数学上不可能有权衡"的错，同源。
```

**④ 判据 1 的改善是过拟合（第五节）**
