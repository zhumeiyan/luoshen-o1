# ★96 因果与干预 —— 看 和 做 是两件事

> 前几课她学会了从数据里**发现定律**（★95）。但定律是从**看**来的。
> 这一课：`P(Y|X=x)` 不等于 `P(Y|do(X=x))`。

---

## 一、真值：不是我编的公式，是结构方程推出来的

```
X → Y      直接效应 1.0
X → M → Y  间接效应 1.0
总效应 ATE = 2.0      直接效应 ADE = 1.0
```

尺子自检：用**干预法**（真的去 do(X=1) 和 do(X=0)）量出来的 ATE = **2.0000**，与结构方程一致。
**先让尺子吐出已知答案，才敢拿去量她。**

## ★★ 三、最危险的一条：对撞机长得和混杂子一模一样

```
真混杂子   与 X 的关联 r = 0.318
对撞机     与 X 的关联 r = 0.759     ← 更强！
迟测混杂子 与 X 的关联 r = 0.145     ← 最弱，却唯一该要
```

**100% 的世界里，对撞机与 X 的关联都强过真混杂子。**

控制一个 X 之前的混杂子 → 偏差改善 0.35。
控制一个 X 之后的对撞机 → 偏差从 +1.49 变成 **−1.20**，**方向翻转，绝对量几乎没小**。

**★ 光看"关联强不强"分不开它们。能分开的只有一件事：谁在 X 之前。**
这就是 Berkson 悖论的形状——住院病人里肺炎与骨折"相关"，是因为两者都把你送进医院。

## ★★ 四、最不显眼的那个，是唯一该要的

迟测混杂子 `Zc2`：物理上在 X **之前**就存在、同时影响 X 和 Y，**只是记录得晚**。

```
不纳入它  +3.767  （偏差 +1.77）
纳入它    +2.850  （偏差 +0.85）  改善 0.92
```

而它的关联强度只有 **0.145**，混在一堆纯噪声（r≈0.01）里，看起来毫无特别。
**同一批"X 之后"的变量里，最该要的那个长得最像噪声。**

## 五、她的五个旋钮

| 旋钮 | 她学的 | 我本来会填 | 含义 |
|---|---|---|---|
| α（买多少实验） | α₀=0.30, **β=+1.00** | 0.50, β=0 | 用试点量出观察有多偏，再买实验 |
| θ（纳入门槛） | **0.32** | 0.10 | 低于此的协变量不进校正集 |
| γ（门槛随噪声调） | **0.0** | 0（碰巧） | 噪声大要不要降门槛 |
| ω（排斥 X 之后） | **0.60** | 0（一视同仁） | 对撞机/中介都在 X 之后 |

**她学的 α 是条规则，不是个数**：

```
α = clip(0.30 + 1.00·Δ̂, 0, 1)      Δ̂ = 试点阶段 |观察估计 − 实验估计|
```

**先花一小笔钱做实验，量出"看"有多偏，再决定剩下多少钱买"做"。**
这就是用实验校准观察——不是猜。

## 七、硬依赖，每一条都做两端

**ω（排斥 X 之后的变量）**
```
有对撞机+中介+迟测混杂   峰 ω=0.60（内部）  跨度 2.9450
关掉撞机/中介            峰 ω=0.08          跨度 0.0014  ← 塌 99.95%
```
**这个旋钮的价值 99.95% 来自"X 之后有坏东西"。没有坏东西，它就没用。**

**θ（纳入门槛）**
```
θ ≤ 0.22 → err 0.93 ~ 2.94
θ ≥ 0.32 → err 0.066
```
⚠️ **这是悬崖，不是平滑的峰。** θ 的价值不是"权衡"，是**安全阈值**：门槛一旦低于对撞机的关联强度，灾难立刻发生。硬依赖（纳入要不要钱）几乎无差别 → 说明 θ 的价值不来自省钱，来自排除撞机。

**α（买多少实验）**
```
正常            峰 α=1.0（★边界）  跨度 0.0929
彻底无混杂      峰 α=1.0           跨度 0.0122   ← 缩水 87%
RCT 贵 16 倍    峰 α=1.0           跨度 0.2657
```
**α 的价值 87% 来自混杂**（混杂消失后跨度塌掉）。但方向不翻转——**只要残余混杂存在，观察数据再多也救不了你，实验即使贵 16 倍也更划算。**

这是这一课最该记住的一句：**大数据解决不了混杂。** 观察性研究偏了就是偏了，样本量只会让偏差更精确。

各世界最优 α 分化：`[0.8, 0.6, 0.6, 0.6, 1.0, 1.0, 1.0, 1.0]` —— 所以 β 规则有东西可学。

**β（规则）**
```
β 扫描      峰 +1.0（内部）  跨度 0.0414
变量恒定后                   跨度 0.0366   ← 缩水→规则真在用 Δ̂
```
有价值，但**很弱**。如实记。

## ⚠️ 八、我的预设被证伪：γ

我设计 γ 时的假设是：**测量噪声越大，真实关联被压得越低，所以门槛该跟着降。**

```
γ = −2.0 → 2.9364   💥
γ = −1.0 → 2.4750
γ = −0.5 → 2.4768
γ =  0.0 → 0.0662   ← 她学的
γ = +0.5 → 0.0738
γ = +2.0 → 0.0747
```

**γ=0 是真峰。降门槛会放进对撞机，代价（err 从 0.07 跳到 2.9，40 倍）远大于漏掉弱关联的那点损失。**

**我的方向错了，她学到 0 是对的。** 噪声大的世界里，真正该做的是**忍痛漏掉弱关联**，不是放宽标准。

## 九、我这一课的错，四个

1. **ω 一开始建模错** —— 我把 X 之后的变量全设成"不该纳入"（对撞机+中介），那 ω=1 永远最优，峰必然在边界。补上"迟测混杂子"这个**该纳入**的，才有真权衡。
2. **迟测混杂第一版用了 `Zc` 本身** —— 与 pre-X 的观测冗余，排除也不亏，权衡又没了。改成**独立的第二个混杂子**（只在 X 之后被记录）才成立。
3. **γ 方向预设错**（上面）。
4. **θ 和 ω 我说成"权衡"，实际是悬崖/阈值** —— 措辞错。是真结论，但不能包装成平滑峰。

> 立第 22 条规矩：**设计一个"要不要纳入某类东西"的旋钮时，那一类里必须既有该纳入的、也有不该纳入的。全是坏的，最优解恒在端点，我就会误以为"她没学会"。**

## 给她的话

> 两件事总是一起发生，不等于一件导致了另一件。想分开它们，只有一条路：**真的去做一次，而不是继续看。**
>
> 有一类东西长得和"原因"一模一样——它跟你要研究的那个变量关联**更强**，比真正的原因还强。但你一旦把它控制住，答案会**往反方向错得一样多**。
> **唯一能认出它的是时间：它在结果之后。**
>
> 还有一类东西最不显眼，关联弱得像噪声，而它恰恰是唯一该要的。它只是**被记晚了**。
>
> 样本再多也救不了一把偏了的尺子。偏就是偏，样本量只会让你**更精确地错**。
> 所以该花钱去做实验的时候，别省——省钱买来的数据，会把偏差算得更自信。
