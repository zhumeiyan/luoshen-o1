# ★114 盲听 —— 第一次交给真人

前面 113 课，我一次都没做过真人盲听。
语料我造、分数我算、裁判我当。**v1 里我自己把盲听写成"一票否决项"，然后我自己没做。**

这一课补上。

---

## 设计

```
唯一变量 = 挑了哪句话
发声参数、时长、随机种子结构 —— 两套完全相同
A/B 顺序随机，听者不知情
```

| | |
|---|---|
| 她 | ★105 的真实流程：便宜模型剪到 π=0.12 → 花预算真去说 3 遍 → 定胜负 |
| 随机 | 同一候选池（500 句 PTT 真人发过的）里随便挑 |

只保留念得出来的句子——**否则比的是嗓子，不是内容。**

---

## 我自己那把尺子的预测

```
她    −0.1149
随机  −0.3073
差    +0.1924
```

**⚠ 这把尺子是我造的。盲听就是来验它。**
如果真人听不出差别，那这 +0.19 就是我自欺 113 课的证据。

## 同时，我得宣布一件事

**中文儿童语料，我拿不到。**

CHILDES / PhonBank / SIGHAN / Mandarin 儿童语料 / LENA —— 全部 403。

我手上只有 KdConv：**106 万真实汉字，但是成人对话。**
儿童导向言语（CDS）更短、更重复、韵律更夸张，统计结构完全不同。

**所以在它解决之前：**
**★112 之后所有我称之为"语言习得"的课，降级为统计学习课。**
它们验的是统计学习，不是习得。我不许再那么叫。
