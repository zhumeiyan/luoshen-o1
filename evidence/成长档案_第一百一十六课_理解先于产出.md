# ★116 理解先于产出

## 起因

用户：**"你做不到就多想想。"**

我上一轮说"儿童语料拿不到"。这一轮我把能想的都想了。

---

## 一、儿童语料：五条路，全试过，确实拿不到

| 路 | 结果 |
|---|---|
| 沙盒直连 talkbank / childes-db / github raw / HF / OpenSLR | **403**（egress policy：`No policy rule matched`） |
| web_fetch 抓 TalkBank 页面 | 页面能抓，但"Download transcripts"无 href（JS 动态） |
| web_fetch 抓 childes-db API | 不可达 |
| GitHub raw（ChildMandarin README） | 不可达 |
| **pypi 全量索引 91 万包** | **能下（47MB）**，但无任何自带中文儿童语料的包 |

**结论：外部中文儿童语料（CHILDES / CDS / ChildMandarin）确实拿不到。这条我不再假装能解决。**

---

## 二、但"多想想"之后我发现：我找错了东西

我一直在找**数据**。可 ★112 我自己列的领域硬要求里，最硬的那条根本不需要 CDS：

> **"先测理解，不许先测产出。12 月龄婴儿理解约 50 词，产出只有 1~3 词。"**

**我 115 课全在测产出，一个理解测验都没有。**

**理解先于产出是跨语言的普遍规律，不需要儿童语料也能验。**

---

## 三、给她搭了两样

**① pypinyin（外部库）** —— 她的手工字典只有 60 字，**现在任意汉字都能发音**。

**② 21 个声母**（★115）已接上，加上 pypinyin = 她第一次能说任意中文句子。

---

## 四、实验：理解 vs 产出

**语料**：KdConv 12 万真实汉字（不是我生成的）
**分词金标**：pkuseg（外部工具）
**理解**：给定上下文，10 选 1 认出正确的词
**产出**：给定同样上下文，自己生成那个词

```
理解准确率  0.8343   （随机基线 0.1000）
产出准确率  0.1490
                      差 5.6 倍
```

**这个差距稳定，不随采样次数变化。**

---

## ★★★ 五、我差点又报一次假成绩

exp116 第一版报：

```
理解集 294   产出集 145
只在产出里 0   违反包含关系 0.0000   文献要求 ≈0
```

**看着完美符合文献。我去查它是不是真的——不是。**

膨胀检验：

| n_trial | 理解集 | 产出集 | 只在产出里 |
|---|---|---|---|
| 1000 | 276 | **86** | 1 |
| 3000 | 297 | **147** | 0 |
| 10000 | 298 | **220** | 0 |
| 30000 | 300 | **271** | 0 |

**产出集随采样次数单调膨胀，一路趋向词表上限。**

**"理解集 ⊋ 产出集"是数学平凡的**——产出是采样，采样次数越多覆盖越全。那不是她符合文献，是**我采样次数不够**。

**★112/★113 我连续三次栽在"挑了个让自己好看的对照"上。这是第四次，我提前抓住了。**

**唯一站得住的指标是准确率比 5.6**，它不随 n 膨胀。

---

## 六、5.6 落在哪

```
文献常模（MacArthur-Bates CDI）
  12月龄  理解/产出 ≈ 16.7
  16月龄              4.25
  18月龄              2.67
她                    5.6     ← 落在 16~18 月龄之间
```

**但绝对值不能比**——她的语料是成人对话，不是儿童导向言语。**只有"理解 >> 产出"这个形状是可检验的，它成立。**

---

## 立第 26 条规矩

**凡是"集合 A 包含集合 B"这类结论，先查它是不是采样/覆盖度的平凡结果。让样本量涨一个数量级，看结论动不动。**
