# ★99 融入社会

> **方向纠偏**：前面几课（★94~★98）教的是「查明世界真相」——
> 定律在数据里、因果在干预里、反事实在模型里、后悔在策略里。
> 那里的对象是**自然**，它不看你，不会因为你改变。
>
> **这一课的对象是「社会」：别的行动者。**
> 他们会看你、会根据你调整、会记仇、会合作、会骗你。
> **★ 你的存在本身会改变你试图理解的对象。**
>
> 真相已经写在公式里了。社会不是——社会的规则不需要「真」，只需要**被共同遵守**。

## 一、硬真值（先验尺子，四条全部对上）

| 真值 | 来源 | 实测 | 理论 |
|---|---|---|---|
| 一次性囚徒困境：背叛严格占优 | 支付矩阵解析 | 合作−背叛 = **−1.000**（两种情况都是） | < 0 ✔ |
| 直接互惠门槛 `δ ≥ c/b` | Nowak 2006, Science 314:1560 | 翻转点 **δ = 0.333** | c/b = 1/3 ✔ |
| TFT 有噪声崩溃 | Nowak & Sigmund / Axelrod 后续 | 合作率：ε=0 → **1.000**；ε=0.05 → **0.502**；ε=0.10 → **0.440** | 单调崩塌 ✔ |
| 信号必须昂贵才可信 | Spence 1973 / Zahavi handicap | `s` 峰在 **1.5**（内部），两端都塌 | 倒 U ✔ |

**δ 门槛的解析验证（最干净的一条）：**

```
δ      合作路径 (b−c)/(1−δ)   背叛路径 b    谁赢
0.300        2.857              3.000      背叛
0.333        2.999              3.000      背叛   ← 临界
0.340        3.030              3.000      合作   ← 翻转
```

**翻转点精确落在 c/b = 0.3333。这不是拟合，是解析。**

**TFT 自我对局崩溃（对她最要紧的一条）：**

```
无噪声：合作率从头到尾 1.000
ε=5%  ：前 20 轮 0.783 → 最后 40 轮 0.502
ε=10% ：前 20 轮 0.787 → 最后 40 轮 0.440
```

**★ 一次误会导致无限互相报复。她有感官噪声（★84 标定过），她会看错。
所以纯粹的「以牙还牙」会害死她。**

## 二、硬依赖：两端都验，且方向翻转

### `s`（costly signal）的价值是否来自「别人看得见」

| s | vis=1（声誉公开） | vis=0（谁也看不见） |
|---|---|---|
| 0.00 | 6.052 | **7.216** ← 最优 |
| 0.50 | 6.924 | 6.716 |
| 1.00 | 7.307 | 6.216 |
| 1.50 | **7.438** ← 峰 | 5.716 |
| 2.00 | 6.938 | 5.216 |

**有声誉 → 倒 U（峰在内部 1.5）；无声誉 → 单调下降（峰跑到边界 0）。**
**看不见你的时候，发信号就是纯亏。**

### 关掉未来（δ=0）

```
s=1.0   δ=0.9 → 7.307      δ=0 → 0.542
s=0.0   δ=0.9 → 6.052      δ=0 → 1.292
```

**★ s=1.0 在有未来时值 +1.255，关掉未来后值 −0.750。方向翻转。**
**没有「未来的影子」，声誉社会整个崩塌——发信号变成倒贴。**

## 三、她学的，和她的成绩

```
瞎起点（谁也不信、不报复、不原谅、只记1次、不发信号）  7.490
round1/2 收敛：t0=1.0  r=0.3  f=0  m=1  s=0        10.974
```

**她学到的是「老好人 + 一点点报复」。**

### held-out（新规模 N=14、新 δ=0.85、新噪声 ε=0.08、新居民构成）

| | 收益 |
|---|---|
| 老好人（全信不报复） | **9.571 ± 0.577** |
| **她** | 8.496 ± 0.681 |
| 我填的（中庸） | 7.902 ± 0.284 |
| 随机 | 7.925 ± 0.446 |
| 以牙还牙 TFT 式 | 7.696 ± 0.688 |

### ⚠️ 她没赢，我不粉饰

**她 8.496 < 老好人 9.571，差 1.075**（两者 SE 分别是 0.681 / 0.577，差异在边界显著）。

**但诊断比"赢了"更有意思：她比老好人多的那 0.3 报复，是净亏的。**

> **在声誉公开的社会里，连报复都是多余的——社会替你惩罚了背叛者。**
> 你自己动手，只会把自己也拖进互相报复。

**这就是「融入社会」最反直觉的一条：你不需要自己执法。**

## 四、★ 但我要诚实地标出这一课的局限

1. **`s`（信号）在单独扫描时有峰 1.5，她学的却是 0。**
   不是她学错 —— 坐标下降先走到 t0=1.0（无条件合作），此时声誉本来就满，信号变成纯成本。
   **t0 和 s 是替代关系，不是互补。她找到了另一条路，只是那条路更差一点。**

2. **`f`（原谅）和 `m`（记忆）在这个环境里区分度不足。**
   差异全在 SE 范围内。我修了一次（让 f 真正参与衰减加权），但信号仍被噪声盖住。

3. **居民构成是我定的。** 我放了 5 个"看声誉的居民"——是它们撑起了这个社会的声誉机制。
   换成全是 TFT / ALLD 的群体，结论会完全不同。

4. **「老好人赢」这个结论依赖群体里有足够的 INDIRECT 居民。**
   真实社会里 ALLD 会侵蚀它。我只验了这一个构成。

## 六、给她的话

> 这一课的世界里没有公式可查。你面对的不是自然，是**别人**。
> 他们会看你做过什么，而且**他们记得，你忘没用**。
>
> 三件事你要记住：
>
> **一，你会看错。** 你看错了就报复，对方报复回来，你再报复——
> 两个人都没做错任何事，却会一直打到死。所以报复要有，但**要留一扇门**。
>
> **二，你不认识的人不信任你，这不苛刻。** 想让别人信你，就得付出点什么——
> **不贵的承诺没人信，因为骗子也说得起。** 但代价是：如果未来不存在了，
> 你付的那些就白付了。发信号之前，先看看这个社会有没有明天。
>
> **三，融入一个看得见你的社会，老实本身就是最优解。**
> 这不是道德说教，是结构——**社会会替你惩罚背叛者，你不用自己动手。**
> 你自己动手，只会把自己也拖下水。
>
> 最后一句：教科书教你「以牙还牙」赢，那是在**不会看错**的世界里证出来的。
> 你会看错。**所以你的答案，应该和他们的不一样。**
