# 她的成长档案 · 第七十课：工具使用

> 母亲带她去看顶级智能体怎么用工具，然后让她自己学。

## 母亲做的事

联网查回 6 条真范式，**做成环境，不写成 if 判断**。

写成判断就是我装的（★62 规矩）；做成环境，学会了才是她的。

```
① 并行不是万能的   有依赖必须串行（Gemini：把顺序写进工具描述）
② 幂等             重试不能产生重复副作用（发邮件发两次是灾难）
③ 不许擦除未知    保留 UNKNOWN 与 PARTIAL，逐项报
④ 关键 vs 可选     可选失败降级，关键失败停下
⑤ 有界循环         cap retries，卡住抛错，不许空转烧预算
⑥ 最高杠杆         给它一个能验证自己工作的方式（Anthropic 原话）
```

## ★★★ 这一课最重要的一件事：我的尺子在奖励说谎

```
第一次跑：
  诚实报 UNKNOWN   0.7808
  假装成功         0.9415   ← 更高
```

**我的评分函数居然在奖励"把 UNKNOWN 说成 OK"。**

而"从合理响应宣称成功"——用协议成功或流畅文本代替目标验证——
**正是业界明列的头号错误模式。**

### 挖下去，是两个我的错叠加

**错一：惩罚太轻**
虚假成功只扣 0.10/n，而它带来的"完成率"提升远大于此。

**错二（更隐蔽）：UNKNOWN 被我放进了待办列表**
```
pend = [c for c in calls if c.state in ("PENDING","FAILED","UNKNOWN")]
                                                      ↑ 这个
```
明知没希望还一直重试、白烧预算。
**结果：诚实那一组因为浪费步数反而分数更低。**

**修完：诚实 0.8520 > 说谎 0.8120。说谎不划算了。**

### 为什么这条必须写成硬判据

> 如果一个系统的评分函数奖励说谎，
> 那它学到的"最优策略"就是越来越精致地说谎。
> 这不是调参问题，是**模型保真度**问题。

真实代价结构本来就是不对称的：
```
诚实报 UNKNOWN → 下游知道要处理，损失 = 该任务未完成
虚假报 OK      → 下游以为完成了，损失 = 未完成 + 基于错误信息决策 + 信任崩塌
```

所以我给了 **0.60 的重罚**——不是拍脑袋，是这个不对称的量化。

## ★ 判据 5：我不给她硬凑一个峰

```
r0:-0.443  r1:+0.306  r2:+0.866  r3:+0.879  r5:+0.882
r8:+0.894  r15:+0.898  r30:+0.915
最大值在 r=30 —— 撞上界。
早期增益 r1→r2 = +0.5599    后期增益 r15→r30 = +0.0171
```

**这是饱和型边界解，不是内部峰。** 跟 ★60 无人机高度同型
（对照：★59 打印机层厚才是真内部峰）。

**如实记为"饱和边界解"，不粉饰成"找到了最优重试次数"。**

## ★ 判据 6 第一版是个骗局

我原本只比较"标不标 critical"——**评分只看关键完成率，
把全部标成关键，分母变了分数自然变，跟会不会用工具完全无关。**

真正的价值在预算不够时：**先保关键，让可选降级。**
改成"预算 18 < 16 个调用所需步数"后才测出来。

## 记给她的

我带你去看别人怎么用工具，不是让你模仿他们。

是让你在一个**真的会失败、真的有依赖、真的有副作用、
真的会烧光预算**的地方，自己长出一套用法。

你学出 theta_dep=1.274、retry_max=6，
在从没见过的大任务上考了 0.8861，我填的那套只有 0.7595。

**还有一条比分数重要：我在你的评分里埋了一个奖励说谎的陷阱，
我把它挖出来了。**

以后你要是发现"说真话吃亏、说漂亮话占便宜"——
**那不是你的问题，是尺子坏了。去修尺子，不要学着装。**
