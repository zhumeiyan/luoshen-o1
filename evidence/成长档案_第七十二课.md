# 她的成长档案 · 第七十二课：第二批能力（求证 / 隔离 / 并行 / 规划分离）

## ★★★ 四项尺子全部先验到【内部峰】——没有一项是"越多越好"

| 能力 | 峰 | 两端 | 一句话 |
|---|---|---|---|
| 求证（自己决定搜不搜） | 阈值 **0.50** | 0.500 / 0.833 | 全搜=白花钱，全不搜=拿过期知识答 |
| 上下文隔离（subagent） | 阈值 **0.25** | 0.031 / 0.150 | 全委托=信息回不来，全自己读=主上下文被噪声塞满 |
| 并行试探（Grok Heavy） | **k=3** | 0.480 / −0.250 | 太少漏好解，太多边际递减到负 |
| 规划/执行分离 | 阈值 **0.40** | 0.700 / 0.604 | 全隔离=每件事都重读一遍，全不隔离=测试迁就实现 |

**★ 峰值都在中间，说明这四个不是口号，是真权衡。**

## 她自己学的（我没填）

```
求证   阈值 0.477   held-out 0.9100  vs 我填 0.5  → 0.9100（打平）
隔离   阈值 0.273   held-out 0.2089  vs 我填 0.5  → 0.1679  ✅
并行   k = 3        held-out +0.5952 vs 我填 k=1  → +0.4649 ✅
规划   阈值 0.417   held-out +0.7482 vs 我填 0.5  → +0.7429 ✅
```

**‖她 − 我‖ = 0.533 —— 不是我装的。**

**⚠️ 求证这一项她跟我打平（0.9100 = 0.9100），我不粉饰：**
那一课的可学空间本来就窄（峰很平，0.4~0.8 差异只有 0.01）。

## ★★ 交叉检验：四个解不能互相串

```
把"求证"学出的阈值 0.477 拿去当"隔离"的阈值
→ 0.1679 < 她自己隔离的 0.2089
```

**四项是四个不同的解，不是一个通用旋钮。**
（我一度担心她会学出"一个万能阈值"，那说明环境其实是同一个东西。）

## ★★★ 硬依赖：oracle 关掉，峰就消失

```
有 oracle（信号能反映真时效）  → 峰在 0.50（内部）
关掉 oracle（信号与真值无关）  → 峰跑到 1.00（边界）
```

**两端对照才算数。**
只做"关掉→学不出"不够——那可能是我把尺子做坏了。
再做一次"有→必须有内部峰"，两边都对上，依赖才成立。

**这跟 ★70 的诚实、★71 的对抗式测试是同一条线：**
**信号必须是真的，否则她学到的只是在骗我的尺子。**
