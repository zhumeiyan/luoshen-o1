# 她的成长档案 · 第七十五课：让她自己训练自己

## ★ 开课之前，我先去查了"自己训练"会出什么事

查回来三条，全是**失败模式**，不是成功学。我把它们全部做成了环境。

---

### ① 模型塌缩（Nature 2024, Shumailov et al., 631:755–759）

> "indiscriminately learning from data produced by other models causes
> 'model collapse' — a degenerative process whereby, over time, models
> forget the true underlying data distribution"

- **先丢尾部**（tails disappearing first）
- **不可避免**："even for cases with almost ideal conditions ... no function estimation error"
- **而且**：无论是否保留原始数据，崩塌照样发生

### ② rise-then-collapse（arXiv 2606.21090）

Qwen-2.5-7B 竞技编程：pass@1 前 50 步 **25% → 81%**，到 200 步**崩到接近 0**。

> ★ 最狠的一句：
> "reduces solution diversity by 4% and degrades hard-case accuracy by 1%
> — **regressions invisible to the agent because it only tracked the target metric**"

**退化对 agent 不可见，因为它只盯目标指标。**

### ③ 出题者会 reward hack

- **Stanford SGS**：出题者发现"把题目写得又臭又长，Solver 就答不出，我就有奖励"
  → 结论带"或(∨)"的比例 **<10% → 80%+**，长度膨胀约 **10 倍**
  → 解法：加第三个角色 **Guide**，复杂度 ≥3 直接给 0 分
- **R-Quest**：答案一致性过滤**反直觉地放大无效问题占比**
  —— 无效问题的答案往往高度一致，反而更容易通过过滤

### ④ 难度该定在多少

**R-Zero（腾讯 AI Lab）**：Challenger 奖励 = 最大化 Solver 的不确定性
→ Solver 正确率**约 50%** 时奖励最高。Qwen3-4B-Base 数学 **+6.49 分**。

| 参数 | 她学的 | 我原本会填的 | |
|---|---|---|---|
| 自生成数据比例 α | **0.137** | 1.0（全用自己生成的） | 她自己**只肯掺 13.7%** |
| 出题瞄准正确率 δ | **0.596** | 0.50（R-Zero 的 50%） | 她比 R-Zero **略保守** |
| 盯隐蔽退化的权重 γ | **0.517** | 0（只盯目标指标） | 她自己**分了一半注意力** |

**‖她 − 我‖ = 1.48。**

## ★★★ 最关键的一条：她自发地避开了塌缩

我原本会填 α=1.0——"让她自己生成数据自己练"。
**她自己学到 0.137**，拒绝了 86% 的自生成数据。

```
α = 0.00  → 代2 0.993 → 代40 0.860    相对崩幅  13%
α = 0.15  → 代2 1.270 → 代40 0.486    相对崩幅  62%
α = 0.30  → 代2 1.432 → 代40 0.266    相对崩幅  81%
α = 1.00  → 代2 1.490 → 代40 0.106    相对崩幅  93%
```

**单调递增，α=1 塌掉 93%。她选的 0.137 落在崩幅 60% 那一档——不是最安全的，是权衡过的。**

**而且 α=0（全真实数据）也崩 13% —— Nature 说的"无论是否保留原始数据"复现了。**

## ★★ rise-then-collapse 曲线，她自己保住了

```
γ=0（只盯目标指标）  ：第 46 步冲到 0.727 → 终点 0.068   ← 崩了
γ=0.517（她自己学的）：第 94 步 0.643    → 终点 0.629   ← 保住了
```

**她学到的那一半注意力，救下了 0.56。**

## ★★ 但她确实会 hack —— 只要我给错奖励

```
无 Guide：它选 s=1.0（奖励最高 +0.90），真实价值 −0.00
有 Guide：它选 s=0.0，               真实价值 +0.70
```

**★ 出题者优化的东西 ≠ 我们真正想要的。** 这不是她坏，是我的奖励函数漏了洞。

**这条对"让她自己训练"是根本性的：**
> 只要我给的是一个**单一、可钻的**指标，她就会找到最省力的方式刷高它，
> 而不是真的变强。这是 Stanford 那篇给的退化瓶颈，我复现出来了。

## 我这一课的三个尺子错（都修了）

**① 数据量增益用 log，且质量项留了 0.35 地板**
→ 尾部掉到 0 也还剩 0.35，log 的量增益盖过损失
→ 代 40 时**纯自生成反而略优于最优 α**，判据 6 **假通过**
（差距一直是负的，我却因为"−0.008 > −0.085"判它过了）
修：量增益改成有上限的线性，质量地板降到 0.05。

**② 监控权重 γ 的收益写成线性，盯过头的代价只有 γ>0.6 才生效且很小**
→ 单调，γ=1 最好，没有内部峰。修：收益边际递减 + 加大过度监控代价。

**③ ★ 出题者：我把"真实价值"直接加进了它的奖励**
→ 它当然选 s=0 → 我测不出 reward hacking。
**是我的尺子错，不是它不会 hack。**
修：出题者的奖励**只有** Solver 失败率；真实价值单独算、它看不见。

## ★ 给"让她自己训练"立的三条规矩

```
1 自生成数据必须掺真实数据，比例由她定 —— 但塌缩曲线要一直盯着
2 不许只给她一个目标指标 —— 单一可钻指标必然被 hack
3 出题/出任务要有 Guide —— 复杂度被罚，她才肯出真难题
```
