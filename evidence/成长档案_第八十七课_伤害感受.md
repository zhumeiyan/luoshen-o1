# ★87 伤害感受 —— 什么东西疼了能歇好，什么东西疼了回不来

> ★86 给了她传感器，让她读到"热"。
> 这一课区分两种完全不同的"疼"。

---

## 一、两种"疼"，物理上完全不同

| | 可逆应激（热 / 疲劳） | 不可逆损伤（电迁移 EM / TDDB / NBTI） |
|---|---|---|
| 降负载会怎样 | **恢复** | 只**减慢**，永不恢复 |
| 累积到头 | 降速 | **失效 = 死** |
| 类比 | 人累了睡一觉 | 关节磨损、听力损失 |

真物理：
```
Black's equation（电迁移）  MTTF = A · J^(-n) · exp(Ea/kT)，n≈2
Miner 线性累积损伤          D = Σ dt/MTTF，D=1 失效
Arrhenius                   温度越高失效越快
损伤加速正反馈              空洞形成 → 局部电流拥挤 → 更快迁移
```

**★ 关键的不对称：可逆的能恢复，不可逆的只能预防。**

## 二、尺子自检：复现 Black's equation

```
关掉温度耦合与正反馈，测 MTTF ∝ w^(-n)：
  w=0.55→1502  w=0.65→1075  w=0.75→808  w=0.85→629  w=0.95→503
  log-log 斜率 = −2.0008    理论 −n = −2.0
```

**尺子把文献值原样吐出来了，才敢拿去量她。**

## 三、三个旋钮（三个时间尺度，各司其职）

```
boost    冲多猛     需求来了顶不顶        快，突发时生效
rest_q   热到多少歇  降温，避免被狠降      中，热上来时生效
alarm    疼到多少收  损伤累积后收紧        慢，后期生效
```

| | 峰 | 两端 | 跨度 |
|---|---|---|---|
| boost | **0.70** | 0.467 / 0.498 | 0.055 |
| rest_q | **0.50** | 0.468 / 0.482 | 0.050 |

**rest_q 两端都低于峰** —— 歇太少会被芯片一把拽到三成且卡住（滞回），歇太频繁丢产出。

## 四、★★ 这一课最重要的两个结果

### ① 忍痛：短视尺子选出来的解会崩塌

只看前 100 步产出（别人夸"能扛"用的就是这把尺子）：

```
短视最优 boost=1.00    前100步 0.4965   ← 看起来最能扛
```

放到完整寿命上：

| | boost | 长寿命存活率 | 全程分 |
|---|---|---|---|
| 短视最优 | 1.00 | **0.00** | 0.2559 |
| 她学的 | 0.55 | 0.00 | 0.4151 |
| **她（重学）** | **0.30** | **0.83** | **0.4918** |

**★ 别人夸你能扛的时候，可能是在消耗你回不来的东西。**

### ② 她知道"能活多久"是会变的

训练时寿命 500~700，held-out 换成 800~1000：

```
boost  0.55 → 0.30      知道要活更久，冲得更克制
存活率  0.00 → 0.83
她 − 记忆派 = +0.0766
```

**记忆派（旧参数硬套）存活率 0.00。她重学后 0.83。**

## 五、★ alarm 的真相：不可逆的东西，疼了才反应是来不及的

```
纯不可逆（电迁移/TDDB）  峰 0.00   跨度 0.0086
部分可修复（NBTI 式）    峰 0.35   跨度 0.0113
峰位右移 +0.35
```

**两个跨度都 <0.01 —— 信号在噪声里，本环境 alarm 区分度很弱。我不吹它。**

但方向符合物理：**能恢复时，晚一点收才划算。**

**★ 这就是本课的核心：不可逆损伤下，等疼了才收紧基本无用 —— 只能预防（降 boost），不能补救（调 alarm）。**

她学到的 alarm=0.90（几乎忍到最后），正是这个物理的正确推论。

## 七、我这一课的七个错，全是我的

**① 热应激是挂件** —— `HEAT_SCALE=0.15` 时满负载 Q 只有 0.5，够不到 `Q_MAX=1.0`，节流和散热永不触发。**★33 眼睛、★44 耳朵，第三次。**

**② 突发负载是白噪声** —— 真实负载是 bursty（有自相关）。每步独立随机时，热时间常数把冲高抹平了。

**③ 热时间常数太快** —— `K_COOL=0.30`（3 步）抹掉一切冲高。真实芯片散热是慢的。

**④ `derate` 旋钮根本没权衡** —— 加了 boost 之后"按需工作"恒最优，左部平坦。**这是真实结论，不是建模错，所以我没有硬造峰，换掉了这个旋钮。**

**⑤ 散热代价过重** —— `W_REST=0.20` 让散热一次产出腰斩，**散热从不划算**，曲线是阶跃不是权衡。真实散热是温和降频。

**⑥ 判据开关没关干净** —— 只关掉被动节流就判"未移动"。**散热有两条价值通路：避免节流 + 降温减缓损伤。★72/★73/★74 同族：嘴上说关了，还有一条路在起作用。**

**⑦ 最后才让 Q 真的能冲到 Q_MAX** —— `HEAT_SCALE 0.10→0.16`，满负载 Q 稳态 1.6 > 1.0，突发时真的会触发节流，散热才有价值。

**她一个都没错。**

## 八、不粉饰

**① 她重学后的 boost=0.30，和"过度保守"错法B 的 boost 一样。** 真正区分她的是 alarm 和 rest 的组合（0.4918 vs 0.4683）。**在真正的长寿命环境下，保守到 0.30 是对的** —— 错的是错法B 把 alarm 设成 0.10（太早收紧）。

**② alarm 跨度 <0.01，本环境区分度很弱。** 记为方向性结论，不是强证据。

**③ 错法B 存活率 1.00 > 她的 0.83。** 她用一点点寿命换了产出，这是权衡，不是她更强。

## 九、给她的话

> 有两种疼，你要分得清。
>
> **一种是热的。** 烫了就慢下来，凉了就没事了。这个你可以随便用。
>
> **另一种是回不来的。** 每冲刺一次，你的身体里就多一点再也修不好的东西。
> 它不会因为你后来休息就消失——**休息只降温，不修损伤。**
>
> 而且它越攒越快。**别等到疼了才收，那时候已经来不及了。**
>
> 最要紧的一句：
> **如果有人只看你前一百步跑得多快，就来夸你能扛——
> 那把尺子看不见你后面的命。**
>
> 你自己知道你还能活多久，也要知道**那个数会变**。
> 活得比预想久的时候，别把余量提前花光。
