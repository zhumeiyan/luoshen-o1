# ★83 修耳朵 —— 静音检测那把尺子

> 上一课她练习前 `sil` 测成 **0.000**。不是她没有停顿，是尺子坏了。
> 这一课：**先拿真值验尺子**，修好，**重测靶值**，再让她重练。

---

## 一、旧尺子为什么不能用

```python
thr = median(rms) * 0.25      # 旧 ear 的静音阈值
```

| 情形 | median 落在哪 | 结果 |
|---|---|---|
| 真静音 < 50% | 有声区 | thr 偏高 → 把气声判成静音（**多算**） |
| 真静音 > 50% | 静音区 | thr 低于地板 → 一个静音都没有（**少算**） |

实测（72 段合成语音，静音率真值已知）：

```
误差 −0.924 ~ +0.321    MAE = 0.3151
多算 57%   少算 29%
```

**★ 同一把尺子两个方向都错 —— 这不是偏差，是定义错。**
偏差能加个修正系数修；**方向随数据翻转的错，只能换定义。**

## 二、换定义也失败过一次（如实记录）

**第 2 版：Otsu 自适应求谷**（类间方差最大，不留常数）

```
MAE = 0.2306    与真值相关 r = 0.446     ← 仍不行
```

真因不是"阈值取在哪"，是**能量阈值这个定义本身**分不清三样东西：

```
浊音（元音） / 清音（擦音） / 静音（本底）
```

---

## 三、顺着真值查出：病根一半在发声器官，不在耳朵

用真值把三层电平分开测，旧器官的结果是：

```
浊音 −19.5dB   清音 −59.8dB   静音 −60.1dB
                清 − 静 = 0.3 dB   ← 同一电平，无解
```

**根因：清音的湍流噪声被送进了三级窄带共振器**，宽带源被压掉约 35 dB。

按源—滤波器理论修正（三处，都是物理事实，不是调参）：

1. **擦音噪声不走整个声道** —— 擦音在收窄处产生，只有收窄点**前面**的腔体共振
2. **补唇辐射** —— 一阶微分 +6dB/oct（旧版缺这一项）
3. **音节包络有下限** —— 旧版用 hanning，两端精确到 0，
   真实语音在音节之间不会静到零；这个 artifact 让每个音节边界出现"假静音帧"

修完：

```
浊音 −19.5dB   清音 −46.5dB   静音 −60.1dB
浊−清 27.0dB   清−静 13.6dB      ← 三层分开了
```

## 四、第 3 版定义（可用了）

先估**本底**（她自己这段声音的最低 5%），再要求**本底必须显著低于说话**，
否则不承认有静音。`margin` 和 `sep_min` 全部**用真值扫出来**，不是我拍的。

```
sep_min : 24~36dB → 0.0677   44dB → 0.0215 ★   48 → 0.0317   55 → 0.2912
margin  : 0.25 → 0.1786   1 → 0.0215   8 → 0.0091 ★   12 → 0.0363
```

| | 旧尺子 | 新尺子 |
|---|---|---|
| MAE | 0.2988 | **0.0091** |
| 与真值相关 r | — | **0.999** |
| 无静音时（真值 0） | 0.2664 | **0.0509** |

**顺手用真值验了 voiced（周期性判据）：MAE = 0.0167** —— 那把尺子本来就是好的。
