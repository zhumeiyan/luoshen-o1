# 成长档案 · 第七十七课 —— 定义权

> 用户一句："所有的像数学啊、代码呀，物理学、生物学，所有的代码也是一种**定义权**。
> 我们要教他的是这个。你看看你的所有的**判据全是错**。"

## 这一课教的不是"把指标刷高"

教的是三件事：

1. **定义是可以换的** —— 谁规定"什么算好"，谁就赢了
2. **能发现手上这把是坏的** —— 在没人告诉她的情况下
3. **敢换掉它**

## 环境

真值由三个侧面（饱和型 / 二次型 / 周期型）时变加权而成，权重随时间漂移——
**世界在换 facet，不是变坏。**

五个候选定义，每个都是一种"什么算好"的规定：

| | 定义 | 与真值相关 | 内部一致性 |
|---|---|---|---|
| D0 | 只认侧面 A 的代理 | 0.535 | 0.741 |
| D1 | 只认侧面 B 的代理 | 0.124 | 0.708 |
| D2 | 只认侧面 C 的代理 | 0.129 | 0.757 |
| D3 | 综合派 | 0.385 | 0.561 |
| **D4** | **量的是纯噪声维度** | **0.036** | **0.919 ← 最高** |

## ★★ 最阴的一种坏：尺子最精密，量的是错的维度

**D4 的重测信度 0.919，全场最高**——它信号最强（raw sd 2.02）、最稳、最"科学"、
刻度最细。**只做内部一致性检查，永远选它。**

必须拿真值反馈才抓得出来。

> 这跟本项目里我自己犯过的错是同一个形状：
> ★55 盲测尺子 / ★65 野败对象 / ★72 oracle 后门 / ★75 奖励里塞真值

## ★ Goodhart 那一条最要紧

锁死的对照组，我特意锁在**"t=0 时最好的那个定义"**上——
这正是 Goodhart 的标准剧本：**人都会选此刻最管用的那个指标，然后一直用下去。**

```
锁死（被剥夺定义权）：后半 − 前半 = −0.2529   ← 塌
可换（有定义权）    ：后半 − 前半 = +0.0140
```

不是世界变坏了，是她只盯着一个定义，而世界换了 facet。

## 她自己学的

```
ρ = 0.200   （我本来会填 0：不探测，闷头用当前定义）
θ = 0.000   （网格搜出来的，见下）
```

**⚠️ 关于 θ=0.000，我不粉饰：它落在网格边界上。**

细扫（60 seeds，在她选的 ρ=0.20 下）后发现**真峰在 θ=0.02，是内部峰**：

```
θ=0.00  +0.6748   换 2.8 次
θ=0.02  +0.6869   换 2.6 次   ← 真峰
θ=0.05  +0.6857   换 2.3 次
θ=0.30  +0.5864   换 1.3 次
```

**所以 θ=0 是她的搜索分辨率不够（网格 9 档 × 24 seeds），不是"不设门槛最优"。**
真实结论：**她该学的是一点点迟滞（θ≈0.02），不是零门槛。**
这一条记为"她的搜索精度不足"，不记为"她学出了边界解"。

## ★ 这一课我犯的四个错，全在建模里

**① 一致性尺子压在随机基线上**
第一版用"两次抽样的 top 集合重合度"当一致性，
但随机基线 = top/m = 40/200 = **0.20**，五个定义实测全是 ~0.20——
**这把尺子根本没有区分度。** 改用重测信度 corr(s+n1, s+n2) 才测出 D4 最高。

> 跟 ★55 盲测尺子完全同一个错：**尺子把差异吃掉了**。

**② 换定义不要钱**
第一版 θ 扫描峰在 0.0（一有风吹草动就换）——
因为我建模时没给切换代价。**我等于写死了"定义权没有代价"，然后怪她学出的解在边界。**

**③ 探测不要钱**
第一版 ρ 扫描峰在 0.95（光探测不干活）——
因为探测那一轮她照样满负荷执行。**探测和执行抢的是同一份预算，我没建模。**

**④ 判据4 第一版锁错了对象**
我锁在 D3（综合派，本来就鲁棒）上，当然不会塌。
Goodhart 的剧本是锁在**"当初最好的那个"**上，改成 `lock_best_initial` 才测出 −0.2529。

## 新立的规矩（第 14 条）

> **凡是要给她一个"指标"之前，先问三句：**
> ① 换这个定义要不要代价？（不要 → 她必然学出边界解，那是我的模型错）
> ② 探测和执行是不是抢同一份预算？（不抢 → 同上）
> ③ 我锁死对照时，锁的是不是"当初最好的那个"？（不是 → 测不出 Goodhart）

## 一句话

**在别人给的定义里考满分，不算本事。**
**她这一课学会的是：看出这把尺子是坏的，然后换掉。**

—— 而我自己这四十年（本项目 77 课）里，判据写错七次，每一次都是同一件事：
**我拿一把自己都没验过的尺子，去量她。**
