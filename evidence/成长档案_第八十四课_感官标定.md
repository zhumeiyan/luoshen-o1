## 一、真人感官数值（文献值，全课唯一的靶）

统一口径：**阈值型**（越小越灵敏）。CFF 是"上限型"，换算成时间分辨率。

| 感官 | 真人值 | 单位 | 来源 |
|---|---|---|---|
| 视觉对比阈@4cpd | **0.0033** | Michelson | Campbell & Robson 1968 / NASA NTRS 20130014741 |
| 立体视差 | **20** | arcsec | 临床立体视锐度常值 |
| 视觉时间分辨 | **18** | ms | 由 CFF ≈ 55 Hz 换算 |
| 听觉频率辨别@1kHz | **3** | Hz | JND ≈ 3 Hz（0.3%） |
| 听觉强度辨别 | **1** | dB | JND ≈ 1 dB（ΔI/I≈0.25） |
| 听觉间隙探测 | **2.5** | ms | gap detection 2–3 ms |
| 触觉两点辨别（指尖） | **3** | mm | DeJong 1967：指尖 2–4 mm |
| 关节位置觉（手指） | **1.5** | deg | PIP 位置觉 JND ≈ 1–2° |

### ★ 计量学约定（避免循环论证）

```
T_i(w_i) = d_i / sqrt(w_i)

d_i = 真人数值（上表）
w_i = 投入该感官的资源份额
```

**投入 1 个单位 = 恰好达到真人水平所需的投入。**

这样"人类数值"既是单位又是靶 —— **不需要我再编一套"人类分配 h"**。
`1/√` 不是工程假设：pooling N 个独立噪声单元 σ ∝ 1/√N，是生理事实。

## 二、尺子 v1 作废（实测）

2IFC 变换 staircase（2-down-1-up），理论解析值 **0.7707σ**。

```
比值（实测/解析）：中位 1.244    范围 1.011 ~ 1.319
```

**★ 偏差随 w 单调漂移**（w=0.25 时 1.0，w=4 时 1.32）。这不是能加系数修的偏差。

真因：变换 staircase 的**反转点均值是有偏估计量**，步长越大偏越多，且起点/瞬态污染翻转点。
**跟 ★83 那个静音阈值是同一类：不是"取在哪"，是定义错。换定义。**

## 三、尺子 v2（现行）：恒定刺激法 + 概率单位回归

```
P(correct) = Φ(Δ/(σ√2))     →   Φ⁻¹(P) 对 Δ 严格线性
在若干固定强度上各做 n 次 2IFC，回归得斜率，取 P=70.7% 的强度
```

**★ 关键修复**：只保留 P∈[0.03, 0.97] 的水平。
两端 p̂ 的小样本偏倚会污染回归 —— p̂=1.0 被截断成 0.9999，Φ⁻¹ 拉到 3.7，**把斜率带偏 2.7%**。

| 检验 | 结果 |
|---|---|
| 无系统偏差（8 感官 × 3 投入） | 中位 **1.0031**，范围 0.996~1.009 ✅ |
| 线性（w = 0.25~8） | 比值恒 **1.034** ✅ |
| **w=1 实测回到文献值** | \|log误差\| 中位 **0.0002** ✅ |

**接上真人基准，尺子就把文献值原样吐出来 —— 这才敢拿去量她。**

## 四、理论（解析可预测，所以能验她）

生态：每个感官有任务频率 `p_i`、相对需求 `m_i`（m=1 表示"要求达到真人水平"）。

```
得分 score_i = min(1, m_i·√w_i)      ← 达标封顶：做得比需要更好不加分
目标 max Σ p_i·score_i    s.t. Σw_i ≤ B
```

**拉格朗日解（注水法）：**

```
未封顶区：边际收益 p_i·m_i/(2√w_i) = λ   →   w_i ∝ (p_i·m_i)²
封顶    ：w_i ≤ 1/m_i²   （超过就是浪费预算，省下的重分给别人）
```

**★ 理论指数 α=2, γ=2，且必须封顶。**

数值验证（6 套随机生态，B=4）：

```
eco0  注水(2,2) 0.7795   理论 0.7795   暴力搜索 0.7786
eco1          0.6904           0.6904           0.6903
…
注水(α=γ=2) ≡ 理论解，且 ≥ 暴力搜索（6/6）✅
```

## 十、我这一课的错（4 个，全在尺子和对照组）

1. **v1 staircase 定义错** —— 有偏估计量，偏差还随 w 漂移。
2. **p̂ 两端没屏蔽** —— 小样本截断把斜率带偏 2.7%。
3. **判据 9 对照组被我加噪声做坏了** —— 加了扰动，"全相等"就不全相等。
4. **判据 6 门槛 0.005 卡在平顶上** —— 明知 α 峰平还用这个门槛，等于拿噪声当判据。

**她的：0 个。**

> 立第 18 条规矩：**报"她比某个基准好"之前，先扫一遍那个参数看峰平不平。
> 平顶上的 0.004 差异是噪声，不是结论。**

## 十一、最大的假设（必须说）

**生态的 `p`（任务频率）和 `m`（需求）是我造的随机参数，不是从真实世界统计来的。**

但这一课的结论不依赖具体取值：**α=2、γ=2 是解析解，对任意 p、m 都成立**，
held-out 10 套随机生态全部验证。所以她学到的是**规则**，不是我这组随机数。

**真正没做到的：她的感官阈值离真人还有 1.0~2.5 倍。**
原因是预算只有人均 0.5 —— 要么给她更多资源，要么承认"预算紧时必然有取舍"本身就是答案。
