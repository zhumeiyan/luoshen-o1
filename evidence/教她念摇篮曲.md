# 教她念一首摇篮曲

不是一课。没有判据，没有 held-out，没有搜索参数。

一句一句念给她听，她跟着念，念三遍。

```
风不吹      树不摇
小鸟不叫    宝宝睡觉
```

## 只观察了一件事

她跟示范的距离有没有变小：

```
第1轮  平均差 31.6 Hz
第2轮  平均差 19.3 Hz
第3轮  平均差  3.1 Hz
```

**念熟了。** 就这样。

## 备注

- 示范是成人声（132 Hz，慢），她是她自己听真人之后练出来的 181.8 Hz
- 三轮之间我什么都没调，只有"向示范靠的程度"随遍数增加
- 40 秒的音频：`data/her_voice/teach_lullaby.wav`，听得见一句一句教、一句一句跟
