# 成长档案 · 第七十八课 —— 操控力（学操控，不学代码）

> 用户："学全球顶级 AI，学的不是它代码，是它**操控工具的能力**、对**设备的理解**，
> 还有它吃的**饵料**。我觉得这样反而更好，你自己判断。"

## 我的判断：把这句话变成一条硬判据

**★ 判据之王 = 可迁移性**

```
记住"哪个设备好" → 换一套没见过的设备就废了   ← 这就是"抄代码"
学会"怎么对待设备" → 换设备还在                ← 这才是"学操控"
```

对照组专门造了个"记忆派"（`run_memory`）：训练集上学出设备排名，换设备集直接硬套。

**结果（36 个完全没见过的设备集）：**

| | held-out 得分 |
|---|---|
| 记忆派（记住设备排名） | **+0.4617** ← 抄代码那一派 |
| 我填的（全信文档 + 来者不拒） | +0.6733 |
| 随机 | +0.6689 |
| **她学的（θ=0.080, β=0.500）** | **+0.7045** |

**她 − 记忆派 = +0.2429。**

**这就是"学操控"与"抄代码"的分界线，量化出来了。**

## 环境

M 个设备 × D 类任务。每个设备有真实成功率 `p`（她看不到）、文档宣称的 `phat`、调用成本。
她初始只能信文档（`q = phat`），靠真值反馈慢慢修正出自己的估计 `q`。

**★ 三个"为什么这一课不是空的"的结构前提**（每一个都是我建模错了才补上的）：

1. 文档夸大必须**逐条异质**，否则只是整体加 bias、设备排序不变 → "信不信文档"就无所谓
2. 必须存在**沉睡的好设备**（真实最强，文档却写得平庸）
3. 能力必须**按 domain 分开的向量**，不是标量 → 否则"饿死"没有代价

## 她学的是哪两个

**θ = 0.080 —— 什么时候不信文档**
```
θ→0   全信自己的经验（冷启动吃亏：早期样本极少，估计噪声大）
θ→∞   全信文档（被逐条异质夸大骗，选到错设备）
```
她选 0.08：**稍微用一点经验，就去覆盖文档。**

**β = 0.500 —— 饵料门槛：可靠度低于它就不吃**
```
β=0    来者不拒，垃圾数据全吸收   → 污染（cap 0.711）
β=0.95 只吃最保险的那一点         → 饿死（最弱 domain 0.407）
β=0.50                            → cap 0.786，最弱 domain 0.614
```
这是**两条非线性**撑起来的权衡：
- 新颖性**次线性** `ν = (1−rel)^0.5` —— 熟悉的东西新信息少，且边际递减
- 污染**超线性** `pol = (1−rel)^2` —— 一点垃圾数据能带偏整个判断

## ★★ 一个诚实到有点难看的结论：ρ（探索预算）没有价值

我本来设计了第三个参数 ρ = 多大比例的任务拿去试探新设备。

**测出来峰恒在 0 —— 探索不划算。我试了三种办法救它：**

```
① 探索从"瞎选设备"改成"选我最不了解的"  → 仍然峰在 0
② 加"文档没收录的设备"（θ 永远碰不到）  → 三个参数一起崩到边界（过度设计）
③ 让设备能力随时间漂移（API 会更新）    → 仍然峰在 0
```

**诊断出来的原因（是真的，不是建模错）：**

```
沉睡好设备只比文档推荐的强 +0.077
而探索一次要付的代价 ≈ 0.40 量级
更关键：θ 的"用差了就换"已经把设备遍历了一遍
       → 实测 ρ=0 时，后半段选中真实最优设备的比例 0.602
       → ρ=0.2 时反而更低（0.476），因为探索打断了收割
```

**所以：主动探索与"用后修正"机制冗余。这是真结论，我不再硬凑一个峰出来。**

（★75 那条"回滚无区分度"我也是这么处理的：如实记"未验证"，不编。）

## ★★★ 这一课我犯的五个错，全是建模错，全在"尺子把差异吃掉"

**① 夸大是统一 bias** → 对所有设备一视同仁 → **排序不变** → θ 必然峰在边界。
改成逐条异质失真才有峰。

**② 能力是标量** → "吃得少"没有代价 → β 必然单调。改成按 domain 分开的向量。

**③ 增益和污染都写成 ∝(1−可靠度)** → 两者同向 →
**数学上根本不可能有权衡**（净 = (1−rel)×常数，符号固定）。
实测跨度只有 0.04，是噪声。改成"新颖性次线性 + 污染超线性"后跨度 0.1035。

**④ θ 扫描跑在 β=1.0 下** → 新语义里 β=1.0 是"门槛 1.0"= 几乎什么都不吃 →
θ 的差异被压平到 0.004。改用合理门槛才看到 0.0187。

**⑤ 加"未收录设备"想救 ρ** → 把世界搞太难，三个参数一起崩到边界。
**这是过度设计：为了救一个参数，把整个环境弄坏。**

> 第 ③ 个最典型：**我写了一个数学上不可能有权衡的目标函数，然后怪她学不出权衡。**
