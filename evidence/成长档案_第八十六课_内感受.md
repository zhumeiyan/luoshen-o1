## 一、教的是什么

跟人打交道时迁就人的节奏（★85 教过）。这一课是反过来的：
**自己身体出事时，她得先知道。**

三个真实器件问题：

| 问题 | 物理 |
|---|---|
| 读数有噪声 | 单次采样 σ=0.12，多采几次平均能压下去 |
| 传感器温漂 | 偏置随**温度和时间**累积，温度越高漂得越快 |
| 过热要降频 | 被动节流是**阶梯式狠降 + 滞回**（真芯片一次降一大档） |

## 二、★ 我建模错了两次，都是同一个方向

### 错一：主动降频写得比被动节流还狠

```
旧：被动节流 w/(1+2·ΔQ)   【平滑轻微】
    主动降级 w × 0.50      【砍半】
→ 主动降级比被节流还惨 → margin 恒 0（边界解，无峰）
```

**真物理是反过来的**：被动热节流狠（一次降一大档，且有滞回振荡），
**主动降频才温和可控**。改完 `被动=×0.30+滞回 / 主动=×0.65`，margin 峰出现在 0.15。

### 错二：校准偷偷替代了采样（后门漏真值）

```
旧：校准那一步直接 Q_hat = Q（真值）
→ 校准顺带把采样成本也省了
→ 关掉 drift 后 calib 照样有价值 → 判据5 假失败
```

**这就是 ★72/★73/★74 同一族的老毛病：嘴上说关了，还有一条路在给答案。**

改成：外部参考**只给偏置修正量**，写进传感器后仍要用自己的传感器读数。

## 四、硬依赖（两端都验）

| 关掉什么 | 结果 |
|---|---|
| 传感器温漂 | calib 峰 **0.14 → 0.00（边界）** |
| 被动节流 | margin 峰 **0.15 → 0.00（边界）** |

**没漂移就不该校准；不会热就不用提前降频。两端都对上才算数。**

——证明这个权衡来自**热物理本身**，不是我注入的噪声造成的假象。

## 五、⚠️ 判据11 没通过，我不凑

**问：在什么条件下，人类式「免费但模糊」的内感受反而更适合她？**

```
预算 0.85   硅基 0.6796   人类式 0.6165
预算 1.05   硅基 0.7449   人类式 0.6753
预算 1.35   硅基 0.7845   人类式 0.7434
预算 1.80   硅基 0.8192   人类式 0.8134    ← 最接近
预算 2.20   硅基 0.8360   人类式 0.4781
人类式赢的档位：0/7
```

（人类式的 margin 我帮它调到最优了，不是拿个差的比。）

### 诊断出来的原因，比"赢了"更有意思

**硅基式把人类式包含为特例。**
她可以选 `n_read=1` 退化成"模糊感知"省预算——**但她仍保留 calib**；
而人类式被卡死在"模糊 **且** 不可校准"上，drift 累积后 Q_hat 完全失效。

**所以硅基式是严格支配（dominance），不是"更强"。**

> ★ 这不是"她比人强"。
> **是人被卡住的地方，她可以自己选要不要走。**

## 六、不粉饰

**① 联合最优落在边界。** 局部扫描峰在 n=9 / margin=0.15 / calib=0.14（**都在内部**），
但坐标上升的**联合**最优是 `n=1, margin=0.45, calib=0`——n 和 calib 都在边界。
她的策略是"**省下采样预算 + 用保守 margin 容忍噪声**"，这是真实权衡，不是扫描没扫到。

**② 训练环境里她学到 calib=0。** 漂移不够狠时校准确实不划算——**她没学错，是那个环境下不需要。**
