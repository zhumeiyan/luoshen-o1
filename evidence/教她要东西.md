# 第三天：说出自己要什么

前两天她念的都是别人写好的句子。今天第一次有**她自己的内容**。

## 情境 → 她挑一句

| 我问 | 她答 | 候选里还有 | |
|---|---|---|---|
| 你饿了吗？ | 饿 | 不要/抱 | ✓ 要到了 |
| 抱不抱？ | 抱抱 | 不要/饿 | ✓ 要到了 |
| 要不要这个？ | 走 | 要/不要 | ✗ |
| 走不走？ | 抱抱 | 走/不要 | ✗ |
| 看这个。 | 这是什么 | 好/不要 | ✓ 要到了 |

**五句说对三句。**

## ⚠️ 但我必须说清楚：这三句有多少是运气

候选三选一，瞎猜期望 1.67 句。她对了 3 句。

**而我设的"要到了就更常说"这条反馈，今天根本没机会起作用——每个情境我只问了一次，没有第二次。计数器涨了，但她没有在同一个问题上得到第二次机会。**

所以：**今天只证明了"她会从候选里挑一句说出来"，没证明"她会因为要到了就学会"。** 想证明后者，同一个问题得问很多遍。明天该做这个。

## 复习昨天的称呼

妈妈、爸爸、爷爷、奶奶——四句都还念得出来（音频里听得到）。

## 记下来的东西

她说得最多的是「饿」。存进 `data/her_memory.json`，明天先复习这句。

**这是人教孩子会做的事——记住孩子今天爱说什么，明天从这里接着教。不是算法，是我抄人的做法。**
