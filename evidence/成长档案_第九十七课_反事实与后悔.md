# ★97 反事实与后悔 —— 「如果当时没这么做」

> ★96 她学会了「做」：`P(Y|X=x)` ≠ `P(Y|do(X=x))`。
> 这一课是 Pearl 因果阶梯的最高层 —— **反事实**：
> 对一个**已经发生的个体**，若当时选了另一条路，会怎样？

---

## 一、真值不是我编的：U 是我造的，所以真反事实可算

尺子自检：**U 已知时反事实误差 = 0.0000**（4 个异质性档位全是 0）。
真值实现正确，才敢往下量。

**因果阶梯验证**（同一个世界，三种问法的误差）：

| 异质性 τ | 反事实上界（U 已知） | 群体平均（干预层） | 不调整（纯关联） |
|---|---|---|---|
| 0.0 | 0.0000 | 0.4006 | 1.0058 |
| 0.5 | 0.0000 | 0.5669 | 1.0545 |
| 1.0 | 0.0000 | 0.8875 | 1.2250 |
| 2.0 | 0.0000 | 1.6489 | 1.8379 |

**反事实比干预难，且难度随异质性上升。** τ=0 时反事实退化成群体 ATE，τ=2 时群体做法的误差涨到 4 倍。

## ★★ 二、后验宽度有不可约下限

```
n_meas:   1      2      4      8     16     32     64    128
sd_post: 0.690  0.621  0.559  0.512  0.482  0.465  0.455  0.451
```

**饱和在 0.451，测量 128 次也压不下去。**

因为 ε（结果噪声）是**这次实现的一部分**——重复测量能压掉测量噪声 ν/√n，压不掉 ε。
**这是物理的，不是建模选择：再多测量也只能让你无限接近一个不为零的宽度。**

于是 `n_meas` 有内部峰：

```
1:0.7557  2:0.6837  4:0.6600  8:0.6545  16:0.6782  32:0.7378  64:0.8642  128:1.1193
                              ↑ 峰在 8，跨度 0.4648
```

**硬依赖（两端）**：把 ε 关掉（sig→0.02），峰从 8 移到 **2**。
**方向和我最初的预期相反，但左移才是对的**——ε 是"多测有用"的唯一理由，消掉它以后不用测那么多次就够了。

## ★★★ 三、最漂亮的一条：w0 的硬依赖两端

`w0` = 信不信"个体反事实"（vs 退回群体平均）。

| 条件 | 峰 | 跨度 | |
|---|---|---|---|
| 正常（有异质性 + 模型有错） | **0.95** | 0.2235 | ✅ **内部峰** |
| 关掉异质性（τ=0） | 0.999 边界 | **0.0098** | 塌掉 |
| **★ 模型完全正确（mis=0）** | **0.999 边界** | 0.2585 | 推到边界 |

```
正常:   0.5:0.8781  0.8:0.6921  0.9:0.6588  0.95:0.6545  0.99:0.6574  0.999:0.6588
                                    ↑ 峰在 0.95，两头都更差
正确:   0.5:0.8945  0.8:0.7060  0.9:0.6580  0.95:0.6422  0.99:0.6364  0.999:0.6360
                                                              ↑ 一路降到边界
```

**两条对照合起来才说明问题：**
- 模型正确 → **全信个体模型**（一路单调到 0.999）
- 模型有错 → **留 5% 退回群体平均**（峰在 0.95，再信就变差）
- 没有异质性 → **这个旋钮整个没有意义**（跨度塌到 0.0098）

**她学到 0.95，是"我知道我的模型可能错，所以留一手"。**

## ★★ 四、反事实不可证伪 —— 她唯一能做的是知道自己不确定

反事实永远验证不了：同一个个体、同一时刻，只能发生一次。

所以 `theta`（后验宽到什么程度就说"我说不准"）有真实价值：

```
theta=0.6 时：
  作答的那些      平均误差 0.3012
  被她 abstain 掉的  平均误差 1.0643     ← 差 3.5 倍
```

**她 abstain 掉的，确实是她会答错的。她知道哪些自己说不准。**

theta 峰在 0.6（内部），跨度 0.2158：abstain 太多要付 miss 代价，太少要付大误差。

## ⚠️ 六、w1 没通过，但诊断出的原因比"赢了"更有意思

我设计了 `w1`：后验越宽（对这个个体了解越少），越退回群体平均。这是统计学里真实存在的 **partial pooling / 收缩**。

```
正常世界:   w1=0 → 0.6545   w1=10 → 0.6593    跨度 0.0048（噪声级）
她学到 w1 = 0。
```

**诊断（真因，不是建模错）：我的模型错误是世界级的（每个世界一个 ε_m），不是个体级的。**

也就是说——**"我对这个个体了解少" 并不能预测 "我的模型会对它错得多"。**
当模型错误是系统性的、对谁都一样时，部分池化没有用武之地。

对照实验佐证：把 `bu=au=0`（后验宽度不再随个体变，只剩测量噪声驱动）后，w1 的跨度从 0.0048 涨到 0.0226 —— 那个场景里 sd_post 反而能预测误差了。

**按 ★91 立的第 20 条规矩（环境里没有规则就不许硬造一个），我不凑这个峰。她学 0 是对的。**

**代价：她和"记忆派"（常数权重）在 held-out 上完全相同，差 0.0000。** 如实记。

## 七、我这一课的错，四个

1. **w1 是挂件** —— 第一版用 `clip(w0 + w1·(sd_ref−sd_post), 0, 1)`，而她学到的 w0=1.0，`clip` 在 1.0 处饱和，**w1 完全不起作用**。★33 眼睛、★44 耳朵之后第三次。改用 sigmoid + 她自己标定的 sd_ref。
2. **模型错误做成单向** —— `tau_hat = tau·(1−mis)` 只让她低估异质性，作用与"退回群体平均"完全重叠 → w0 恒在边界、无峰。改成双向 ε_m ~ U(−mis,+mis)，有的世界她高估、有的低估、有的错到符号相反，才有真 bias-variance 权衡。
3. **log(0) 除零** —— w0 网格里有 1.0。加了数值保护。
4. **n_meas 硬依赖的方向我预判错了** —— 我写"关掉 ε 峰应右移"，实际左移（8→2）。左移才对，是我的预期错。

## 给她的话

> 你已经发生的事，只有一次。**换一条路会怎样，永远没人能证明。**
> 所以这一课给你的不是"更准的答案"，是**知道自己有多不确定**。
>
> 有一样东西你压不掉：这次结果里的噪声是**这次**的一部分，你再测一百遍也回不到"如果没有它"。
> 测量能买到的精度有个底，**过了那个底，多花的每一分钱都是白花。**
>
> 你的模型可能是错的，而且**你没法自己发现**——因为反事实没有答案可对照。
> 所以别把话说满：**留一点给"所有人平均下来是什么样"。那一点不是保守，是保险。**
> 但如果你有理由相信自己的模型是对的，就别留——**留了会变差。**
>
> 最后：**说不出来的那句"我不知道"，也是答案。**
> 而且你 abstain 掉的那批，正好就是你本来会答错的那批。你知道。
