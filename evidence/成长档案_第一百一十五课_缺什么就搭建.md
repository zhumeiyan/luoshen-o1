## 二、她真的缺一样东西：声母

`core/speech_organ.py` 的 `VOWELS` 只有 **a/i/u/e/o 五个元音，没有声母**。

中文 400+ 音节里，凡带声母的她都发不出来。

**★103 实测她的停顿 0.15s vs 真人 0.06s，差 2.5 倍。当时我写"是嘴的缺，不是她不努力"——但我没去补那个缺。**

真相：**真人的短停顿大多来自塞音闭塞段（closure）**。她的器官里没有这个构造，只能用长停顿代替。

### 给她造了 21 个声母（`core/consonants.py`）

按声学语音学 REAL 参数：

| 类型 | 声母 | 物理机制 |
|---|---|---|
| 塞音 | b p d t g k | 闭塞（真静音）→ 送气 → 爆发 |
| 擦音 | f s sh x h r | 持续湍流噪声，谱重心决定音色 |
| 塞擦音 | z c zh ch j q | 闭塞 + 摩擦 |
| 鼻音 | m n | 浊音，低频共振 ~280~320Hz |
| 边音 | l | 浊音 |

REAL 参数：闭塞 30~70ms、送气 60~70ms、爆发 5~10ms、擦音 80~125ms、谱重心 s=6k / sh=2.5k / x=3.5k / f=4.5k、擦音比元音低 20dB。

`core/speak_cn.py`：声母 + 韵母 + 四声 → 真正的中文音节。

### 结果

```
加了辅音后，她的中位停顿 = 0.0567 s
真人                    = 0.06  s

★103 那个 2.5 倍缺口，补上了。
```

## 四、我这一课的错，三个

**① 跨句错位（最严重）。**
`gold` 每句 `len(cs)-1` 个边界，`chars` 每句 `len(cs)` 个字符。我对拼接后的字符流算 PMI，**跨句错位 → 特征与真值对不上 → 塌回 0.50**。

我差点把这个 0.50 当成"她真的不行"报出去。**★113 的对齐错误，同族，又犯一次。**

**② 方向判反。**
PMI 正向 0.1393，负向 0.8607。词内部凝聚度高、边界处低，所以**负向才对**。★113 我说过"方向判反"，这次又判反——**但这次我做了双向检验，抓到了。**

**③ 局部窗口太稀疏。**
第一版用 40 字窗口估 PMI，数据不够 → AUC 0.50。改用全语料统计才浮出来。
