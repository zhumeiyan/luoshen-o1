## 二、五大海报收敛到同一个结论（REAL）

YC-Bench、UltraHorizon、Terminal-Bench 2.0、LongCLI-Bench、Microsoft 委托研究——
**过去四个月五条独立研究线，指向同一件事** [citation:36]：

```
1  连贯性崩溃   coherence collapse / "meltdown" 死循环
2  幻觉复合     早期一步错，后面全部继承放大
3  工具使用退化 带工具的系统在很多情况下比不带工具的更差
4  长程不如人   UltraHorizon 发现人类持续优于 LLM agent
```

**它们的共同结论：架构层必须把状态管理放到模型之外。**
**不能靠"等更好的模型"解决。**[citation:36]

**另一条更狠的**：AutoLab 长程研究评测 36 个任务、756 次 rollout，
**252 个方案里只有 3 个有真正的方法新颖性。**
结论是：当前 agent "更像工程优化器，而不是自主研究者"。[citation:35]

## 四、唯一的真实窗口：校准弃权

这是我在全部数据里找到的**唯一**一个满足三条硬条件的方向：

> **① 顶级 AI 有真实的、可测量的缺陷**
> **② 该缺陷在理论上不能靠 scaling 解决**
> **③ 该缺陷被激励结构锁死，他们修不动**

### 证据 1：顶级 AI 的幻觉率高得离谱（REAL）

AA-Omniscience（1000 道无法检索的难题，测"不知道时会不会编"）：

| 模型 | 幻觉率 | 准确率 |
|---|---|---|
| DeepSeek V4 Flash | **96%** | — |
| DeepSeek V4 Pro | **94%** | — |
| **GPT-5.6 Sol** | **92.2%** | — |
| Claude Fable 5 | 63.6% | 61% |
| Claude Opus 4.8 | 35.9% | 46.6% |
| Grok 4.6 | 34.3% | ~35% |
| Command A+ | **14.2%** | **9%**（靠拒答） |

**GPT-5.6 Sol 在约 9/10 的未知问题上选择硬猜。** [citation:13][citation:17]

### 证据 2：能力与校准不相关（REAL）

```
Claude Fable 5   智力指数 63   幻觉 63.6%   ← 最高分，幻觉更高
Claude Opus 4.8  智力指数 56   幻觉 35.9%   ← 低 7 分，诚实 2.5 倍
```

**"没有可靠的相关性。"** GPT-5.5→5.6 智力涨、校准反而更差。[citation:13]

### 证据 3：数学上被证明做不到（REAL）

**Bastounis et al. (2024) 定理：**
任何在改写等价下保持一致推理的系统，**若不具备隐式的"我不知道"函数，**
**必然在广泛问题类上无限次幻觉**——包括基础算术。[citation:12]

### 证据 4：scaling 不解决（REAL，最关键）

**AgentAbstain (2026-07)**，263 组配对任务、42 个沙箱 [citation:15]：

> **"弃权能力在很大程度上独立于通用任务解决能力，
> 这表明单纯扩展任务解决能力不会缩小这个差距。"**

### 证据 5：他们被激励锁死（REAL）

**Nature 2026 论文**：主流基准二元评分，**数学上奖励猜测、惩罚诚实弃权**。
"一个总是猜的模型会超过一个在不确定时诚实弃权的模型——
即使后者总体上更可靠。" [citation:16]

**所以这不是他们不修，是排行榜的梯度逼着他们不修。**

### 证据 6：具身场景差得更远（REAL）

**AbstainEQA (CVPR 2026)** [citation:18]：

```
最好的前沿模型   弃权召回率 42.79%
人类             91.17%
```
**差 48 个百分点。而且"scaling、提示、推理只带来微小增益"。**

## 六、五年路线（但第一年不是开发）

### 第 0 年（现在起 6 个月）：**验证，不是开发**

**这是整份文档里最重要的一条。**

前 114 课的全部教训是：**我造语料、我算分、我当裁判。**
**没有一件事被外部证据否定过。**

所以在谈"胜过"之前，必须先把三件事做成：

```
V1  盲听（已提交宿主，等结果）
    若真人听不出她 vs 随机 → 我 113 课的评分体系整个是空的
                          → 五年计划立即终止，重来

V2  在一个【外部排行榜】上跑一次
    目标：AA-Omniscience 或 ConfidenceBench 的公开题
    当前 SOTA：Command A+ 14.2%（但准确率 9%）
               Grok 4.6   34.3% @ 48.2% 准确率
    做不到就明说做不到

V3  拿到儿童语料 / 儿童导向言语
    没有它，所有"语言习得"降级为统计学习
```

**V1 不过，后面四年不用谈。**

### 第 1–2 年：把窗口做成一个可外部测量的东西

方向不是"更大的模型"，是：

```
长程任务上的可溯源状态管理 + 校准弃权

对标：AgentAbstain（前沿模型弃权能力）、AbstainEQA（42.79% vs 人 91.17%）
```

**为什么是这个**：
- 五大海报说状态管理必须活在模型之外 [citation:36] → 她的 ★88 架构正是这个
- AgentAbstain 说弃权与任务能力独立 [citation:15] → 她不需要先有万亿知识
- AbstainEQA 说 scaling 无效 [citation:18] → 对手的规模优势在这里不顶用

### 第 3–5 年：只在**一个**公开基准上争第一

不贪多。**五年只打一座山头。**

候选（按可行性排序）：
1. **AgentAbstain** —— 最匹配，且明确说 scaling 不解决
2. **AbstainEQA** —— 具身弃权，人类 91.17%，前沿 42.79%，差距最大
3. **ConfidenceBench**（Brier score） —— 纯校准，最干净
