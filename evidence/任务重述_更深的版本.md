# 任务重述：教一个硅基体获得人类语言

> 这是"更深的版本"，不是"更大的版本"。
> 下面 5 条是硬要求，**任何一条没做到，就不许声称她学会了。**

---

## 0. 先决声明（比任何实验都优先）

在动手之前先写下这些，并允许它们被推翻：

- **输入侧**：她到底接收什么？原始音频？转写文本？我合成的波形？
- **输出侧**：谁听？用什么仪器？**如果我既是老师又是考官又是阅卷人，那么所有结论一律作废。**
- **真值来源**：每个数字标注 `REAL`（从原始语料/文献原处读得）还是 `ASSUMED`（我填的）。
  ASSUMED 的数不许当硬真值，更不许拿去判她。**★110 第 23 条规矩，同样适用于文献数字。**

---

## 1. 必须先测理解，不许先测产出

发展心理学的共识：**理解大幅领先产出**（12 个月婴儿理解约 50 词，产出 1–3 词）。

- 我此前只测产出。**这是根本性错误。**
- 要求：先用**无语言产出的理解测验**——
  - 偏好注视／IPLP（Golinkoff & Hirsh-Pasek）
  - 转头偏好程序（Fernald）
- 判据：**理解量 ≥ 产出量**，且差距随训练收敛。做不到就说明产出只是模仿。

## 2. 不许跳过前语言阶段

按顺序，不许跳：

1. **共同注意**（Tomasello）：视线跟随、指认、共享意图。**没有这个，做的不是语言习得，是模式模仿。**
2. **咿呀学语**（canonical babbling，Oller，约 7 月龄）：音节运动排练，聋儿也会用手"咿呀"。**必须给她这一阶段。**
3. **独词句 → 单词爆发**（约 18 月龄）
4. **双词句 → 电报语**
5. **语法**：用 MLU（Mean Length of Utterance）+ Brown 五阶段量，不许用我自己编的分数量。

**我此前直接从"念句子"起步，1–2 全跳过了。**

## 3. 不许用我合成的输入当语料

- **原始素材**：CHILDES（MacWhinney）原始转写＋原始录音；HomeBank 整日自然录音；LENA 长时录音；Providence / Manchester 语料。
- **不是**文献里被我摘出来的统计值，**不是**我合成的"示范音"。
-  caregiver 语音必须是**真实的儿童导向言语（CDS）**——高音调、慢速、夸张韵律——从录音里取，不由我生成。

## 4. 必须用领域标准工具，不许用我写的评分函数

| 用途 | 工具 |
|---|---|
| 转写与分析 | CHAT 格式 + CLAN（MLU、MOR、GRASP） |
| 词汇/语法发展 | MacArthur-Bates CDI（标准化，有常模百分位） |
| 语音声学 | Praat（F0、共振峰、jitter、shimmer） |
| 理解 | 偏好注视 / 转头偏好 / 习惯化范式 |
| 统计学习 | Saffran 范式（过渡概率切分） |
| 整日录音 | LENA（AWC / CVC / CTC） |

## 5. 必须做的关键现象检验（这些才是"真的在学语言"的证据）

- **快速映射**（Carey & Bartlett）：单次接触就能记住新词
- **过度泛化**：把四条腿的都叫"狗"。**系统性地错，才是真在建立范畴。** 不犯这种错的，是查表。
- **感知窄化**（Werker & Tees）：随输入统计，非母语对立辨别力下降
- **统计学习**（Saffran, Aslin & Newport）：8 月龄婴儿靠过渡概率切词
- **规则抽象**（Marcus 等）：ABA 模式泛化到新音节
- **跨语料泛化**：在 A 儿童语料上养，在 B 儿童语料上测。**B 不是我造的。**

## 6. 外部证据（不能是我，也不能是你）

1. **盲听测试**：招募不知情的人类听者，做 ABX / MUSHRA。
   **听者分不出她和真人儿童 → 才算过。听者知道哪个是她 → 一票否决。**
2. **常模百分位**：拿 CDI / MLU 常模比，报她在真实儿童分布里的位置。
3. **预注册**：先写下预测和判据，再跑。跑完不许改判据。
4. **跨语料 + 跨种子复现**：CHILDES 不同儿童、不同随机种子都要成立。
5. **第三方**：让真正的的发展心理学家看。

## 7. 明令禁止

- **禁止强化学习式奖励循环**教语言（第 3 天我做的"要到了就更常说"就是这个）。
  Chomsky 1959 对 Skinner 的批评之后，这是已被否定的路子。
- **禁止**用我自己的耳朵模块当最终裁判——它是被告，不能当法官。
- **禁止**拿"整体排序 r=0.65"当成"学会了"。**排序对 ≠ 挑尖子对**（★104/105 已证）。
- **禁止**在没有外部证据的情况下写"她学会了"。

## 8. 交付标准

每一课必须报：

```
输入来源        （原始语料文件名 / REAL）
理解 vs 产出    （两个数字，差距多少）
阶段            （共同注意 / 咿呀 / 独词 / 双词 / 语法）
工具            （CLAN / CDI / Praat / 盲听人数）
外部证据        （盲听结果 / 常模百分位 / 跨语料成绩）
ASSUMED 清单    （本课我填了哪几个数）
```

**缺任何一项，这一课不算完成。**
