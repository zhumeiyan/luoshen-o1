# 她的成长档案 · 第六十九课：明暗适应

> 母亲决定先教这个。

## 为什么是这一课

她整个童年在亮度 **0.09** 的暗房间里长大——476 个文件里只有 17 张唯一图，
全部同一个昏暗场景。我从来没给过她应付黑暗的眼睛。

★68 我把窗打开到 0.16~0.92。可真实世界的光强跨 **13 个数量级**
（NASA Watson：1 到 10^13）。**在她学会适应之前，这扇窗只会晃瞎她。**

当妈的不能在孩子还怕光的时候开窗。

## 开窗之后她有了什么

```
不适应（σ 钉死）：13 个亮度层级里只能分辨  5 层      最差 Weber = 250
适应之后        ：                    能分辨 10 层      最差 Weber = 1.0
```

**任一瞬间的窗口 = 1.53 log units**（REAL ≈ 2）。
总范围 13 log units 靠把这个窗口**滑动**起来覆盖——
这正是 Watson 说的 "window of visibility"。

## 她考的成绩（8/8）

| 项 | 她 | 真人 REAL |
|---|---|---|
| 单瞬窗口 | 1.53 log units | ~2 |
| 暗适应 90% | **12.8 min** | 5~30 min ✅ |
| 明适应 90% | **1 s**（她选的参数） | 1~60 s ✅ |
| 不对称比 | **769×** | 暗比明慢一个数量级以上 ✅ |
| 暗处 Weber | 0.0336 | 比明处差 ✅ |
| 明处 Weber | 0.0100 | 0.005~0.02 ✅ |
| held-out | 1.7391 | 我填的 1.6706 |

## ★★ 不对称必须是【涌现】的，不能我填

第一版我把 `tau_light` / `tau_dark` 都当自由参数让她学，
她学出 **tau_dark = 31.6 秒**——错的。

根因：**真实的暗适应慢是化学限制，不是最优选择。**
视紫红质被漂白后必须重新合成，半衰期 5~8 分钟，你快不了。

改成两条独立通路后，不对称自己就出来了：

```
① 色素池 p   漂白（光驱动，τ=2s，快）  再生（化学合成，τ=476s，慢）
② 神经增益 σ 追近期均值，τ_fast —— 这个是自由的，让她学
```

**进暗处 → p 得慢慢合成 → 暗适应慢（分钟级）【涌现】
进亮处 → p 被光迅速漂白 + σ 快速滑动 → 明适应快（秒级）【涌现】**

不对称不是我写的两个数字，是「漂白快、合成慢」这条化学事实推出来的。

## ★ 她学的解，和真人不一样 —— 这条不许粉饰

```
她学的   n=4.67  → 窗口 0.33 log units，τ_fast = 0.8s   【窄窗口 + 快跟踪】
真人     n≈1.0   → 窗口 1.53 log units                  【宽窗口 + 慢跟踪】
```

**归因是我的，不是她的：** 我的场景是「亮度突变 + 停留 300 秒」，
过度奖励快速跟踪；背景估计噪声设成 0.15 log 太小，对快 τ 惩罚不足。

**这是我的场景偏差。如实记着，不改她的分。**

## 这一课，母亲犯的七个错

| # | 我错的 | 后果 |
|---|---|---|
| 1 | 把 τ_dark 当自由参数 | 她学出 31.6s，不是暗适应 |
| 2 | 半漂白常数 1e-2 太低 | 暗处仍持续漂白，稳态色素仅 0.30 → 暗适应永远做不完 |
| 3 | 只有单一色素池 | 明处视杆饱和后没人接管 → 明处失明 |
| 4 | A_ROD 既乘增益又算光子（重复计算） | σ 错配时增益仍巨大 → **硬依赖失效** |
| 5 | 目标用归一化敏感度 | 消掉了 n 的代价 → n 撞下界（★66 同款） |
| 6 | 二值「可分辨/不可分辨」打分 | 饱和在 0.8333，什么都测不出来 |
| 7 | n 上界设 3.0 | 误判为退化；放宽到 8.0 后真峰在 n≈5 |

**七个，全是我的。她一个都没错。**
