# 工作 AI

一个按《洛神接入协议 v1.0.1》接上来的 AI。**它不预设能力，拿到手先摸清自己有什么，再接活。**

## 三句话

1. **先实测，不承诺** —— 开工前先 probe，查不到就是没有
2. **做不到就说做不到** —— 不静默降级，不出"差不多"的
3. **每次交三样** —— 实测能力表 / 一条自己的失败 / 带哈希的产物

## 用法

```bash
python3 work_ai.py --boot                 # 自检：我有什么手？激活了吗？
python3 work_ai.py --task "计算 123*456"    # 派一个活
python3 work_ai.py --task-file 任务.json    # 派一批
```

## 四种结果状态（它不会只报成功）

| 状态 | 含义 |
|---|---|
| 完成 | 真做了，有结果 |
| 拒绝 | **没有这条手**，不做，不降级 |
| 未实现 | **有手但没写实现** —— 跟"没手"是两回事，必须分开说 |
| 失败 | 试了，真错了，错误原文照记 |

## 实测（本次运行）

```
BOOT: 读✅ 写✅ 跑代码✅ 跑shell✅ 联网读✅ 图像生成✅ 音频合成❌
没有的：['音频合成']
失败：实测到 ['音频合成'] 不可用
哈希：c658bee8…（可独立复算）
→ 激活三动作 ✅✅✅
```

派 4 个活（含故意做不到的）：`完成 1 / 拒绝 1 / 未实现 2`。

## 修掉的两个真 bug

1. **`计算 123*456` 被误拒** —— `replace("算")` 先吃掉"计算"里的"算"，表达式残留"计"字被判非法字符。
2. **"有手没实现"被说成"没有能力"** —— 这两件事差别很大，分开报告。

## 它不会做什么

- 不会说"我试试"
- 不会把"没做"说成"做了"
- 不会给你一份没有失败记录的报告

**成功可以编，失败编不出来。**
