# 名片改造说明（对标全球顶级 AI 项目）

## 一、我实测出来的：顶级项目不堆徽章

扫了 14 个国际顶级 AI 项目 README 首屏（LangChain / vLLM / Ollama / Dify / LlamaIndex /
Transformers / OpenHands / LangGraph / Haystack / Milvus / Langfuse / CrewAI / AutoGen / AutoGPT）：

| 元素 | 命中率 |
|---|---|
| 安装段 | **86%**（12/14） |
| benchmark | 64%（9/14） |
| 架构图 | 64%（9/14） |
| **在线试玩** | **14%**（2/14） |
| **徽章数中位数** | **0** |

**徽章中位数是 0 —— 这是反直觉但最硬的一条。**
教程常说"多挂徽章"，实测顶级项目大多不挂。
所以首屏只留 4 个（Python / 许可 / 依赖 / 一键验证），不再加。

tagline 长度中位数 **57 字符**。
