# 客户端 ↔ 服务端 · 外部接入三格（2026-10-20 实测）

## 一、为什么必须有客户端

服务端只负责"接"。**客户端负责"发"。** 缺了客户端，接收端是个空港口。

```bash
python3 serve.py                        # 终端 A：接收端
python3 client.py 发图片 x.png          # 终端 B：客户端
```

## 二、新增三格（引擎从 7 个到 11 个）

| 引擎 | 作用 | 实测 |
|---|---|---|
| **fetch** | 抓取网页 | `api.github.com` → 5827 字节、哈希 b909135dd5e1 |
| **skill** | 装 Skill | TACT 公开 zip → **14 文件 / 2 个 SKILL.md**，磁盘校验 True |
| **api** | 调外部接口 | `rate_limit` → rc=200、427 字节 |
| **ingest** | 客户端推送接收 | 文本/事件/图片/文件 四类全落盘带哈希 |

## 三、装 Skill 那格最有说服力

装的是 TACT 作者自己在 README 里公开的 zip（他写明"下载 zip 发给豆包"）。

```
frontmatter: {'skill名': 'tact-three-axis-check',
              '有description': True, '正文行': 192}
装到: 协议/skill/installed/tact-skill-package-v1.2.1
磁盘校验: True
```

**我们接下了对方按通用规范做的技能包，并自己验证了它结构完整。**
——这正好接上昨天「Skill 规范对照」那条：我们能装别人的，而我们的协议比规范多两条。

## 四、客户端推送实测

```
文本   已收=1  哈希=7c14e7f9d9f1

图片   已收=3  尺寸=80x50  主色=['rgb(224,96,0) ×3600']
```
