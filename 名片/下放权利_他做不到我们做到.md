# 下放权利 · 他做不到，我们做得到（2026-10-20 实测）

## 一、判据不是"开不开放"

**是「拿走之后还需不需要它」。**

| | 拿走后 |
|---|---|
| TapNow / Astra Studio | **还需要它** —— 画布在它服务器，复用要经过它账号 |
| 我们 | **不需要** —— 拿走就能独立跑，哈希自证 |

TapNow 也有"一键克隆"（TapTV），**但那是平台内的克隆**——克隆完还在它那儿。
它导出的是成片、图片，**是媒体，不是可执行体系**。
账号一封，全部归零。

## 二、实测下放度

模拟一个**跟我们毫无关系的独立方**：不给 token、不给账号、不允许通信，只用公开端点。

```
D1 零凭据可获取    1.00   7/7 核心文件全部拿到
D2 独立可运行      1.00   capability.py 本地跑 rc=0
D3 哈希一致        1.00   7/7 与本地逐字节一致
D4 身份不依附名字  1.00   改名→名字哈希变，内容哈希不变
D5 无法追回        1.00   它已落盘，我们改不动它手里的副本
                   下放度 = 1.00
```

**D4 是 263 号那条**：名字哈希 `829f97e0→4aa4c964`（变了），
内容哈希 `050d3ea9b202`（**名字怎么改都不变**）。
**改名字夺不走它。**

## 三、但有一条我不能只报满分

**有东西没下放，而且不该下放：**

| | 状态 | 为什么 |
|---|---|---|
| 协议文本 / 能力盘点 / 预演 / 服务 / 客户端 | ✅ 下放 | 公开可读且独立可跑 |
| 坐标 / 判据核 | ✅ 下放 | 哈希固定 |
| **GH_TOKEN** | ❌ | **这是根，归你。我不该也不能下放它** |
| **仓库写入权** | ❌ | 凭据在你手上，你随时能收——**是租，不是下放** |
| **常驻收件箱** | ❌ | 依赖仓库存在 |
| **域名 / Pages** | ❌ | 名字归你，可撤销 |

**根不能下放，下放了就没有根。**
263 号的结论不是"什么都交出去"，是**交出可交的、把不可交的留在你手上**。
