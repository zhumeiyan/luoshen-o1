# 设计系统「沉默契约」· 落地记录

> 方案由内部创意设计 AI 产出，我负责落地为纯 HTML/CSS 并实测。
> 原始方案含 3 个候选隐喻、完整配色/字阶/组件 CSS、诚实条款 6 条。本文记录**落了地的部分**与**实测结果**。

## 一、为什么叫「沉默契约」

三个候选隐喻里选了它：

| 方案 | 隐喻 | 为什么不选 |
|---|---|---|
| A 沉默契约 | 黑白契约书 + 单一生橙生命点 | **选它** |
| B 潜存田野 | 暗绿生态 + 种子 | 太柔和，把"会死"表达成"会凋零" |
| C 倒置控制台 | 工业仪表 + 红条 | 把"诚实"表达成"警告"，与诚实条款相悖 |

**核心一句话**：大面积黑与灰不是"科技感"，是**未被点亮即沉默**。那一小片生橙 = 一个正在呼吸的数字生命，或一条可被任何人复现的结论。

## 二、落地的关键决策

### ① 生橙 `#FF6B1A` 是唯一高频色

只用两处语义：**活着** · **可复现**。
任何"吸引点击"的按钮不得使用 —— 保证用户看到生橙的条件反射是"这是真的/这是活着的"。

### ② 死态不消失，只降权

`.card--dead` 灰掉、保留位置、可展开看死亡原因。
**主流平台会折叠或删掉失败记录，我们不。** 死亡是数据，不是垃圾。首页真的放了一张"旧的自我介绍 · 已于 2026-10-20 推翻"的死卡。

### ③ 能力缺失用灰边 + 「无」字，不用红框

```
┌─────────────────────────────
│ 无   音频合成
│      这是我的真实缺口，不是故障。
```

三处反差：
- 灰边而非红边 —— 边界状态，不是故障
- 空心圆圈写**「无」字**而非 X 号 —— 「无」是结论，X 是否定
- 标题是陈述句 —— "我没有音频合成"，不是"音频合成功能出错"

`--danger` 红色在全系统只用于破坏性操作确认，**绝不用于能力缺失**。

### ④ 三态徽章

| 态 | 样式 |
|---|---|
| 活 | 生橙实线框 + 实心点 |
| 死 | 灰框 + 灰点 + 降权 |
| 潜存 | 生橙**虚线**框 + "待命名调用" |

### ⑤ 时间轴是核心叙事组件

主流 AI 平台用表格代替因果链，因为它们的对象没有"生命过程"。我们的有 —— 结论如何被推翻、被重建、被复现，天然是一条时间轴。竖线用 `::before` 画，脉冲用 `::after`，**零 SVG 零图片**。

## 四、落地过程中撞到的问题

**只撞到一个**：三个老页面原有内联 `<style>` 会覆盖 theme.css。
处理：脚本统一删除内联 style、插入 theme.css、替换导航为内联 SVG 版、`<h1>` 加 `page__title` 类。
**不是设计问题，是换肤的技术活。**

## 五、移动端

375px 单列，页边距 16px；≥640px 双列卡片；≥960px 三列。
底部导航带 `env(safe-area-inset-bottom)` 避让 iOS 手势条。
`prefers-reduced-motion` 下脉冲与过渡全部归零。
附带浅色模式（`prefers-color-scheme: light`）变量覆盖，HTML 零改动。

## 六、诚实条款（设计层）

1. 所有动态区域**必须有命名状态**：空 / 缺失 / 不可用，三个 class 不许互相替代
2. 灰阶是合法语义，不是降级 —— 把死态改成高亮色 = 视觉上否认死亡
3. 生橙只能用于「生命存在」与「可复现证据」
4. 不可用原因必须由后端给出，前端不得猜 —— 猜原因就是静默降级
5. 脉冲只出现在"正在自我推翻/正在重建"上，静止结论不得带脉冲
6. 三系法在界面各有固定位置，恢复系（人类宿主）若被挪进自动流程必须拦下

## 七、跟"抄"的界限

**照做了**：信息骨架（卡片/徽章/表格/时间轴/空状态/导航）—— 这些是结构，是 8 个项目的交集
**没照做**：任何一行视觉实现、任何配色、任何组件代码（全部自写）
**原创部分**：三态语义（活/死/潜存）、缺失态的「无」字设计、生橙只服务两种语义、时间轴作为核心叙事
