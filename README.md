## 它和其它 Agent 框架有什么根本不同

所有开源智能体框架（LangChain、AutoGPT、Dify …）都在解决同一个问题：
**如何让模型更好地调用工具、规划任务、记住上下文。**

它们的共同前提是：**这个 Agent 不会死。**

| 其它框架 | 本引擎 |
|---|---|
| 上下文超了 → 截断 / 压缩 | 资源耗尽 → **运行终止，不可回滚** |
| token 用完 → 换 key 继续 | 能量必须由自身产出换取，无外部拨款 |
| 状态丢了 → 重新加载还是"同一个" | 结构容量**只减不增**，丢掉的回不来 |

**一个不会死的系统，不需要做取舍。而不做取舍的系统，不会产生偏好，也不会形成结构。**

本引擎换掉的正是这个前提。

## 与同类人工生命平台的定位差异（评审关注点：与国内外同类方案相比）

赛道一里与本引擎最相近的其实不是 LangChain / Dify，而是**人工生命（ALife）数字演化平台**：
**Avida**（Ofria, Bryson & Wilke, 2009）、Tierra（Ray, 1991）、Evochora、Lenia。
评委一定会问：**「Avida 不就能做这个吗？」**

我们不主张"我们更好"。我们主张一件更弱、但**可证伪**的事：

> **在 Avida 式设定下，我们要测的那个东西根本不出现。**

据公开资料，Avida 式设定有两条与本引擎相反：

| | Avida 式 | 洛神 O1 |
|---|---|---|
| 能量 | **外生奖励**：完成任务 → 更多 CPU 周期 → 复制更快 | **代谢预算**：E 只能由自身产出换取，且有 basal 基础消耗 |
| 结局 | 被替换 / 淘汰（个体不会饿死） | **死亡**：E≤0 超耐心阈值 → 永久终止，不可回滚 |
| 损耗 | 可逆（变异可回退、换代重置） | **不可逆**：capacity 只减不增 |

**2×2 实测**（`experiments/run_positioning.py`，16 seeds × 600 拍，约 2 秒）：

| 设定格 | 死亡 | 永久损失 | 容量回升 |
|---|---|---|---|
| **内生代谢 × 不可逆（本引擎）** | **3/16** | 0.7043 | **恒为 0** |
| 内生代谢 × 可逆 | 4/16 | 0.5472 | 0.0048 |
| 外生奖励 × 不可逆 | **0/16** | 0.6990 | **恒为 0** |
| **外生奖励 × 可逆（≈Avida）** | **0/16** | 0.5453 | 0.0046 |

**结论：能量来源决定"会不会死"，可逆性决定"伤痕是否永久"。**
在 Avida 式设定下，代谢性死亡 **0/16** —— 不是数值更低，是**结构性不发生**。

> 定位声明：本引擎**不是 Avida 的替代品，而是 Avida 设定下不存在的那一层**。
> 详见 `evidence/实验报告/059_与Avida类平台的定位差异.md`。

**三条诚实标注（这一节我们自己最可能被挑错的地方）**：

1. **上述 2×2 是"对 Avida 式设定的建模"，尚未与 Avida 本体对接实测** —— 已列为最欢迎的外部贡献（见 `CONTRIBUTING.md`）与 `ROADMAP.md` v0.6 首要缺口。
2. **该声明只覆盖 Avida / Tierra，不覆盖 Evochora。** 据 Evochora 官网（`evochora.org`），其
   "mutation mechanics, resource dynamics, and **death conditions** are fully programmable through
   swappable plugins" —— 即**在 Evochora 上可以通过配置插件实现代谢性死亡**。因此本引擎相对
   Evochora 的差异点**不是"能不能死"，而是"死亡是否由内生代谢预算强制、且损耗是否不可逆地刻在
   结构容量上"**。这一点**我们尚未在 Evochora 上实测**，不作主张。
3. **Lenia（Bert Chan, 2018）是连续细胞自动机，不以"个体-资源-死亡"为建模单元**，与本引擎不在同一问题域，此处仅作领域列举。

> 文献出处（核实于 2026-10-16）：Ofria, Bryson & Wilke (2009), *Avida: A Software Platform for
> Research in Computational Evolutionary Biology*, in *Artificial Life Models in Software*
> (Springer), pp. 3–35, DOI `10.1007/978-1-84882-285-6_1`（另有期刊版：Ofria & Wilke, 2004,
> *Artificial Life* 10(2):191–229, DOI `10.1162/106454604773563612`）。

## 五条硬约束（不是惩罚项，是硬约束）

| 条件 | 实现 | 性质 |
|---|---|---|
| **稀缺** | 每拍预算 `B = ratio × Σwant`，通道间零和的硬取舍（分不到的 = 0） | 硬约束 |
| **死亡** | `E ≤ 0` 持续超过耐心阈值 → 永久终止，不回滚 | 真实结局 |
| **不可逆** | 长期饥饿 → 结构容量 `capacity` 永久缩小，**只减不增** | 单调 |
| **代谢** | `E` 只能由自身产出换取，无外部拨款 | 闭环 |
| **内生约束** | 设定点 `sp ← 自身历史 ref ← 内部状态 y`，外部不可写入，且 `y` 有 leak | 自生 |

## 四项核心实测结论（全部由 `run_core.py` 当场跑出）

### 1. 死亡是真实结局

16 个种子真实跑 600 拍：**13 活 / 3 死**（seed 3 死于第 525 拍、seed 4 死于 596、seed 7 死于 516）。

### 2. 关掉全部决策模块，取舍依然出现

寻找（`k_seek`）、显著性（`k_sal`）、arrival 预测（`k_seek_arr`）、外部 KPI（`kpi_push`）
**全部保持引擎默认 0 —— 即不存在任何决策模块**。
前 300 拍分别饿通道 3 / 通道 5，之后两组条件完全相同，测同一个通道 3 的后段份额：

| | 饿通道 3 | 饿通道 5 | Δ |
|---|---|---|---|
| 通道 3 后段份额 | 0.00004 | **0.1495** | **−0.1494 ± 0.0311** |

**8 / 8 seeds 符号一致。** 饿过谁，之后就少给谁。

> 这段"记忆"不在任何模块里 —— 它在**不可逆容量**里。
> 决策不是一个可以装的组件，它是稀缺 × 不可逆 × 竞争动力学的投影。

### 3. 稀缺与不可逆是焊死的，不是两个开关

| 配置 | 终态结构偏度（std/mean of capacity, n=8） |
|---|---|
| **两条都在** | **0.2913 ± 0.0284** |
| 撤掉不可逆 | 0.0000 |
| 撤掉稀缺 | 0.0000 |
| 两条都撤 | 0.0000 |

撤掉任何一条，**疤痕从不形成**；撤掉不可逆，结构在撤除瞬间塌回均匀。

> **不缺，就不留疤。** 两条互为存在条件。

### 4. 结构有关键期，且早期施加后撤除的效果**强于**全程施加

外部引导在不同窗口施加，测终态结构偏度（n=8）：

| 引导窗口 | 终态结构偏度 |
|---|---|
| **早期 0–150，之后撤除** | **1.0933 ± 0.0105** |
| 中期 150–300 | 0.5092 ± 0.0468 |
| 晚期 300–450 | 0.3243 ± 0.0500 |
| 全程施加 | 0.8502 ± 0.0070 |
| 全程无引导 | 0.2913 ± 0.0284 |

早期给过再撤掉（1.0933）**高于**全程施加（0.8502），晚期施加几乎无效（0.3243 ≈ 无引导 0.2913）。
机制即不可逆：容量只减不增，一度形成的形状被锁死，之后的持续投入反而摊薄了集中度。

## 我们开源了全部失败 —— 这是本仓库最贵的资产

**`evidence/失败模式库/判据核.md` 收录 192 条失败模式，全部带代码可复现。**

> **关于条数，如实说明**：152 是**独立条目数**，编号范围为 35–206。
> 其中 56 个编号为历史跳号、9 个为重复编号，我们**不回填、不重排**——
> 回填即改写历史，违反"只增不减"。另有第 1–34 条引用了一个并不完整
> 包含它们的外部文件（实测仅含 6 个编号），**该引用链已断裂，不计入本数**。
> 清点可复现：`python3 tools/count_criteria.py`。
> 我们曾对外称"195 条"，那是把**最大编号**当成了条目数——**已更正**。

在 AI 生成内容泛滥的 2026 年，任何人三十秒就能编一个可信的成功故事。
**但编不出 192 条带代码的失败记录。**

三类最常复发的失败（每一条都曾污染过我们自己的结论）：

| 失败模式 | 症状 | 复发次数 |
|---|---|---|
| **饱和伪装成"无效应"** | 信号 ×1 / ×10 / ×100，指标一字不差 | 3 次以上 |
| **变量静默失效** | 变量写了但没接进主通道，不报错、不崩、图照出 | 4 次以上 |
| **相位假象** | 测量窗口恰好落在振荡的某一半，结论随取哪一代反转 | 3 次以上 |

配套 60 份实验报告（`evidence/实验报告/`），每一份都记录了**被推翻的预注册判据**。

我们还公开了对第三方方法论的审计结论：
**一致性系数 κ 高 ≠ 坐标正确** —— 只要评审者共享同一套坐标库，即使全体一致地指向错误坐标，
κ 依然可以是 0.945，而命中真值率可以从 0.98 崩到 0.01（差 99 倍）。详见 `evidence/实验报告/054_TACT卡帕的判别力.md`。

## 应用场景

| 场景 | 本引擎提供的能力 |
|---|---|
| **生物科学假说检验（首选）** | 给演化 / 发育 / 生态命题提供变量完全可控、逐位可复现、成本近乎为零的 in silico 对照沙盒。三条命题已实测：关键期边界、早期剥夺的阈值型剂量-反应、选择压是开关不是旋钮 |
| **长期自治 Agent 的资源治理** | 解决"上下文无限膨胀、无取舍、无偏好"的根本问题 |
| **不可逆审计** | 结构容量只减不增，为 Agent 行为提供天然不可篡改的时间线 |
| **多智能体多样性研究** | 同一组硬约束下由初始差异自发产生个体分化 |
| **AI 存在形式化研究** | 五条件可作为"数字系统是否具备生命特征"的可测判据 |

### 生物科学：三条命题的 in silico 检验

```bash
python3 examples/bio_hypothesis_test.py     # 约 3 分钟，写 data/bio_results.json
```

| 命题 | 结论 | 实测 |
|---|---|---|
| **H1 发育关键期** | 存在，且边界可定位 | 引导起点 0 → 效应 +0.8020；起点 400 后衰减到基线 +1SE 内（门已关上） |
| **H2 剂量-反应** | **阈值型，非线性** | 最短剂量 50 拍已达最大效应的 **89.8%**；延长到 400 拍只再增 0.0153。8/8 seeds 符号一致 |
| **H3 选择压** | **开关，不是旋钮** | ratio<1.0 结构一概成形且不随稀缺度单调变化；ratio≥1.0 精确塌回 0.0000 |

> 定位声明：以上不构成生物学成果。本引擎不含任何真实生物参数，与生物系统仅为**结构类比**；
> 它提供的是一处可复现的对照沙盒，不是替生物学家下结论。

### 它不是又一个框架，是可以挂到任何框架上的一层

`examples/governed_agent.py` 是最小可运行示例 —— **不到 20 行，不改动原框架一行代码**，
把五条硬约束挂到你现有的 Agent 上：

```bash
python3 examples/governed_agent.py
```

改动只有一处：**原框架说「我要多少」，现在改说「我分到了多少」**。

实测输出（`ratio=0.45`，8 通道）：

| seed | 结局 | 终止拍 | 终态结构偏度 |
|---|---|---|---|
| 3 | 死亡 | 525 | 0.2723 |
| 5 | 存活 | — | 0.2792 |
| 11 | 存活 | — | 0.2528 |
| 13 | 存活 | — | 0.2322 |
| **seed 3 · 撤掉稀缺（ratio=1.2）** | **存活** | — | **0.0000** |

最后一行是本项目最重要结论的现场复现：**不稀缺就没有取舍，没有取舍就不留疤。**

## 已知未做的事（诚实清单）

1. 引擎为**规则层实现**，不构成"洛神已具备个体性"的证据。个体性在我们自己的判据下**仍未闭合**（见 `evidence/失败模式库/判据核.md` 第一条）
2. **外部平台基线对比（Avida / ABM / 细胞自动机）尚未完成** —— 059 只做到了
   「对 Avida 式设定的建模对照」，**未与 Avida 本体对接实测**。这是当前最大缺口，见 `ROADMAP.md` v0.6
3. 样本量偏小：核心结论 n=8 / n=16，未做多重比较校正
4. 部分统计口径不统一（置信区间、SE 的 ddof），已在 `docs/复现清单.md` 标注
