状态 / States

六个状态，颜色与呼吸节奏各不相同；动画为 SVG 内嵌 CSS，无 JavaScript。

状态节奏含义
静置 · idle4s 慢呼吸冷色低亮度
推演 · thinking0.8s 快脉冲琥珀偏移
执行 · busy持续旋转亮度拉高
受阻 · blocked脉冲冻结低饱和红
失败 · error红色一次抽动后静止
达成 · success短暂暖脉冲 → 回落 idle短暂暖脉冲 → 回落 idle

python3 facade.py --repo owner/name --out ./assets
