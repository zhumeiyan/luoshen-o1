### 139 语义手性与镜像逃逸 ★★★
`result139c.json` 已回读：

```
MIRROR(保集合)  BOW  tpr 1.0  fpr 1.0  disc 0.0   degenerate 1
MIRROR(保集合)  POS  tpr 1.0  fpr 0.0  disc 1.0   degenerate 0
CONTROL(变集合) BOW  tpr 0.66 fpr 0.34 disc 0.32
```

**词袋的判别度精确是 0**——主宾互换、词集合不变，它全判同一类。**不是漏检，是根本没在看。** 而词集合一变它立刻能看见（0.32）。

这就是镜像逃逸的硅基版本：**逃过检测不是因为伪装得好，是因为检测器用的表示不含手性。**

剂量扫描：χ₀=1e-5 → 最终 0.927（未到 1.0，真实材料有饱和）；χ₀=0 → 120/120 全部自发破缺，方向随机。**不需要任何初始不对称。**

## 五、横跨这些实验的一条硬规律

把这些"正经发现"放一起看，它们几乎全是同一句话的变体：

**判据必须能同时产生真和假，否则它只是装饰。**

- 112：开环 0/12 让闭环 12/12 有了意义
- 117：6 个钟表让 1 只眼睛有了意义
- 128 多重比较：3 真 0 假 = 全真饱和 = 判据失效
- 138：4 条不翻转的例子，让 2 条翻转的有了意义
- 139：CONTROL 的 0.32 让 MIRROR 的 0.0 有了意义

**而我自己犯的错，也全是它的反面**：只统计成功响应、只挑会翻转的例子、只报埋雷召回不报真实语料精确率、把"我做完了"当成证据。
