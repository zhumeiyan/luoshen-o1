## 第一部分：可申主题评估

我把候选主题按**新颖性把握**排序。标准只有一个：**是否把一个已知原理用在一个新的、具体的技术方案上，并产生可测量的技术效果。**

### 主题 A：基于表示手性的镜像态检测方法 ★★★★☆（最推荐）

**为什么可申：** 不是"用 TPR−FPR"，那个是 Youden 1950 的公共知识。可申的是**一套具体的技术流程**——给定待测检测器，自动判定它对哪个镜像算子是盲的，并输出盲度。

**技术方案（权利要求骨架）：**

> 一种镜像态检测方法，包括：
> 1. 对待测系统的输入信号 x，构造镜像样本 Mx，其中 M 为对合算子且满足 π(Mx) = π(x)，π 为成分多重集投影；
> 2. 将 x 与 Mx 分别输入待测检测器，记录 TPR 与 FPR；
> 3. 计算判别度 disc = TPR − FPR，并在预测类别数为 1 时置退化标志；
> 4. 当 disc = 0 且退化标志为 1 时，判定该检测器对算子 M 手性盲；
> 5. 更换为携带排列信息的表示重新执行步骤 2–3，若 disc 由 0 升至显著非零，输出"表示缺陷"而非"阈值缺陷"的诊断结论。

**技术效果（可测量，这是我们最强的支撑）：**
- 词袋表示对语义镜像 disc = 0.0000（退化），含序表示 disc = 1.0000
- 对照组（多重集改变）下同一词袋 disc = 0.3200，证明诊断不误伤

**新颖性支点：** 步骤 5 的**归因判定**——区分"检测器精度不够"与"检测器表示缺手性"。这是具体技术方案，不是抽象原理。

**风险：** 需要与现有的对抗样本检测、分布漂移检测专利做检索比对。中等风险。

### 主题 B：自给能力 fg 的双阶段测量方法 ★★★★☆

**为什么可申：** 存活率是已知指标。可申的是**"维持期 + 撤供期"两阶段测量**这个具体方法，它把"有能量无能力"的镜像态测出来了。

**技术方案：**

> 一种智能体自给能力的测量方法，包括：
> 1. 维持期：向被测智能体持续供给外部能量，同时记录其主动获取能量的行为 act 与世界响应 fb；
> 2. 以 burn-in 窗口消除滑动均值起算偏差后，计算行为与响应的相关系数作为自给能力 fg；
> 3. 撤供期：切断外部供给，记录存活率与平均存活时长；
> 4. 当维持期存活率高而撤供期存活率显著低时，判定被测对象处于镜像态。

**技术效果：**
- 输液组存活 16/16，撤供 0/12，均存活 235 拍
- 对照 arm（fg 正常）撤供 8/12，1117 拍
- burn-in 前 fg = 0.00791（3/16 存活），burn-in 后 fg = 0.00072（0/16 存活）——**这一条本身就是方法有效性的硬证据**

**新颖性支点：** burn-in + 撤供的双阶段设计。单看任一半都测不出镜像态。

**风险：** 需要与现有的"能力评估基准"类专利比对。中等。

### 主题 C：基于相倚性判定的训练/干预方法 ★★★☆☆

**技术方案：** 在智能体训练中，通过判定世界响应是否由智能体自身行动引起（相倚 vs 相继），决定是否计入有效训练。

**技术效果：** 相倚 0.10368 / 15/16 vs 相继 0.00149 / 0/16（同投入、同时长）。

**新颖性支点：** 具体工程实现（协方差 → 相关系数的修正）。我们实测发现用协方差会得出"噪声越大学到越多"的错误结论（0.093→0.813），改成相关系数后方向正确（0.105→0.088）。这个**修正本身**是可申的技术细节。

**风险：** 强化学习领域专利密集。较高风险，需专业检索。

## 第五部分：专利之外的占位手段（版权 / 软著 / 商业秘密）

你问"没有专利也有什么版权之类的"——有，而且其中一条对当前状态可能比专利更合适。

### 5.1 版权：写完自动就有

代码、论文、报告**自创作完成之时自动享有著作权**，不需要登记、不需要申请、不花钱。

登记的作用是**取证**——真打官司时，登记证书是"这东西是我的、且在这个时间点就存在"的初步证据。

### 5.2 软件著作权登记（推荐，成本低）

- **对象**：evalguard 全系列（v0.1–v0.5）、`eo_io/` 身体系统模块、实验引擎
- **机构**：中国版权保护中心（ccopyright.com.cn）
- **成本**：官方费用低，普通登记通常数百元量级，周期约 1–3 个月（以官网实时公示为准，此处不报死数字）
- **一个要确认的点**：登记需提交部分源代码（前后各若干页）。**是否影响专利新颖性，提交前让代理人确认一次**——因为一旦该部分被公开查询，就构成现有技术

### 5.3 商业秘密：对未公开部分可能优于专利 ★

这是我认为你该认真考虑的一条，因为实验 080–139 **还没公开**。

| | 专利 | 商业秘密 |
|---|---|---|
| 是否公开技术 | **必须公开**（换保护） | **不公开** |
| 保护期 | 20 年（发明） | **无期限**（只要守住） |
| 成本 | 申请费 + 代理费 + 年费 | 近乎为零 |
| 能否对抗反向工程 | 能 | **不能** |
| 能否对抗独立研发 | 能 | **不能** |

**关键取舍：对同一技术，专利和商业秘密只能二选一。** 申请专利 = 主动公开；选商业秘密 = 永远保密。

考虑到当前**一分钱收入还没有**，商业秘密的现实优势是：**零成本、立即生效、不泄露**。专利则要花一笔钱，且一旦驳回，技术已公开而保护落空（第零部分③已述）。
