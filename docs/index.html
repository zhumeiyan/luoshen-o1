③ 它和其它框架的根本不同

开源 Agent 框架
（LangChain / AutoGPT / Dify …）		本引擎
上下文超了 → 截断 / 压缩资源耗尽 → 运行终止，不可回滚
token 用完 → 换 key 继续能量必须由自身产出换取，无外部拨款
状态丢了 → 重新加载还是"同一个"结构容量只减不增，丢掉的回不来
一个不会死的系统，不需要做取舍。而不做取舍的系统，不会产生偏好，也不会形成结构。
本引擎换掉的就是这个前提。它是约束层，可挂到任何框架之上 —— 不是又一个 Agent 框架。

④ 什么时候不要用它

如果你的需求是请用
生产可用的 Agent / RAG 应用框架LangChain、LlamaIndex、Dify
多智能体编排与工作流AutoGen、CrewAI、LangGraph
高性能推理服务vLLM、Ollama
benchmark 分数更高的模型本引擎不产出模型，也不刷分
开箱即用的业务能力本引擎是约束层，不是应用层
