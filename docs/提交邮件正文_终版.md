## 四、一句话作品定位

> 所有开源 Agent 框架都在问"它能做什么"。
> 本项目问的是"当它必须取舍、必须记住、而且真的会死的时候，它是什么"。

五条硬约束（稀缺 / 死亡 / 不可逆 / 代谢 / 内生约束）下，结构不是被设计的，
是被约束逼出来的。我们同时开源了**全部失败模式**——成功可以编，失败编不出来。

## 五、场景落地（评审占 30%，此处为最强项）

`evalguard` 是从判据核编译出的可执行检查器，能 pip 安装、能命令行跑、能起 HTTP 服务、能挂进 CI。
它只做一件事：**判断一个评测结论是不是静默错的。**

- 实测 55 个真实脚本，精度 90%
- 与 ruff `--select ALL` 对标（真跑）：对方 39 条命中，实质相关仅 1 条；
  **我们 README 里直接写着"你该用 ruff，我们跑在它旁边"**
- 对外接口实测 18/18 通过：REST API + SARIF 2.1.0 + GitHub Action + pre-commit
- 现场试用台：粘贴代码当场扫，全程在浏览器内跑，不发往任何服务器
