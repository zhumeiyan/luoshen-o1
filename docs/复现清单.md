## 1. 指标定义（公式从源码逐行抽出）

| 指标 | 定义 | 源码位置 |
|---|---|---|
| `capacity` | 结构容量，逐拍 `cap ← max(cap − cap_decay × unmet × cap, cap_min)`，**只减不增** | `core/life5.py: step()` ② 段 |
| `unmet` | `max(want − a, 0)`，即"想要的但没分到" | 同上 |
| `E` | 能量；`E ← E − (basal + c1·Σdone) + fg·Σdone[forage_ch]/cap_share` | 同上 ③ 段 |
| `share_i` | 通道 i 的分配占比 `a_i / Σa` | `run_core.py: tail_share()` |
| **结构偏度** | `std(capacity, ddof=1) / mean(capacity)`，终态取最后一拍 | `run_core.py: struct_skew()` |
| 死亡 | `E ≤ 0` 连续超过 `death_patience`（默认 60）拍 → `alive=False`，`death_t` 记录 | `core/life5.py: step()` ⑤ 段 |

**统计口径**：所有 `±` 为 **SE**（`std(ddof=1)/√n`）。
⚠️ 未做多重比较校正；n=8 / n=16，样本量偏小。

## 3. 实验设计的关键点（为什么这样才算数）

**① "决策模块全部关闭"如何保证**
`k_seek`、`k_sal`、`k_seek_arr`、`kpi_push` 全部使用引擎默认参数 **0**，
即寻找、自下而上显著性、到达预测、外部 KPI 四条通路**都不存在**。
这不是"关掉了但代码还在"，是这些项对 `want` 的贡献恒为 0。

**② "前 300 拍饿某通道"如何实现**
替换 `alloc_fn`：`make_starver(ch, warm)` 在 `t < warm` 时**跳过**该通道，
使其在排序分配中拿不到任何资源 —— 是真实的硬取舍（分不到 = 0），不是"少给一点"。
`warm` 之后 `alloc_fn` 完全放开，**两组运行条件从此完全相同**。

**③ 为什么两组都测同一个通道 3**
若各自测自己被饿的通道，两组都近似 0，没有区分度。
必须交叉：饿 3 / 饿 5 两组**都测通道 3**，差值才是"饿谁"这一件事的效应。

**④ 撤掉稀缺 / 不可逆怎么撤**
撤稀缺：`ratio=50.0`（预算极大 → 不再触发取舍，`unmet ≡ 0`）
撤不可逆：`cap_decay=0.0`（不留疤）
两者都撤：`ratio=50.0, cap_decay=0.0`

## 6. 失败模式库

`evidence/失败模式库/判据核.md` 收录 **261 条**失败模式，全部带代码可复现。
`evidence/实验报告/` 收录 **70 份**实验报告，每份记录被推翻的预注册判据。

三类最常复发（每一类都曾污染过我们自己的结论）：

| 失败模式 | 症状 | 复发次数 |
|---|---|---|
| 饱和伪装成"无效应" | 信号 ×1 / ×10 / ×100，指标一字不差 | ≥ 3 次 |
| 变量静默失效 | 变量写了但没接进主通道，不报错、不崩、图照出 | ≥ 4 次 |
| 相位假象 | 测量窗口恰好落在振荡的某一半，结论随取哪一代反转 | ≥ 3 次 |

另含对第三方方法论的审计：**κ 高 ≠ 坐标正确**
（共享同一套坐标库时，全体一致地错，κ 仍可达 0.945，而命中真值率 0.98 → 0.01）。
