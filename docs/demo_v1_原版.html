2现场运行：同一个引擎，16 个个体

点上方任一编号切换个体。红色竖线 = 判定死亡时刻。 注意死亡通常是先缓慢下降、再加速归零，不是瞬间断崖。

3唯一的对照：撤掉稀缺会怎样

这是全项目最硬的一条因果对照： 只改「稀缺」这一个变量，结构偏度精确归零。 富足条件下没有个体死亡，但也没有结构——活下来的是一个没有形状的个体。

4生物科学：三条可检验命题

定位声明：这不是生物学成果，而是给演化 / 发育 / 生态假说提供一处 变量完全可控、逐位可复现、成本近乎为零的 in silico 对照沙盒。 与真实生物系统仅为结构类比，未经生物学家外部验证。

5我们开源了全部失败

条数由 tools/count_patterns.py 实时统计， 不由人（含维护者与 AI）口头报数。此前我们曾称「195 条」（把最大编号当条目数）， 随后清点脚本又因正则漏掉行首加粗写法而少计 2 条——两处均已修正并公开。

6与同类平台的定位差异

我们不是 Avida 的替代品。在 Avida 式设定（外生奖励 × 可逆）下， 代谢性死亡 0/16 —— 不是数值低，是结构性不发生。

7一键复现

git clone <仓库地址> && cd luoshen-o1
pip install -r requirements.txt      # 仅 numpy
python3 tests/test_engine.py         # 11 项自检
python3 experiments/demo_terminal.py # 本页数字的来源
