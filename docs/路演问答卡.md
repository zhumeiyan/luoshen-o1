# 洛神 O1 · 路演问答卡

**用法**：8 分钟讲完后进入提问环节。这张卡按"评委最可能问倒你的顺序"排列。
每条分三块：**答什么**（30 秒内讲完）、**不要说**（会失分的本能反应）、**必须承认**。

> 总原则：**能答的用数字答，答不了的当场承认并说明为什么现在答不了。**
> 我们全项目的人设是"开源全部失败"——在这个环节含糊其辞，前面 221 条失败记录的可信度一起归零。

## Q1 这跟 Avida / Tierra 有什么本质区别？

**答**：Avida 的死亡是**外部设定的裁决规则**，我们的死亡是**内生代谢预算的必然结局**。
我们做了 2×2 对照（`evidence/实验报告/059_与Avida类平台的定位差异.md`）：
外生奖励 × 可逆损耗（≈Avida 式设定）下，代谢性死亡 **0/16**——不是数值低，是结构性不发生。
内生代谢 × 不可逆下 **3/16**，且永久损失 0.7043、容量回升恒为 0。

**不要说**："我们比 Avida 强"。我们是 Avida 设定下不存在的那一层，不是它的竞品。

**必须承认**：我们**尚未与 Avida 做过实测对照**，这是当前最大缺口，已写进 CONTRIBUTING 的"最欢迎的贡献"。
另外 Evochora 宣称死亡条件可编程（"fully programmable through swappable plugins"），
所以差异点不是"能不能死"，而是"死亡是否由内生预算强制、损耗是否不可逆地刻在结构上"——**这一点未在 Evochora 上实测，不作主张**。

## Q2 它到底死没死？"死亡"是不是就是程序退出？

**答**：不是。死亡有诊断书，崩溃才有 traceback。
演示视频里有定格 6 秒的诊断书：判定死亡第 525 拍、能量在第 466 拍就归零（**早于判定 59 拍**）、
峰值能量 0.7777、**进程状态无异常、退出码 0、引擎继续运行**。
崩溃是中断，死亡是带归因的终止且系统接着往下跑。

**不要说**："它崩了"——这个词一出口，整个项目的核心主张就废了。

**必须承认**：死亡是**规则层实现**，不构成"数字生命已具备个体性"的证据。
个体性在我们自己的判据下**仍未闭合**，判据核第一条即已声明。

## Q3 n=8 / n=16，没做多重比较校正，统计上站得住吗？

**答**：站不住，我们不主张它站得住。已写进作品介绍第七节"已知未做的事"第 2 条。
我们依赖的是**符号一致性**而不是 p 值：创新一 8/8 seeds 符号一致、
H2 剂量-反应五档**全部 8/8 符号一致**、H1 关键期效应**单调衰减**。
机制性结论（如"撤掉稀缺后结构精确归零 0.0000"）是**二值结果**，不依赖样本量。

**不要说**："样本量够了"。它不够。

**必须承认**：未做多重比较校正；核心结论样本量 n=8 / n=16。
若评委追问，可补一句：这正是我们把 221 条失败模式全开源的原因——**读者可以自己判断哪些结论该打折扣**。

## Q4 你说生物科学落地，有生物学家验证过吗？

**答**：**没有。** 我们明确声明：以上不构成生物学成果。
本引擎不含任何真实生物参数，与生物系统仅为**结构类比**。
我们的定位是**给假说提供一处变量完全可控、逐位可复现、成本近乎为零的 in silico 对照沙盒**——
湿实验贵、慢、混杂变量多，沙盒的作用是把机制单独剥离出来先跑一遍，
让研究者决定值不值得去做昂贵的真实验。

**不要说**："我们证明了发育关键期存在"。我们证明的是**在我们的约束下**关键期存在。

**必须承认**：无任何生物学外部验证；H1/H2/H3 只有结构类比，无真实生物参数。

## Q5 五条凭什么是这五条？为什么不是四条或六条？

**答**：因为它们是**互为存在条件**的，不是并列清单。实验给出了直接证据：
撤掉稀缺 → 结构偏度 **0.0000**；撤掉不可逆 → 结构**塌回均匀 0.0000**；两者皆无 → **0.0000**。
只有五条同时成立时才出现 0.2913。所以它们不是"我们挑了五条"，是"少一条其余全不成立"。

**不要说**："我们参考了某某理论选出五条"。这会暗示它是设计出来的——而我们的核心主张恰恰是结构不是被设计的。

**必须承认**：我们没有穷举过其他组合，也没有证明这五条是**最小**充分集。这是开放问题。

## Q6 "结构偏度"是你自己定义的指标吧？会不会是自证？

**答**：是自定义的（capacity 的 std/mean），而且这个问题问到了点子上。
我们做了两件事对冲：一是**结论尽量落在二值结果上**（0.0000 vs 0.2913，不依赖指标刻度）；
二是我们**审计过自己**——判据核里第 23 条"变量静默失效"、第 111 条"表型空间坍缩"
都是我们自己指标出问题后的记录。
另外我们实测过：**一致性系数 κ 高 ≠ 分类正确**（`054`），
评审者共享同一套坐标库时即使全体指向错误坐标，κ 仍可达 **0.9438 → 0.9463（几乎不动）**，
而命中真值率从 **0.9799 崩到 0.0099（差 99 倍）**。这条同样打在我们自己身上。

**不要说**："指标经过验证"。没经过外部验证。

**必须承认**：偏度是自定义指标；判据核自身的前瞻判别力只在特定阈值档成立（对阈值敏感），见 `050`。

## Q7 决策模块全是 0，那它其实什么都没做？

**答**：对，它什么都没"做"——这正是创新一的要点。
寻找、显著性、到达预测、外部 KPI 全部保持引擎默认 0，系统中**不存在任何决策模块**。
前 300 拍饿通道 3 与通道 5，此后条件完全相同，通道 3 后段份额 0.00004 vs 0.1495，
Δ = −0.1494 ± 0.0311，8/8 符号一致。
**取舍是稀缺 × 不可逆 × 竞争动力学的投影**，不是决策的产物。

**不要说**："它学会了"。没有学习模块。

**必须承认**：这是规则层实现，不涉及任何学习算法。

## Q8 你是单人独立开发者，项目长期怎么保证？

**答**：这是"长期发展"维度最该被质疑的地方，我们不回避。三点缓解：
① 零依赖（仅 numpy），一条命令 `python3 experiments/run_core.py` 复现全部结论，**项目价值不依赖维护者在线**；
② 判据核"只增不减"，改动需本人 merge——这跟项目主张的"不可逆"是同一条原则在治理层面的应用；
③ 已备 GOVERNANCE.md / ROADMAP.md / Issue-PR 双模板。

**不要说**："我打算组建团队"。没有具体计划就是没有。

**必须承认**：单人维护是**真实风险**，已正面写进 GOVERNANCE.md，未粉饰。

## Q9 你完全不接 LLM，是不是因为接不起？

**答**：不是成本问题，是设计选择。接了 LLM 就引入不可复现性——
而本项目全部价值建立在"你跑会得到**逐位相同**的数字"上。
零 LLM、零网络意味着任何机器 `pip install numpy` 后都能独立验证我们的结论，
包括验证我们是错的。

**不要说**："以后会接"。接了就破坏复现性这个核心卖点。

**必须承认**：不接 LLM 意味着本引擎**不能直接处理自然语言任务**，它是一个运行时约束层，不是应用。

## Q10 它能挂到 LangChain / AutoGPT 上吗？要改多少？

**答**：核心 30 行，**不改原框架一行代码**。
原框架照常产出"想要多少"，我们把它变成"分到了多少"（`examples/governed_agent.py` 已实跑验证）。
挂上之后得到三个原框架给不了的性质：预算零和必须取舍、结构容量只减不增因而做过的事留疤、
死亡是可观测的真实结局。

**不要说**："它能替代 LangChain"。它改的是 Agent 的**运行时前提**，不是功能层。

**必须承认**：示例是玩具级 agent，未在真实生产 Agent 上做过压测。
