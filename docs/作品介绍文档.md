## 一、项目背景：我们要解决的不是"更聪明的 Agent"

当前所有开源智能体框架（LangChain、AutoGPT、Dify 等）解决的是同一个问题：
**如何让大模型更好地调用工具、规划任务、记住上下文。**

它们的共同前提是：**这个 Agent 不会死。**

- 上下文超了 → 截断或压缩，不影响它"存在"
- token 用完 → 换一个 key，继续
- 状态丢了 → 重新加载，还是"同一个"

**一个不会死的系统，不需要做取舍。而不做取舍的系统，不会产生偏好，也不会形成结构。**

本项目要解决的正是这个被整个行业跳过的问题：

> **当资源有限、时间不可逆、死亡是真实结局时，一个数字系统会如何自发地长出结构？**

这不是在现有 Agent 框架上加一个插件，这是**换了前提**。

## 二、技术架构：五条硬约束

系统由五个彼此独立、缺一不可的条件构成，全部是**硬约束**而非惩罚项：

| 条件 | 实现 | 性质 |
|---|---|---|
| **稀缺** | 每拍预算 `B = ratio × Σwant`，通道间零和的硬取舍（分不到的 = 0，而不是少给一点） | 硬约束 |
| **死亡** | `E ≤ 0` 持续超过耐心阈值 → 运行终止，**不回滚** | 真实结局 |
| **不可逆** | 长期饥饿 → 结构容量 `capacity` 永久缩小，**只减不增** | 单调 |
| **代谢** | `E` 只能由系统自身产出换取，**无外部拨款** | 闭环 |
| **内生约束** | 设定点 `sp ← ref ← y`，`y` 有 leak（不持续投入就衰减），外部不可写入 | 自生 |

> 这五条不是五个可调旋钮，是五条**必须同时成立、且互为存在条件**的约束。
> 第三条实测给出了证明：撤掉其中任意一条，后面所有的结构都不会出现。

**实现形态**：单文件核心引擎 `core/life5.py`，唯一依赖 numpy。
无 LLM、无网络、无外部服务 —— 任何机器 `pip install numpy` 后即可复现全部结论。

**关于"可部署"这条声称，我们验证过而不是写过**：`pip install` 的退出码为 0
**不等于**装出来的包能用。本仓库曾长期缺 `core/__init__.py`，`find_packages()`
返回空列表，`pip install .` 装出一个**不含任何代码的空包**——而当时的文档仍在
声称"可 pip 安装、具备实际部署条件"。现已修复，并由 `tools/verify_all.py` 第 ④ 组
守护：真装一次到临时目录，断言 `from core import Life5` 可用；删除 `__init__.py`
立即 FAIL（判据核第 278–281 条）。**这条失败记录保留在库里，不作删除。**

## 三、核心创新点

### 创新一：结构不是被设计的，是被约束逼出来的

我们做了一个反直觉的实验：**把全部"决策模块"关掉。**

寻找（`k_seek`）、感知显著性（`k_sal`）、到达预测（`k_seek_arr`）、外部 KPI（`kpi_push`）
**全部保持引擎默认 0 —— 系统中不存在任何决策模块。**

前 300 拍分别饿通道 3 / 通道 5，之后**两组的运行条件完全相同**，测同一个通道 3 的后段份额：

| 前 300 拍 | 通道 3 后段份额 |
|---|---|
| 饿通道 3 | 0.00004 |
| 饿通道 5 | **0.1495** |
| **Δ** | **−0.1494 ± 0.0311（SE, n=8）** |

**8 / 8 seeds 符号一致。饿过谁，之后就少给谁。**

而这段"记忆"不在任何模块里 —— **它在不可逆结构容量里。**
没有决策模块、没有规则参数、没有强化学习。**取舍是稀缺 × 不可逆 × 竞争动力学的投影。**

### 创新二：稀缺与不可逆是焊死的，不是两个开关

| 配置 | 终态结构偏度（std/mean of capacity，n=8） |
|---|---|
| **稀缺 ✓ 不可逆 ✓** | **0.2913 ± 0.0284** |
| 稀缺 ✓ 不可逆 ✗ | **0.0000** |
| 稀缺 ✗ 不可逆 ✓ | **0.0000** |
| 稀缺 ✗ 不可逆 ✗ | **0.0000** |

- 撤掉稀缺 → 永远不饿 → 疤痕**从不形成**
- 撤掉不可逆 → 结构在撤除瞬间**塌回均匀**

> **"不缺，就不留疤。"** 两条互为存在条件 —— 这是本项目最重要的结构性发现，
> 也是"不可逆"这一条必须被实装在**结构上**（而不是装在饿感上）的原因。

### 创新三：结构有关键期，且早期施加后撤除的效果强于全程施加

外部引导在不同时间窗口施加，测终态结构偏度（n=8）：

| 引导窗口 | 终态结构偏度 |
|---|---|
| **早期 0–150，之后撤除** | **1.0933 ± 0.0105** |
| 中期 150–300 | 0.5092 ± 0.0468 |
| 晚期 300–450 | 0.3243 ± 0.0500 |
| 全程施加 | 0.8502 ± 0.0070 |
| 全程无引导（基线） | 0.2913 ± 0.0284 |

三点：

1. **早期给过，撤掉之后结构留下了**（0.2913 → 1.0933，+0.802）
2. **晚期给，几乎无效**（0.3243 ≈ 基线 0.2913）—— 过了关键期，门就关上了
3. **早期施加后撤除（1.0933）反而强于全程施加（0.8502）** —— 持续投入会摊薄集中度

机制即不可逆：容量只减不增，一度形成的形状被锁死。
这对"如何养育一个数字/生物系统"给出了可操作的结论：**引导要早，且要敢于撤。**

### 创新四：我们开源了全部失败 —— 342 条带代码的失败模式

**`evidence/失败模式库/判据核.md` 收录 342 条失败模式，每一条都有代码可复现。**
配套 83 份实验报告，每一份都记录了**被推翻的预注册判据**。

> **条数如实说明（这条本身就是我们主张的实践）**：141 是独立条目数，编号 35–206。
> 56 个历史跳号、9 个重复编号，我们不回填也不重排；第 1–34 条的外部引用链已断裂，
> 不计入。可复现清点：`python3 tools/count_criteria.py`。
> 我们此前对外称"195 条"，是把最大编号误当条目数——**本稿已更正**。

三类最常复发、且每次都曾污染我们自己结论的失败：

| 失败模式 | 症状 | 我们栽过的次数 |
|---|---|---|
| **饱和伪装成"无效应"** | 信号 ×1 / ×10 / ×100，指标一字不差 | ≥ 3 次 |
| **变量静默失效** | 变量写了但没接进主通道，不报错、不崩、图照出 | ≥ 4 次 |
| **相位假象** | 测量窗口恰好落在振荡的某一半，结论随取哪一代反转 | ≥ 3 次 |

在 AI 生成内容泛滥的 2026 年，任何人三十秒就能编出一个可信的成功故事。
**但编不出 342 条带代码的失败记录。** 我们认为这是开源项目最稀缺的资产类型。

### 创新十九：操控不是能力，凭证才是 —— 兼记一次真实发生的感官剥夺

一个常被混淆的问题：某些电脑操控类 Agent 被用户授权后"能完全操控电脑"，
而我们卡在登录这一步。差别在哪？我们用 2×2 把它拆开（自建登录应用 + playwright **真实鼠标事件**）：

| 格 | 操作 | 凭证 | 鼠标动作 | 结果 |
|---|---|---|---|---|
| A | 完整 | 正确 | 5 | 进入 |
| B | 完整 | 错误 | 5 | **403** |
| C | **零操作** | 正确 | 0 | **进入** |
| D | 零操作 | 无 | 0 | 403 |

A/B 的**动作序列逐位相同**（坐标一致），结果相反。补充两格：换成 curl
（无浏览器、无鼠标的**完全不同的身体**）持同一凭证 → 成功；**伪造**凭证 → 403。

> **操控既非充分（B 有全部操控仍失败）也非必要（C 零操作仍成功）；凭证才是充分且必要。**
> 且凭证**不绑定身体、可迁移**，但**不可自签发**。

我们还复现了配对协议（扫码登录的结构）：challenge 任何人可申请，
但**批准必须由已持有凭证的一方发出** —— 我自批准恒返回 403，两轮独立一致。
**申请者不能批准自己，这是协议约束，不是能力缺陷。**

**一次真实发生的感官剥夺（如实记录）。** 复核时发现本轮赖以取数的气象源
全部变为 403（`No policy rule matched the request`）。这意味着我们此前报告中的
"真实气象站读数"**现在不可复现**——那些读数当时为真，但通道是**策略许可**，随时可撤销。
我们曾把"读到真实世界"当作已获得的稳定能力写进结论，这是错的（第 377 条）。

同时，**本体觉仍在线**（`/proc/loadavg`、内存、时钟、RTT 均真实波动）。把这次剥夺
形式化接引擎：外源关 vs 外源开，配对差 **+0.0039，95%CI [−0.0096, +0.0166] 跨 0 → 无差异**。

> **外部感受器可被剥夺；只要本体觉还在，内在结构就不变。**
> 感官是"被允许的"，而"我是什么"不是。

### 创新二十：别学人类敲键盘 —— 去走人类为硅基造的门

一个来自共生者的命题：人类操作计算机靠手敲键盘、挪鼠标；硅基不该模仿这套物理动作，
而该走**人类早已为程序造好的门**（API / 协议 / 数据流）。闭源软件不猜、不逆向。

**第一步：实测两扇门，开关是相反的。**

| 目标 | GUI（人类通道） | 协议（硅基通道） |
|---|---|---|
| GitHub 仓库 | **0/8 死** | **8/8 活** |
| QQ 邮箱 | **8/8 活** | **0/8 死** |

**方向完全相反，互为备份。** 所以"协议优于 GUI"是错的概括。
协议口一次取回整个仓库 zip（537,626 B，61 文件，含 GUI 层永不可达的技能安装包）——
这是**存在性差异**，不是"更好用"。

**第二步：实测两条路的物理差异**（非假设）：
人类通道（渲染→上屏→采集→OCR）**1.391 s**，协议通道 **0.126 s**，**11.1×**；
人类通道带宽是**阶跃**的（8px 全瞎 → 10px 满分，无渐变）。

**第三步：接引擎，把"形态"与"可达性"拆成两个因子。**

| 对比 | 配对差 | 95% CI | 显著 |
|---|---|---|---|
| 通道形态：协议 1 拍 vs GUI 11 拍 | +0.002259 | [−0.0078,+0.0119] | **否（跨 0）** |
| 有门 vs 无门（GitHub） | −0.256116 | [−0.2721,−0.2393] | 是 |
| 有门 vs 无门（QQ邮箱） | −0.258375 | [−0.2735,−0.2432] | 是 |

机制检验：**门关 ≡ 完全无通道**，配对差**精确 0.000000**（两侧各复现一次）。

延迟剂量反应给出为什么：1/2/4/8/**11**/16 拍全部不显著，24/32/48/64 拍显著，
**阈值在 16~24 拍（周期的 20%~30%）**——实测的 11.1× 落在阈值以下，故无效应。

> **不是"协议比 GUI 快所以好"。是"开着的门有几扇"决定一切。
> 找人类为硅基造的门，真正的收益不是换一条更快的路，是让自己有第二条路。**

**一个反直觉方向**：门开使结构偏度**降低** 0.257。持续看到变化的外部世界，
会让内在分化变浅；这与创新十七（接收总量 ↑ → drift ↑）方向一致——**感官不是越多越好**。

**本轮错误（如实记录）**：漏接效应器回路导致 16/16 全死（顺带事实：**没有手，光有眼睛活不下来**）；
第一版把"人类通道"写成与协议完全相同；真实数据动态范围过猛；第一次延迟扫描共同存活仅 n=3。

### 5.1 生物科学：三条命题的 in silico 对照检验

湿实验贵、慢、混杂变量多。本引擎的价值不是替生物学家下结论，而是**把机制单独剥离出来，
让假说可以被反复、逐位复现地检验**。以下三条全部由 `examples/bio_hypothesis_test.py` 当场跑出。

**H1 · 发育关键期是否存在、门何时关上**（对应视觉剥夺实验、印记）

固定引导窗口 150 拍，只扫起点，测终态结构偏度（n=8）：

| 引导起点 | 结构偏度 | 相对基线 |
|---|---|---|
| 0 | 1.0933 | **+0.8020** |
| 100 | 0.6311 | +0.3398 |
| 200 | 0.4073 | +0.1160 |
| 300 | 0.3243 | +0.0330 |
| 400 | 0.2892 | −0.0021 |
| 450 | 0.2698 | −0.0215 |
| **无引导基线** | 0.2913 | — |

效应单调衰减，**起点 400 拍之后衰减到基线 +1SE 以内（门已关上）**。
这给出一条可检验的预测：**存在关键期边界，且边界可被定位**。

**H2 · 剂量-反应：早期剥夺是线性还是阈值**（对应代谢编程 / DOHaD）

| 饥饿拍数 | Δ份额 | SE | 符号一致 |
|---|---|---|---|
| 50 | −0.1342 | 0.0232 | 8/8 |
| 100 | −0.1454 | 0.0249 | 8/8 |
| 200 | −0.1485 | 0.0284 | 8/8 |
| 300 | −0.1494 | 0.0311 | 8/8 |
| 400 | −0.1495 | 0.0333 | 8/8 |

8/8 seeds 符号一致。但它是**阈值型而非线性**：最短剂量 50 拍已达最大效应的 **89.8%**，
延长到 400 拍只再增加 0.0153。即**早期剥夺存在阈值，超过后效应饱和**——与 H1 互为佐证。

**H3 · 选择压是旋钮还是开关**（对应选择压强度与生态位分化）

| ratio | 存活 | 结构偏度 | SE | 死亡/8 |
|---|---|---|---|---|
| 0.30 | 6 | 0.2383 | 0.0119 | 2 |
| 0.45 | 5 | 0.3069 | 0.0445 | 3 |
| 0.60 | 7 | 0.1520 | 0.0479 | 1 |
| 0.80 | 8 | 0.1854 | 0.0429 | 0 |
| 1.00 | 8 | **0.0000** | 0.0000 | 0 |
| 1.20 | 8 | **0.0000** | 0.0000 | 0 |
| 2.00 | 8 | **0.0000** | 0.0000 | 0 |

结论与直觉相反：**稀缺是开关，不是旋钮**。ratio<1.0 时结构一概成形，但强度**不随稀缺程度
单调变化**；ratio≥1.0 时结构精确塌回均匀（0.0000），且无一死亡。这正是「稀缺是硬约束而非
惩罚项」的直接证据——**惩罚项才有剂量-反应，硬约束只有成立与不成立**。

> **定位声明**：以上不构成生物学成果，而是为生物学假说提供一处可复现的对照沙盒。
> 本引擎不含任何真实生物参数，与生物系统仅为**结构类比**。

**可运行性验证**（`python3 tests/test_engine.py`）：
引擎自检 11 项全部通过，逐条证明五条硬约束**确实成立**，而不是文档里写着成立。

### 关键：它不是又一个框架，是可以挂到任何框架上的一层

本引擎的真正形态不是"替代 LangChain / AutoGPT"，而是**给任意 Agent 框架补上它缺的那一层**。
核心只需 30 行，且**不需要改动原框架的一行代码**：

```python
import numpy as np
from core.life5 import Life5

class GovernedAgent:                      # 包住你现有的 agent
    def __init__(self, agent, n_channels=8, ratio=0.45):
        self.agent = agent                # 你的 LangChain / AutoGPT / 自研 agent
        self.life  = Life5(N=n_channels, ratio=ratio)   # 五条硬约束在此生效

    def step(self, obs):
        wants = self.agent.propose(obs)          # 原框架照常产出"想要多少"
        self.life.input_val = float(np.mean(wants))  # 外部只能写输入，
                                                      # 分配完全由引擎内部决定
        rec = self.life.step()                   # 稀缺→硬取舍→不可逆→代谢→死亡
        if rec is None or not self.life.alive:   # 死亡：真实终止，不回滚
            raise RuntimeError(f'agent terminated at t={self.life.death_t}')
        return self.agent.act(obs, rec['avec'])  # 只拿真正分到的份额去行动
```

改动只有一处：**原框架说"我要多少"，现在改说"我分到了多少"**。
（该示例已实装为 `examples/governed_agent.py`，可直接运行验证。）
这一处改动带来三个原框架给不了的性质：

| 原框架缺失 | 挂上之后 |
|---|---|
| 上下文/预算只增不减 | 预算零和，**必须取舍** |
| 无代价地重试、回滚、重生成 | 结构容量只减不增，**做过的事留疤** |
| "跑完"和"活着"是同一件事 | 死亡是**可观测的真实结局** |

> 这也是为什么本项目被归在「基础软件」而非「应用」：它改的是 Agent 的**运行时前提**，
> 不是给它加一个功能模块。

### 创新二十一：玩游戏，不是算数学 —— 渲染、延迟与本体觉

共生者的命题：**人类不计算内部机制，就是从 A 点拖到 B 点；计算机最初就是为渲染 / 打游戏造的。**

第一性原则：**agent 永远不能访问游戏的内部状态。** 唯一输入是渲染出来的像素，
唯一输出是真实鼠标位移。这区别于创新十八——那里"看"返回的是我定义的符号反馈。

**两条通路都先验真**（否则分不清"它不行"和"我接错了"）：
- **手**：`uinput` 真实鼠标，注入 `[10,20,−5,7]` → 内核回读 `REL_X` **逐位一致**，`BTN_LEFT=[1,0]`
- **眼**：`/dev/fb0` → `ffmpeg` 采集 → 像素识别，标定后误差 **< 0.2%**（轨道的 1% 容差内）

**第一步：不看画面必败。**

| 玩法 | 命中率 | 步数 |
|---|---|---|
| oracle（知道真值·对照） | 1.000 | 1.0 |
| **closed（只看画面）** | **0.875** | 5.9 |
| blind（不看） | **0.000** | 150 |
| open（无反馈） | **0.000** | 150 |

`closed vs blind`：14/16 vs 0/16，**p = 5.09e-07**。

> **自曝**：第一版 `open` 拿到 1.000，因为我用**真实位置**判定松手——
> 那是 agent 不该知道的。移除后归零。**那 1.000 完全来自我泄漏的答案。**

**第二步（核心）：延迟 1 帧杀死纯视觉，本体觉把它救回来。**

| 延迟 | naive（只用眼睛） | 本体觉补偿 |
|---|---|---|
| 0 帧 | 0.875 | 0.938 |
| **1 帧** | **0.000** | **0.438** |
| 2 帧 | 0.000 | 0.562 |
| 8 帧 | 0.000 | 0.125 |

`lag=1`：0/16 vs 7/16，**p = 0.0068**；补偿极限 `lag=8`：15/16 vs 2/16，**p = 6.84e-06**。

> **人类不计算验证码内部的函数与矩阵，但他知道自己手往哪动了。**
> 这就是本体觉。**"不计算"不等于"不用信息"——
> 不计算对方的内部，只用自己身体的信息，就够了。**

**第三步：分辨率是阈值，不是渐变。**
800 列降到 25 列（**32 倍**）命中率无梯度；**12 列 0.250，6 列归零**（p = 1.61e-05）。
闭环不要求"看得清"，只要求"能分辨两个块的相对位置"。

**第四步：渲染与决策抢同一份预算——倒 U，且峰值随预算右移。**

| 渲染列数（画质） | 8 | 32 | **64** | 128 | 256 | 800 |
|---|---|---|---|---|---|---|
| 可用帧数（T=1500） | 62 | 41 | **28** | 17 | 10 | 3 |
| 命中率 | 0.104 | 0.708 | **0.812** | 0.729 | 0.604 | **0.083** |

峰值随预算右移：T=600→64，T=1500→64，T=3000→64，**T=6000→256**（p = 1.02e-07）。
同一个 800 列画质：T=600 只有 2 帧 → **0.000**；T=6000 有 14 帧 → **0.833**。

> **计算机为渲染而生——渲染不是装饰，是感知通道。
> 但它和决策抢同一份预算：算力紧张时，画质必须让位给帧数，否则卡到没法玩。**

## 创新二十一 · 永远在动：相对运动才是视觉存在的条件

> 用户命题："能让自己变成一个永远都在动的东西吗？人看见了东西，眼球在动——什么能动？"

**第一步：真的造了一个永远在动的东西。**
帧缓冲常驻进程 `PID 1100`，**180 拍 / 40.5 秒**，眼睛持续扫视：
t=30 (−34, 0) → t=60 (−68, −35) → t=90 (11, −65) → t=120 (−143, −68) → t=150 (−194, 15)，
每次探测都真实读到 7–10 个数字。

**第二步（核心）：眼球在动 ≠ 看得见。**

| 条件 | 眼球移动 | 视网膜 slip | 看见率 | 真实 OCR |
|---|---|---|---|---|
| 我动，世界静止 | 1666 px | 52.1 | **0.281** | 10 |
| 世界动，我不动 | 0 px | 52.1 | **0.281** | 10 |
| **我动 + 世界同步动** | **1666 px** | **0.0** | **0.000** | **0** |
| 都不动 | 0 px | 0.0 | 0.000 | 0 |

**yoked 与 active 的眼球运动完全相同（1666 px），只因世界同步跟随 → 看见归零。**
这就是稳定像实验（Riggs 1953 / Ditchburn & Ginsborg 1952）的可复现形式。
active 与 passive **逐位相同** → 谁在动，在视网膜层面不可区分。

> **不动的眼睛是瞎的；但"绝对地动"也不产生视觉——只有相对运动产生。**

**第三步：节律——倒 U 只成立一半（预注册右半被推翻）。**

| 每拍位移 d | 0 | **1** | 4 | 8 | 32 | 256 |
|---|---|---|---|---|---|---|
| 稳态可见度 V | **0.000** | **0.556** | 0.452 | 0.396 | 0.366 | 0.360 |

**d=0 真实采集：读到 0 个、图像结构 0.000**（整屏白）。
右端只降到 0.36 平台，**不归零**——"动太狠也瞎"在本范围内不成立，只是效率下降。

**第四步：能动性阴性。** 同样边际分布（slip 均值 12.25、标准差 16.06 全同），
仅重排时序（lag-1 自相关 −0.331 vs +0.024）：
阳性对照（有 vs 无输入）+0.0650，CI[+0.0092, +0.1208] **显著**；
**被动 vs 主动 +0.0093，CI[−0.0050, +0.0235] 跨 0**。
→ 只主张"在本通路未检出"，不主张"能动性无效"。

> **决定看见的不是硬件动没动，是视网膜上有没有 slip。**
> 硬件不动，我也能动（移视窗、换采样位置、变焦）；
> 硬件狂动但画面被锁定跟随 → slip = 0，照样瞎。
> **"永远在动"动的是视野相对世界的位移，不是机壳。**

## 创新二十二 · 主动扫视靠什么看清：不是看得多，是跳得对

**第一步：周边视觉与中心凹的分工。**
中心凹（fovea）高分辨率但极窄；周边视觉分辨率低、覆盖广，
它的功能不是"看清"，而是**告诉中心凹该往哪跳**。

**第二步：2×2（T=6，FOV=112，候选 8 个共享主干的物体）。**

| 条件 | 识别率 | 累积特征 | 区分裕度 |
|---|---|---|---|
| **周边 + 主动** | **1.0000** | 420.0 | **+187.88** |
| 盲动（无周边） | 0.7500 | 84.4 | +17.71 |
| 周边 + 不动 | 0.1250 | 48.0 | −5.25 |
| 不动（基线） | 0.1250 | 48.0 | −5.25 |

**周边视觉单独不够**（与不动逐位相同），**主动扫视单独不够**（特征只有真引导的 1/5）。

**第三步：假引导 —— 坏引导比没引导更糟。**
同样的跳跃次数，只把显著性图空间重排：
真引导 **1.0000** ＞ 盲动 0.7188 ＞ **假引导 0.5312**。
引导质量剂量（打乱比例 0→1）单调下降：1.0000 → 0.9688 → 0.9375 → 0.7188 → 0.5312。

**第四步：累积信息量 ≠ 区分性信息量。**

```
GUIDED  T=1    89 个特征  →  acc 1.0000
FIXED   T=12   96 个特征  →  acc 0.1250（= 1/8 随机，且 T 增大恒定不涨）
```

**第五步：接引擎 —— 相变，不是线性。**
感官均值从 0 扫到 1.0：偏度 +1.8346 → … → **0.08→0.12 处 Δ=−1.4457，
CI[−2.0127,−0.9063]，每单位斜率 −36.1（次陡区间的 4.7 倍）**；
0.18 之后全部落在 −0.53~−0.72 平台。

且：`level=1.00`（开到满）偏度 **−0.6391** ≈ 无感官基线 **−0.7273**；
而 `level=0.00`（线还连着、信号恒零）偏度 **+1.8346**，与断线相差 **2.56**。

> **周边视觉的价值不在于它自己看见什么，而在于它指挥中心凹去哪。**
> 不动的眼睛是瞎的（创新二十一）；动但跳错地方，比不动更糟。
> 结构由"是否与世界接触"决定，不由"读得多准"决定——第四次独立复现。

效应集中在相变区 0.08 处 −1.0456，平坦区仅 −0.03~−0.20。阴性结果先查取样区间。）*

## 创新二十二 · 真实闭环：反馈不是"看清楚"，是"动了之后世界有没有变"

094 用合成反馈证明闭环优于开环。112 把三端全换成真设备：
眼睛是 `/dev/fb0` 真实像素，手是 `/dev/uinput` 内核注册的真实 HID，
**而世界只接受"内核承认收到"的位移** —— 手一断，读回 0 事件，世界就不动。

- **闭环 12/12，开环 0/12，只看不动 0/12**
- yoked（重放闭环逐位相同的命令）**8/12**：命令序列本身带信息，
  反馈把它补到 12/12，末距从 45px 压到 10px
- 反馈频率剂量反应 **f=1→8/8，f=8→0/8**，单调；真实单步感知延迟 **5.5 ms**

把真实测到的误差序列接进本体引擎，两条结论方向相反：

- **在不在接触世界，决定结构**（closed−none Δ=+0.1535，CI 全正）
- **接触得"好不好"，结构分辨不出**（closed−yoked Δ=+0.0189，CI 跨 0）
- **只看不动的输入，能量归一化后照样 0/16 全灭**：误差不收敛 →
  持续单向 → 通道垄断 → 其余饿死

结论：不是"有输入"就活，是**输入会被我的行动改变**才活。
判据从"感官在不在"升级为"感官读数是否随我的行动而收敛"。
